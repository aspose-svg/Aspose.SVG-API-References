## IDrawingFactory.CreateInterpolationColor method

Crea un color de interpolación con el color y la posición especificados.

```csharp
public IInterpolationColor CreateInterpolationColor(Color color, float position)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| color | Color | Representa el color que se usará en la posición correspondiente del degradado. |
| position | Single | La posición, representada como un porcentaje de 0 a 1, en la que se usará el color de degradado correspondiente. |

### Valor de retorno

El [`IInterpolationColor`](../../iinterpolationcolor/) creado.

## CompositingOperator enumeration

Especifica el tipo de operación de composición que se aplicará en operaciones de enmascarado SVG.

```csharp
public enum CompositingOperator
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Add | `0` | Añade los valores de color del gráfico de origen al gráfico de destino. |
| Subtract | `1` | Resta los valores de color del gráfico de origen del gráfico de destino. |
| Intersect | `2` | Muestra solo las áreas donde se superponen tanto el gráfico de origen como el de destino. |
| Exclude | `3` | Excluye las áreas superpuestas del gráfico de origen y del gráfico de destino. |

## Observaciones

Los operadores de composición en máscaras SVG determinan cómo se combinan diferentes elementos gráficos para crear un efecto de máscara. Cada operador define un método único de mezcla o combinación de estos elementos para lograr diversos efectos de enmascarado.

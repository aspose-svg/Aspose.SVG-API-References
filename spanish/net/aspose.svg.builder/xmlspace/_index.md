## XmlSpace enumeration

Especifica cómo se maneja el espacio en blanco dentro de los elementos en documentos XML.

```csharp
public enum XmlSpace
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Default | `0` | Indica que el espacio en blanco debe manejarse de acuerdo con el comportamiento predeterminado del procesador XML, normalmente normalizando el espacio en blanco al eliminar saltos de línea y espacios adicionales. |
| Preserve | `1` | Indica que el espacio en blanco debe preservarse tal como aparece en el documento XML. Esto es útil para mantener el formato del texto donde el espacio en blanco es significativo. |

## Observaciones

El atributo 'xml:space' en XML se utiliza para controlar si el espacio en blanco dentro de los elementos debe preservarse o normalizarse. Esta enumeración ofrece opciones para establecer este comportamiento en documentos XML y SVG.

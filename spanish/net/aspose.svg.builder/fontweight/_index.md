## FontWeight enumeration

Especifica los diferentes pesos de fuentes para elementos de texto SVG.

```csharp
public enum FontWeight
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Normal | `0` | Representa el grosor de fuente normal, que es el grosor predeterminado. |
| Bold | `1` | Representa un grosor de fuente negrita, típicamente usado para énfasis. |
| Bolder | `2` | Representa un grosor de fuente que es más grueso que el grosor del elemento padre. |
| Lighter | `3` | Representa un grosor de fuente que es más ligero que el grosor del elemento padre. |
| W100 | `4` | Representa el grosor de fuente 100, el más delgado disponible. |
| W200 | `5` | Representa el grosor de fuente 200. |
| W300 | `6` | Representa el grosor de fuente 300. |
| W400 | `7` | Representa el grosor de fuente 400, equivalente a 'normal'. |
| W500 | `8` | Representa el grosor de fuente 500. |
| W600 | `9` | Representa el grosor de fuente 600. |
| W700 | `10` | Representa el grosor de fuente 700, equivalente a 'negrita'. |
| W800 | `11` | Representa el grosor de fuente 800. |
| W900 | `12` | Representa el grosor de fuente 900, el más grueso disponible. |

## SVGGElementBuilder class

Clase Builder para construir un elemento SVG 'g' (grupo). El elemento 'g' se utiliza para agrupar formas SVG juntas. Agrupar elementos permite una manipulación y estilo más fáciles de múltiples elementos como una sola unidad dentro de los gráficos SVG.

```csharp
public class SVGGElementBuilder : SVGElementBuilder<SVGGElement>, ICompositeAttributeSetter, 
    ICompositeElementBuilder
```

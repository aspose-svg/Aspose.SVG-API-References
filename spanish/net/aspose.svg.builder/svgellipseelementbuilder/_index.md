## SVGEllipseElementBuilder class

Clase Builder para construir un elemento SVG 'ellipse', que se utiliza para dibujar elipses dentro de gráficos SVG. Permite la construcción de contenido dentro del elemento 'ellipse' y proporciona métodos para establecer varios atributos específicos del elemento 'ellipse' en SVG.

```csharp
public class SVGEllipseElementBuilder : SVGElementBuilder<SVGEllipseElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IShapeAttributeSetter, IShapeContentElementBuilder
```

## FontStyle enumeration

Especifica los diferentes estilos de fuentes para elementos de texto SVG.

```csharp
public enum FontStyle
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Normal | `0` | Representa el estilo de fuente normal, sin énfasis ni inclinación. |
| Italic | `1` | Representa un estilo de fuente con apariencia cursiva, típicamente usado para énfasis. |
| Oblique | `2` | Representa un estilo de fuente con apariencia oblicua, similar a la cursiva pero con una inclinación menos pronunciada. |

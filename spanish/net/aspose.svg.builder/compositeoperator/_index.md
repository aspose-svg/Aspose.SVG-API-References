## CompositeOperator enumeration

Especifica el tipo de operación de composición que se aplicará en operaciones de composición SVG.

```csharp
public enum CompositeOperator
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Over | `0` | Coloca el gráfico de origen sobre el gráfico de destino. |
| In | `1` | Muestra el gráfico de origen donde se superpone al gráfico de destino. |
| Out | `2` | Muestra el gráfico de origen donde no se superpone al destino. |
| Atop | `3` | Muestra el gráfico de origen encima del gráfico de destino. |
| Xor | `4` | Muestra el gráfico de origen donde no se superpone al destino y viceversa. |
| Arithmetic | `5` | Permite una operación de composición aritmética personalizada. |

## Observaciones

Las operaciones de composición en SVG determinan cómo se combinan dos elementos gráficos en una sola imagen. Cada operador define un método distinto de mezclar o combinar estos elementos.

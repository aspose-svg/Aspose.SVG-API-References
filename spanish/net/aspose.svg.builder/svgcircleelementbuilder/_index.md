## SVGCircleElementBuilder class

Clase Builder para construir un elemento SVG 'circle', que se utiliza para dibujar círculos dentro de gráficos SVG. Permite la construcción de contenido dentro del elemento 'circle' y proporciona métodos para establecer varios atributos específicos del elemento 'circle' en SVG.

```csharp
public class SVGCircleElementBuilder : SVGElementBuilder<SVGCircleElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IShapeAttributeSetter, IShapeContentElementBuilder
```

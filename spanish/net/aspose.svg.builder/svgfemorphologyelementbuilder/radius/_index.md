## SVGFEMorphologyElementBuilder.Radius method

Establece el atributo 'radius' del elemento feMorphology, definiendo el radio para la operación morfológica.

```csharp
public SVGFEMorphologyElementBuilder Radius(double rx, double? ry = null)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| rx | Double | El radio a lo largo del eje x. |
| ry | Nullable`1 | Opcional. El radio a lo largo del eje y. Si no se proporciona, se usa rx para ambos ejes. |

### Valor de retorno

La instancia actual del builder.

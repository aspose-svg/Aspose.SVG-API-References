## Dash enumeration

Define el patrón de guiones y espacios utilizado para dibujar el contorno de formas (trazo) en elementos SVG.

```csharp
public enum Dash
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| None | `0` | Indica un trazo sólido sin guiones. Este es el comportamiento predeterminado cuando no se especifica 'stroke-dasharray'. |

## Observaciones

El atributo 'stroke-dasharray' en SVG se usa para crear líneas discontinuas especificando el patrón de guiones y espacios. Esta enumeración ofrece opciones para establecer este patrón.

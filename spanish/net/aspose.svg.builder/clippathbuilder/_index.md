## ClipPathBuilder class

Una clase builder para construir valores de clip-path CSS. Esta clase proporciona métodos para definir rutas de recorte usando formas básicas, referencias externas o cajas geométricas. Permite la creación de rutas de recorte complejas de manera estructurada y legible.

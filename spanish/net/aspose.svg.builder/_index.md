El espacio de nombres **Aspose.Svg.Builder** contiene clases e interfaces para crear y manipular documentos SVG (Scalable Vector Graphics) utilizando la biblioteca Aspose.SVG. Este espacio de nombres proporciona un conjunto amplio de clases builder que simplifican la creación y modificación de elementos SVG y sus atributos. Estos builders ofrecen una API fluida, haciendo que el código sea más legible y mantenible.

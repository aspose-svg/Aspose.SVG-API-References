## WhiteSpace enumeration

Especifica cómo se maneja el espacio en blanco dentro de un elemento SVG.

```csharp
public enum WhiteSpace
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Normal | `0` | El espacio en blanco se colapsa; los caracteres de nueva línea crean nuevas líneas. |
| Pre | `1` | El espacio en blanco se conserva; el texto solo se ajusta donde contiene caracteres de nueva línea. |
| NoWrap | `2` | El espacio en blanco se colapsa; el texto no se ajusta. |
| PreWrap | `3` | El espacio en blanco se conserva; el texto se ajusta donde sea necesario y en los caracteres de nueva línea. |
| BreakSpaces | `4` | El espacio en blanco se conserva; se añaden saltos de línea para llenar los cuadros de línea. |
| PreLine | `5` | El espacio en blanco se conserva; el texto se ajusta donde sea necesario, pero sin caracteres de nueva línea. |

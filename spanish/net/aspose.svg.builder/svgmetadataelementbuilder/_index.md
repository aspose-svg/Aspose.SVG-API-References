## SVGMetadataElementBuilder class

Clase Builder para construir un elemento SVG 'metadata', que se utiliza para agregar metadatos a un documento SVG. Esta clase permite la incorporación de contenido de metadatos y proporciona métodos para establecer varios atributos específicos del elemento 'metadata' en SVG.

```csharp
public class SVGMetadataElementBuilder : SVGElementBuilder<SVGMetadataElement>, 
    ICoreAttributeSetter, IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, 
    ITextContentSetter
```

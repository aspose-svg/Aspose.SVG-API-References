## MorphologyOperator enumeration

Especifica el tipo de operación morfológica que se aplicará en los filtros SVG.

```csharp
public enum MorphologyOperator
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Erode | `0` | Erosiona los gráficos, haciendo que las formas sean más pequeñas y los bordes más suaves. |
| Dilate | `1` | Dilata los gráficos, haciendo que las formas sean más grandes y los bordes más pronunciados. |

## Observaciones

Esta enumeración se utiliza en el contexto de los filtros SVG para definir el tipo de operación morfológica. Las operaciones morfológicas se usan para procesar la forma y la estructura de los elementos en una imagen, típicamente para erosionar o dilatar los gráficos.

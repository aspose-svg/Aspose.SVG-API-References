## DisplayType enumeration

Especifica el comportamiento de visualización de los elementos en documentos SVG.

```csharp
public enum DisplayType
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Inline | `0` | El elemento genera una o más cajas en línea. |
| Block | `1` | El elemento genera una caja de bloque. |
| ListItem | `2` | El elemento genera una caja de bloque para el contenido y una caja en línea de elemento de lista separada. |
| InlineBlock | `3` | El elemento genera una caja de bloque para el contenido y una caja en línea para el contenedor. |
| Table | `4` | El elemento se comporta como un elemento de tabla. |
| InlineTable | `5` | El elemento se comporta como una tabla en línea. |
| TableRowGroup | `6` | El elemento se comporta como un grupo de filas de tabla. |
| TableHeaderGroup | `7` | El elemento se comporta como un grupo de encabezado de tabla. |
| TableFooterGroup | `8` | El elemento se comporta como un grupo de pie de tabla. |
| TableRow | `9` | El elemento se comporta como una fila de tabla. |
| TableColumnGroup | `10` | El elemento se comporta como un grupo de columnas de tabla. |
| TableColumn | `11` | El elemento se comporta como una columna de tabla. |
| TableCell | `12` | El elemento se comporta como una celda de tabla. |
| TableCaption | `13` | El elemento se comporta como un título de tabla. |
| None | `14` | El elemento no genera ninguna caja y no se renderiza. No afecta al diseño. |
| Flex | `15` | El elemento se comporta como un contenedor flex. |
| InlineFlex | `16` | El elemento se comporta como un contenedor flex en línea. |
| Grid | `17` | El elemento se comporta como un contenedor de cuadrícula. |
| InlineGrid | `18` | El elemento se comporta como un contenedor de cuadrícula en línea. |

## Observaciones

La propiedad 'display' en SVG y CSS determina cómo se muestra un elemento en el diseño del documento. Esta enumeración ofrece varias opciones para establecer el tipo de visualización, influyendo en cómo se renderizan los elementos e interactúan con el diseño.

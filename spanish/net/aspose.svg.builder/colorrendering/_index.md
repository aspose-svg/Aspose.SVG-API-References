## ColorRendering enumeration

Especifica el modo de renderizado de color para un elemento SVG.

```csharp
public enum ColorRendering
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Auto | `0` | Permite al navegador o visor elegir el modo de renderizado de color, equilibrando entre velocidad y calidad. |
| OptimizeSpeed | `1` | Prioriza la velocidad de renderizado sobre la precisión del color y la calidad visual. |
| OptimizeQuality | `2` | Prioriza la precisión del color y la calidad visual sobre la velocidad de renderizado. |

## Observaciones

Esta propiedad determina cómo se renderizan los colores, especialmente al trabajar con degradados de color, patrones y renderizado de imágenes. Diferentes modos pueden afectar el rendimiento y la calidad del proceso de renderizado de color.

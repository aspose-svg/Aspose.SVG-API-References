## ColorInterpolation enumeration

Especifica el modo de interpolación de color para elementos y filtros SVG.

```csharp
public enum ColorInterpolation
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Auto | `0` | Determina automáticamente el modo de interpolación de color. |
| SRGB | `1` | Utiliza el espacio de color RGB estándar (sRGB) para la interpolación de color. |
| LinearRGB | `2` | Utiliza un espacio de color RGB lineal para la interpolación de color. |

## Observaciones

La interpolación de color en SVG afecta cómo se calculan y combinan los colores tanto en los elementos gráficos como en los efectos de filtro. Los diferentes modos pueden impactar significativamente la apariencia de las transiciones de color, los degradados y el renderizado general del color. Esta configuración es crucial para lograr el resultado visual deseado en los gráficos SVG.

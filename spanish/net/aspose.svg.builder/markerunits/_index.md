## MarkerUnits enumeration

Especifica el sistema de coordenadas para el tamaño del marcador en SVG.

```csharp
public enum MarkerUnits
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| StrokeWidth | `0` | El tamaño del marcador es relativo al ancho del trazo del camino. |
| UserSpaceOnUse | `1` | El tamaño del marcador se basa en el sistema de coordenadas del usuario, haciéndolo independiente del ancho del trazo. |

## Observaciones

Esta enumeración define el sistema de coordenadas utilizado para calcular el tamaño de los marcadores en SVG. Determina si el tamaño del marcador es relativo al ancho del trazo o se basa en el sistema de coordenadas del usuario.

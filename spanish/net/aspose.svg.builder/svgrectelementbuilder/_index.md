## SVGRectElementBuilder class

Clase Builder para construir un elemento SVG 'rect'. El elemento 'rect' se usa para crear rectángulos dentro de gráficos SVG. Esta clase proporciona métodos para establecer varios atributos específicos del elemento 'rect', incluidos los radios de las esquinas y las dimensiones.

```csharp
public class SVGRectElementBuilder : SVGElementBuilder<SVGRectElement>, IAnimationElementBuilder, 
    IDescriptiveElementBuilder, IPaintServerElementBuilder, IRectAttributeSetter, 
    IShapeAttributeSetter, IShapeContentElementBuilder
```

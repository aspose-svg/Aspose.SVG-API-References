## TransformationType enumeration

Especifica el tipo de transformación aplicada a un elemento SVG.


### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Translate | `0` | Traslada (mueve) un elemento una cierta distancia. |
| Scale | `1` | Escala un elemento hacia arriba o hacia abajo en tamaño. |
| Rotate | `2` | Rota un elemento alrededor de un punto dado. |
| SkewX | `3` | Inclina un elemento a lo largo del eje X. |
| SkewY | `4` | Inclina un elemento a lo largo del eje Y. |

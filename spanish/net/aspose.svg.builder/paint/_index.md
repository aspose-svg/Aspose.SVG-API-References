## Paint enumeration

Especifica las opciones de pintura para los atributos de relleno y trazo en los elementos SVG.

```csharp
public enum Paint
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| None | `0` | Indica que no se debe aplicar pintura. |
| ContextFill | `1` | Utiliza el color de relleno del contexto actual para pintar. |
| ContextStroke | `2` | Utiliza el color de trazo del contexto actual para pintar. |

## Observaciones

Esta enumeración define los tipos de pintura que pueden aplicarse a las propiedades de relleno y trazo de los elementos SVG. Permite colores estándar, rellenos y trazos basados en el contexto, o ninguna pintura.

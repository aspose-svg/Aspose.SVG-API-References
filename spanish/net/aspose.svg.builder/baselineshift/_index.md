## BaseLineShift enumeration

Especifica la posición vertical de un elemento respecto a su línea base en SVG.

```csharp
public enum BaseLineShift
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Sub | `0` | Alinea la línea base del elemento con la línea base de subíndice del texto del padre. |
| Super | `1` | Alinea la línea base del elemento con la línea base de superíndice del texto del padre. |
| Top | `2` | Alinea la parte superior del elemento con la parte superior del recuadro de línea. |
| Center | `3` | Centra el elemento en el recuadro de línea. |
| Bottom | `4` | Alinea la parte inferior del elemento con la parte inferior del recuadro de línea. |

## Observaciones

El atributo 'baseline-shift' en SVG se utiliza para ajustar la posición vertical de un elemento respecto a su línea base, lo que resulta particularmente útil en la renderización de texto. Esta enumeración ofrece varias opciones para desplazar la línea base y lograr diferentes efectos de texto.

## MaskBuilder class

Una clase builder para crear propiedades de máscara CSS. Esta clase permite la construcción de estilos de máscara complejos utilizando diversas propiedades como origen de la máscara, posición, tamaño, estilo de repetición y más. La cadena resultante puede usarse en CSS para definir el comportamiento de enmascarado de un elemento.

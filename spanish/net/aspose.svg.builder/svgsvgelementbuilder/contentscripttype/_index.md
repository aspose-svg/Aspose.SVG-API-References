Establece el atributo 'contentScriptType' del elemento SVG. Este atributo especifica el lenguaje de secuencias de comandos predeterminado para el contenido del documento SVG.

```csharp
public SVGSVGElementBuilder ContentScriptType(string value)
```

| Parámetro | Tipo | Descripción |

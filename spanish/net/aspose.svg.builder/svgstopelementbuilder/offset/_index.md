## SVGStopElementBuilder.Offset method

Establece el atributo 'offset' del elemento SVG 'stop', especificando la posición del punto de color dentro del degradado.

```csharp
public SVGStopElementBuilder Offset(double value, StopUnitType unitType = StopUnitType.Number)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| value | Double | El valor de desplazamiento de la parada de color (de 0 a 1 para números, de 0 % a 100 % para porcentajes). |
| unitType | StopUnitType | El tipo de unidad del valor de desplazamiento (número o porcentaje). |

### Valor de retorno

La instancia actual de SVGStopElementBuilder para encadenamiento de métodos.

## TimingValueBuilder.AddSyncbase method

Agrega un valor de temporización syncbase, que se sincroniza con la temporización de otro elemento.

```csharp
public TimingValueBuilder AddSyncbase(string id, string timing, TimeSpan? offset = default)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| id | String | El ID del elemento con el que sincronizar. |
| timing | String | El atributo timing al que sincronizar (p.ej., "start", "end"). |
| offset | Nullable`1 | Desplazamiento opcional desde la temporización syncbase. |

### Valor de retorno

La instancia actual de TimingValueBuilder para encadenamiento.

## UnicodeBidi enumeration

Especifica el manejo del texto bidireccional en SVG.

```csharp
public enum UnicodeBidi
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Normal | `0` | Manejo normal de texto bidireccional. |
| Embed | `1` | Incrusta una sección de texto con una direccionalidad diferente o explícita. |
| Isolate | `2` | Aísla una sección de texto de su entorno para el manejo de texto bidireccional. |
| BidiOverride | `3` | Sobrescribe la direccionalidad inherente de los caracteres en una sección de texto. |
| IsolateOverride | `4` | Aísla una sección de texto y sobrescribe su direccionalidad. |
| Plaintext | `5` | Trata la sección de texto como texto plano sin manejo bidireccional especial. |

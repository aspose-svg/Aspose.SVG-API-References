## Kerning enumeration

Especifica el comportamiento del interletraje para el texto en SVG.

```csharp
public enum Kerning
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Auto | `0` | Permite al navegador determinar si se debe aplicar kerning. |
| Normal | `1` | Aplica el kerning estándar, según lo definido en el archivo de fuente. |
| None | `2` | Desactiva el kerning, ignorando cualquier información de kerning en la fuente. |

## Observaciones

La propiedad 'font-kerning' en SVG controla el uso de la información de kerning almacenada en una fuente. El kerning ajusta el espacio entre pares de letras individuales para mejorar la apariencia visual del texto. Este enum proporciona opciones para controlar el comportamiento del kerning en los elementos de texto SVG.

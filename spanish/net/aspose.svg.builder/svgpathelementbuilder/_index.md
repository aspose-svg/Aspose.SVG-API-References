## SVGPathElementBuilder class

Clase Builder para construir un elemento SVG 'path', que se utiliza para definir una ruta en un documento SVG. Esta clase proporciona métodos para establecer varios atributos específicos del elemento 'path' y para construir su contenido.

```csharp
public class SVGPathElementBuilder : SVGElementBuilder<SVGPathElement>, IAnimationElementBuilder, 
    IDescriptiveElementBuilder, IPaintServerElementBuilder, IShapeAttributeSetter, 
    IShapeContentElementBuilder
```

## Overflow enumeration

Especifica el comportamiento de desbordamiento para los elementos SVG.

```csharp
public enum Overflow
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Visible | `0` | El contenido que excede los límites del elemento es visible. |
| Hidden | `1` | El contenido que excede los límites del elemento se recorta y no es visible. |
| Scroll | `2` | Proporciona barras de desplazamiento para el contenido que excede los límites del elemento. |

## Observaciones

Esta enumeración controla cómo se muestra el contenido que excede los límites de un elemento SVG. Determina si el contenido excedente es visible, recortado o se le proporcionan barras de desplazamiento.

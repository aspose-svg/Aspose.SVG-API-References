## FontStretch enumeration

Especifica los diferentes niveles de estiramiento de fuente para elementos de texto SVG.

```csharp
public enum FontStretch
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Normal | `0` | Representa el estiramiento de fuente normal (por defecto). |
| UltraCondensed | `1` | Representa el estiramiento de fuente más condensado. |
| ExtraCondensed | `2` | Representa un estiramiento de fuente más condensado que 'condensed' pero menos que 'ultra-condensed'. |
| Condensed | `3` | Representa un estiramiento de fuente condensado. |
| SemiCondensed | `4` | Representa un estiramiento de fuente ligeramente condensado. |
| SemiExpanded | `5` | Representa un estiramiento de fuente ligeramente expandido. |
| Expanded | `6` | Representa un estiramiento de fuente expandido. |
| ExtraExpanded | `7` | Representa una expansión de fuente más amplia que 'expanded' pero menos que 'ultra-expanded'. |
| UltraExpanded | `8` | Representa la mayor expansión de fuente. |

## LengthType enumeration

Especifica las unidades de medida para longitudes en SVG.

```csharp
public enum LengthType
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Number | `1` | Representa un valor numérico sin ninguna unidad. A menudo se interpreta en el contexto de otros valores o unidades predeterminadas. |
| Percentage | `2` | Representa un valor porcentual, relativo a otro valor o a una dimensión de contorno. |
| Ems | `3` | Representa una longitud en 'ems', una unidad escalable que es relativa al tamaño de fuente actual. |
| Exs | `4` | Representa una longitud en 'exs', relacionada con la altura x de la fuente actual. |
| Px | `5` | Representa una longitud en píxeles, una unidad de medida basada en la representación digital de una imagen. |
| Cm | `6` | Representa una longitud en centímetros. |
| Mm | `7` | Representa una longitud en milímetros. |
| In | `8` | Representa una longitud en pulgadas. |
| Pt | `9` | Representa una longitud en puntos, una unidad tradicional en tipografía. 1 punto equivale aproximadamente a 1/72 de pulgada. |
| Pc | `10` | Representa una longitud en picas, una unidad tipográfica de medida. 1 pica equivale a 12 puntos. |

## Observaciones

Esta enumeración define varias unidades que pueden usarse para especificar longitudes en elementos SVG. Estas unidades incluyen medidas absolutas como píxeles y centímetros, así como medidas relativas como porcentajes y ems.

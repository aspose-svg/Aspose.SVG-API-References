## PaintOrder enumeration

Especifica el orden en que se aplican el relleno, el trazo y los marcadores a los elementos SVG.

```csharp
public enum PaintOrder
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Normal | `0` | El orden de pintura predeterminado: primero el relleno, luego el trazo y, finalmente, los marcadores. |
| Fill | `1` | Pintar solo el relleno. |
| Stroke | `2` | Pintar solo el trazo. |
| Markers | `3` | Pintar solo los marcadores. |
| FillStroke | `4` | Pintar en el orden de relleno, luego trazo. |
| FillMarkers | `5` | Pintar en el orden de relleno, luego marcadores. |
| StrokeFill | `6` | Pintar en el orden de trazo, luego relleno. |
| StrokeMarkers | `7` | Pintar en el orden de trazo, luego marcadores. |
| MarkersFill | `8` | Pintar en el orden de marcadores, luego relleno. |
| MarkersStroke | `9` | Pintar en el orden de marcadores, luego trazo. |
| FillStrokeMarkers | `10` | Pintar en el orden de relleno, luego trazo y, finalmente, marcadores. |
| FillMarkersStroke | `11` | Pintar en el orden de relleno, luego marcadores y, finalmente, trazo. |
| StrokeFillMarkers | `12` | Pintar en el orden de trazo, luego relleno y, finalmente, marcadores. |
| StrokeMarkersFill | `13` | Pintar en el orden de trazo, luego marcadores y, finalmente, relleno. |

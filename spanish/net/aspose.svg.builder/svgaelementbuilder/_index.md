## SVGAElementBuilder class

Clase builder para construir un elemento SVG 'a', que se usa para definir hipervínculos. Permite crear contenido dentro del elemento 'a' y proporciona métodos para establecer varios atributos específicos del elemento 'a' en SVG.

```csharp
public class SVGAElementBuilder : SVGElementBuilder<SVGAElement>, ICompositeAttributeSetter, 
    ICompositeElementBuilder
```

## SVGForeignObjectElementBuilder class

Clase Builder para construir un elemento SVG 'foreignObject', que permite la inclusión de contenido externo en un documento SVG. Este elemento puede contener varios tipos de contenido, como HTML y XHTML, habilitando representaciones gráficas más complejas dentro de SVG.

```csharp
public class SVGForeignObjectElementBuilder : SVGElementBuilder<SVGForeignObjectElement>, 
    ICompositeAttributeSetter, IRectAttributeSetter, ITextContentSetter
```

## AspectRatioAlign enumeration

Especifica los tipos de alineación para el atributo 'preserveAspectRatio' en SVG.

```csharp
public enum AspectRatioAlign
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| None | `0` | Indica que no se aplica un escalado uniforme; la relación de aspecto no se conserva. |
| XMinYMin | `1` | Alinea el X mínimo y el Y mínimo del viewBox con los valores X y Y más pequeños del viewport. |
| XMidYMin | `2` | Alinea el X medio y el Y mínimo del viewBox con el X medio y el valor Y más pequeño del viewport. |
| XMaxYMin | `3` | Alinea el X máximo y el Y mínimo del viewBox con el X más grande y el valor Y más pequeño del viewport. |
| XMinYMid | `4` | Alinea el X mínimo y el Y medio del viewBox con el X más pequeño y el valor Y medio del viewport. |
| XMidYMid | `5` | Alinea el X medio y el Y medio del viewBox con el X medio y el Y medio del viewport. |
| XMaxYMid | `6` | Alinea el X máximo y el Y medio del viewBox con el X más grande y el valor Y medio del viewport. |
| XMinYMax | `7` | Alinea el X mínimo y el Y máximo del viewBox con el X más pequeño y el valor Y más grande del viewport. |
| XMidYMax | `8` | Alinea el X medio y el Y máximo del viewBox con el X medio y el valor Y más grande del viewport. |
| XMaxYMax | `9` | Alinea el X máximo y el Y máximo del viewBox con los valores X y Y más grandes del viewport. |

## ColorMatrixOperation enumeration

Especifica el tipo de operación que se aplicará en un filtro de matriz de color.

```csharp
public enum ColorMatrixOperation
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Matrix | `0` | Aplica una transformación matricial a los datos de color. |
| Saturate | `1` | Ajusta el nivel de saturación de la imagen. |
| HueRotate | `2` | Aplica una rotación de tono en la imagen. |
| LuminanceToAlpha | `3` | Convierte los colores de la imagen a escala de grises según su luminancia. |

## Observaciones

El filtro de matriz de color en SVG permite diversas operaciones sobre los datos de color de una imagen. Cada tipo de operación manipula los colores de una manera específica, ofreciendo una variedad de efectos visuales.

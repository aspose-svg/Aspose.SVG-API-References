## Cursor enumeration

Define los tipos de cursor para elementos SVG, permitiendo la personalización de la apariencia del cursor al pasar el ratón sobre estos elementos.

```csharp
public enum Cursor
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Auto | `0` | El navegador determina el cursor a mostrar según el contexto actual. |
| Default | `1` | Cursor predeterminado, típicamente una flecha. |
| None | `2` | No se muestra ningún cursor. |
| ContextMenu | `3` | Cursor que indica que hay un menú contextual disponible. |
| Help | `4` | Cursor que indica que hay información de ayuda disponible. |
| Pointer | `5` | Cursor que indica un elemento clicable, típicamente un puntero en forma de mano. |
| Progress | `6` | Cursor que indica una operación o tarea en curso. |
| Wait | `7` | Cursor que indica que el sistema está ocupado y el usuario debe esperar. |
| Cell | `8` | Cursor que indica un elemento de celda o tabla. |
| Crosshair | `9` | Cursor que indica una selección de precisión, típicamente una cruz. |
| Text | `10` | Cursor que indica selección de texto. |
| VerticalText | `11` | Cursor que indica selección de texto vertical. |
| Alias | `12` | Cursor que indica que se está creando un alias o acceso directo. |
| Copy | `13` | Cursor que indica una operación de copia. |
| Move | `14` | Cursor que indica un elemento o área movible. |
| NoDrop | `15` | Cursor que indica que soltar no está permitido. |
| NotAllowed | `16` | Cursor que indica que una acción no está permitida. |
| Grab | `17` | Cursor que indica que un elemento puede ser agarrado. |
| Grabbing | `18` | Cursor que indica que un elemento está siendo agarrado. |
| EResize | `19` | Cursor que indica redimensionamiento hacia el este. |
| NResize | `20` | Cursor que indica redimensionamiento hacia el norte. |
| NEResize | `21` | Cursor que indica redimensionamiento hacia el noreste. |
| NWResize | `22` | Cursor que indica redimensionamiento hacia el noroeste. |
| SResize | `23` | Cursor que indica redimensionamiento hacia el sur. |
| SEResize | `24` | Cursor que indica redimensionamiento hacia el sureste. |
| SWResize | `25` | Cursor que indica redimensionamiento hacia el suroeste. |
| WResize | `26` | Cursor que indica redimensionamiento hacia el oeste. |
| EWResize | `27` | Cursor que indica redimensionamiento este-oeste. |
| NSResize | `28` | Cursor que indica redimensionamiento norte-sur. |
| NESWResize | `29` | Cursor que indica redimensionamiento noreste-suroeste. |
| NWSeResize | `30` | Cursor que indica redimensionamiento noroeste-sureste. |
| ColResize | `31` | Cursor que indica redimensionamiento de columna. |
| RowResize | `32` | Cursor que indica redimensionamiento de fila. |
| AllScroll | `33` | Cursor que indica desplazamiento en todas las direcciones. |
| ZoomIn | `34` | Cursor que indica capacidad de acercar. |
| ZoomOut | `35` | Cursor que indica capacidad de alejar. |

## Observaciones

Esta enumeración proporciona una variedad de estilos de cursor que pueden aplicarse a elementos SVG. Estos estilos ayudan a indicar el tipo de interacción disponible o el estado del elemento bajo el cursor.

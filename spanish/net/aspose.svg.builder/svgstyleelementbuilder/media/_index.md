## SVGStyleElementBuilder.Media method

Establece el atributo 'media' del elemento SVG 'style'. Este atributo especifica los medios para los que se destinan los estilos, permitiendo que los estilos sean condicionales según el tipo de medio.

```csharp
public SVGStyleElementBuilder Media(string mediaDescriptors)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| mediaDescriptors | String | La cadena del descriptor de medios (p.ej., "screen", "print"). |

### Valor de retorno

La instancia de SVGStyleElementBuilder para encadenamiento.

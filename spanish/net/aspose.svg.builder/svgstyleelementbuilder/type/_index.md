## SVGStyleElementBuilder.Type method

Establece el atributo 'type' del elemento SVG 'style'. Este atributo especifica el lenguaje de la hoja de estilo del contenido del elemento.

```csharp
public SVGStyleElementBuilder Type(string contentType)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| contentType | String | El tipo MIME del lenguaje de estilo (p.ej., "text/css"). |

### Valor de retorno

La instancia de SVGStyleElementBuilder para encadenamiento.

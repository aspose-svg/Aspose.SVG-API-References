## SVGStyleElementBuilder.Title method

Establece el atributo 'title' del elemento SVG 'style'. Este atributo proporciona un título descriptivo para el elemento de estilo, lo que puede ser útil para la accesibilidad y el texto de información sobre herramientas.

```csharp
public SVGStyleElementBuilder Title(string advisoryTitle)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| advisoryTitle | String | El texto del título informativo. |

### Valor de retorno

La instancia de SVGStyleElementBuilder para encadenamiento.

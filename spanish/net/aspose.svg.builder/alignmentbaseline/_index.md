## AlignmentBaseline enumeration

Especifica la línea base de alineación para texto y otro contenido en línea en SVG.

```csharp
public enum AlignmentBaseline
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Baseline | `0` | Alinea la línea base del cuadro con la línea base del cuadro padre. |
| TextBottom | `1` | Alinea la parte inferior del cuadro con la parte inferior del área de contenido del padre. |
| Middle | `2` | Alinea el medio del cuadro con el medio del área de contenido del padre. |
| Central | `3` | Alinea la línea base central del cuadro con la línea base central del cuadro padre. |
| TextTop | `4` | Alinea la parte superior del cuadro con la parte superior del área de contenido del padre. |
| Ideographic | `5` | Alinea la línea base ideográfica del cuadro con la línea base ideográfica del padre. |
| Alphabetic | `6` | Alinea la línea base alfabética del cuadro con la línea base alfabética del padre. |
| Mathematical | `7` | Alinea la línea base matemática del cuadro con la línea base matemática del padre. |

## Observaciones

La propiedad 'alignment-baseline' está definida en la especificación CSS Line Layout Module 3. SVG 2 introduce cambios en la definición de esta propiedad.

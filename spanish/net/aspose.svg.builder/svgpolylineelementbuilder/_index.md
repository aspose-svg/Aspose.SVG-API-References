## SVGPolylineElementBuilder class

Clase Builder para construir un elemento SVG 'polyline'. El elemento 'polyline' se usa para crear una serie de líneas rectas que conectan múltiples puntos en gráficos SVG. Esta clase proporciona métodos para establecer varios atributos y animar el elemento polyline.

```csharp
public class SVGPolylineElementBuilder : SVGElementBuilder<SVGPolylineElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IPointsAttributeSetter, IShapeAttributeSetter, IShapeContentElementBuilder
```

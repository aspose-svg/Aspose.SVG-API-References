## LengthAdjust enumeration

Especifica cómo se realizan los ajustes de longitud del texto en SVG.

```csharp
public enum LengthAdjust
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Spacing | `0` | Ajusta el espaciado entre caracteres para lograr la longitud deseada. |
| SpacingAndGlyphs | `1` | Ajusta tanto el espaciado como el tamaño de los glifos para lograr la longitud deseada. |

## Observaciones

El atributo 'lengthAdjust' en los elementos de texto SVG controla cómo se aplica el escalado del texto cuando este debe ajustarse a una longitud especificada.

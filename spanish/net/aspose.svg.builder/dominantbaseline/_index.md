## DominantBaseline enumeration

Especifica la línea base dominante utilizada para alinear texto.

```csharp
public enum DominantBaseline
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Auto | `0` | Determina automáticamente la línea base dominante según la fuente y/o el idioma. |
| TextBottom | `1` | Alinea el texto al fondo del cuadrado em. |
| Alphabetic | `2` | Alinea el texto en la línea base utilizada por los caracteres alfabéticos. |
| Ideographic | `3` | Alinea el texto en la línea base utilizada por los caracteres ideográficos. |
| Middle | `4` | Alinea el texto en el medio del cuadrado em. |
| Central | `5` | Alinea el texto en la línea base central del cuadrado em. |
| Mathematical | `6` | Alinea el texto en la línea base utilizada por los caracteres matemáticos. |
| Hanging | `7` | Alinea el texto en la línea base colgante, típicamente usado para tibetano u otras escrituras asiáticas. |
| TextTop | `8` | Alinea el texto a la parte superior del cuadrado em. |

## SVGLineElementBuilder class

Clase Builder para construir un elemento SVG 'line', que se utiliza para dibujar líneas rectas dentro de gráficos SVG. Esta clase permite la creación de contenido dentro del elemento 'line' y proporciona métodos para establecer varios atributos específicos del elemento 'line' en SVG.

```csharp
public class SVGLineElementBuilder : SVGElementBuilder<SVGLineElement>, IAnimationElementBuilder, 
    IDescriptiveElementBuilder, IPaintServerElementBuilder, IShapeAttributeSetter, 
    IShapeContentElementBuilder
```

## RepeatStyle enumeration

Especifica el estilo de repetición para imágenes de fondo o patrones en SVG.

```csharp
public enum RepeatStyle
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| RepeatX | `0` | La imagen o patrón se repite solo horizontalmente. |
| RepeatY | `1` | La imagen o patrón se repite solo verticalmente. |
| Repeat | `2` | La imagen o patrón se repite tanto horizontalmente como verticalmente. |
| Space | `3` | La imagen o patrón se repite tanto como sea posible sin recortar, y el espacio restante se distribuye uniformemente entre las imágenes. |
| Round | `4` | La imagen o patrón se escala para que encaje y se repita sin recortar, manteniendo su relación de aspecto. |
| NoRepeat | `5` | La imagen o patrón no se repite, y solo se dibujará una copia de la imagen. |

## EdgeMode enumeration

Especifica el modo de borde para la primitiva de filtro feConvolveMatrix en SVG.

```csharp
public enum EdgeMode
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Duplicate | `0` | La imagen de entrada se extiende a lo largo de cada uno de sus bordes según sea necesario duplicando los valores de color en el borde dado de la imagen de entrada. |
| Wrap | `1` | La imagen de entrada se envuelve conceptualmente (o se mosaica) y la convolución utiliza estos valores envueltos. Esto crea una topología toroidal para la imagen. |
| None | `2` | El modo de borde no está definido, y el efecto del filtro lo define la implementación. |

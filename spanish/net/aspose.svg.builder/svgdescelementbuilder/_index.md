## SVGDescElementBuilder class

Clase Builder para construir un elemento SVG 'desc', que se utiliza para proporcionar una descripción de los elementos contenedores SVG. Permite la construcción de contenido dentro del elemento 'desc' y proporciona métodos para establecer varios atributos específicos del elemento 'desc' en SVG.

```csharp
public class SVGDescElementBuilder : SVGElementBuilder<SVGDescElement>, ICoreAttributeSetter, 
    IDescriptiveElementBuilder, IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, 
    ITextContentSetter
```

## ClipRule enumeration

Define la regla para determinar cómo recortar rutas en gráficos SVG.

```csharp
public enum ClipRule
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| Nonzero | `0` | La regla de enrollado no cero para recortar rutas. |
| Evenodd | `1` | La regla de enrollado par-impar para recortar rutas. |

## Observaciones

La propiedad clip rule en SVG determina cómo se recortan las rutas. Es particularmente importante cuando una ruta se intersecta consigo misma o cuando se combinan múltiples rutas. La regla ayuda a decidir qué partes de la ruta están \"dentro\" y deben rellenarse (o ser visibles) y cuáles están \"fuera\" y deben recortarse (o ser invisibles).

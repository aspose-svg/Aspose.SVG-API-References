## IAttributeSetter.Attribute method

Establece o actualiza un atributo en un elemento SVG.

```csharp
public void Attribute(string name, string value)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| nombre | String | El nombre del atributo a establecer. Debe ser un nombre de atributo SVG válido. |
| value | String | El valor a asignar al atributo. El valor debe ser una representación en cadena adecuada para el atributo SVG específico. |

## Observaciones

Este método se utiliza para agregar o modificar dinámicamente atributos de elementos SVG durante el proceso de construcción. Proporciona flexibilidad al definir y personalizar elementos SVG al permitir que los atributos se establezcan según diversas condiciones o entradas.

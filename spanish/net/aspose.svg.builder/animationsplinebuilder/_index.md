## AnimationSplineBuilder class

Una clase builder para construir funciones de temporización de animación utilizando curvas Bézier cúbicas. Esta clase permite la definición de una o más curvas Bézier cúbicas, cada una especificada por dos puntos de control. La cadena resultante puede usarse en animaciones o transiciones CSS para controlar el ritmo de la animación.

## CoordinateUnits enumeration

Especifica las unidades del sistema de coordenadas para varios elementos SVG como máscaras, servidores de pintura y filtros.

```csharp
public enum CoordinateUnits
```

### Valores

| Nombre | Valor | Descripción |
| --- | --- | --- |
| UserSpaceOnUse | `0` | Utiliza el sistema de coordenadas del usuario para el elemento SVG. |
| ObjectBoundingBox | `1` | Utiliza el cuadro delimitador del objeto para el elemento SVG. |

## Observaciones

Las unidades de coordenadas determinan cómo se interpretan los valores en diferentes contextos SVG. Pueden configurarse para usar las coordenadas del espacio del usuario o ser relativas al cuadro delimitador del objeto.

## SVGBuilderExtensions.SetAttribute<TBuilder> method

Establece un atributo en el elemento SVG. Este método se utiliza para agregar o modificar un atributo del elemento SVG que se está construyendo.

```csharp
public static TBuilder SetAttribute<TBuilder>(this TBuilder builder, string name, string value)
    where TBuilder : IAttributeSetter
```

| Parámetro | Descripción |
| --- | --- |
| TBuilder | El tipo del constructor de elementos SVG. |
| constructor | El generador de elementos SVG en el que se establece el atributo. |
| nombre | El nombre del atributo a establecer. |
| value | El valor del atributo. |

### Valor de retorno

El generador de elementos SVG original para encadenamiento de métodos.

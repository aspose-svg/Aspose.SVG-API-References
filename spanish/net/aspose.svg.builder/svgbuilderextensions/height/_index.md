## SVGBuilderExtensions.Height<TBuilder> method

Establece el atributo 'height' para un elemento SVG.

```csharp
public static TBuilder Height<TBuilder>(this TBuilder builder, double value, 
    LengthType type = LengthType.Px)
    where TBuilder : ISVGElementBuilder, IHeightAttributeSetter
```

| Parámetro | Descripción |
| --- | --- |
| TBuilder | El tipo del constructor de elementos SVG. |
| constructor | La instancia del constructor. |
| value | El valor del atributo 'height'. |
| type | El tipo de medida de longitud (el valor predeterminado es píxeles). |

### Valor de retorno

La instancia del constructor para encadenamiento.

## SVGBuilderExtensions.OnMouseMove<TBuilder> method

Establece el atributo de evento 'onmousemove' para manejar eventos de movimiento del ratón en el elemento.

    where TBuilder : ISVGElementBuilder, IGlobalEventAttributeSetter

| Parámetro | Descripción |

| value | La función o script JavaScript que se ejecutará cuando el puntero del ratón se mueva dentro del elemento. |

## SVGBuilderExtensions.StopOpacity<TBuilder> method

Establece el atributo 'stop-opacity' para un elemento SVG, definiendo la opacidad en una parada de degradado.

```csharp
public static TBuilder StopOpacity<TBuilder>(this TBuilder builder, double opacity)
    where TBuilder : IAttributeSetter, IPresentationAttributeSetter
```

| Parámetro | Descripción |
| --- | --- |
| TBuilder | El tipo del constructor de elementos SVG. |
| constructor | La instancia del constructor. |
| opacity | El valor de opacidad (0.0 para totalmente transparente, 1.0 para totalmente opaco). |

### Valor de retorno

La instancia del constructor para encadenamiento.

## SVGBuilderExtensions.OnSeeking<TBuilder> method

Establece el atributo de evento 'onseeking' para manejar eventos cuando se inicia una operación de búsqueda en el medio.

```csharp
public static TBuilder OnSeeking<TBuilder>(this TBuilder builder, string value)
    where TBuilder : ISVGElementBuilder, IGlobalEventAttributeSetter
```

| Parámetro | Descripción |

| TBuilder | El tipo del constructor de elementos SVG. |
| constructor | El constructor de elementos SVG. |
| value | La función o script JavaScript que se ejecutará cuando se inicie la operación de búsqueda. |

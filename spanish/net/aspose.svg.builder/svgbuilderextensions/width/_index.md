## SVGBuilderExtensions.Width<TBuilder> method

Establece el atributo 'width' para un elemento SVG.

```csharp
public static TBuilder Width<TBuilder>(this TBuilder builder, double value, 
    LengthType type = LengthType.Px)
    where TBuilder : ISVGElementBuilder, IWidthAttributeSetter
```

| Parámetro | Descripción |
| --- | --- |
| TBuilder | El tipo del constructor de elementos SVG. |
| constructor | La instancia del constructor. |
| value | El valor del atributo 'width'. |
| type | El tipo de medida de longitud (el valor predeterminado es píxeles). |

### Valor de retorno

La instancia del constructor para encadenamiento.

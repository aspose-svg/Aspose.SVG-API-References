## SVGBuilderExtensions.FormatSvgLengths method

Formatea una matriz de valores double en una representación de cadena de longitudes SVG.

```csharp
public static string FormatSvgLengths(double[] values, LengthType type)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| valores | Double[] | La matriz de valores double que representan longitudes. |
| type | LengthType | El tipo de unidad de longitud a usar (p.ej., píxeles). |

### Valor de retorno

Una cadena formateada de longitudes SVG.

## Observaciones

Este método utilitario se usa para formatear valores de longitud para atributos SVG, añadiendo la unidad apropiada (como 'px') a cada valor.

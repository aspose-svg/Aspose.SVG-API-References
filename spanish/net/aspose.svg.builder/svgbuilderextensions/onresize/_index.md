## SVGBuilderExtensions.OnResize<TBuilder> method

Establece el atributo de evento 'onresize' para manejar eventos de redimensionamiento de la ventana o de los elementos.

```csharp
public static TBuilder OnResize<TBuilder>(this TBuilder builder, string value)
    where TBuilder : ISVGElementBuilder, ICommonEventAttributeSetter
```

| Parámetro | Descripción |
| --- | --- |
| TBuilder | El tipo del constructor de elementos SVG. |
| constructor | El constructor de elementos SVG. |
| value | La función o script JavaScript que se ejecuta cuando el elemento o la ventana se redimensiona. |

### Valor de retorno

La instancia del constructor para encadenamiento.

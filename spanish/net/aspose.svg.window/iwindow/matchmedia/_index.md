## IWindow.MatchMedia method

Devuelve un nuevo objeto MediaQueryList que puede usarse para determinar si el documento coincide con la cadena de consulta de medios, así como para monitorizar el documento y detectar cuándo coincide (o deja de coincidir) con esa consulta de medios. Ver la especificación del módulo CSSOM View: [https://www.w3.org/TR/cssom-view/#extensions-to-the-window-interface](https://www.w3.org/TR/cssom-view/#extensions-to-the-window-interface)

```csharp
public MediaQueryList MatchMedia(string query)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| query | String | La cadena que contiene una consulta de medios; vea [https://drafts.csswg.org/mediaqueries/](https://drafts.csswg.org/mediaqueries/) para más detalles. |

### Valor de retorno

Objeto MediaQueryList

## IStorage.SetItem method

Establece el valor del par identificado por la clave a value, creando un nuevo par clave/valor si previamente no existía ninguno para esa clave.

```csharp
public void SetItem(string key, string value)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| key | String | Cadena de clave del elemento. |
| value | String | Cadena de valor del elemento. |

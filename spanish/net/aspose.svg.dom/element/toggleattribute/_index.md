## ToggleAttribute(*string*) {#toggleattribute}

Si no se proporciona force, "toggles" qualifiedName, eliminándolo si está presente y añadiéndolo si no lo está. Si force es true, añade qualifiedName. Si force es false, elimina qualifiedName.

```csharp
public bool ToggleAttribute(string qualifiedName)
```

| Parámetro | Tipo | Descripción |
| --- | --- | --- |
| qualifiedName | String | El atributo QualifiedName. |

### Valor de retorno

Devuelve true si qualifiedName está presente ahora; de lo contrario, false.

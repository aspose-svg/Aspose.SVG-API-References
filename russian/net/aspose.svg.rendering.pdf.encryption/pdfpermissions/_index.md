## PdfPermissions enumeration

Это перечисление представляет разрешения пользователя для PDF.

```csharp
[Flags]
public enum PdfPermissions
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| PrintDocument | `4` | (Обработчики безопасности версии 2) Печать документа. (Обработчики безопасности версии 3 и выше) Печать документа (возможно не в самом высоком качестве, в зависимости от того, установлен ли параметр PrintingQuality). |
| ModifyContent | `8` | Изменять содержимое документа операциями, отличными от контролируемых ModifyTextAnnotations, FillForm и 11. |
| ExtractContent | `10` | (Обработчики безопасности версии 2) Копировать или иным способом извлекать текст и графику из документа, включая их извлечение (в поддержку доступности для пользователей с ограниченными возможностями или для других целей). (Обработчики безопасности версии 3 и выше) Копировать или иным способом извлекать текст и графику из документа операциями, отличными от контролируемых ExtractContentWithDisabilities. |
| ModifyTextAnnotations | `20` | Добавлять или изменять текстовые аннотации, заполнять интерактивные поля форм, и, если установлен ModifyContent, создавать или изменять интерактивные поля форм (включая поля подписи). |
| FillForm | `100` | (Обработчики безопасности версии 3 и выше) Заполнять существующие интерактивные поля форм (включая поля подписи), даже если флаг ModifyTextAnnotations не установлен. |
| ExtractContentWithDisabilities | `200` | (Обработчики безопасности версии 3 и выше) Извлекать текст и графику (в поддержку доступности для пользователей с ограниченными возможностями или для других целей). |
| AssembleDocument | `400` | (Обработчики безопасности версии 3 и выше) Собирать документ (вставлять, вращать или удалять страницы и создавать закладки или миниатюры), даже если флаг ModifyContent не установлен. |
| PrintingQuality | `800` | (Обработчики безопасности версии 3 и выше) Печатать документ в представление, из которого можно создать точную цифровую копию содержимого PDF. Когда этот бит не установлен (и установлен бит 3), печать ограничивается низкоуровневым представлением внешнего вида, возможно, с пониженным качеством. |

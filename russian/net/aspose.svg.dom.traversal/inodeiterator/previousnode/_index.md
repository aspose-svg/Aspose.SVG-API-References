## INodeIterator.PreviousNode method

Возвращает предыдущий узел в наборе и перемещает позицию NodeIterator назад в наборе.

```csharp
public Node PreviousNode()
```

### Возвращаемое значение

Предыдущий узел в наборе, по которому производится итерация, или null, если в этом наборе больше нет элементов.

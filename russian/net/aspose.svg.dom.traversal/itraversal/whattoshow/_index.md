## ITraversal.WhatToShow property

Этот атрибут определяет, какие типы узлов представлены через итератор. Доступный набор констант определён в интерфейсе NodeFilter. Узлы, не принятые whatToShow, будут пропущены, но их дочерние элементы могут всё равно учитываться. Обратите внимание, что такое пропускание имеет приоритет над фильтром, если он присутствует.

public long WhatToShow { get; }

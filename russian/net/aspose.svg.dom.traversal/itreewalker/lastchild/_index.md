## ITreeWalker.LastChild method

Перемещает TreeWalker к последнему видимому дочернему узлу текущего узла и возвращает новый узел. Если у текущего узла нет видимых дочерних элементов, возвращает null и сохраняет текущий узел.

```csharp
public Node LastChild()
```

### Возвращаемое значение

Новый узел, или null, если у текущего узла нет дочерних узлов в логическом представлении TreeWalker.

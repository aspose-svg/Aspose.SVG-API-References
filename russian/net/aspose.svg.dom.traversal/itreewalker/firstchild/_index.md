## ITreeWalker.FirstChild method

Перемещает TreeWalker к первому видимому дочернему узлу текущего узла и возвращает новый узел. Если у текущего узла нет видимых дочерних элементов, возвращает null и сохраняет текущий узел.

```csharp
public Node FirstChild()
```

### Возвращаемое значение

Новый узел, или null, если у текущего узла нет видимых дочерних узлов в логическом представлении TreeWalker.

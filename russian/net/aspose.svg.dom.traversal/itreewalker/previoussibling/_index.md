## ITreeWalker.PreviousSibling method

Перемещает TreeWalker к предыдущему соседу текущего узла и возвращает новый узел. Если у текущего узла нет видимого предыдущего соседа, возвращает null и сохраняет текущий узел.

```csharp
public Node PreviousSibling()
```

### Возвращаемое значение

Новый узел, или null, если у текущего узла нет предыдущего соседа в логическом представлении TreeWalker.

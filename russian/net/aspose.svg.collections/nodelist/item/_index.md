## NodeList indexer

Метод возвращает элемент с индексом index в коллекции. Если index больше или равен количеству узлов в списке, возвращается null.

```csharp
public abstract Node this[int index] { get; }
```

| Параметр | Описание |
| --- | --- |
| index | Индекс. |

### Возвращаемое значение

Возвращает узел.

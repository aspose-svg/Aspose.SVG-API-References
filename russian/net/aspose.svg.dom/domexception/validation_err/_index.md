## DOMException.VALIDATION_ERR field

Если вызов метода, например insertBefore или removeChild, сделает узел недействительным с точки зрения «частичной валидности», будет выброшено исключение, и операция не будет выполнена. Этот код используется в [DOM Level 3 Validation]. Обратитесь к этой спецификации для получения дополнительной информации.

```csharp
public const ushort VALIDATION_ERR;
```

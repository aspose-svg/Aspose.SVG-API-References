## Element.GetAttributeNames method

Возвращает имена атрибутов элемента в виде массива строк. Если у элемента нет атрибутов, возвращается пустой массив.

```csharp
public string[] GetAttributeNames()
```

### Возвращаемое значение

Массив строк, представляющих имена атрибутов.

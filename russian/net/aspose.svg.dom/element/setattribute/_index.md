## Element.SetAttribute method

Добавляет новый атрибут. Если атрибут с таким именем уже присутствует в элементе, его значение изменяется на значение параметра value.

```csharp
public void SetAttribute(string qualifiedName, string value)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| qualifiedName | String | Имя атрибута. |
| значение | String | Значение. |

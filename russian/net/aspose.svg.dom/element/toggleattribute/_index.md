## ToggleAttribute(*string*) {#toggleattribute}

Если параметр force не указан, "переключает" qualifiedName, удаляя его, если он присутствует, и добавляя, если отсутствует. Если force равно true, добавляет qualifiedName. Если force равно false, удаляет qualifiedName.

```csharp
public bool ToggleAttribute(string qualifiedName)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| qualifiedName | String | Атрибут QualifiedName. |

### Возвращаемое значение

Возвращает true, если qualifiedName теперь присутствует; иначе false.

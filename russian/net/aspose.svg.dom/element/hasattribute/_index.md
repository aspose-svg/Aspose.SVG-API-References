## Element.HasAttribute method

Возвращает true, если атрибут с заданным именем указан у этого элемента или имеет значение по умолчанию, иначе false.

```csharp
public bool HasAttribute(string qualifiedName)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| qualifiedName | String | Имя атрибута. |

### Возвращаемое значение

`true` если указанное имя имеет атрибут; иначе `false`.

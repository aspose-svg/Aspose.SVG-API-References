## Node.BaseURI property

Возвращает абсолютный базовый URL документа, содержащего узел.

Базовый URL используется для разрешения относительных URL, когда браузеру необходимо получить абсолютный URL, например при обработке атрибута src элемента img в HTML или атрибутов xlink:href или href в SVG.

```csharp
public virtual string BaseURI { get; }
```

### Property Value

Геттер baseURI возвращает базовый URL документа узла, сериализованный.

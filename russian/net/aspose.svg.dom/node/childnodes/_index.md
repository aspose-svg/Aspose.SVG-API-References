## Node.ChildNodes property

Возвращает живой [`NodeList`](../../../aspose.svg.collections/nodelist/) дочерних узлов данного элемента, где первому дочернему узлу присваивается индекс 0. Дочерние узлы включают элементы, текст и комментарии.

Примечание: То, что [`NodeList`](../../../aspose.svg.collections/nodelist/) является живым, означает, что его содержимое меняется каждый раз, когда добавляются или удаляются новые дочерние узлы.

```csharp
public NodeList ChildNodes { get; }
```

### Property Value

Живой [`NodeList`](../../../aspose.svg.collections/nodelist/), содержащий дочерние узлы узла.

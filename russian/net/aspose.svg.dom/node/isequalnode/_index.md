## Node.IsEqualNode method

Проверяет, равны ли два узла. Этот метод проверяет равенство узлов, а не их тождественность (т.е. являются ли два узла ссылками на один и тот же объект), что можно проверить с помощью Node.isSameNode(). Все узлы, которые тождественны, также будут равны, хотя обратное может быть неверным.

```csharp
public bool IsEqualNode(Node otherNode)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| otherNode | Node | Другой узел. |

### Возвращаемое значение

`true` если [равен узел] [указанный аргумент]; в противном случае `false`.

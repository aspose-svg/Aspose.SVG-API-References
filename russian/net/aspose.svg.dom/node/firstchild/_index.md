## Node.FirstChild property

Возвращает первого дочернего узла в дереве, или null, если у узла нет дочерних элементов.

Если узел является Document, это свойство возвращает первый узел в списке его непосредственных дочерних элементов.

```csharp
public Node FirstChild { get; }
```

### Property Value

[`Node`](../), или null, если их нет.

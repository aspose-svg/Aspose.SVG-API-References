## Node.IsSameNode method

Метод является устаревшим псевдонимом для оператора строгого равенства ===. То есть он проверяет, являются ли два узла одинаковыми (иначе говоря, ссылаются ли они на один и тот же объект).

Примечание: Нет необходимости использовать `IsSameNode`; вместо этого используйте оператор строгого равенства ===.

```csharp
public bool IsSameNode(Node otherNode)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| otherNode | Node | Узел, с которым производится проверка. |

### Возвращаемое значение

Булево значение, которое истинно, если оба узла строго равны, иначе ложно.

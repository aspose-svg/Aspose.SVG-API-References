## Node.LookupPrefix method

Ищет префикс, связанный с указанным URI пространства имён, начиная с этого узла. Объявления пространства имён по умолчанию игнорируются этим методом. См. Namespace Prefix Lookup для подробностей алгоритма, используемого этим методом.

```csharp
public string LookupPrefix(string namespaceURI)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| namespaceURI | String | URI пространства имён. |

### Возвращаемое значение

Возвращает префикс

## Node.LocalName property

Возвращает локальную часть квалифицированного имени этого узла. Для узлов любого типа, кроме [`ELEMENT_NODE`](../element_node/) и [`ATTRIBUTE_NODE`](../attribute_node/), а также узлов, созданных методом уровня DOM 1, например [`CreateElement`](../../document/createelement/), всегда возвращается null.

```csharp
public virtual string LocalName { get; }
```

### Property Value

Строка, представляющая локальную часть квалифицированного имени элемента.

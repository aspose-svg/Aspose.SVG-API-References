## Node.AppendChild method

Добавляет узел в конец списка дочерних элементов указанного родительского узла. Если переданный дочерний элемент является ссылкой на уже существующий узел в документе, `AppendChild` перемещает его из текущего положения в новое (нет необходимости удалять узел из его родительского узла перед тем, как добавить его к другому узлу).

Это означает, что узел не может находиться в двух местах документа одновременно. Поэтому, если у узла уже есть родитель, он сначала удаляется, а затем добавляется в новое положение. Метод [`CloneNode`](../clonenode/) можно использовать для создания копии узла перед его добавлением к новому родителю. Копии, созданные с помощью [`CloneNode`](../clonenode/), не синхронизируются автоматически.

```csharp
public Node AppendChild(Node node)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| node | Node | Узел, который будет добавлен к указанному родительскому узлу (обычно элементу). |

### Возвращаемое значение

Узел, который является добавленным дочерним элементом, за исключением случая, когда дочерний элемент является [`DocumentFragment`](../../documentfragment/); в этом случае возвращается пустой [`DocumentFragment`](../../documentfragment/).

### Исключения

| исключение | условие |
| --- | --- |
| DOMException | Выбрасывается, когда нарушаются ограничения дерева DOM. |

## CloneNode() {#clonenode}

Возвращает дубликат узла, для которого был вызван этот метод.

Клонирование узла копирует все его атрибуты и их значения, включая встроенные (inline) слушатели. Оно не копирует обработчики событий, добавленные с помощью [`AddEventListener`](../../../aspose.svg.dom.events/ieventtarget/addeventlistener/) или назначенные свойствам элемента (например, node.onclick = someFunction). Кроме того, для элемента HTMLCanvasElement нарисованное изображение не копируется.

```csharp
public Node CloneNode()
```

### Возвращаемое значение

Новый клонированный [`Node`](../). Клонированный узел не имеет родителя и не является частью документа, пока не будет добавлен к другому узлу, который находится в документе, с помощью [`AppendChild`](../appendchild/) или аналогичного метода.

## CloneNode(*bool*) {#clonenode_1}

Возвращает дубликат узла, для которого был вызван этот метод. Его параметр определяет, будет ли также клонировано поддерево, содержащееся в узле, или нет.

Клонирование узла копирует все его атрибуты и их значения, включая встроенные (inline) слушатели. Оно не копирует обработчики событий, добавленные с помощью [`AddEventListener`](../../../aspose.svg.dom.events/ieventtarget/addeventlistener/) или назначенные свойствам элемента (например, node.onclick = someFunction). Кроме того, для элемента HTMLCanvasElement нарисованное изображение не копируется.

```csharp
public Node CloneNode(bool deep)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| deep | Boolean | Если true, то узел и всё его поддерево, включая текст, который может находиться в дочерних узлах [`Text`](../../text/), также копируются. |

### Возвращаемое значение

Новый клонированный [`Node`](../). Клонированный узел не имеет родителя и не является частью документа, пока не будет добавлен к другому узлу, который находится в документе, с помощью [`AppendChild`](../appendchild/) или аналогичного метода.

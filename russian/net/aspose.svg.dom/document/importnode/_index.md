## Document.ImportNode method

Импортирует узел из другого документа в текущий документ, не изменяя и не удаляя исходный узел из оригинального документа; этот метод создаёт новую копию исходного узла.

```csharp
public Node ImportNode(Node importedNode, bool deep)
```

| importedNode | Node | Импортированный узел. |
| deep | Boolean | если установлено `true` [deep]. |

## Document.StrictErrorChecking property

Атрибут, указывающий, применяется ли проверка ошибок. Когда установлен в false, реализация может не проверять каждый возможный случай ошибки, обычно определённый для операций DOM, и не генерировать DOMException при операциях DOM или сообщать об ошибках при использовании Document.normalizeDocument(). В случае ошибки поведение неопределено. По умолчанию этот атрибут имеет значение true.

```csharp
public bool StrictErrorChecking { get; set; }
```

### Property Value

`true`, если включена строгая проверка ошибок; иначе `false`.

## Document.StyleSheets property

Список, содержащий все таблицы стилей, явно подключённые или встроенные в документ. Для HTML‑документов это включает внешние таблицы стилей, подключённые через элемент HTML LINK, и встроенные элементы STYLE.

```csharp
public IStyleSheetList StyleSheets { get; }
```

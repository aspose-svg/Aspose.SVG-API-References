## TypeInfo.TypeNamespace property

Получает пространство имён типа. Пространство имён типа, объявленного для связанного элемента или атрибута, или null, если элемент не имеет объявления или если информация о пространстве имён недоступна.

```csharp
public string TypeNamespace { get; }
```

### Property Value

Пространство имён типа.

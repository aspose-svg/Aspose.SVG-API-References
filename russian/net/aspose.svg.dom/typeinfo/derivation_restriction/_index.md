## TypeInfo.DERIVATION_RESTRICTION field

Если схема документа является XML Schema [XML Schema Part 1], эта константа представляет наследование посредством ограничения, если задействованы сложные типы, или ограничение, если задействованы простые типы.

```csharp
public const ulong DERIVATION_RESTRICTION;
```

Помимо стандартных средств ввода-вывода (IO) **Aspose.Svg.IO** пространство имён содержит вспомогательные классы и интерфейсы.

## Классы

| Класс | Описание |
| --- | --- |
| [FileCreateStreamProvider](./filecreatestreamprovider/) | Представляет реализацию FileStream для предоставления потоков устройствам рендеринга. |
## Интерфейсы

| Интерфейс | Описание |
| --- | --- |
| [IBlob](./iblob/) | Объект Blob представляет собой последовательность байтов и имеет атрибут size, который является общим количеством байтов в последовательности, а также атрибут type, представляющий собой строку в нижнем регистре, закодированную в ASCII, описывающую тип медиа последовательности байтов. |
| [ICreateStreamProvider](./icreatestreamprovider/) | Представляет интерфейс, который может быть реализован классами, предоставляющими потоки устройствам рендеринга. |
| [IFile](./ifile/) | Объект File — это объект Blob с атрибутом name, который является строкой; он может быть создан в веб‑приложении через конструктор или является ссылкой на последовательность байтов из файла файловой системы (ОС). |
| [IFileList](./ifilelist/) | Представляет интерфейс для списка файлов. |

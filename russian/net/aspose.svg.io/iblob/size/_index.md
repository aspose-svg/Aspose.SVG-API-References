## IBlob.Size property

Возвращает размер последовательности байтов в количестве байтов. При получении совместимые пользовательские агенты должны возвращать общее количество байтов, которое может быть прочитано объектом FileReader или FileReaderSync, или 0, если у Blob нет байтов для чтения.

```csharp
public ulong Size { get; }
```

## IBlob.Slice method

Возвращает новый объект Blob с байтами от необязательного параметра start до, но не включая, необязательного параметра end, и с атрибутом type, значение которого равно значению необязательного параметра contentType.

```csharp
public IBlob Slice(ulong start, ulong end, string contentType)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| start | UInt64 | Параметр представляет значение начальной точки среза. |
| end | UInt64 | Параметр представляет значение начальной точки среза. |
| contentType | String | Параметр представляет медиа‑тип Blob. |

### Возвращаемое значение

Возвращает новый объект Blob с байтами от необязательного параметра start до, но не включая, необязательного параметра end, и с атрибутом type, значение которого равно значению необязательного параметра contentType.

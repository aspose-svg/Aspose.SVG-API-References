## IBlob interface

Объект Blob представляет собой последовательность байтов и имеет атрибут size, который является общим количеством байтов в последовательности, а также атрибут type, представляющий собой строку в нижнем регистре, закодированную в ASCII, описывающую тип медиа последовательности байтов.

```csharp
public interface IBlob
```

## Свойства

| Имя | Описание |
| --- | --- |
| [Size](../../aspose.svg.io/iblob/size/) { get; } | Возвращает размер последовательности байтов в количестве байтов. При получении совместимые пользовательские агенты должны возвращать общее количество байтов, которое может быть прочитано объектом FileReader или FileReaderSync, или 0, если у Blob нет байтов для чтения. |
| [Type](../../aspose.svg.io/iblob/type/) { get; } | Строка в кодировке ASCII в нижнем регистре, представляющая тип медиа Blob. При получении пользовательские агенты должны возвращать тип Blob как строку в кодировке ASCII в нижнем регистре, так чтобы при преобразовании в последовательность байтов получался корректный MIME‑тип, или пустую строку — 0 байт — если тип определить невозможно. |

## IBlob.Type property

Строка в кодировке ASCII в нижнем регистре, представляющая тип медиа Blob. При получении пользовательские агенты должны возвращать тип Blob как строку в кодировке ASCII в нижнем регистре, так чтобы при преобразовании в последовательность байтов получался корректный MIME‑тип, или пустую строку — 0 байт — если тип определить невозможно.

```csharp
public string Type { get; }
```

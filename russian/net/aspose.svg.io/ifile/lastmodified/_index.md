## IFile.LastModified property

Дата последнего изменения файла. При получении, если пользовательские агенты могут предоставить эту информацию, должно возвращаться значение типа long long, установленное во время последнего изменения файла в виде количества миллисекунд, прошедших с эпохи Unix.

```csharp
public long LastModified { get; }
```

## IFile interface

Объект File — это объект Blob с атрибутом name, который является строкой; он может быть создан в веб‑приложении через конструктор или является ссылкой на последовательность байтов из файла файловой системы (ОС).

```csharp
public interface IFile : IBlob
```

| Имя | Описание |
| --- | --- |
| [LastModified](../../aspose.svg.io/ifile/lastmodified/) { get; } | Дата последнего изменения файла. При получении, если пользовательские агенты могут предоставить эту информацию, должно возвращаться значение типа long long, установленное во время последнего изменения файла в виде количества миллисекунд, прошедших с эпохи Unix. |
| [Name](../../aspose.svg.io/ifile/name/) { get; } | Имя файла. При получении должно возвращаться имя файла в виде строки. |

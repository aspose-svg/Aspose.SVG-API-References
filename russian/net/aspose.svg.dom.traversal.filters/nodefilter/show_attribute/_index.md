## NodeFilter.SHOW_ATTRIBUTE field

Показать узлы Attr. Это имеет смысл только при создании итератора или tree-walker с узлом-атрибутом в качестве корня; в этом случае атрибутный узел будет находиться в первой позиции итерации или обхода. Поскольку атрибуты никогда не являются дочерними узлами других узлов, они не появляются при обходе дерева документа.

```csharp
public const long SHOW_ATTRIBUTE;
```

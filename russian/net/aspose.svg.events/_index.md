Это пространство имён состоит из классов для интерактивности, основанной на событиях, таких как временные события и масштабирование.

## Классы

| Класс | Описание |
| --- | --- |
| [SVGZoomEvent](./svgzoomevent/) | Событие масштабирования происходит, когда пользователь инициирует действие, которое приводит к изменению масштаба текущего представления фрагмента SVG‑документа. Обработчики событий распознаются только на элементах ‘svg’. |
| [TimeEvent](./timeevent/) | Интерфейс TimeEvent предоставляет конкретную контекстную информацию, связанную со временными событиями. Различные типы событий, которые могут происходить, включают: beginEvent, endEvent и repeatEvent. |

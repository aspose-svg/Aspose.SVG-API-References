Пространство имён **Aspose.Svg.Rendering.Image** предоставляет конкретный класс устройства, а также несколько классов параметров рендеринга, отвечающих за вывод в растровые форматы: jpeg, png, bmp, gif, tiff.

## Классы

| Класс | Описание |
| --- | --- |
| [ImageDevice](./imagedevice/) | Представляет рендеринг в растровые форматы: jpeg, png, bmp, gif, tiff. |
| [ImageRenderingOptions](./imagerenderingoptions/) | Представляет параметры рендеринга для [`ImageDevice`](../aspose.svg.rendering.image/imagedevice/). Эти параметры используются для указания формата выходного изображения, сжатия, разрешения и т.д. |
| [TextOptions](./textoptions/) | Представляет параметры рендеринга текста для [`ImageDevice`](../aspose.svg.rendering.image/imagedevice/). |
## Перечисление

| Перечисление | Описание |
| --- | --- |
| [Compression](./compression/) | Указывает возможные схемы сжатия для растровых изображений в формате Tagged Image File Format (TIFF). |
| [ImageFormat](./imageformat/) | Указывает формат файла изображения. |

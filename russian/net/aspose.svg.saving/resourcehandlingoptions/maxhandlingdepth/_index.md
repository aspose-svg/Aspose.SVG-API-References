## ResourceHandlingOptions.MaxHandlingDepth property

Получает или задает максимальную глубину страниц, которые будут обрабатываться. Глубина 1 означает, что будут обрабатываться только страницы, непосредственно ссылочные из сохранённого документа. Установка этого свойства в -1 приведёт к обработке всех страниц. Значение по умолчанию — 0.

```csharp
public int MaxHandlingDepth { get; set; }
```

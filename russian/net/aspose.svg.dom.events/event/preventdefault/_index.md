## Event.PreventDefault method

Если событие отменяемо, метод `PreventDefault` используется для указания, что событие должно быть отменено, что означает, что любое действие по умолчанию, обычно выполняемое реализацией в результате события, не произойдёт.

```csharp
public void PreventDefault()
```

## Замечания

Если на любом этапе потока событий вызывается метод `PreventDefault`, событие отменяется. Любое действие по умолчанию, связанное с событием, не будет выполнено. Вызов этого метода для неотменяемого события не оказывает эффекта. После вызова `PreventDefault` он остаётся действующим до завершения распространения события. Этот метод может использоваться на любом этапе потока событий.

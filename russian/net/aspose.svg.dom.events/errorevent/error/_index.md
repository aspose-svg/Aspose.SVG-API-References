## ErrorEvent.Error property

Атрибут error должен возвращать значение, к которому он был инициализирован. При создании объекта этот атрибут должен быть инициализирован значением null. При необходимости он устанавливается в объект, представляющий ошибку (например, объект исключения в случае необработанного исключения DOM).

```csharp
public object Error { get; }
```

### Property Value

Ошибка.

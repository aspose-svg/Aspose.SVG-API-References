## ErrorEvent.ColNo property

Атрибут colno должен возвращать значение, с которым он был инициализирован. При создании объекта этот атрибут должен быть инициализирован нулём. Он представляет номер столбца, где в скрипте произошла ошибка.

```csharp
public uint ColNo { get; }
```

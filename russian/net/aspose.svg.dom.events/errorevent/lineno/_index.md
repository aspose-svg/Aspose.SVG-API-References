## ErrorEvent.LineNo property

Атрибут lineno должен возвращать значение, к которому он был инициализирован. При создании объекта этот атрибут должен быть инициализирован нулём. Он представляет номер строки, где в скрипте произошла ошибка.

```csharp
public uint LineNo { get; }
```

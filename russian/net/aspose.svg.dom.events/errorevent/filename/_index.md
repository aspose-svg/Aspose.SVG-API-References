## ErrorEvent.FileName property

Атрибут filename должен возвращать значение, к которому он был инициализирован. При создании объекта этот атрибут должен быть инициализирован пустой строкой. Он представляет абсолютный URL скрипта, в котором изначально произошла ошибка.

```csharp
public string FileName { get; }
```

### Property Value

Имя файла.

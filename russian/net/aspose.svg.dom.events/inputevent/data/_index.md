## InputEvent.Data property

Данные содержат значение символов, сгенерированных методом ввода. Это МОЖЕТ быть один отдельный символ Unicode или непустая последовательность символов Unicode [Unicode]. Символы ДОЛЖНЫ быть нормализованы в соответствии с формой нормализации Unicode NFC, определённой в [UAX15]. Этот атрибут МОЖЕТ содержать пустую строку.

```csharp
public string Data { get; }
```

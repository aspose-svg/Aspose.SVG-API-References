## KeyboardEvent.Code property

Код содержит строку, идентифицирующую физическую клавишу, которая нажата. Значение не зависит от текущей раскладки клавиатуры или состояния модификаторов, поэтому конкретная клавиша всегда будет возвращать одно и то же значение.

```csharp
public string Code { get; }
```

### Property Value

Код клавиши.

## KeyboardEvent.CtrlKey property

true, если модификатор клавиши Control (control) был активен. Неинициализированное значение этого атрибута ДОЛЖНО быть false.

```csharp
public bool CtrlKey { get; }
```

### Property Value

`true` если Control; иначе, `false`.

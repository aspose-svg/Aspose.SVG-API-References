## KeyboardEvent.DOM_KEY_LOCATION_NUMPAD field

Активация клавиши произошла на цифровой клавиатуре или с помощью виртуальной клавиши, соответствующей цифровой клавиатуре (когда существует более одного возможного расположения этой клавиши). Обратите внимание, что клавиша NumLock всегда должна кодироваться с расположением DOM_KEY_LOCATION_STANDARD.

```csharp
public const ulong DOM_KEY_LOCATION_NUMPAD;
```

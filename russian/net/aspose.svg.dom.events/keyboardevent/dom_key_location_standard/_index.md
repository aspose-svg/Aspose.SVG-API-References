## KeyboardEvent.DOM_KEY_LOCATION_STANDARD field

Активация клавиши НЕ ДОЛЖНА различаться как левая или правая версия клавиши, и (за исключением клавиши NumLock) не происходила с цифровой клавиатуры (или не происходила с виртуальной клавишей, соответствующей цифровой клавиатуре).

```csharp
public const ulong DOM_KEY_LOCATION_STANDARD;
```

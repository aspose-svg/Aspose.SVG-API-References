## KeyboardEvent.Key property

Ключ содержит значение клавиши, которая была нажата. Если значение имеет печатное представление, оно ДОЛЖНО быть непустой строкой Unicode‑символов, соответствующей алгоритму определения значения клавиши, определённому в этой спецификации. Если значение является управляющей клавишей без печатного представления, оно ДОЛЖНО быть одним из значений клавиш, определённых в наборе значений клавиш, как определяется алгоритмом определения значения клавиши. Реализации, которые не могут идентифицировать клавишу, ДОЛЖНЫ использовать значение клавиши Unidentified.

```csharp
public string Key { get; }
```

### Property Value

Значение клавиши.

## KeyboardEvent.Repeat property

true, если клавиша удерживается длительное время. Удерживание клавиши ДОЛЖНО приводить к повторению событий keydown, beforeinput, input в указанном порядке, с частотой, определяемой конфигурацией системы. Для мобильных устройств с поведением длительного нажатия первая клавиша‑событие с атрибутом repeat, равным true, ДОЛЖНА служить индикатором длительного нажатия. Длительность, в течение которой клавиша ДОЛЖНА быть удержана, чтобы началось повторение, зависит от конфигурации.

```csharp
public bool Repeat { get; }
```

### Property Value

`true`, если повтор; иначе `false`.

Пространство имён **Aspose.Svg.Drawing** содержит объекты и интерфейсы для указания измерений и единиц, а также объектов атрибутов рисования, таких как кисти, цвета и шрифты.

## Классы

| Класс | Описание |
| --- | --- |
| [Angle](./angle/) | Тип данных angle |
| [Color](./color/) | Класс Color позволяет задавать цвета в виде значений Red-Green-Blue (RGB), Hue-Saturation-Luminosity (HSL), Hue-Saturation-Value (HSV), Hue-Whiteness-Blackness (HWB), lightness-A-B (LAB), Luminance-Chroma-Hue (LCH), Cyan-Magenta-Yellow-Key (CMYK), Natural colors (NCOL) или по имени цвета. Также доступен альфа‑канал для указания прозрачности. |
| [Dimension](./dimension/) | Предоставляет базовый класс для измерений. Общий термин «dimension» относится к числу с прикреплённой к нему единицей и обозначается типом [`UnitType`](../aspose.svg.drawing/unittype/). |
| [Frequency](./frequency/) | Единица «frequency». |
| [Length](./length/) | Представляет единицу измерения длины. |
| [LengthOrAuto](./lengthorauto/) | Представляет контейнер для хранения длины или единиц 'auto'.. |
| [Margin](./margin/) | Представляет отступ страницы. |
| [Numeric](./numeric/) | Предоставляет базовый класс для числовых типов. |
| [Page](./page/) | Представляет объект страницы, используемый для конфигурации выводимой страницы. Значение по умолчанию для размера страницы — A4 (210x297 мм). |
| [Resolution](./resolution/) | Представляет единицу разрешения. |
| [Size](./size/) | Сохраняет значения, указывающие высоту и ширину. |
| [Time](./time/) | Представляет единицу времени. |
| [Unit](./unit/) | Предоставляет базовый класс для единиц измерения. |
| [UnitType](./unittype/) | Указывает единицу измерения. |

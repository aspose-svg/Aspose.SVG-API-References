## FillRule enumeration

Указывает правило заполнения, используемое при рендеринге SVG и HTML.

```csharp
public enum FillRule
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| EvenOdd | `0` | Определяет область заполнения, используя правило чётно‑нечётного чередования. Поведение соответствует System.Drawing.Drawing2D.FillMode.Alternate. |
| Nonzero | `1` | Определяет область заполнения, используя правило ненулевого суммирования. Поведение соответствует System.Drawing.Drawing2D.FillMode.Winding. |

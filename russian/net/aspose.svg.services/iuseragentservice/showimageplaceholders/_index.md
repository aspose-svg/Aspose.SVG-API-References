## IUserAgentService.ShowImagePlaceholders property

Изображения могут иметь резервный контент: контент, который следует использовать, когда внешний ресурс недоступен (например, потому что он находится в неподдерживаемом формате). Свойство `ShowImagePlaceholders` указывает, следует ли отображать резервное изображение (по умолчанию true)

```csharp
public bool ShowImagePlaceholders { get; set; }
```

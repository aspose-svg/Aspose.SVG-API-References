**Aspose.Svg.Dom.Views** namespace describes AbstractView and DocumentView interfaces according Document Object Model Views specification.

## Интерфейсы

| Интерфейс | Описание |
| --- | --- |
| [IAbstractView](./iabstractview/) | Базовый интерфейс, от которого должны наследоваться все представления. |
| [IDocumentView](./idocumentview/) | Интерфейс DocumentView реализуется объектами Document в реализациях DOM, поддерживающих DOM Views. Он предоставляет атрибут для получения представления документа по умолчанию. |

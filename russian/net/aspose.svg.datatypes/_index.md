Это пространство имён предоставляет доступ ко всем специфическим типам данных SVG.

## Классы

| Класс | Описание |
| --- | --- |
| [SVGAngle](./svgangle/) | Интерфейс SVGAngle соответствует базовому типу данных angle. |
| [SVGAnimatedAngle](./svganimatedangle/) | Используется для атрибутов базового типа данных angle, которые могут быть анимированы. |
| [SVGAnimatedBoolean](./svganimatedboolean/) | Используется для атрибутов типа boolean, которые могут быть анимированы. |
| [SVGAnimatedEnumeration](./svganimatedenumeration/) | Используется для атрибутов, значение которых должно быть константой из определённого перечисления и которые могут быть анимированы. |
| [SVGAnimatedInteger](./svganimatedinteger/) | Используется для атрибутов базового типа integer, которые могут быть анимированы. |
| [SVGAnimatedLength](./svganimatedlength/) | Используется для атрибутов базового типа length, которые могут быть анимированы. |
| [SVGAnimatedLengthList](./svganimatedlengthlist/) | Используется для атрибутов типа SVGLengthList, которые могут быть анимированы. |
| [SVGAnimatedNumber](./svganimatednumber/) | Используется для атрибутов базового типа number, которые могут быть анимированы. |
| [SVGAnimatedNumberList](./svganimatednumberlist/) | Используется для атрибутов, принимающих список чисел и которые могут быть анимированы. |
| [SVGAnimatedPreserveAspectRatio](./svganimatedpreserveaspectratio/) | Используется для атрибутов типа SVGPreserveAspectRatio, которые могут быть анимированы. |
| [SVGAnimatedRect](./svganimatedrect/) | Используется для атрибутов типа SVGRect, которые могут быть анимированы. |
| [SVGAnimatedString](./svganimatedstring/) | Используется для атрибутов типа DOMString, которые могут быть анимированы. |
| [SVGAnimatedTransformList](./svganimatedtransformlist/) | Используется для различных атрибутов, задающих набор преобразований, таких как атрибут ‘transform’, доступный для многих элементов SVG, и которые могут быть анимированы. |
| [SVGAnimatedValue<T>](./svganimatedvalue-1/) | Используется для атрибутов типов, которые могут быть анимированы. |
| [SVGLength](./svglength/) | Интерфейс SVGLength соответствует базовому типу данных length. Объект SVGLength может быть помечен как только для чтения, что означает, что попытки изменить объект приведут к выбросу исключения, как описано ниже. |
| [SVGLengthList](./svglengthlist/) | Этот интерфейс определяет список объектов SVGLength. |
| [SVGMatrix](./svgmatrix/) | Многие графические операции SVG используют 2x3 матрицы вида: [a c e] [b d f], которые при расширении до 3x3 матрицы для целей матричной арифметики становятся: [a c e] [b d f] [0 0 1] |
| [SVGNumber](./svgnumber/) | Используется для атрибутов базового типа number. |
| [SVGNumberList](./svgnumberlist/) | Этот интерфейс определяет список объектов SVGNumber. |
| [SVGPoint](./svgpoint/) | Многие интерфейсы SVG DOM ссылаются на объекты класса SVGPoint. SVGPoint представляет собой пару координат (x, y). При использовании в матричных операциях SVGPoint рассматривается как вектор вида: [x] [y] [1]. Если объект SVGRect помечен как только для чтения, попытка присвоить значение одному из его атрибутов приведёт к выбросу исключения. |
| [SVGPointList](./svgpointlist/) | Этот интерфейс определяет список объектов SVGPoint. |
| [SVGPreserveAspectRatio](./svgpreserveaspectratio/) | Интерфейс SVGPreserveAspectRatio соответствует атрибуту ‘preserveAspectRatio’, доступному для некоторых элементов SVG. |
| [SVGRect](./svgrect/) | Представляет прямоугольную геометрию. Прямоугольники определяются как состоящие из пары координат (x,y), указывающих минимальное значение X, минимальное значение Y, а также ширину и высоту, которые обычно ограничены неотрицательными значениями. |
| [SVGStringList](./svgstringlist/) | SVGStringList имеет те же атрибуты и методы, что и другие интерфейсы SVGxxxList. Реализаторы могут рассмотреть возможность использования единого базового класса для реализации различных интерфейсов SVGxxxList. |
| [SVGTransform](./svgtransform/) | SVGTransform — это интерфейс одной из компонентных трансформаций внутри SVGTransformList; таким образом, объект SVGTransform соответствует отдельной компоненте (например, 'scale(…)' или 'matrix(…)') в спецификации атрибута ‘transform’. |
| [SVGTransformList](./svgtransformlist/) | Этот интерфейс определяет список объектов SVGTransform. |
| [SVGValueType](./svgvaluetype/) | Тип SVGValueType используется для представления базового типа значения SVG. |

## SVGTransform.Angle property

Удобный атрибут для SVG_TRANSFORM_ROTATE, SVG_TRANSFORM_SKEWX и SVG_TRANSFORM_SKEWY. Он хранит указанное значение угла. Для SVG_TRANSFORM_MATRIX, SVG_TRANSFORM_TRANSLATE и SVG_TRANSFORM_SCALE угол будет равен нулю.

```csharp
public float Angle { get; }
```

### Property Value

Указанный угол.

## SVGTransform.SetMatrix method

Устанавливает тип трансформации в SVG_TRANSFORM_MATRIX, с параметром matrix, определяющим новую трансформацию. Значения из параметра matrix копируются, параметр matrix не заменяет SVGTransform::matrix.

```csharp
public void SetMatrix(SVGMatrix matrix)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| matrix | SVGMatrix | Новая матрица для преобразования. |

| исключение | условие |

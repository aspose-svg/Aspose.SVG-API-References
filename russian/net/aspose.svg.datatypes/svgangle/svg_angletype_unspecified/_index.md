## SVGAngle.SVG_ANGLETYPE_UNSPECIFIED field

Тип единицы измерения не указан (т.е. задано значение без единицы). Для углов значение без единицы рассматривается так же, как если бы были указаны градусы.

```csharp
public const ushort SVG_ANGLETYPE_UNSPECIFIED;
```

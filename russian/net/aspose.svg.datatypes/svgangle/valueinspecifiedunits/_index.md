## SVGAngle.ValueInSpecifiedUnits property

Значение угла как число с плавающей запятой, в единицах, указанных в unitType. Установка этого атрибута приведёт к автоматическому обновлению value и valueAsString, чтобы отразить эту настройку.

```csharp
public float ValueInSpecifiedUnits { get; set; }
```

### Property Value

Значение в указанных единицах.

## FontSize enumeration

Указывает предопределённые размеры шрифтов для текстовых элементов SVG.

```csharp
public enum FontSize
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| XXSmall | `0` | Представляет размер шрифта extra-extra-small. |
| XSmall | `1` | Представляет размер шрифта extra-small. |
| Small | `2` | Представляет размер шрифта small. |
| Medium | `3` | Представляет размер шрифта medium. |
| Large | `4` | Представляет размер шрифта large. |
| XLarge | `5` | Представляет размер шрифта extra-large. |
| XXLarge | `6` | Представляет размер шрифта extra-extra-large. |
| Larger | `7` | Представляет размер шрифта, больший, чем размер шрифта родительского элемента. |
| Smaller | `8` | Представляет размер шрифта, меньший, чем размер шрифта родительского элемента. |
| Inherit | `9` | Наследует размер шрифта от родительского элемента. |

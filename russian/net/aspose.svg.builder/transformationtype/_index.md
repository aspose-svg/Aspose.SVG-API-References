## TransformationType enumeration

Указывает тип трансформации, применяемой к элементу SVG.

```csharp
public enum TransformationType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Translate | `0` | Перемещает (транслирует) элемент на определённое расстояние. |
| Scale | `1` | Масштабирует элемент увеличивая или уменьшая его размер. |
| Rotate | `2` | Вращает элемент вокруг заданной точки. |
| SkewX | `3` | Искажает элемент вдоль оси X. |
| SkewY | `4` | Искажает элемент вдоль оси Y. |

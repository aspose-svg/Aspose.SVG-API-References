## AnimationSplineBuilder class

Класс‑строитель для создания функций синхронизации анимации с использованием кубических кривых Безье. Этот класс позволяет определять одну или несколько кубических кривых Безье, каждая из которых задаётся двумя контрольными точками. Полученная строка может использоваться в CSS‑анимациях или переходах для управления темпом анимации.

## LengthAdjust enumeration

Указывает, как выполняются корректировки длины текста в SVG.

```csharp
public enum LengthAdjust
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Spacing | `0` | Регулирует интервал между символами для достижения требуемой длины. |
| SpacingAndGlyphs | `1` | Регулирует как интервал, так и размер глифов для достижения требуемой длины. |

## Замечания

Атрибут 'lengthAdjust' в SVG‑элементах текста управляет тем, как применяется масштабирование текста, когда текст должен вписаться в заданную длину.

## ColorMatrixOperation enumeration

Указывает тип операции, применяемой в фильтре цветовой матрицы.

```csharp
public enum ColorMatrixOperation
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Matrix | `0` | Применяет матричное преобразование к данным цвета. |
| Saturate | `1` | Регулирует уровень насыщенности изображения. |
| HueRotate | `2` | Применяет вращение оттенка к изображению. |
| LuminanceToAlpha | `3` | Преобразует цвета изображения в градации серого на основе их яркости. |

## Замечания

Фильтр цветовой матрицы в SVG позволяет выполнять различные операции над цветовыми данными изображения. Каждый тип операции манипулирует цветами определённым способом, предоставляя широкий спектр визуальных эффектов.

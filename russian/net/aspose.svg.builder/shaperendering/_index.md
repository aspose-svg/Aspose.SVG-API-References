## ShapeRendering enumeration

Указывает режим отрисовки формы для элементов SVG.

```csharp
public enum ShapeRendering
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Auto | `0` | Браузер делает компромиссы между скоростью, плавностью и геометрической точностью при отрисовке фигур. |
| OptimizeSpeed | `1` | Браузер отдает приоритет скорости отрисовки над геометрической точностью и плавностью. Этот режим может обеспечить более быструю отрисовку, но менее точные формы. |
| CrispEdges | `2` | Браузер пытается сохранять острые края и углы. Этот режим полезен для отрисовки графики с прямыми линиями и краями. |
| GeometricPrecision | `3` | Браузер подчеркивает геометрическую точность при рендеринге за счёт скорости. Этот режим подходит для высококачественного рендеринга, где важна точная геометрия. |

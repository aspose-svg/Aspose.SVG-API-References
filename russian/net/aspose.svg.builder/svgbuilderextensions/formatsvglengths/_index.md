## SVGBuilderExtensions.FormatSvgLengths method

Форматирует массив значений double в строковое представление длин SVG.

```csharp
public static string FormatSvgLengths(double[] values, LengthType type)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| значения | Double[] | Массив значений double, представляющих длины. |
| type | LengthType | Тип единицы измерения длины, который следует использовать (например, пиксели). |

### Возвращаемое значение

Отформатированная строка SVG‑длин.

## Замечания

Этот вспомогательный метод используется для форматирования значений длины в атрибутах SVG, добавляя к каждому значению соответствующую единицу (например, 'px').

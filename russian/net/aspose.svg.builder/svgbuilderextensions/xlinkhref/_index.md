## SVGBuilderExtensions.XlinkHref<TBuilder> method

Устанавливает атрибут 'xlink:href' для элемента SVG. Этот атрибут используется для определения ссылки на ресурс.

```csharp
public static TBuilder XlinkHref<TBuilder>(this TBuilder builder, string value)
    where TBuilder : ISVGElementBuilder, IXLinkAttributeSetter
```

| Параметр | Описание |

| билдер | Экземпляр билдера. |
| значение | URI ресурса, на который следует создать ссылку. |

## SVGForeignObjectElementBuilder class

Класс‑строитель для создания элемента SVG 'foreignObject', который позволяет включать внешнее содержимое в документ SVG. Этот элемент может содержать различные типы контента, такие как HTML и XHTML, обеспечивая более сложные графические представления в SVG.

```csharp
public class SVGForeignObjectElementBuilder : SVGElementBuilder<SVGForeignObjectElement>, 
    ICompositeAttributeSetter, IRectAttributeSetter, ITextContentSetter
```

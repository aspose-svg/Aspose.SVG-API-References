## FilterInput enumeration

Указывает предопределённые входные изображения для фильтра SVG.

```csharp
public enum FilterInput
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| SourceGraphic | `0` | Относится к графическому элементу, к которому применяется фильтр. |
| SourceAlpha | `1` | Относится к альфа‑каналу графического элемента, к которому применяется фильтр. |
| BackgroundImage | `2` | Относится к фоновому изображению, которое находится непосредственно под графическим элементом, к которому применяется фильтр. |
| BackgroundAlpha | `3` | Относится к альфа-каналу фонового изображения, которое находится непосредственно под графическим элементом, к которому применяется фильтр. |
| FillPaint | `4` | Относится к заливке графического элемента, к которому применяется фильтр. |
| StrokePaint | `5` | Относится к обводке графического элемента, к которому применяется фильтр. |

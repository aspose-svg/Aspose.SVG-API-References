## MaskBuilder class

Класс‑строитель для создания свойств CSS mask. Этот класс позволяет конструировать сложные маски, используя различные свойства, такие как источник маски, позиция, размер, стиль повторения и другие. Полученная строка может использоваться в CSS для определения поведения маскирования элемента.

```csharp
public class MaskBuilder
```

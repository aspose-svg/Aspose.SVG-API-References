## Rotate enumeration

Указывает поведение вращения элементов во время анимации движения в SVG.

```csharp
public enum Rotate
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Auto | `0` | Автоматически вращает элемент в направлении пути. |
| AutoReverse | `1` | Автоматически вращает элемент в направлении пути и позволяет ему менять направление. |

## Замечания

Атрибут 'rotate' в элементе SVG 'animateMotion' управляет вращением элемента вдоль траектории движения. Это перечисление предоставляет варианты того, как элемент должен вращаться, следуя по траектории.

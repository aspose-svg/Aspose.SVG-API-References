## AnimationFill enumeration

Указывает поведение анимации до и после её выполнения.

```csharp
public enum AnimationFill
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Freeze | `0` | Анимация применит значения свойств в течение времени, когда анимация завершилась. |
| Remove | `1` | Анимация не будет применять какие-либо значения после завершения её выполнения. |

## Замечания

Атрибут 'fill' в SVG‑анимациях управляет тем, какие значения применяются анимацией за пределами времени её выполнения. Это перечисление предоставляет варианты управления этими поведениями.

## StrokeLineJoin enumeration

Указывает форму, используемую на углах путей или базовых фигур при их обводке.

```csharp
public enum StrokeLineJoin
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Miter | `0` | Для соединения сегментов пути используется острый угол. |
| MiterClip | `1` | Похоже на 'miter', но если соединение выходит за пределы, оно обрезается. |
| Round | `2` | Для соединения сегментов пути используется скруглённый угол. |
| Bevel | `3` | Для соединения сегментов пути используется фаска. |
| Arcs | `4` | Угол соединяется дугами. |

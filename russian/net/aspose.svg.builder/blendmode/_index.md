## BlendMode enumeration

Указывает режимы смешивания, доступные для комбинирования изображений или элементов в SVG.

```csharp
public enum BlendMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Normal | `0` | Отображает исходное изображение без изменений, без какого-либо смешивания. |
| Multiply | `1` | Умножает цвета исходного изображения и фона. В результате получается более тёмное изображение. |
| Screen | `2` | Осветляет тёмные части исходного изображения, оставляя светлые части без изменений. |
| Overlay | `3` | Комбинирует режимы наложения Multiply и Screen для повышения контраста. |
| Darken | `4` | Затемняет фон в зависимости от цветов исходного изображения. |
| Lighten | `5` | Осветляет фон в зависимости от цветов исходного изображения. |
| ColorDodge | `6` | Осветляет фон, отражая исходное изображение. |
| ColorBurn | `7` | Затемняет фон, отражая исходное изображение. |
| HardLight | `8` | Создаёт эффект жёсткого света на основе яркости исходного изображения. |
| SoftLight | `9` | Создаёт эффект мягкого света на основе яркости исходного изображения. |
| Difference | `10` | Выделяет различия между исходным изображением и фоном. |
| Exclusion | `11` | Создаёт эффект, похожий на Difference, но с более низким контрастом. |
| Hue | `12` | Использует оттенок исходного изображения в сочетании с яркостью и насыщенностью фона. |
| Saturation | `13` | Использует насыщенность исходного изображения в сочетании с оттенком и яркостью фона. |
| Color | `14` | Использует оттенок и насыщенность исходного изображения в сочетании с яркостью фона. |
| Luminosity | `15` | Использует яркость исходного изображения в сочетании с оттенком и насыщенностью фона. |

## Замечания

Режимы наложения в SVG используются для определения того, как два слоя смешиваются друг с другом. Это перечисление предоставляет разнообразные варианты, контролирующие, как цвета смешанных слоёв комбинируются и создают различные визуальные эффекты.

## AngleUnits enumeration

Указывает единицы измерения углов, используемых при определении ориентации маркеров в SVG.

```csharp
public enum AngleUnits
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Degrees | `0` | Указывает угол в градусах. Полный круг составляет 360 градусов. |
| Gradians | `1` | Указывает угол в градах. Полный круг составляет 400 градов. |
| Radians | `2` | Указывает угол в радианах. Полный круг примерно равен 6,283 радиан (2π радиан). |
| None | `3` | Указывает отсутствие конкретной единицы угла. Используется для настроек по умолчанию или зависящих от контекста. |

## Замечания

Атрибут 'orient' маркеров SVG может быть указан в различных единицах угла. Это перечисление предоставляет варианты установки этих единиц.

## Paint enumeration

Указывает параметры заливки для атрибутов fill и stroke в элементах SVG.

```csharp
public enum Paint
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | `0` | Указывает, что заливка не должна применяться. |
| ContextFill | `1` | Использует текущий цвет заливки контекста для рисования. |
| ContextStroke | `2` | Использует текущий цвет обводки контекста для рисования. |

## Замечания

Это перечисление определяет типы заливки, которые могут быть применены к свойствам fill и stroke SVG‑элементов. Оно позволяет использовать стандартный цвет, заливки и обводки, зависящие от контекста, либо отсутствие заливки.

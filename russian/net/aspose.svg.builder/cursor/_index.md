## Cursor enumeration

Определяет типы курсора для элементов SVG, позволяя настраивать внешний вид курсора при наведении на эти элементы.

```csharp
public enum Cursor
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Auto | `0` | Браузер определяет, какой курсор отображать, исходя из текущего контекста. |
| Default | `1` | Курсор по умолчанию, обычно стрелка. |
| None | `2` | Курсор не отображается. |
| ContextMenu | `3` | Курсор, указывающий, что доступно контекстное меню. |
| Help | `4` | Курсор, указывающий, что доступна справочная информация. |
| Pointer | `5` | Курсор, указывающий на кликабельный элемент, обычно в виде указателя‑руки. |
| Progress | `6` | Курсор, указывающий на выполняющуюся операцию или задачу. |
| Wait | `7` | Курсор, указывающий, что система занята и пользователю следует подождать. |
| Cell | `8` | Курсор, указывающий на ячейку или элемент таблицы. |
| Crosshair | `9` | Курсор, указывающий точный выбор, обычно в виде перекрестия. |
| Text | `10` | Курсор, указывающий выделение текста. |
| VerticalText | `11` | Курсор, указывающий вертикальное выделение текста. |
| Alias | `12` | Курсор, указывающий, что создаётся псевдоним или ярлык. |
| Copy | `13` | Курсор, указывающий операцию копирования. |
| Move | `14` | Курсор, указывающий перемещаемый объект или область. |
| NoDrop | `15` | Курсор, указывающий, что перемещение недоступно. |
| NotAllowed | `16` | Курсор, указывающий, что действие недоступно. |
| Grab | `17` | Курсор, указывающий, что объект можно захватить. |
| Grabbing | `18` | Курсор, указывающий, что объект в данный момент захвачен. |
| EResize | `19` | Курсор, указывающий изменение размера на восток. |
| NResize | `20` | Курсор, указывающий изменение размера на север. |
| NEResize | `21` | Курсор, указывающий изменение размера на северо-восток. |
| NWResize | `22` | Курсор, указывающий изменение размера на северо-запад. |
| SResize | `23` | Курсор, указывающий изменение размера на юг. |
| SEResize | `24` | Курсор, указывающий изменение размера на юго-восток. |
| SWResize | `25` | Курсор, указывающий изменение размера на юго-запад. |
| WResize | `26` | Курсор, указывающий изменение размера на запад. |
| EWResize | `27` | Курсор, указывающий изменение размера по горизонтали (восток‑запад). |
| NSResize | `28` | Курсор, указывающий изменение размера по вертикали (север‑юг). |
| NESWResize | `29` | Курсор, указывающий изменение размера по диагонали северо‑восток‑юго‑запад. |
| NWSeResize | `30` | Курсор, указывающий изменение размера с северо-запада на юго-восток. |
| ColResize | `31` | Курсор, указывающий изменение размера столбца. |
| RowResize | `32` | Курсор, указывающий изменение размера строки. |
| AllScroll | `33` | Курсор, указывающий прокрутку во всех направлениях. |
| ZoomIn | `34` | Курсор, указывающий возможность увеличения. |
| ZoomOut | `35` | Курсор, указывающий возможность уменьшения. |

## Замечания

Эта перечисление предоставляет набор стилей курсора, которые можно применять к элементам SVG. Эти стили помогают указывать тип доступного взаимодействия или состояние элемента под курсором.

## BaseLineShift enumeration

Указывает вертикальное положение элемента относительно его базовой линии в SVG.

```csharp
public enum BaseLineShift
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Sub | `0` | Выравнивает базовую линию элемента с базовой линией нижнего индекса текста родителя. |
| Super | `1` | Выравнивает базовую линию элемента с базовой линией верхнего индекса текста родителя. |
| Top | `2` | Выравнивает верх элемента с верхом строки. |
| Center | `3` | Центрирует элемент в строке. |
| Bottom | `4` | Выравнивает нижнюю часть элемента с нижней частью строки. |

## Замечания

Атрибут 'baseline-shift' в SVG используется для регулировки вертикального положения элемента относительно его базовой линии, что особенно полезно при отображении текста. Это перечисление предоставляет различные варианты смещения базовой линии для получения разных текстовых эффектов.

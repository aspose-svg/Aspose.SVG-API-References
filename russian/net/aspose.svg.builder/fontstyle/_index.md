## FontStyle enumeration

Указывает различные стили шрифтов для текстовых элементов SVG.

```csharp
public enum FontStyle
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Normal | `0` | Представляет обычный стиль шрифта без выделения или наклона. |
| Italic | `1` | Представляет стиль шрифта с курсивным отображением, обычно используемый для выделения. |
| Oblique | `2` | Представляет стиль шрифта с наклонным отображением, похожий на курсив, но с менее выраженным наклоном. |

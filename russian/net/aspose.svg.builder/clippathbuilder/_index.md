## ClipPathBuilder class

Класс‑строитель для создания значений CSS clip-path. Этот класс предоставляет методы для определения областей обрезки с использованием базовых фигур, внешних ссылок или геометрических коробок. Он позволяет создавать сложные пути обрезки в структурированном и читаемом виде.

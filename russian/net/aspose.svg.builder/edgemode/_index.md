## EdgeMode enumeration

Указывает режим краев для примитива фильтра feConvolveMatrix в SVG.

```csharp
public enum EdgeMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Duplicate | `0` | Входное изображение расширяется вдоль каждой из своих границ по мере необходимости, дублируя значения цвета на заданном крае изображения. |
| Wrap | `1` | Входное изображение концептуально оборачивается (или заполняется плиткой), и свёртка использует эти обёрнутые значения. Это создаёт тороидальную топологию изображения. |
| None | `2` | Режим краёв не определён, и эффект фильтра определяется реализацией. |

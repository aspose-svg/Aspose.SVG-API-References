## FontWeight enumeration

Указывает различные толщины шрифтов для текстовых элементов SVG.

```csharp
public enum FontWeight
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Normal | `0` | Представляет обычную толщину шрифта, которая является толщиной по умолчанию. |
| Bold | `1` | Представляет жирную толщину шрифта, обычно используемую для выделения. |
| Bolder | `2` | Представляет толщину шрифта, более жирную, чем у родительского элемента. |
| Lighter | `3` | Представляет толщину шрифта, более лёгкую, чем у родительского элемента. |
| W100 | `4` | Представляет толщину шрифта 100, самую тонкую доступную. |
| W200 | `5` | Представляет толщину шрифта 200. |
| W300 | `6` | Представляет толщину шрифта 300. |
| W400 | `7` | Представляет толщину шрифта 400, эквивалентную 'normal'. |
| W500 | `8` | Представляет толщину шрифта 500. |
| W600 | `9` | Представляет толщину шрифта 600. |
| W700 | `10` | Представляет толщину шрифта 700, эквивалентную 'bold'. |
| W800 | `11` | Представляет толщину шрифта 800. |
| W900 | `12` | Представляет толщину шрифта 900, самая жирная доступная. |

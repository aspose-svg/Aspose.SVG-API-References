## SVGAElementBuilder class

Класс‑строитель для создания SVG‑элемента 'a', который используется для определения гиперссылок. Он позволяет формировать содержимое внутри элемента 'a' и предоставляет методы установки различных атрибутов, специфичных для элемента 'a' в SVG.

```csharp
public class SVGAElementBuilder : SVGElementBuilder<SVGAElement>, ICompositeAttributeSetter, 
    ICompositeElementBuilder
```

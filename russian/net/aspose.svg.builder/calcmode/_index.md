## CalcMode enumeration

Указывает режимы расчёта для интерполяции значений в SVG-анимациях.

```csharp
public enum CalcMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Discrete | `0` | Анимация переходит от одного значения к другому без какой‑либо интерполяции. |
| Linear | `1` | Значения анимации интерполируются линейно в течение всей длительности анимации. |
| Paced | `2` | Анимация синхронизирована так, чтобы прогресс был равномерным на протяжении всей анимации. |
| Spline | `3` | Анимация использует кубические сплайны Безье для интерполяции значений. |

## Замечания

Режим расчёта определяет, как анимация SVG переходит между значениями в течение анимации. Разные режимы могут использоваться для создания различных эффектов и управления темпом и плавностью анимации.

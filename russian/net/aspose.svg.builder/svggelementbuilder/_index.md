## SVGGElementBuilder class

Класс‑строитель для создания элемента SVG 'g' (группа). Элемент 'g' используется для группировки фигур SVG. Группировка элементов упрощает манипулирование и стилизацию нескольких элементов как единого блока в графике SVG.

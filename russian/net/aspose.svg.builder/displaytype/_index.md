## DisplayType enumeration

Указывает поведение отображения элементов в документах SVG.

```csharp
public enum DisplayType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Inline | `0` | Элемент генерирует один или несколько встроенных блоков. |
| Block | `1` | Элемент генерирует блочный блок. |
| ListItem | `2` | Элемент генерирует блочный блок для содержимого и отдельный встроенный (inline) блок списка. |
| InlineBlock | `3` | Элемент генерирует блочный блок для содержимого и встроенный (inline) блок для контейнера. |
| Table | `4` | Элемент ведёт себя как табличный элемент. |
| InlineTable | `5` | Элемент ведёт себя как встроенная таблица. |
| TableRowGroup | `6` | Элемент ведёт себя как группа строк таблицы. |
| TableHeaderGroup | `7` | Элемент ведёт себя как группа заголовков таблицы. |
| TableFooterGroup | `8` | Элемент ведёт себя как группа подвалов таблицы. |
| TableRow | `9` | Элемент ведёт себя как строка таблицы. |
| TableColumnGroup | `10` | Элемент ведёт себя как группа столбцов таблицы. |
| TableColumn | `11` | Элемент ведёт себя как столбец таблицы. |
| TableCell | `12` | Элемент ведёт себя как ячейка таблицы. |
| TableCaption | `13` | Элемент ведёт себя как подпись таблицы. |
| None | `14` | Элемент не генерирует никаких блоков и не отображается. Он не влияет на раскладку. |
| Flex | `15` | Элемент ведёт себя как flex‑контейнер. |
| InlineFlex | `16` | Элемент ведёт себя как встроенный flex‑контейнер. |
| Grid | `17` | Элемент ведёт себя как grid‑контейнер. |
| InlineGrid | `18` | Элемент ведёт себя как встроенный grid‑контейнер. |

## Замечания

Свойство 'display' в SVG и CSS определяет, как элемент отображается в раскладке документа. Это перечисление предоставляет различные варианты установки типа отображения, влияя на то, как элементы рендерятся и взаимодействуют с раскладкой.

## SVGDescElementBuilder class

Класс‑строитель для создания SVG‑элемента 'desc', который используется для предоставления описания контейнерных элементов SVG. Он позволяет формировать содержимое внутри элемента 'desc' и предоставляет методы для установки различных атрибутов, специфичных для элемента 'desc' в SVG.

```csharp
public class SVGDescElementBuilder : SVGElementBuilder<SVGDescElement>, ICoreAttributeSetter, 
    IDescriptiveElementBuilder, IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, 
    ITextContentSetter
```

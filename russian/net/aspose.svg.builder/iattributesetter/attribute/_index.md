## IAttributeSetter.Attribute method

Устанавливает или обновляет атрибут SVG‑элемента.

```csharp
public void Attribute(string name, string value)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| name | String | Имя атрибута, который нужно установить. Это должно быть действительное имя атрибута SVG. |
| значение | String | Значение, которое следует присвоить атрибуту. Значение должно быть строковым представлением, подходящим для конкретного атрибута SVG. |

## Замечания

Этот метод используется для динамического добавления или изменения атрибутов элементов SVG во время процесса построения. Он обеспечивает гибкость в определении и настройке элементов SVG, позволяя устанавливать атрибуты в зависимости от различных условий или входных данных.

## Restart enumeration

Указывает поведение перезапуска для анимаций SVG.

```csharp
public enum Restart
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Always | `0` | Анимацию можно перезапустить в любой момент, даже если она в данный момент активна. |
| WhenNotActive | `1` | Анимацию можно перезапустить только тогда, когда она не активна. |
| Never | `2` | Анимацию нельзя перезапустить после её начала; она будет выполнена до конца. |

## WhiteSpace enumeration

Указывает, как обрабатываются пробельные символы внутри элемента SVG.

```csharp
public enum WhiteSpace
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Normal | `0` | Пробелы схлопываются; символы новой строки создают новые строки. |
| Pre | `1` | Пробелы сохраняются; текст переносится только там, где присутствуют символы новой строки. |
| NoWrap | `2` | Пробелы схлопываются; текст не переносится. |
| PreWrap | `3` | Пробелы сохраняются; текст переносится там, где это необходимо, и при символах новой строки. |
| BreakSpaces | `4` | Пробелы сохраняются; разрывы строк добавляются для заполнения строковых блоков. |
| PreLine | `5` | Пробелы сохраняются; текст переносится там, где необходимо, но без символов новой строки. |

## ColorInterpolation enumeration

Указывает режим интерполяции цвета для элементов SVG и фильтров.

```csharp
public enum ColorInterpolation
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Auto | `0` | Автоматически определяет режим интерполяции цвета. |
| SRGB | `1` | Использует стандартное цветовое пространство RGB (sRGB) для интерполяции цвета. |
| LinearRGB | `2` | Использует линейное цветовое пространство RGB для интерполяции цвета. |

## Замечания

Интерполяция цвета в SVG влияет на то, как цвета вычисляются и смешиваются как в графических элементах, так и в эффектах фильтров. Разные режимы могут существенно влиять на внешний вид переходов цветов, градиентов и общего отображения цвета. Эта настройка имеет решающее значение для достижения желаемого визуального результата в графике SVG.

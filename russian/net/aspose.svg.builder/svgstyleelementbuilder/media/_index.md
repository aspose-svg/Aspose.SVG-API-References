## SVGStyleElementBuilder.Media method

Устанавливает атрибут 'media' SVG‑элемента 'style'. Этот атрибут указывает носитель, для которого предназначены стили, позволяя делать стили условными в зависимости от типа носителя.

```csharp
public SVGStyleElementBuilder Media(string mediaDescriptors)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| mediaDescriptors | String | Строка дескриптора носителя (например, "screen", "print"). |

### Возвращаемое значение

Экземпляр SVGStyleElementBuilder для цепочечного вызова.

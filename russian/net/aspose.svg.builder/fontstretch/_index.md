## FontStretch enumeration

Указывает различные уровни растяжения шрифта для текстовых элементов SVG.

```csharp
public enum FontStretch
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Normal | `0` | Представляет обычное (по умолчанию) растяжение шрифта. |
| UltraCondensed | `1` | Представляет самое сжатое растяжение шрифта. |
| ExtraCondensed | `2` | Представляет более сжатое растяжение шрифта, чем 'condensed', но менее, чем 'ultra-condensed'. |
| Condensed | `3` | Представляет сжатое растяжение шрифта. |
| SemiCondensed | `4` | Представляет слегка сжатое растяжение шрифта. |
| SemiExpanded | `5` | Представляет слегка расширенное растяжение шрифта. |
| Expanded | `6` | Представляет расширенное растяжение шрифта. |
| ExtraExpanded | `7` | Представляет более расширенное растяжение шрифта, чем 'expanded', но менее, чем 'ultra-expanded'. |
| UltraExpanded | `8` | Представляет самое расширенное растяжение шрифта. |

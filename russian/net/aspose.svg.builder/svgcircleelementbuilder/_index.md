## SVGCircleElementBuilder class

Класс‑строитель для создания SVG‑элемента 'circle', который используется для рисования кругов в SVG‑графике. Он позволяет формировать содержимое внутри элемента 'circle' и предоставляет методы для установки различных атрибутов, специфичных для элемента 'circle' в SVG.

```csharp
public class SVGCircleElementBuilder : SVGElementBuilder<SVGCircleElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IShapeAttributeSetter, IShapeContentElementBuilder
```

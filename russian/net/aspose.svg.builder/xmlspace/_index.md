## XmlSpace enumeration

Указывает, как обрабатываются пробельные символы внутри элементов в XML‑документах.

```csharp
public enum XmlSpace
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Default | `0` | Указывает, что пробелы должны обрабатываться согласно поведению процессора XML по умолчанию, обычно нормализуя пробелы путем удаления разрывов строк и лишних пробелов. |
| Preserve | `1` | Указывает, что пробелы должны сохраняться так, как они представлены в XML‑документе. Это полезно для поддержания форматирования текста, где пробелы имеют значение. |

## Замечания

Атрибут 'xml:space' в XML используется для управления тем, должны ли пробелы внутри элементов сохраняться или нормализоваться. Эта перечисление предоставляет варианты настройки этого поведения в XML и SVG‑документах.

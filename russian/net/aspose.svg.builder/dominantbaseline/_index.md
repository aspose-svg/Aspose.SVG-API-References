## DominantBaseline enumeration

Указывает доминирующую базовую линию, используемую для выравнивания текста.

```csharp
public enum DominantBaseline
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Auto | `0` | Автоматически определяет доминирующую базовую линию на основе шрифта и/или языка. |
| TextBottom | `1` | Выравнивает текст по нижней части квадрата em. |
| Alphabetic | `2` | Выравнивает текст по базовой линии, используемой алфавитными символами. |
| Ideographic | `3` | Выравнивает текст по базовой линии, используемой идеографическими символами. |
| Middle | `4` | Выравнивает текст по середине квадрата em. |
| Central | `5` | Выравнивает текст по центральной базовой линии квадрата em. |
| Mathematical | `6` | Выравнивает текст по базовой линии, используемой математическими символами. |
| Hanging | `7` | Выравнивает текст по висячей базовой линии, обычно используемой для тибетского или других азиатских письменностей. |
| TextTop | `8` | Выравнивает текст по верхней части квадрата em. |

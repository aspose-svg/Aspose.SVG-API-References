## SVGEllipseElementBuilder class

Класс‑строитель для создания SVG‑элемента 'ellipse', который используется для рисования эллипсов в SVG‑графике. Он позволяет формировать содержимое внутри элемента 'ellipse' и предоставляет методы для установки различных атрибутов, специфичных для элемента 'ellipse' в SVG.

```csharp
public class SVGEllipseElementBuilder : SVGElementBuilder<SVGEllipseElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IShapeAttributeSetter, IShapeContentElementBuilder
```

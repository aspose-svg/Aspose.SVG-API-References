## CompositingOperator enumeration

Указывает тип операции композитинга, применяемой в операциях маскирования SVG.

```csharp
public enum CompositingOperator
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Add | `0` | Добавляет значения цвета исходного графического объекта к целевому графическому объекту. |
| Subtract | `1` | Вычитает значения цвета исходного графического объекта из целевого графического объекта. |
| Intersect | `2` | Отображает только области, где перекрываются исходный и целевой графические объекты. |
| Exclude | `3` | Исключает перекрывающиеся области исходного и целевого графических объектов. |

## Замечания

Операторы композитинга в масках SVG определяют, как различные графические элементы комбинируются для создания маски. Каждый оператор определяет уникальный метод смешивания или объединения этих элементов для достижения различных эффектов маскирования.

## TextRendering enumeration

Указывает стратегию отрисовки текста в SVG.

```csharp
public enum TextRendering
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Auto | `0` | Позволяет браузеру выбрать оптимизированный режим рендеринга текста. |
| OptimizeSpeed | `1` | Отдаёт приоритет скорости рендеринга над читаемостью текста и геометрической точностью. |
| OptimizeLegibility | `2` | Отдаёт приоритет читаемости над скоростью рендеринга и геометрической точностью. |
| GeometricPrecision | `3` | Отдаёт приоритет геометрической точности над скоростью рендеринга и читаемостью. |

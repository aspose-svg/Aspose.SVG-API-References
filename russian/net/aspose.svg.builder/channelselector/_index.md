## ChannelSelector enumeration

Указывает селекторы каналов для использования в операциях фильтрации SVG.

```csharp
public enum ChannelSelector
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| R | `0` | Выбирает красный канал изображения. |
| G | `1` | Выбирает зелёный канал изображения. |
| B | `2` | Выбирает синий канал изображения. |
| A | `3` | Выбирает альфа‑канал (прозрачность) изображения. |

## Замечания

Селекторы каналов используются в различных примитивах SVG‑фильтров для выбора конкретных цветовых каналов (Red, Green, Blue) или альфа‑канала изображения. Это позволяет точно управлять этими каналами во время обработки фильтра.

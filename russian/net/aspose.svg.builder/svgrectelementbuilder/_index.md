## SVGRectElementBuilder class

Класс‑строитель для создания SVG‑элемента 'rect'. Элемент 'rect' используется для создания прямоугольников в SVG‑графике. Этот класс предоставляет методы для установки различных атрибутов, специфичных для элемента 'rect', включая радиусы углов и размеры.

```csharp
public class SVGRectElementBuilder : SVGElementBuilder<SVGRectElement>, IAnimationElementBuilder, 
    IDescriptiveElementBuilder, IPaintServerElementBuilder, IRectAttributeSetter, 
    IShapeAttributeSetter, IShapeContentElementBuilder
```

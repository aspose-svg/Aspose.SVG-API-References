## CoordinateUnits enumeration

Указывает единицы системы координат для различных элементов SVG, таких как маски, серверы заливки и фильтры.

```csharp
public enum CoordinateUnits
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| UserSpaceOnUse | `0` | Использует пользовательскую систему координат для элемента SVG. |
| ObjectBoundingBox | `1` | Использует ограничивающий прямоугольник объекта для элемента SVG. |

## Замечания

Единицы координат определяют, как значения интерпретируются в разных контекстах SVG. Их можно задать либо для использования координат пользовательского пространства, либо относительно ограничивающего прямоугольника объекта.

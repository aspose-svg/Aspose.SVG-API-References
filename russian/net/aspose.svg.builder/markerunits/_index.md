## MarkerUnits enumeration

Указывает систему координат для размера маркера в SVG.

```csharp
public enum MarkerUnits
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| StrokeWidth | `0` | Размер маркера относительно ширины штриха пути. |
| UserSpaceOnUse | `1` | Размер маркера основан на пользовательской системе координат, делая его независимым от ширины штриха. |

## Замечания

Это перечисление определяет систему координат, используемую для расчёта размера маркеров в SVG. Оно определяет, является ли размер маркера относительным к ширине штриха или основанным на пользовательской системе координат.

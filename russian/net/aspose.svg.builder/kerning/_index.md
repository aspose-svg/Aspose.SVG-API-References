## Kerning enumeration

Указывает поведение кернинга для текста в SVG.

```csharp
public enum Kerning
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Auto | `0` | Позволяет браузеру определить, следует ли применять кернинг. |
| Normal | `1` | Применяет стандартный кернинг, как определено в файле шрифта. |
| None | `2` | Отключает кернинг, игнорируя любую информацию о кернинге в шрифте. |

## Замечания

Свойство 'font-kerning' в SVG управляет использованием информации о кернинге, хранящейся в шрифте. Кернинг регулирует расстояние между отдельными парами букв для улучшения визуального вида текста. Это перечисление предоставляет варианты управления поведением кернинга в текстовых элементах SVG.

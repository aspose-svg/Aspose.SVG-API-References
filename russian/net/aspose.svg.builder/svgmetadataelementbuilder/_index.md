## SVGMetadataElementBuilder class

Класс‑строитель для создания элемента SVG 'metadata', который используется для добавления метаданных в документ SVG. Этот класс позволяет добавлять содержимое метаданных и предоставляет методы для установки различных атрибутов, специфичных для элемента 'metadata' в SVG.

```csharp
public class SVGMetadataElementBuilder : SVGElementBuilder<SVGMetadataElement>, 
    ICoreAttributeSetter, IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, 
    ITextContentSetter
```

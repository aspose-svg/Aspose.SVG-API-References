## UnicodeBidi enumeration

Указывает обработку двунаправленного текста в SVG.

```csharp
public enum UnicodeBidi
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Normal | `0` | Обычная обработка двунаправленного текста. |
| Embed | `1` | Встраивает раздел текста с иной или явно заданной направленностью. |
| Isolate | `2` | Изолирует раздел текста от окружающего контекста для обработки двунаправленного текста. |
| BidiOverride | `3` | Переопределяет внутреннюю направленность символов в разделе текста. |
| IsolateOverride | `4` | Изолирует раздел текста и переопределяет его направленность. |
| Plaintext | `5` | Обрабатывает раздел текста как обычный текст без специальной обработки двунаправленности. |

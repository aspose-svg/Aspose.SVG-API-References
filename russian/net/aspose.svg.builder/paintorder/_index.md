## PaintOrder enumeration

Указывает порядок применения fill, stroke и маркеров к элементам SVG.

```csharp
public enum PaintOrder
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Normal | `0` | Порядок заливки по умолчанию: сначала заливка, затем обводка и, наконец, маркеры. |
| Fill | `1` | Отрисовывать только заливку. |
| Stroke | `2` | Отрисовывать только обводку. |
| Markers | `3` | Отрисовывать только маркеры. |
| FillStroke | `4` | Отрисовывать в порядке: заливка, затем обводка. |
| FillMarkers | `5` | Отрисовывать в порядке: заливка, затем маркеры. |
| StrokeFill | `6` | Отрисовывать в порядке: обводка, затем заливка. |
| StrokeMarkers | `7` | Отрисовывать в порядке: обводка, затем маркеры. |
| MarkersFill | `8` | Отрисовывать в порядке: маркеры, затем заливка. |
| MarkersStroke | `9` | Отрисовывать в порядке: маркеры, затем обводка. |
| FillStrokeMarkers | `10` | Отрисовывать в порядке: заливка, затем обводка и, наконец, маркеры. |

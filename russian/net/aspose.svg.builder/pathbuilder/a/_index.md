## PathBuilder.A method

Добавляет команду 'Elliptical Arc Curve' к данным пути.

```csharp
public PathBuilder A(double r1, double r2, double angle, bool largeArcFlag, bool sweepFlag, 
    double x, double y)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| r1 | Double | Радиус по оси x эллипса. |
| r2 | Double | Радиус по оси y эллипса. |
| angle | Double | Угол поворота эллипса в градусах. |
| largeArcFlag | Boolean | Флаг, указывающий, следует ли дуге быть большей или равной 180 градусам. |
| sweepFlag | Boolean | Флаг, указывающий, должна ли дуга быть нарисована в положительном направлении угла. |
| x | Double | Координата x конечной точки дуги. |
| y | Double | Координата y конечной точки дуги. |

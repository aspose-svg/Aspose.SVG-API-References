## PathBuilder.Ar method

Добавляет относительную команду 'Elliptical Arc Curve' к данным пути.

```csharp
public PathBuilder Ar(double r1, double r2, double angle, bool largeArcFlag, bool sweepFlag, 
    double x, double y)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| r1 | Double | Радиус x эллипса, относительно текущей позиции. |
| r2 | Double | Радиус y эллипса, относительно текущей позиции. |
| angle | Double | Угол вращения эллипса в градусах, относительно текущей позиции. |
| largeArcFlag | Boolean | Флаг, указывающий, следует ли дуге быть большей или равной 180 градусам. |
| sweepFlag | Boolean | Флаг, указывающий, должна ли дуга быть нарисована в положительном направлении угла. |
| x | Double | Координата x конечной точки дуги, относительно текущей позиции. |
| y | Double | Координата y конечной точки дуги, относительно текущей позиции. |

### Возвращаемое значение

Текущий экземпляр PathBuilder.

## SVGLineElementBuilder class

Класс‑строитель для создания элемента SVG 'line', который используется для рисования прямых линий в графике SVG. Этот класс позволяет формировать содержимое внутри элемента 'line' и предоставляет методы для установки различных атрибутов, специфичных для элемента 'line' в SVG.

```csharp
public class SVGLineElementBuilder : SVGElementBuilder<SVGLineElement>, IAnimationElementBuilder, 
    IDescriptiveElementBuilder, IPaintServerElementBuilder, IShapeAttributeSetter, 
    IShapeContentElementBuilder
```

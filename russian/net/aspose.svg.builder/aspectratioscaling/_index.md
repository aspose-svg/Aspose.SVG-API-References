## AspectRatioScaling enumeration

Указывает поведение масштабирования элементов SVG при сохранении их соотношения сторон.

```csharp
public enum AspectRatioScaling
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Meet | `0` | Масштабирует SVG‑элемент так, чтобы он помещался в область просмотра, сохраняя его соотношение сторон. Если соотношение сторон области просмотра не совпадает с элементом, дополнительное пространство будет распределено равномерно вдоль оси, где есть больше места. |
| Slice | `1` | Масштабирует SVG‑элемент так, чтобы он заполнял область просмотра, сохраняя его соотношение сторон. Если соотношение сторон области просмотра не совпадает с элементом, элемент будет обрезан для соответствия. |

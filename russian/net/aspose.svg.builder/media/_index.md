## Media enumeration

Указывает условия синхронизации, связанные с медиа, для анимаций SVG.

```csharp
public enum Media
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Media | `0` | Указывает, что время анимации зависит от времени медиа. |

## Замечания

Это перечисление используется для определения условий синхронизации, связанных с медиа, в анимациях SVG. Оно особенно актуально для анимаций, зависящих от внешних медиа или синхронизированных с ними, таких как аудио или видео.

## LengthType enumeration

Указывает единицы измерения длины в SVG.

```csharp
public enum LengthType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Number | `1` | Представляет числовое значение без единицы измерения. Часто интерпретируется в контексте других значений или единиц по умолчанию. |
| Percentage | `2` | Представляет процентное значение, относительное к другому значению или граничному измерению. |
| Ems | `3` | Представляет длину в 'ems' — масштабируемой единице, относительной к текущему размеру шрифта. |
| Exs | `4` | Представляет длину в 'exs', связанной с высотой x текущего шрифта. |
| Px | `5` | Представляет длину в пикселях, единице измерения, основанной на цифровом представлении изображения. |
| Cm | `6` | Представляет длину в сантиметрах. |
| Mm | `7` | Представляет длину в миллиметрах. |
| In | `8` | Представляет длину в дюймах. |
| Pt | `9` | Представляет длину в пунктах, традиционной единице в типографии. 1 пункт приблизительно равен 1/72 дюйма. |
| Pc | `10` | Представляет длину в пики, типографической единице измерения. 1 пика эквивалентна 12 пунктам. |

## Замечания

Этот перечисление определяет различные единицы, которые могут использоваться для указания длины в SVG‑элементах. Эти единицы включают абсолютные измерения, такие как пиксели и сантиметры, а также относительные измерения, такие как проценты и em.

## SVGDefsElementBuilder class

Класс‑строитель для создания SVG‑элемента 'defs', который используется для определения переиспользуемых элементов. Он позволяет формировать содержимое внутри элемента 'defs' и предоставляет методы для установки различных атрибутов, специфичных для элемента 'defs' в SVG.

```csharp
public class SVGDefsElementBuilder : SVGElementBuilder<SVGDefsElement>, ICompositeElementBuilder, 
    ICoreAttributeSetter, IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, 
    IGraphicalEventAttributeSetter, IPresentationAttributeSetter
```

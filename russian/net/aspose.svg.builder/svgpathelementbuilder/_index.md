## SVGPathElementBuilder class

Класс‑строитель для создания элемента SVG 'path', который используется для определения пути в документе SVG. Этот класс предоставляет методы для установки различных атрибутов, специфичных для элемента 'path', и для формирования его содержимого.

```csharp
public class SVGPathElementBuilder : SVGElementBuilder<SVGPathElement>, IAnimationElementBuilder, 
    IDescriptiveElementBuilder, IPaintServerElementBuilder, IShapeAttributeSetter, 
    IShapeContentElementBuilder
```

## CompositeOperator enumeration

Указывает тип операции композитинга, применяемой в операциях композитинга SVG.

```csharp
public enum CompositeOperator
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Over | `0` | Размещает исходный графический объект над целевым графическим объектом. |
| In | `1` | Отображает исходный графический объект там, где он перекрывает целевой графический объект. |
| Out | `2` | Отображает исходный графический объект там, где он не перекрывает целевой графический объект. |
| Atop | `3` | Отображает исходный графический объект поверх целевого графического объекта. |
| Xor | `4` | Отображает исходный графический объект там, где он не перекрывает целевой объект, и наоборот. |
| Arithmetic | `5` | Позволяет выполнить пользовательскую арифметическую операцию композитинга. |

## Замечания

Операции композитинга в SVG определяют, как два графических элемента объединяются в одно изображение. Каждый оператор определяет отдельный метод смешивания или комбинирования этих элементов.

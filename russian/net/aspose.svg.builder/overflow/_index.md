## Overflow enumeration

Указывает поведение переполнения для элементов SVG.

```csharp
public enum Overflow
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Visible | `0` | Содержимое, выходящее за пределы элемента, видно. |
| Hidden | `1` | Содержимое, выходящее за пределы элемента, обрезается и не видно. |
| Scroll | `2` | Предоставляет полосы прокрутки для содержимого, выходящего за пределы элемента. |

## Замечания

Это перечисление управляет тем, как отображается содержимое, выходящее за пределы SVG‑элемента. Оно определяет, будет ли избыточное содержимое видно, обрезано или будет предоставлена полоса прокрутки.

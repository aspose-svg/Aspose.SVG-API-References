## MorphologyOperator enumeration

Указывает тип морфологической операции, применяемой в фильтрах SVG.

```csharp
public enum MorphologyOperator
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Erode | `0` | Эрозирует графику, делая формы меньше и края более гладкими. |
| Dilate | `1` | Дилатирует графику, делая формы больше и края более выраженными. |

## Замечания

Это перечисление используется в контексте SVG-фильтров для определения типа морфологической операции. Морфологические операции применяются для обработки формы и структуры элементов изображения, обычно для эрозии или дилатации графики.

## AlignmentBaseline enumeration

Указывает базовую линию выравнивания для текста и другого встроенного содержимого в SVG.

```csharp
public enum AlignmentBaseline
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Baseline | `0` | Выравнивает базовую линию коробки с базовой линией родительской коробки. |
| TextBottom | `1` | Выравнивает нижнюю часть коробки с нижней частью области содержимого родителя. |
| Middle | `2` | Выравнивает середину коробки с серединой области содержимого родителя. |
| Central | `3` | Выравнивает центральную базовую линию коробки с центральной базовой линией родительской коробки. |
| TextTop | `4` | Выравнивает верхнюю часть коробки с верхней частью области содержимого родителя. |
| Ideographic | `5` | Выравнивает идеографическую базовую линию коробки с идеографической базовой линией родителя. |
| Alphabetic | `6` | Выравнивает алфавитную базовую линию коробки с алфавитной базовой линией родителя. |
| Mathematical | `7` | Выравнивает математическую базовую линию коробки с математической базовой линией родителя. |

## Замечания

Свойство 'alignment-baseline' определено в спецификации CSS Line Layout Module 3. SVG 2 вводит изменения в определение этого свойства.

## Dash enumeration

Определяет шаблон штрихов и промежутков, используемых для рисования контура фигур (stroke) в элементах SVG.

```csharp
public enum Dash
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | `0` | Указывает сплошную обводку без штрихов. Это поведение по умолчанию, когда 'stroke-dasharray' не указан. |

## Замечания

Атрибут 'stroke-dasharray' в SVG используется для создания пунктирных линий путем указания шаблона штрихов и промежутков. Это перечисление предоставляет варианты настройки этого шаблона.

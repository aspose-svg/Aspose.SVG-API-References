## PointerEvents enumeration

Указывает, как графические элементы в SVG обрабатывают события указателя.

```csharp
public enum PointerEvents
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| BoundingBox | `0` | События указателя направлены на ограничивающий прямоугольник элемента. |
| VisiblePainted | `1` | События указателя направлены только на видимые (нарисованные) части элемента. |
| VisibleFill | `2` | События указателя направлены только на видимые (заполненные) части элемента. |
| VisibleStroke | `3` | События указателя направлены только на видимые (обведённые) части элемента. |
| Visible | `4` | События указателя направлены на все видимые части элемента. |
| Painted | `5` | События указателя направлены на все нарисованные части элемента, включая заливку и обводку. |
| Fill | `6` | События указателя направлены только на заполненные части элемента. |
| Stroke | `7` | События указателя направлены только на обведённые части элемента. |
| All | `8` | События указателя направлены на все части элемента, независимо от их видимости. |
| None | `9` | Элемент не становится целью событий указателя. |

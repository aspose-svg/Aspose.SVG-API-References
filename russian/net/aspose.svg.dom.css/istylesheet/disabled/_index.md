## IStyleSheet.Disabled property

false если таблица стилей применена к документу. true если не применена. Изменение этого атрибута может вызвать новое вычисление стилей для документа. Таблица стилей применяется только если присутствует соответствующее определение среды и атрибут disabled имеет значение false. Поэтому, если медиа не применимы к текущему пользовательскому агенту, атрибут disabled игнорируется.

```csharp
public bool Disabled { get; set; }
```

### Property Value

`true` если отключено; иначе, `false`.

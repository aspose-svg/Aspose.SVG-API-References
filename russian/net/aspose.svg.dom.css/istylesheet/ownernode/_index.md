## IStyleSheet.OwnerNode property

Узел, который связывает эту таблицу стилей с документом. Для HTML это может быть соответствующий элемент LINK или STYLE. Для XML это может быть инструкция обработки связывания. Для таблиц стилей, включаемых другими таблицами стилей, значение этого атрибута равно null.

```csharp
public Node OwnerNode { get; }
```

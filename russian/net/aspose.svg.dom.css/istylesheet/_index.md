## IStyleSheet interface

Интерфейс StyleSheet является абстрактным базовым интерфейсом для любого типа таблицы стилей. Он представляет одну таблицу стилей, связанную со структурированным документом.

```csharp
public interface IStyleSheet
```

## Свойства

| Имя | Описание |
| --- | --- |
| [Disabled](../../aspose.svg.dom.css/istylesheet/disabled/) { get; set; } | false если таблица стилей применена к документу. true если не применена. Изменение этого атрибута может вызвать новое вычисление стилей для документа. Таблица стилей применяется только если присутствует соответствующее определение среды и атрибут disabled имеет значение false. Поэтому, если медиа не применимы к текущему пользовательскому агенту, атрибут disabled игнорируется. |
| [Href](../../aspose.svg.dom.css/istylesheet/href/) { get; } | Если таблица стилей является связанной таблицей стилей, значение её атрибута — это её местоположение. Для встроенных таблиц стилей значение этого атрибута равно null. |
| [Media](../../aspose.svg.dom.css/istylesheet/media/) { get; } | Предназначенные целевые носители для информации о стиле. |
| [OwnerNode](../../aspose.svg.dom.css/istylesheet/ownernode/) { get; } | Узел, который связывает эту таблицу стилей с документом. Для HTML это может быть соответствующий элемент LINK или STYLE. Для XML это может быть инструкция обработки связывания. Для таблиц стилей, включаемых другими таблицами стилей, значение этого атрибута равно null. |
| [ParentStyleSheet](../../aspose.svg.dom.css/istylesheet/parentstylesheet/) { get; } | Для языков таблиц стилей, поддерживающих концепцию включения таблиц стилей, этот атрибут представляет включающую таблицу стилей, если она существует. Если таблица стилей является таблицей верхнего уровня или язык таблиц стилей не поддерживает включение, значение этого атрибута равно null. |
| [Title](../../aspose.svg.dom.css/istylesheet/title/) { get; } | Рекомендованное название. |
| [Type](../../aspose.svg.dom.css/istylesheet/type/) { get; } | Это указывает язык таблицы стилей для данной таблицы стилей. Язык таблицы стилей задаётся как тип содержимого (например, "text/css"). |

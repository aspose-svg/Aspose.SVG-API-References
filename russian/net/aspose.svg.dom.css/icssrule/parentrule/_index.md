## ICSSRule.ParentRule property

Если это правило находится внутри другого правила (например, правило стиля внутри блока @media), то это правило‑контейнер. Если правило не вложено ни в одно другое правило, возвращается null.

```csharp
public ICSSRule ParentRule { get; }
```

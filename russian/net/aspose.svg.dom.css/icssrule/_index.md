## ICSSRule interface

Интерфейс CSSRule является абстрактным базовым интерфейсом для любого типа CSS‑оператора. Это включает как наборы правил, так и at‑правила. Ожидается, что реализация сохранит все правила, указанные в таблице стилей CSS, даже если правило не распознано парсером. Нераспознанные правила представляются с помощью интерфейса ICSSUnknownRule.

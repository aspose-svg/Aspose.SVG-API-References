## ICSSRuleList indexer

Используется для получения правила CSS методом item() (http://www.w3.org/TR/DOM-Level-2-Style/css.html#CSS-CSSRuleList). Порядок в этой коллекции соответствует порядку правил в таблице стилей CSS. Если индекс больше или равен количеству правил в списке, возвращается null.

```csharp
public ICSSRule this[int index] { get; }
```

| Параметр | Описание |
| --- | --- |
| index | Индекс правила |

### Возвращаемое значение

Экземпляр CSS‑правила.

### Property Value

Эта [`ICSSRule`](../../icssrule/).

## CSSPrimitiveValue.GetRGBColorValue method

Этот метод используется для получения цвета RGB. Если данное CSS‑значение не содержит значения цвета RGB, генерируется DOMException. Изменение соответствующего свойства стиля может быть выполнено с помощью интерфейса RGBColor.

```csharp
public abstract RGBColor GetRGBColorValue()
```

### Возвращаемое значение

Возвращает значение цвета RGB

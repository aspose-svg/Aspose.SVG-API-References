## CSSPrimitiveValue.SetStringValue method

Метод для установки строкового значения с указанной единицей. Если свойство, связанное с этим значением, не может принять указанную единицу или строковое значение, значение останется неизменным, и будет выброшено DOMException.

```csharp
public abstract void SetStringValue(ushort stringType, string stringValue)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| stringType | UInt16 | Тип строки. |
| stringValue | String | Строковое значение. |

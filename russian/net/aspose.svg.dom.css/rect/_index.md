## Rect class

Интерфейс Rect используется для представления любого значения rect. Этот интерфейс отражает значения в базовом свойстве стиля. Таким образом, изменения, внесённые в объекты CSSPrimitiveValue, изменяют свойство стиля.

public class Rect : DOMObject

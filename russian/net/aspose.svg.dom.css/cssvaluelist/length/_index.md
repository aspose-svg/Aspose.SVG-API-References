## CSSValueList.Length property

Свойство length только для чтения интерфейса CSSValueList представляет количество CSSValue в списке. Диапазон допустимых значений индексов — от 0 до length‑1 включительно.

```csharp
public int Length { get; }
```

### Property Value

Целое число, представляющее количество CSSValues в текущем экземпляре.

## ICSSStyleDeclaration.CSSText property

Текстовое представление декларативного блока, пригодное для разбора (за исключением окружающих фигурных скобок). Установка этого атрибута приведёт к разбору нового значения и сбросу всех свойств в декларативном блоке, включая удаление или добавление свойств.

```csharp
public string CSSText { get; set; }
```

### Property Value

Текст CSS.

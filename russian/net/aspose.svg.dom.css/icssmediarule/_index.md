## ICSSMediaRule interface

Интерфейс CSSMediaRule представляет правило @media в таблице стилей CSS. Правило @media может использоваться для ограничения правил стилей для конкретных типов носителей.

```csharp
public interface ICSSMediaRule : ICSSRule
```

## Пространства имён

| Пространство имён | Описание |
| --- | --- |
| [Aspose.Svg](./aspose.svg/) | Все классы в пространстве имён **Aspose.Svg.Dom.Svg** основаны на рекомендациях w3c SVG2. Используя это пространство имён, вы можете загружать, перемещаться по или рендерить SVG‑файл в соответствии с вашими требованиями. |
| [Aspose.Svg.Builder](./aspose.svg.builder/) | Пространство имён **Aspose.Svg.Builder** содержит классы и интерфейсы для создания и манипулирования документами SVG (Scalable Vector Graphics) с использованием библиотеки Aspose.SVG. Это пространство имён предоставляет обширный набор классов‑строителей, упрощающих создание и изменение элементов SVG и их атрибутов. Эти строительные классы предлагают удобный fluent API, делая код более читаемым и поддерживаемым. |
| [Aspose.Svg.Collections](./aspose.svg.collections/) | Пространство имён **Aspose.Svg.Collections** состоит из классов для представления, хранения и манипулирования узлами и элементами. |
| [Aspose.Svg.Converters](./aspose.svg.converters/) | Цель пространства имён **Aspose.Svg.Converters** — простой доступ к методам конвертации. Оно предоставляет широкий спектр преобразований в популярные форматы, такие как PDF, XPS, форматы изображений и т.д. Более специфические сценарии конвертации (рендеринг, сохранение) представлены известными и документированными низкоуровневыми функциями API в предметно‑ориентированных пространствах имён. |
| [Aspose.Svg.DataTypes](./aspose.svg.datatypes/) | Это пространство имён предоставляет доступ ко всем специфическим типам данных SVG. |
| [Aspose.Svg.Diagnostics](./aspose.svg.diagnostics/) | Пространство имён **Aspose.Svg.Diagnostics** содержит интерфейсы для работы с метриками и сбора журналов и трасс. |
| [Aspose.Svg.Dom](./aspose.svg.dom/) | Пространство имён **Aspose.Svg.Dom (Document Object Model)** предоставляет API, представляющее и взаимодействующее с любыми документами HTML, XML или SVG. DOM — это модель документа, загружаемая в браузере и представляющая документ в виде дерева узлов, где каждый узел соответствует части документа (например, элементу, строке текста или комментарию). |
| [Aspose.Svg.Dom.Attributes](./aspose.svg.dom.attributes/) | Пространство имён **Aspose.Svg.Dom.Attributes** содержит унифицированные классы атрибутов, которые определяют или уточняют любые свойства или поведение объектов (узла, элемента и т.д.). |
| [Aspose.Svg.Dom.Css](./aspose.svg.dom.css/) | Пространство имён **Aspose.Svg.Dom.Css** предназначено для всех манипуляций, связанных с CSS. Оно сосредоточено вокруг пар «имя свойства – значение», указанных в официальных документах CSS. |
| [Aspose.Svg.Dom.Events](./aspose.svg.dom.events/) | Пространство имён **Aspose.Svg.Dom.Events** предоставляет объекты для любых событий, связанных с обновлением DOM. Оно включает подписку на наблюдение за конкретной контекстной информацией, связанной с событием, а также создание пользовательских событий. |
| [Aspose.Svg.Dom.Mutations](./aspose.svg.dom.mutations/) | Пространство имён **Aspose.Svg.Dom.Mutations** предоставляет возможность наблюдать за мутациями DOM и получать конкретную информацию обратных вызовов. |
| [Aspose.Svg.Dom.Traversal](./aspose.svg.dom.traversal/) | Пространство имён **Aspose.Svg.Dom.Traversal** содержит методы, создающие итераторы и обходчики дерева для навигации между элементами и обхода узла и его дочерних элементов в порядке документа. |
| [Aspose.Svg.Dom.Traversal.Filters](./aspose.svg.dom.traversal.filters/) | Это пространство имён реализует функциональность фильтрации узлов. Фильтры — это объекты, умеющие «отфильтровывать» узлы. Если итератор узлов или обходчик дерева получает фильтр узлов, он применяет фильтр перед тем, как вернуть следующий узел. Если фильтр разрешает узел, логика обхода возвращает его; в противном случае обход ищет следующий узел, будто отклонённый узел не существует. |
| [Aspose.Svg.Dom.Views](./aspose.svg.dom.views/) | Пространство имён **Aspose.Svg.Dom.Views** описывает интерфейсы AbstractView и DocumentView в соответствии со спецификацией Document Object Model Views. |
| [Aspose.Svg.Dom.XPath](./aspose.svg.dom.xpath/) | Пространство имён **Aspose.Svg.Dom.XPath** содержит методы для навигации по элементам и атрибутам в XML‑документе. |
| [Aspose.Svg.Drawing](./aspose.svg.drawing/) | Пространство имён **Aspose.Svg.Drawing** содержит объекты и интерфейсы для указания измерений и единиц, а также объектов атрибутов рисования, таких как кисти, цвета и шрифты. |
| [Aspose.Svg.Events](./aspose.svg.events/) | Это пространство имён состоит из классов для интерактивности, основанной на событиях, таких как временные события и масштабирование. |
| [Aspose.Svg.Filters](./aspose.svg.filters/) | Пространство имён **Aspose.Svg.Dom.Svg.Filters** содержит классы и интерфейсы, связанные с эффектами фильтров в спецификации SVG. |
| [Aspose.Svg.ImageVectorization](./aspose.svg.imagevectorization/) | Пространство имён **Aspose.Svg.ImageVectorization** содержит классы для векторизации растровых изображений и их преобразования в SVG‑документы. Этот процесс включает преобразование битмапов в геометрические формы, состоящие из элементов пути, и их сохранение в виде SVG. Пространство имён включает классы для построения сегментов пути, упрощения и сглаживания точек трассировки, а также настройки параметров векторизации. |
| [Aspose.Svg.IO](./aspose.svg.io/) | Помимо стандартных средств ввода-вывода (IO) **Aspose.Svg.IO** пространство имён содержит вспомогательные классы и интерфейсы. |
| [Aspose.Svg.Net](./aspose.svg.net/) | Пространство имён **Aspose.Svg.Net** представлено классами и интерфейсами, которые отвечают за упрощённую обработку сетевых операций. |
| [Aspose.Svg.Net.Headers](./aspose.svg.net.headers/) | Пространство имён **Aspose.Svg.Net.Headers** предоставляет несколько классов данных для описания содержимого заголовков в сетевых взаимодействиях. |
| [Aspose.Svg.Net.MessageFilters](./aspose.svg.net.messagefilters/) | Пространство имён **Aspose.Svg.Net.MessageFilters** предоставляет классы, реализующие абстракцию фильтра сообщений. |
| [Aspose.Svg.Net.MessageHandlers](./aspose.svg.net.messagehandlers/) | Пространство имён **Aspose.Svg.Net.MessageHandlers** представлено классами — обработчиками сообщений различных протоколов. |
| [Aspose.Svg.Paths](./aspose.svg.paths/) | Пространство имён **Aspose.Svg.Dom.Svg.Paths** описывает классы для представления контура фигуры, который может быть заполнен или обведён. Контур также может использоваться в качестве обрезающего пути, для описания анимации или позиционирования текста. |
| [Aspose.Svg.Rendering](./aspose.svg.rendering/) | Пространство имён **Aspose.Svg.Rendering** состоит из множества объектов рендерера, а также соответствующих классов параметров низкого уровня, отвечающих за рендеринг документов/файлов в реализацию IDevice. |
| [Aspose.Svg.Rendering.Fonts](./aspose.svg.rendering.fonts/) | Пространство имён **Aspose.Svg.Rendering.Fonts** содержит классы и методы, позволяющие управлять некоторыми частями алгоритма сопоставления шрифтов. |
| [Aspose.Svg.Rendering.Image](./aspose.svg.rendering.image/) | Пространство имён **Aspose.Svg.Rendering.Image** предоставляет конкретный класс устройства, а также несколько классов параметров рендеринга, отвечающих за вывод в растровые форматы: jpeg, png, bmp, gif, tiff. |
| [Aspose.Svg.Rendering.Pdf](./aspose.svg.rendering.pdf/) | Пространство имён **Aspose.Svg.Rendering.Pdf** предоставляет конкретный класс устройства, а также несколько классов параметров рендеринга, отвечающих за вывод в PDF‑документ. |
| [Aspose.Svg.Rendering.Pdf.Encryption](./aspose.svg.rendering.pdf.encryption/) | Пространство имён **Aspose.Svg.Rendering.Pdf.Encryption** содержит классы данных, описывающие детали шифрования PDF, такие как пароль, алгоритм шифрования и т.д. |
| [Aspose.Svg.Rendering.Xps](./aspose.svg.rendering.xps/) | Пространство имён **Aspose.Svg.Rendering.Xps** предоставляет конкретный класс устройства, а также несколько классов параметров рендеринга, отвечающих за вывод в XPS‑документ. |
| [Aspose.Svg.Saving](./aspose.svg.saving/) | Пространство имён **Aspose.Svg.Saving** представлено классами данных для описания конкретных параметров сохранения при процессе конвертации/сохранения. |
| [Aspose.Svg.Saving.ResourceHandlers](./aspose.svg.saving.resourcehandlers/) | Пространство имён **Aspose.Svg.Saving.ResourceHandlers** содержит классы, отвечающие за обработку ресурсов. |
| [Aspose.Svg.Services](./aspose.svg.services/) | Пространство имён **Aspose.Svg.Services** содержит интерфейсы, выступающие в роли протоколов для реализаций сервисов. |
| [Aspose.Svg.Toolkit.Optimizers](./aspose.svg.toolkit.optimizers/) | Пространство имён **Aspose.Svg.Toolkit.Optimizers** содержит классы для оптимизации SVG‑документов. Процесс оптимизации включает удаление неиспользуемых или невидимых элементов и их атрибутов, объединение групп и уменьшение размера сегментов путей. |
| [Aspose.Svg.Window](./aspose.svg.window/) | Пространство имён **Aspose.Svg.Window** связано с объектом окна, представляющим окно, содержащее DOM‑документ. Оно включает классы и интерфейсы, связанные с адресом активного документа и историей навигации. |

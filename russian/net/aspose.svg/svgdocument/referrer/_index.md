## SVGDocument.Referrer property

Возвращает URI страницы, которая ссылалась на эту страницу. Значение является пустой строкой, если пользователь перешёл на страницу напрямую (не через ссылку, а, например, через закладку).

```csharp
public string Referrer { get; }
```

### Property Value

Referrer.

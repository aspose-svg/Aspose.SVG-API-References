## SVGDocument.GetOverrideStyle method

Этот метод используется для получения переопределённого объявления стиля для указанного элемента и указанного псевдо‑элемента.

```csharp
public ICSSStyleDeclaration GetOverrideStyle(Element elt, string pseudoElt)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| elt | Element | Элемент, стиль которого будет изменён. Этот параметр не может быть null. |
| pseudoElt | String | Псевдо-элемент или null, если его нет. |

### Возвращаемое значение

Объявление переопределяющего стиля.

## SVGDocument class

`SVGDocument` — корень иерархии SVG и содержит всё содержимое. Помимо доступа к иерархии, он также предоставляет удобные методы для получения определённых наборов информации из документа. Помимо загрузки стандартных файлов .svg, как конструкторы, так и метод [`Navigate`](../../aspose.svg.dom/document/navigate/) могут загружать gzip‑сжатые файлы .svgz. Когда элемент ‘svg’ встроен inline как компонент документа из другого пространства имён, например когда элемент ‘svg’ встроен inline в документ XHTML [XHTML], объект SVGDocument не существует; вместо этого корневой объект в иерархии объектов документа будет объект Document другого типа, например HTMLDocument. Однако объект SVGDocument действительно существует, когда корневым элементом иерархии XML‑документа является элемент ‘svg’, например при просмотре отдельного SVG‑файла (i.e., файл с MIME‑типом \"image/svg+xml\"). В этом случае объект SVGDocument будет корневым объектом иерархии модели объектного документа.

```csharp
public class SVGDocument : Document, IDocumentCSS
```

## IUrlSearchParams.Set method

Устанавливает значение первой найденной пары имя‑значение в указанное значение и удаляет остальные. Если пары имя‑значение с указанным именем не найдены, в список будет добавлена новая.

```csharp
public void Set(string name, string value)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| name | String | Ключ, который будет использоваться для поиска пар имя‑значение. |
| значение | String | Значение, которое будет установлено. |

## MimeType Equality operator

Сравнивает два типа Mime и возвращает логическое значение, указывающее, совпадают ли они.

```csharp
public static bool operator ==(MimeType a, MimeType b)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| a | MimeType | Первый Mime для сравнения. |
| b | MimeType | Второй Mime для сравнения. |

### Возвращаемое значение

True, если оба приоритета равны, иначе false.

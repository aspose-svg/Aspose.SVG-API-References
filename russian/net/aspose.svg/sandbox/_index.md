## Sandbox enumeration

Набор флагов песочницы — это набор из нуля или более следующих флагов, которые используются для ограничения возможностей потенциально недоверенных ресурсов.

```csharp
[Flags]
public enum Sandbox
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | `0` | Флаги не установлены, все функции песочницы принимаются. |
| Navigation | `1` | Этот флаг предотвращает навигацию содержимого в контексты просмотра, отличные от самого изолированного контекста просмотра (или вложенных в него контекстов), вспомогательные контексты просмотра (которые защищены флагом изолированной вспомогательной навигации, определённым далее), а также контекст просмотра верхнего уровня (который защищён флагом изолированной навигации верхнего уровня, определённым ниже). Если флаг изолированной вспомогательной навигации не установлен, то в некоторых случаях ограничения всё же позволяют открывать всплывающие окна (новые контексты просмотра верхнего уровня). Эти контексты просмотра всегда имеют один разрешённый изолированный навигатор, задаваемый при создании контекста просмотра, который позволяет контексту, создавшему их, действительно навигировать их. (В противном случае флаг изолированной навигации контекста просмотра предотвратил бы их навигацию, даже если они были открыты.) |
| AuxiliaryNavigation | `2` | Этот флаг предотвращает создание содержимым новых вспомогательных контекстов просмотра, например с помощью атрибута target или метода window.open(). |
| TopLevelNavigation | `4` | Этот флаг предотвращает навигацию содержимого в его контекст просмотра верхнего уровня и предотвращает закрытие этого контекста. Когда флаг изолированной навигации контекста просмотра верхнего уровня не установлен, содержимое может навигировать свой контекст просмотра верхнего уровня, но другие контексты просмотра всё ещё защищены флагом изолированной навигации контекста просмотра и, возможно, флагом изолированной вспомогательной навигации контекста просмотра. |
| Plugins | `8` | Этот флаг предотвращает создание содержимым плагинов, будь то с помощью элемента embed, элемента object, элемента applet или через навигацию вложенного контекста просмотра, если только эти плагины не могут быть защищены. |
| Origin | `10` | Этот флаг принуждает содержимое к уникальному источнику, тем самым предотвращая доступ к другому содержимому того же источника. |
| Forms | `20` | Этот флаг блокирует отправку форм. |
| PointerLock | `40` | Этот флаг отключает API захвата указателя. |
| Scripts | `80` | Этот флаг блокирует выполнение скриптов. |
| AutomaticFeatures | `100` | Этот флаг блокирует функции, которые срабатывают автоматически, например автоматическое воспроизведение видео или автоматический фокус на элементе формы. |
| Fullscreen | `200` | Этот флаг предотвращает использование содержимым метода requestFullscreen(). |
| DocumentDomain | `400` | Этот флаг предотвращает использование содержимым возможности document.domain для изменения фактического источника скриптов. |
| Images | `800` | Этот флаг отключает загрузку изображений. |

## SVGPolylineElement.AnimatedPoints property

Обеспечивает доступ к текущему анимированному содержимому атрибута ‘points’. Если данный атрибут или свойство анимируется, содержит текущее анимированное значение атрибута или свойства. Если данный атрибут или свойство в данный момент не анимируется, содержит то же значение, что и points.

```csharp
public SVGPointList AnimatedPoints { get; }
```

### Property Value

Анимированные точки.

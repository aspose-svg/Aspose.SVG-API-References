## ISVGAnimatedPoints interface

Интерфейс SVGAnimatedPoints поддерживает элементы, имеющие атрибут ‘points’, содержащий список координат, и позволяющий анимировать этот атрибут. Кроме того, атрибут ‘points’ оригинального элемента, доступный через XML DOM (например, с помощью вызова метода getAttribute()), будет отражать любые изменения, внесённые в точки.

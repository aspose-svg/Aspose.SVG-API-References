## Классы

| Класс | Описание |
| --- | --- |
| [XpsDevice](./xpsdevice/) | Представляет рендеринг в документ XPS. |
| [XpsRenderingOptions](./xpsrenderingoptions/) | Представляет параметры рендеринга для [`XpsDevice`](../aspose.svg.rendering.xps/xpsdevice/). |

Пространство имён **Aspose.Svg.Dom.XPath** содержит методы для навигации по элементам и атрибутам в XML‑документе.

## Интерфейсы

| Интерфейс | Описание |
| --- | --- |
| [IXPathEvaluator](./ixpathevaluator/) | Оценка XPath‑выражений предоставляется [`IXPathEvaluator`](../aspose.svg.dom.xpath/ixpathevaluator/). |
| [IXPathExpression](./ixpathexpression/) | Интерфейс `XPathExpression` представляет разобранное и разрешённое XPath‑выражение. |
| [IXPathNamespace](./ixpathnamespace/) | Интерфейс XPathNamespace возвращается интерфейсами XPathResult для представления типа узла пространства имён XPath, которого не хватает в DOM. |
| [IXPathNSResolver](./ixpathnsresolver/) | Интерфейс `XPathNSResolver` позволяет строкам `prefix` в выражении правильно связываться со строками `namespaceURI`. [`IXPathEvaluator`](../aspose.svg.dom.xpath/ixpathevaluator/) может создать реализацию [`IXPathNSResolver`](../aspose.svg.dom.xpath/ixpathnsresolver/) из узла, либо интерфейс может быть реализован любым приложением. |
| [IXPathResult](./ixpathresult/) | Интерфейс `XPathResult` представляет результат оценки XPath‑выражения 1.0 в контексте конкретного узла. Поскольку оценка XPath‑выражения может приводить к различным типам результатов, этот объект позволяет обнаруживать и манипулировать типом и значением результата. |
## Перечисление

| Перечисление | Описание |
| --- | --- |
| [XPathResultType](./xpathresulttype/) | Беззнаковый short, указывающий, какого типа результат. Если указан конкретный `type`, то результат будет возвращён как соответствующий тип, используя преобразования типов XPath там, где это требуется и возможно. |

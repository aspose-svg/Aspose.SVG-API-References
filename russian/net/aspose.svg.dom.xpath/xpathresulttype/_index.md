## XPathResultType enumeration

Беззнаковый short, указывающий, какого типа результат. Если указан конкретный `type`, то результат будет возвращён как соответствующий тип, используя преобразования типов XPath там, где это требуется и возможно.

```csharp
public enum XPathResultType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Any | `0` | Этот код не представляет конкретный тип. Оценка XPath‑выражения никогда не будет возвращать этот тип. Если запрашивается этот тип, то оценка возвращает любой тип, естественно полученный в результате оценки выражения. Если естественный результат — набор узлов, когда запрошен тип `Any`, то результирующим типом всегда будет `UnorderedNodeIterator`. Любое другое представление набора узлов должно быть запрошено явно. |
| Number | `1` | Результат — число, как определено в [XPath 1.0]. Изменение документа не делает число недействительным, но может означать, что повторная оценка не даст того же числа. |
| String | `2` | Результат — строка, как определено в [XPath 1.0]. Изменение документа не делает строку недействительной, но может означать, что строка больше не соответствует текущему документу. |
| Boolean | `3` | Результат — логическое значение, как определено в [XPath 1.0]. Изменение документа не делает логическое значение недействительным, но может означать, что повторная оценка не даст того же логического значения. |
| UnorderedNodeIterator | `4` | Результат — набор узлов, как определено в [XPath 1.0], который будет доступен итеративно и может не выдавать узлы в определённом порядке. Изменение документа делает итерацию недействительной. Это тип по умолчанию, возвращаемый, если результат — набор узлов и запрошен тип `Any`. |
| OrderedNodeIterator | `5` | Результат — набор узлов, как определено в [XPath 1.0], который будет доступен итеративно и будет выдавать узлы в порядке документа. Изменение документа делает итерацию недействительной. |
| UnorderedNodeSnapshot | `6` | Результат — набор узлов, как определено в [XPath 1.0], который будет доступен как список снимков узлов, который может быть не в определённом порядке. Изменение документа не делает снимок недействительным, но может означать, что повторная оценка не даст того же снимка, и узлы в снимке могли быть изменены, перемещены или удалены из документа. |
| OrderedNodeSnapshot | `7` | Результат — набор узлов, как определено в [XPath 1.0], который будет доступен как список снимков узлов, который будет в оригинальном порядке документа. Изменение документа не делает снимок недействительным, но может означать, что повторная оценка не даст того же снимка, и узлы в снимке могли быть изменены, перемещены или удалены из документа. |
| AnyUnorderedNode | `8` | Результат представляет собой набор узлов, определённый [XPath 1.0], и будет доступен как один узел, который может быть `null`, если набор узлов пуст. Изменение документа не делает узел недействительным, но может означать, что результирующий узел больше не соответствует текущему документу. Это удобство, позволяющее оптимизацию, поскольку реализация может остановиться, как только найден любой узел в результирующем наборе. Если в фактическом результате более одного узла, возвращённый один узел может не быть первым в порядке документа. |
| FirstOrderedNode | `9` | Результат представляет собой набор узлов, определённый [XPath 1.0], и будет доступен как один узел, который может быть `null`, если набор узлов пуст. Изменение документа не делает узел недействительным, но может означать, что результирующий узел больше не соответствует текущему документу. Это удобство, позволяющее оптимизацию, поскольку реализация может остановиться, как только найден первый узел в порядке документа результирующего набора. Если в фактическом результате более одного узла, возвращённый один узел будет первым в порядке документа. |

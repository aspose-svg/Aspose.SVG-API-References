## IXPathNamespace.OwnerElement property

Элемент [`Element`](../../../aspose.svg.dom/element/), в области действия которого находилось пространство имён в момент запроса. Он не меняется у возвращённого узла пространства имён, даже если документ изменяется так, что пространство имён выходит из области действия этого элемента и узел больше не находится там при выполнении XPath.

```csharp
public Element OwnerElement { get; }
```

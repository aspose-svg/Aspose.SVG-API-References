## SizingType enumeration

Представляет перечисление типов размеров страниц.

```csharp
public enum SizingType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| FitContent | `0` | Изменение заданных размеров страницы для соответствия размеру содержащегося в ней контента. |
| ScaleContent | `1` | Масштабирование размера контента в соответствии с заданным размером страницы. |
| Contain | `2` | Подгонка размера контента к размеру страницы при сохранении предпочтительного соотношения сторон насколько это возможно. |
| Crop | `3` | Размещение контента на странице и обрезка всего, что выходит за заданный размер страницы. |

Пространство имён **Aspose.Svg.Rendering** состоит из множества объектов рендерера, а также соответствующих классов параметров низкого уровня, отвечающих за рендеринг документов/файлов в реализацию IDevice.

## Классы

| Класс | Описание |
| --- | --- |
| [CssOptions](./cssoptions/) | Представляет параметры рендеринга CSS. |
| [Device](./device/) | Представляет базовый класс для реализации рендеринговых устройств, используемых для отрисовки графики в различных форматах и средах. |
| [Device<TGraphicContext,TRenderingOptions>](./device-2/) | Представляет базовый класс для реализации конкретных рендеринговых устройств. |
| [GraphicContext](./graphiccontext/) | Содержит текущие параметры управления графикой. Эти параметры определяют глобальную структуру, в которой выполняются графические операции. |
| [PageSetup](./pagesetup/) | Представляет объект настройки страницы, используемый для конфигурации набора выводимых страниц. |
| [Renderer](./renderer/) | Представляет базовый класс для всех рендереров и реализует интерфейс IDisposable. |
| [Renderer<TSource>](./renderer-1/) | Базовый абстрактный класс для всех рендереров. |
| [RenderingOptions](./renderingoptions/) | Представляет параметры рендеринга. |
| [SvgRenderer](./svgrenderer/) | Представляет рендерер SVG‑документов. |
| [TextInfo](./textinfo/) | Содержит информацию о отрендеренном тексте. |

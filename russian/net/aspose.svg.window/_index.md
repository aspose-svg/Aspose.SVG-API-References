Пространство имён **Aspose.Svg.Window** связано с объектом окна, представляющим окно, содержащее DOM‑документ. Оно включает классы и интерфейсы, связанные с адресом активного документа и историей навигации.

## Классы

| Класс | Описание |
| --- | --- |
| [Location](./location/) | Объекты Location предоставляют представление адреса активного документа их контекста просмотра Document и позволяют изменять текущую запись истории сеанса контекста просмотра, добавляя или заменяя записи в объекте history. |
| [MediaQueryList](./mediaquerylist/) | Объект MediaQueryList хранит информацию о медиазапросе, применённом к документу, с поддержкой как немедленного, так и событийного сопоставления с состоянием документа. См. спецификацию модуля CSSOM View: [https://www.w3.org/TR/cssom-view/#the-mediaquerylist-interface](https://www.w3.org/TR/cssom-view/#the-mediaquerylist-interface) |
## Интерфейсы

| Интерфейс | Описание |
| --- | --- |
| [IWindow](./iwindow/) | Объект window представляет окно, содержащее DOM‑документ. |
| [IWindowEventHandlers](./iwindoweventhandlers/) | Представляет интерфейс, который должен наследоваться объектом window |
| [IWindowTimers](./iwindowtimers/) | Позволяет авторам планировать обратные вызовы, основанные на таймерах. |

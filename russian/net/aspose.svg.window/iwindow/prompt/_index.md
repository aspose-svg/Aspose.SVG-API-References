## IWindow.Prompt method

Отображает модальное окно с полем ввода текста и указанным сообщением, ждёт, пока пользователь закроет его, и возвращает введённое пользователем значение. Если пользователь отменил запрос, возвращается null. Если присутствует второй аргумент, то указанное значение используется как значение по умолчанию.

```csharp
public string Prompt(string message, string @default)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| сообщение | String | Сообщение. |
| по умолчанию | String | По умолчанию. |

### Возвращаемое значение

Возвращает значение, введённое пользователем.

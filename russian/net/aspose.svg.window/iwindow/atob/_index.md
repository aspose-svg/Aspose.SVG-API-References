## IWindow.Atob method

Принимает входные данные в виде Unicode‑строки, содержащей бинарные данные, закодированные в base64, декодирует их и возвращает строку, состоящую из символов в диапазоне U+0000–U+00FF, каждый из которых представляет бинарный байт со значением от 0x00 до 0xFF соответственно, соответствующий этим бинарным данным.

```csharp
public string Atob(string data)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| данные | String | Unicode‑строка, содержащая base64‑закодированные бинарные данные |

### Возвращаемое значение

Строка, состоящая из символов в диапазоне U+0000–U+00FF

### Исключения

| исключение | условие |
| --- | --- |
| [DOMException](../../../aspose.svg.dom/domexception/) | Выбрасывает исключение DOMException "InvalidCharacterError", если входная строка не является корректными base64‑данными. |

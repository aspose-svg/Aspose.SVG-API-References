## IWindow.Top property

IDL‑атрибут top у объекта Window документа в контексте просмотра b должен возвращать объект WindowProxy его верхнего (top‑level) контекста просмотра (который будет его собственным объектом WindowProxy, если он сам является верхним контекстом), если такой существует, либо его собственный объект WindowProxy в противном случае (например, если это отсоединённый вложенный контекст).

```csharp
public IWindow Top { get; }
```

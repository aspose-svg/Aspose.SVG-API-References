## IBlob.Slice method

返回一个新的 Blob 对象，其字节范围从可选的 start 参数开始，但不包括可选的 end 参数，并且其 type 属性为可选的 contentType 参数的值。

```csharp
public IBlob Slice(ulong start, ulong end, string contentType)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| 开始 | UInt64 | 该参数是切片起始点的值 |
| 结束 | UInt64 | 该参数是切片起始点的值 |
| contentType | String | 该参数是 Blob 的媒体类型 |

### 返回值

返回一个新的 Blob 对象，其字节范围从可选的 start 参数开始，但不包括可选的 end 参数，并且其 type 属性为可选的 contentType 参数的值。

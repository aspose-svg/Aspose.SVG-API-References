## IFile.LastModified property

文件的最后修改日期。获取时，如果用户代理能够提供此信息，则必须返回一个 long long，表示自 Unix 纪元以来的毫秒数，即文件最后修改的时间。

```csharp
public long LastModified { get; }
```

## IColorComponents.ToString method

将颜色分量转换为字符串表示。

```csharp
public string ToString(bool includeAlpha, bool asDecimal, int digits)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| includeAlpha | Boolean | 指定是否添加 Alpha 组件。 |
| asDecimal | Boolean | 指定颜色组件是以十进制数还是百分比形式保留。 |
| digits | Int32 | 设置颜色组件的四舍五入精度。 |

### 返回值

颜色组件的字符串表示形式。

## MimeType Inequality operator

比较两个 Mime 类型并返回一个布尔值，指示两者是否匹配。

```csharp
public static bool operator !=(MimeType a, MimeType b)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| a | MimeType | 要比较的第一个 MIME。 |
| b | MimeType | 要比较的第二个 MIME。 |

### 返回值

如果两个优先级不相等，则为 True，否则为 false。

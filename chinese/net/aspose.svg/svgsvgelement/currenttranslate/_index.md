## SVGSVGElement.CurrentTranslate property

在最外层的 svg 元素上，此属性对应考虑用户\"放大\"的平移因子。当在不是最外层的 ‘svg’ 元素上访问时，此属性的行为未定义。

```csharp
public SVGPoint CurrentTranslate { get; }
```

### Property Value

当前平移。

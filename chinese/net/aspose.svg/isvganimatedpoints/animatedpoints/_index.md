## ISVGAnimatedPoints.AnimatedPoints property

提供对 ‘points’ 属性当前动画内容的访问。如果给定的属性或属性正在动画中，则包含该属性或属性的当前动画值。如果给定的属性或属性当前未动画，则包含与 points 相同的值。

```csharp
public SVGPointList AnimatedPoints { get; }
```

### Property Value

动画后的点。

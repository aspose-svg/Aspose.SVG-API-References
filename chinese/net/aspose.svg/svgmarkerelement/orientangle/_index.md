## SVGMarkerElement.OrientAngle property

对应给定 ‘marker’ 元素的属性 ‘orient’。如果 markerUnits 为 SVG_MARKER_ORIENT_ANGLE，则为属性 ‘orient’ 的角度值；否则，将设置为零。

```csharp
public SVGAnimatedAngle OrientAngle { get; }
```

### Property Value

给定 ‘marker’ 元素的属性 ‘orient’。

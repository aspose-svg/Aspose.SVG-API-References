## KeyboardEvent.AltKey property

如果 Alt（替代）键（或 “Option” 键）修饰键处于激活状态，则为 true。该属性未初始化时的值必须为 false。

```csharp
public bool AltKey { get; }
```

### Property Value

`true` 如果是 Alt；否则为 `false`。

## KeyboardEvent.CtrlKey property

如果 Control（控制）键修饰键处于激活状态，则为 true。该属性未初始化时的值必须为 false。

```csharp
public bool CtrlKey { get; }
```

### Property Value

`true` 如果是 Control；否则为 `false`。

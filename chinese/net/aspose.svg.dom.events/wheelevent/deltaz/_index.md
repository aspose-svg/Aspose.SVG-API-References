## WheelEvent.DeltaZ property

在默认操作为滚动的用户代理中，值必须是沿 z 轴的测量值（以像素、行或页为单位），用于在事件未被取消的情况下滚动。否则，这是围绕 z 轴的滚轮设备运动的实现特定测量（以像素、行或页为单位）。

public double DeltaZ { get; }

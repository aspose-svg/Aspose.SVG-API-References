## Event.IsTrusted property

isTrusted 属性必须返回其初始化时的值。事件创建时，该属性必须初始化为 false。

```csharp
public bool IsTrusted { get; }
```

### Property Value

`true` 表示此实例是可信的；否则为 `false`。

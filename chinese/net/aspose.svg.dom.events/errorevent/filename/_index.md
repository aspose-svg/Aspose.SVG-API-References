## ErrorEvent.FileName property

filename 属性必须返回其初始化时的值。对象创建时，该属性必须初始化为空字符串。它表示错误最初发生的脚本的绝对 URL。

```csharp
public string FileName { get; }
```

### Property Value

文件名。

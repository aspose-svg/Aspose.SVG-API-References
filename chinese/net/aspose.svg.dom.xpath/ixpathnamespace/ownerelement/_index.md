## IXPathNamespace.OwnerElement property

在请求时命名空间处于作用域内的 [`Element`](../../../aspose.svg.dom/element/)。即使文档更改导致该元素的命名空间超出作用域并且 XPath 再也找不到此节点，返回的命名空间节点也不会改变。

```csharp
public Element OwnerElement { get; }
```

## IXPathResult.InvalidIteratorState property

表示迭代器已失效。如果 `resultType` 为 `UnorderedNodeIterator` 类型或 `OrderedNodeIterator` 类型，并且自返回此结果后文档已被修改，则为 true。

public bool InvalidIteratorState { get; }

```csharp
public void CubicBezierTo(PointF pt1, PointF pt2, PointF pt3)
```

| pt1 | PointF | 第一个点的坐标 |
| pt2 | PointF | 第二个点的坐标 |
| pt3 | PointF | 第三个点的坐标 |

## SizingType enumeration

表示页面尺寸类型的枚举。

```csharp
public enum SizingType
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| FitContent | `0` | 更改页面的给定尺寸以适应其包含的内容尺寸。 |
| ScaleContent | `1` | 根据页面的给定尺寸缩放内容大小。 |
| Contain | `2` | 在尽可能保持首选宽高比的情况下，将内容尺寸适配到页面尺寸。 |
| Crop | `3` | 将内容放置在页面上，并裁剪超出给定页面尺寸的所有部分。 |

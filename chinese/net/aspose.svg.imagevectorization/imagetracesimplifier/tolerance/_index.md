## ImageTraceSimplifier.Tolerance property

容差值决定了允许从跟踪中消除点的最大误差容限。该值必须在 0 到 4 的范围内。任何超出此范围的值将相应地对齐到该范围的最小值或最大值。默认值为 0.3。

```csharp
public float Tolerance { get; set; }
```

## IUserAgentService.Language property

The `Language` 指定元素内容以及任何元素属性中包含文本的主要语言。其值必须是有效的 BCP 47 语言标签，或空字符串。将属性设置为空字符串表示主要语言未知。

```csharp
public string Language { get; set; }
```

### Property Value

用户代理语言。

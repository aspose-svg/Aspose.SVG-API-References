## IRuntimeService.JavaScriptTimeout property

获取或设置限制 JavaScript 执行时间的 TimeSpan。如果脚本执行时间超过提供的 TimeSpan，将被取消。您可以通过将 TimeSpan 设置为 -1 毫秒来指定无限超时。默认值为 1 分钟。

```csharp
public TimeSpan JavaScriptTimeout { get; set; }
```

## NodeFilter.SHOW_ATTRIBUTE field

显示属性节点。仅在以属性节点作为根创建迭代器或树遍历器时才有意义；在这种情况下，表示属性节点将在迭代或遍历的首位出现。由于属性永远不是其他节点的子节点，在遍历文档树时它们不会出现。

```csharp
public const long SHOW_ATTRIBUTE;
```

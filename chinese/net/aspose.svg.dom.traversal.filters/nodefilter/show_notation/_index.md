## NodeFilter.SHOW_NOTATION field

显示 Notation 节点。仅在使用 Notation 节点作为根创建迭代器或树遍历器时才有意义；在这种情况下，这意味着 Notation 节点将在遍历的第一个位置出现。由于符号不是文档树的一部分，它们在遍历文档树时不会出现。

```csharp
public const long SHOW_NOTATION;
```

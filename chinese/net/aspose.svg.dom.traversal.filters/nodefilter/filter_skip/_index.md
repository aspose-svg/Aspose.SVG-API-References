## NodeFilter.FILTER_SKIP field

跳过此单个节点。为 NodeIterator 或 TreeWalker 定义的导航方法将不会返回此节点。对于 NodeIterator 和 TreeWalker，仍会考虑该节点的子节点。

```csharp
public const short FILTER_SKIP;
```

## NodeFilter.FILTER_REJECT field

拒绝该节点。为 NodeIterator 或 TreeWalker 定义的导航方法将不会返回此节点。对于 TreeWalker，该节点的子节点也将被拒绝。NodeIterator 将其视为 FILTER_SKIP 的同义词。

```csharp
public const short FILTER_REJECT;
```

## ICSSStyleDeclaration.CSSText property

声明块的可解析文本表示（不包括外围的大括号）。设置此属性将导致解析新值并重置声明块中的所有属性，包括属性的删除或添加。

```csharp
public string CSSText { get; set; }
```

### Property Value

CSS 文本。

## ICSSStyleDeclaration.GetPropertyCSSValue method

用于检索在此声明块中显式设置的 CSS 属性值的对象表示。如果属性是简写属性，则此方法返回 null。简写属性的值只能通过字符串访问和修改，使用 getPropertyValue 和 setProperty 方法。

```csharp
public CSSValue GetPropertyCSSValue(string propertyName)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| propertyName | String | 属性的名称。 |

### 返回值

返回属性值

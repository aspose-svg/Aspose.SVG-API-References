## ICSSRule.ParentRule property

如果此规则包含在另一个规则内部（例如位于 @media 块中的样式规则），则它是包含该规则的规则。如果此规则未嵌套在任何其他规则中，则返回 null。

```csharp
public ICSSRule ParentRule { get; }
```

## ICSSStyleSheet.OwnerRule property

如果此样式表来自 @import 规则，ownerRule 属性将包含 CSSImportRule。在这种情况下，StyleSheet 接口中的 ownerNode 属性将为 null。如果样式表来自元素或处理指令，ownerRule 属性将为 null，ownerNode 属性将包含 Node。

```csharp
public ICSSRule OwnerRule { get; }
```

## ICSSKeyframesRule.DeleteRule method

deleteRule 方法会删除具有给定键的 CSSKeyframeRule。如果不存在具有该键的规则，方法不执行任何操作。

```csharp
public void DeleteRule(string key)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| key | String | 描述待删除规则的键。键必须解析为 0 到 1 之间的数值，否则该规则将被忽略。 |

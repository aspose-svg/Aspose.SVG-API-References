## ICSSKeyframesRule.FindRule method

findRule 方法返回键与给定键匹配的规则。如果不存在此类规则，则返回 null 值。

```csharp
public ICSSKeyframeRule FindRule(string key)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| key | String | 描述待查找规则的键。键必须解析为 0 到 1 之间的数值，否则该规则将被忽略。 |

### 返回值

找到的规则

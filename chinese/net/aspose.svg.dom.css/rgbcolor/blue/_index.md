## RGBColor.Blue property

获取此 Color 类的 blue 分量值。

```csharp
public CSSPrimitiveValue Blue { get; }
```

### Property Value

此 Color 的蓝色分量值。

## 备注

每个像素的颜色表示为一个 32 位数字：alpha、红、绿、蓝各占 8 位（ARGB）。alpha 分量指定颜色的透明度：0 表示完全透明，255 表示完全不透明。同样，A 值为 255 表示不透明颜色。A 值在 1 到 254 之间表示半透明颜色。随着 A 接近 255，颜色变得更不透明。

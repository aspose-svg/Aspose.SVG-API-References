## ILinkStyle interface

LinkStyle 接口提供了一种机制，可从负责将样式表链接到文档的节点检索该样式表。可以通过在链接节点（DOM Level 2 中的 HTMLLinkElement、HTMLStyleElement 或 ProcessingInstruction）的实例上使用特定绑定的强制转换方法来获取 LinkStyle 接口的实例。

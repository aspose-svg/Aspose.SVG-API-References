## IWindow.Parent property

浏览上下文 b 中 Document 的 Window 对象的 parent IDL 属性必须返回父浏览上下文的 WindowProxy 对象（如果存在，即 b 为子浏览上下文），否则返回浏览上下文 b 本身的 WindowProxy 对象（即它是顶层浏览上下文或已分离的嵌套浏览上下文）。

```csharp
public IWindow Parent { get; }
```

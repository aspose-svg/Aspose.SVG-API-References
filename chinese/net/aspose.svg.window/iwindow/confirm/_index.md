## IWindow.Confirm method

显示带有给定消息的模态 OK/Cancel 提示框，等待用户关闭，并在用户点击 OK 时返回 true，点击 Cancel 时返回 false。

```csharp
public bool Confirm(string message)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| 要发送的 message。 | String | 消息。 |

### 返回值

如果用户点击 OK 则返回 true，点击 Cancel 则返回 false。

## DOMTokenList.Replace method

用新标记替换已有的标记。如果第一个标记不存在，则不执行任何操作。

```csharp
public bool Replace(string token, string newToken)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| token | String | 您想要替换的标记。 |
| newToken | String | 您想要用来替换旧标记的标记。 |

### 返回值

如果找到并替换了标记，则为 Boolean `true`，否则为 `false`。

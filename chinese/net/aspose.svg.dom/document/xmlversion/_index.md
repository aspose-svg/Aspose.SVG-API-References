## Document.XmlVersion property

一个属性，作为 XML 声明的一部分，指定此文档的版本号。如果没有声明且文档支持 "XML" 功能，则值为 "1.0"。如果文档不支持 "XML" 功能，则值始终为 null。

```csharp
public string XmlVersion { get; set; }
```

### Property Value

XML 版本。

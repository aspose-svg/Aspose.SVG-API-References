## Document.DefaultView property

Document 接口的 defaultView IDL 属性，在获取时必须返回该 Document 所关联的浏览上下文的 WindowProxy 对象；如果该 Document 没有关联的浏览上下文，则返回 null。

```csharp
public IWindow DefaultView { get; }
```

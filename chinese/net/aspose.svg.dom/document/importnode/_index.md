## Document.ImportNode method

```csharp
public Node ImportNode(Node importedNode, bool deep)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| importedNode | Node | 导入的节点。 |
| deep | Boolean | 如果设置为 `true` [deep]。 |

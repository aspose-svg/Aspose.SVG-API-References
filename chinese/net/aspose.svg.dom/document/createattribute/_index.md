## Document.CreateAttribute method

此方法创建一个新的属性节点，并返回它。创建的对象是实现 [`Attr`](../../attr/) 类的节点。DOM 不强制限制以这种方式可以添加到特定元素的属性类型。

```csharp
public Attr CreateAttribute(string localName)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| localName | String | localName 是一个包含属性名称的字符串。 |

### 返回值

一个 [`Attr`](../../attr/) 节点。

## DOMException.VALIDATION_ERR field

如果对 insertBefore 或 removeChild 等方法的调用会导致节点在“部分有效性”方面无效，则会抛出此异常，且操作不会完成。此代码用于 [DOM Level 3 Validation]。有关更多信息，请参阅此规范。

```csharp
public const ushort VALIDATION_ERR;
```

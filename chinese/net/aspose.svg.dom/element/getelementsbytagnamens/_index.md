## Element.GetElementsByTagNameNS method

返回 [`HTMLCollection`](../../../aspose.svg.collections/htmlcollection/) 对象，包含文档顺序中具有给定本地名称和命名空间 URI 字符串的所有 [`elements`](../)。

```csharp
public HTMLCollection GetElementsByTagNameNS(string namespaceURI, string localName)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| namespaceURI | String | 命名空间 URI 字符串表示。 |
| localName | String | 本地名称的字符串表示。 |

### 返回值

一个实时的[`HTMLCollection`](../../../aspose.svg.collections/htmlcollection/)，包含找到的元素。

## 备注

请参阅官方 [spec](https://dom.spec.whatwg.org/#dom-element-getelementsbytagnamens)。

## Element.LocalName property

返回此节点的限定名称的本地部分。对于除 ELEMENT_NODE 和 ATTRIBUTE_NODE 之外的任何类型的节点，以及使用 DOM Level 1 方法（如 Document.createElement()）创建的节点，此值始终为 null。

```csharp
public override string LocalName { get; }
```

### Property Value

本地的名称。

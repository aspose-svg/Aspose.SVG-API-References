## Attr.TextContent property

此属性返回该节点及其后代的文本内容。当其被定义为 null 时，设置它不会产生任何效果。设置时，节点可能拥有的所有子节点都会被移除，如果新字符串非空且非 null，则会被一个包含该字符串的单一 Text 节点所取代。

```csharp
public override string TextContent { get; set; }
```

### Property Value

文本的内容。

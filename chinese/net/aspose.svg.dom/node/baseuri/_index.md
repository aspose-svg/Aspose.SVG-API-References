## Node.BaseURI property

返回包含该节点的文档的绝对基础 URL。

基础 URL 用于在浏览器需要获取绝对 URL 时解析相对 URL，例如在处理 HTML img 元素的 src 属性或 SVG 中的 xlink:href 或 href 属性时。

```csharp
public virtual string BaseURI { get; }
```

### Property Value

baseURI getter 返回此节点文档的文档基础 URL（已序列化）。

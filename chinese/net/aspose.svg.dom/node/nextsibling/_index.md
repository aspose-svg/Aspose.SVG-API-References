## Node.NextSibling property

返回在其父节点的 [`ChildNodes`](../childnodes/) 中紧随指定节点之后的节点，或者如果指定节点是父元素的最后一个子节点，则返回 null。

```csharp
public Node NextSibling { get; }
```

### Property Value

一个表示当前节点的下一个兄弟节点的 [`Node`](../)，如果不存在则为 null。

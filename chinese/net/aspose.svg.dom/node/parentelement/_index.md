## Node.ParentElement property

返回 DOM 节点的父 [`Element`](../../element/)，如果节点没有父节点，或其父节点不是 DOM Element，则返回 null。

```csharp
public Element ParentElement { get; }
```

### Property Value

一个 [`Element`](../../element/)，它是当前节点的父元素，如果不存在则为 null。

## Node.FirstChild property

返回节点在树中的第一个子节点，如果节点没有子节点则返回 null。

如果节点是 Document，则此属性返回其直接子节点列表中的第一个节点。

```csharp
public Node FirstChild { get; }
```

### Property Value

一个 [`Node`](../)，如果没有则为 null。

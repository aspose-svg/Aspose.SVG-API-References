## Node.PreviousSibling property

返回在其父节点的 [`ChildNodes`](../childnodes/) 列表中紧邻指定节点之前的节点，如果指定节点是列表中的第一个，则返回 null。

```csharp
public Node PreviousSibling { get; }
```

### Property Value

一个 [`Node`](../)，表示当前节点的前一个兄弟节点，如果不存在则为 null。

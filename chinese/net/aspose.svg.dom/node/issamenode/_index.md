## Node.IsSameNode method

该方法是 === 严格相等运算符的旧别名。即，它测试两个节点是否相同（换句话说，它们是否引用同一对象）。

注意：无需使用 `IsSameNode`；请改用 === 严格相等运算符。

```csharp
public bool IsSameNode(Node otherNode)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| otherNode | Node | 用于测试的节点。 |

### 返回值

布尔值，如果两个节点严格相等则为 true，否则为 false。

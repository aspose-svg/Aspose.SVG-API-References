## Node.ChildNodes property

返回给定元素的子节点的实时 [`NodeList`](../../../aspose.svg.collections/nodelist/)，其中第一个子节点的索引为 0。子节点包括元素、文本和注释。

注意：[`NodeList`](../../../aspose.svg.collections/nodelist/) 为实时的意味着每次添加或删除子节点时，其内容都会改变。

```csharp
public NodeList ChildNodes { get; }
```

### Property Value

一个实时的 [`NodeList`](../../../aspose.svg.collections/nodelist/)，包含该节点的子节点。

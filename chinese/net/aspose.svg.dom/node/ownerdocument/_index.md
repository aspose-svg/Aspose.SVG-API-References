## Node.OwnerDocument property

返回该节点的顶层文档对象。

```csharp
public virtual Document OwnerDocument { get; }
```

### Property Value

一个 [`Document`](../../document/)，它是创建所有子节点的顶层对象。

如果在本身就是文档的节点上使用此属性，则值为 null。

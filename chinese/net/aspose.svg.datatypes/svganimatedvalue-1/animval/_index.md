## SVGAnimatedValue<T>.AnimVal property

如果给定的属性或属性正在进行动画，则包含该属性或属性的当前动画值。如果给定的属性或属性当前未进行动画，则包含与 baseVal 相同的值。

```csharp
public virtual T AnimVal { get; }
```

### Property Value

`true` 如果 [anim value]；否则为 `false`。

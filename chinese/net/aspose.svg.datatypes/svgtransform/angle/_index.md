## SVGTransform.Angle property

一个用于 SVG_TRANSFORM_ROTATE、SVG_TRANSFORM_SKEWX 和 SVG_TRANSFORM_SKEWY 的便利属性。它保存指定的角度。对于 SVG_TRANSFORM_MATRIX、SVG_TRANSFORM_TRANSLATE 和 SVG_TRANSFORM_SCALE，角度将为零。

```csharp
public float Angle { get; }
```

### Property Value

指定的角度。

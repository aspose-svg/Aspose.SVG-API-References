## AnimationFill enumeration

指定动画在执行前后的行为。

```csharp
public enum AnimationFill
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Freeze | `0` | 动画将在动画结束时应用属性值。 |
| Remove | `1` | 动画在执行完毕后将不再应用任何值。 |

## 备注

SVG 动画中的 'fill' 属性控制动画在执行时间之外应用的值。此枚举提供了控制这些行为的选项。

## WhiteSpace enumeration

指定 SVG 元素内部空白的处理方式。

```csharp
public enum WhiteSpace
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Normal | `0` | 空白被折叠；换行符会创建新行。 |
| Pre | `1` | 空白被保留；文本仅在包含换行符的地方换行。 |
| NoWrap | `2` | 空白被折叠；文本不换行。 |
| PreWrap | `3` | 空白被保留；文本在必要时以及在换行符处换行。 |
| BreakSpaces | `4` | 空白被保留；添加换行以填充行框。 |
| PreLine | `5` | 空白被保留；文本在必要时换行，但不使用换行符。 |

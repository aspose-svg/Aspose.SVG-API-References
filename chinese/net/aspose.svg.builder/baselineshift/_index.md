## BaseLineShift enumeration

指定 SVG 中元素相对于其基线的垂直位置。

```csharp
public enum BaseLineShift
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Sub | `0` | 将元素的基线与父级文本的下标基线对齐。 |
| Super | `1` | 将元素的基线与父级文本的上标基线对齐。 |
| Top | `2` | 将元素的顶部与行框的顶部对齐。 |
| Center | `3` | 将元素在行框中居中。 |
| Bottom | `4` | 将元素的底部与行框的底部对齐。 |

## 备注

SVG 中的 'baseline-shift' 属性用于调整元素相对于其基线的垂直位置，这在文本渲染中尤为有用。此枚举提供了多种基线偏移选项，以实现不同的文本效果。

## CompositingOperator enumeration

指定在 SVG 遮罩操作中应用的合成操作类型。

```csharp
public enum CompositingOperator
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Add | `0` | 将源图形的颜色值添加到目标图形。 |
| Subtract | `1` | 从目标图形中减去源图形的颜色值。 |
| Intersect | `2` | 仅显示源图形和目标图形重叠的区域。 |
| Exclude | `3` | 排除源图形和目标图形的重叠区域。 |

## 备注

SVG 蒙版中的合成运算符决定不同图形元素如何组合以创建蒙版效果。每个运算符定义了一种独特的混合或组合方式，以实现各种蒙版效果。

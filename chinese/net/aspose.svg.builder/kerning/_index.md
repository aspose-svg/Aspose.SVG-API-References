## Kerning enumeration

指定 SVG 中文本的字距行为。

```csharp
public enum Kerning
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Auto | `0` | 允许浏览器决定是否应应用字距调整。 |
| Normal | `1` | 应用字体文件中定义的标准字距调整。 |
| None | `2` | 禁用字距调整，忽略字体中的任何字距信息。 |

## 备注

SVG 中的 'font-kerning' 属性控制字体中存储的字距信息的使用。字距调整通过调节字母对之间的间距来提升文本的视觉效果。此枚举提供了控制 SVG 文本元素字距行为的选项。

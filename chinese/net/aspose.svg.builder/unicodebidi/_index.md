## UnicodeBidi enumeration

指定 SVG 中双向文本的处理方式。

```csharp
public enum UnicodeBidi
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Normal | `0` | 普通双向文本处理。 |
| Embed | `1` | 嵌入具有不同或明确方向性的文本段落。 |
| Isolate | `2` | 将文本段落与其周围环境隔离，以进行双向文本处理。 |
| BidiOverride | `3` | 覆盖文本段落中字符的固有方向性。 |
| IsolateOverride | `4` | 隔离文本段落并覆盖其方向性。 |
| Plaintext | `5` | 将文本段落视为纯文本，不进行特殊的双向处理。 |

## DisplayType enumeration

指定 SVG 文档中元素的显示行为。

```csharp
public enum DisplayType
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Inline | `0` | 该元素生成一个或多个内联框。 |
| Block | `1` | 该元素生成一个块级框。 |
| ListItem | `2` | 该元素为内容生成块级框，并生成一个单独的列表项内联框。 |
| InlineBlock | `3` | 该元素为内容生成块级框，并为容器生成一个内联框。 |
| Table | `4` | 该元素的行为类似于表格元素。 |
| InlineTable | `5` | 该元素的行为类似于内联表格。 |
| TableRowGroup | `6` | 该元素的行为类似于表格行组。 |
| TableHeaderGroup | `7` | 该元素的行为类似于表格头部组。 |
| TableFooterGroup | `8` | 该元素的行为类似于表格页脚组。 |
| TableRow | `9` | 该元素的行为类似于表格行。 |
| TableColumnGroup | `10` | 该元素的行为类似于表格列组。 |
| TableColumn | `11` | 该元素的行为类似于表格列。 |
| TableCell | `12` | 该元素的行为类似于表格单元格。 |
| TableCaption | `13` | 该元素的行为类似于表格标题。 |
| None | `14` | 该元素不生成任何框，也不渲染。它不影响布局。 |
| Flex | `15` | 该元素的行为类似于弹性容器。 |
| InlineFlex | `16` | 该元素的行为类似于内联弹性容器。 |
| Grid | `17` | 该元素的行为类似于网格容器。 |
| InlineGrid | `18` | 该元素的行为类似于内联网格容器。 |

## 备注

SVG 和 CSS 中的 'display' 属性决定元素在文档布局中的显示方式。此枚举提供了多种设置显示类型的选项，影响元素的渲染方式以及与布局的交互。

## PointerEvents enumeration

指定 SVG 中图形元素的指针事件处理方式。

```csharp
public enum PointerEvents
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| BoundingBox | `0` | 指针事件的目标是元素的边界框。 |
| VisiblePainted | `1` | 指针事件仅针对元素的可见（已绘制）部分。 |
| VisibleFill | `2` | 指针事件仅针对元素的可见（已填充）部分。 |
| VisibleStroke | `3` | 指针事件仅针对元素的可见（已描边）部分。 |
| Visible | `4` | 指针事件的目标是元素的所有可见部分。 |
| Painted | `5` | 指针事件的目标是元素的所有已绘制部分，包括填充和描边。 |
| Fill | `6` | 指针事件仅针对元素的已填充部分。 |
| Stroke | `7` | 指针事件仅针对元素的已描边部分。 |
| All | `8` | 指针事件的目标是元素的所有部分，无论是否可见。 |
| None | `9` | 该元素不会成为指针事件的目标。 |

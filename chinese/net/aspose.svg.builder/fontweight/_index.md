## FontWeight enumeration

指定 SVG 文本元素的不同字体粗细。

```csharp
public enum FontWeight
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Normal | `0` | 表示普通字体粗细，即默认粗细。 |
| Bold | `1` | 表示粗体字体粗细，通常用于强调。 |
| Bolder | `2` | 表示比父元素粗细更粗的字体粗细。 |
| Lighter | `3` | 表示比父元素粗细更细的字体粗细。 |
| W100 | `4` | 表示 100 级字体粗细，是最细的可用粗细。 |
| W200 | `5` | 表示 200 级字体粗细。 |
| W300 | `6` | 表示 300 的字体粗细。 |
| W400 | `7` | 表示 400 的字体粗细，相当于“normal”。 |
| W500 | `8` | 表示 500 的字体粗细。 |
| W600 | `9` | 表示 600 的字体粗细。 |
| W700 | `10` | 表示 700 的字体粗细，相当于“bold”。 |
| W800 | `11` | 表示 800 的字体粗细。 |
| W900 | `12` | 表示 900 的字体粗细，是可用的最粗。 |

## Rotate enumeration

指定在 SVG 中元素在运动动画期间的旋转行为。

```csharp
public enum Rotate
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Auto | `0` | 自动沿路径方向旋转元素。 |
| AutoReverse | `1` | 自动沿路径方向旋转元素并允许其反向。 |

## 备注

SVG 的 'animateMotion' 元素中的 'rotate' 属性控制元素沿运动路径的旋转。此枚举提供了元素在沿路径移动时应如何旋转的选项。

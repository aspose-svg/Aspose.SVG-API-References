## SVGStyleElementBuilder.Media method

设置 SVG 'style' 元素的 'media' 属性。此属性指定样式所针对的媒体，使样式能够根据媒体类型进行条件化。

```csharp
public SVGStyleElementBuilder Media(string mediaDescriptors)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| mediaDescriptors | String | 媒体描述符字符串（例如 \"screen\"、\"print\"）。 |

### 返回值

用于链式调用的 SVGStyleElementBuilder 实例。

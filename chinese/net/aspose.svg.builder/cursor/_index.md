## Cursor enumeration

定义 SVG 元素的光标类型，允许在悬停这些元素时自定义光标外观。

```csharp
public enum Cursor
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Auto | `0` | 浏览器根据当前上下文决定显示的光标。 |
| Default | `1` | 默认光标，通常是箭头。 |
| None | `2` | 不显示光标。 |
| ContextMenu | `3` | 光标指示可用上下文菜单。 |
| Help | `4` | 光标指示有帮助信息可用。 |
| Pointer | `5` | 光标指示可点击的元素，通常为手形指针。 |
| Progress | `6` | 光标指示正在进行的操作或任务。 |
| Wait | `7` | 光标指示系统繁忙，请用户等待。 |
| Cell | `8` | 光标指示单元格或表格元素。 |
| Crosshair | `9` | 光标指示精确选择，通常为十字准星。 |
| Text | `10` | 光标指示文本选择。 |
| VerticalText | `11` | 光标指示垂直文本选择。 |
| Alias | `12` | 光标指示正在创建别名或快捷方式。 |
| Copy | `13` | 光标指示复制操作。 |
| Move | `14` | 光标指示可移动的项目或区域。 |
| NoDrop | `15` | 光标指示不允许放置。 |
| NotAllowed | `16` | 光标指示不允许此操作。 |
| Grab | `17` | 光标指示可抓取项目。 |
| Grabbing | `18` | 光标指示项目正在被抓取。 |
| EResize | `19` | 光标指示向东调整大小。 |
| NResize | `20` | 光标指示向北调整大小。 |
| NEResize | `21` | 光标指示向东北调整大小。 |
| NWResize | `22` | 光标指示向西北调整大小。 |
| SResize | `23` | 光标指示向南调整大小。 |
| SEResize | `24` | 光标指示向东南调整大小。 |
| SWResize | `25` | 光标指示向西南调整大小。 |
| WResize | `26` | 光标指示向西调整大小。 |
| EWResize | `27` | 光标指示东西方向调整大小。 |
| NSResize | `28` | 光标指示南北方向调整大小。 |
| NESWResize | `29` | 光标指示东北-西南方向的调整大小。 |
| NWSeResize | `30` | 光标指示西北-东南方向的调整大小。 |
| ColResize | `31` | 光标指示列的调整大小。 |
| RowResize | `32` | 光标指示行的调整大小。 |
| AllScroll | `33` | 光标指示全方向滚动。 |
| ZoomIn | `34` | 光标指示放大功能。 |
| ZoomOut | `35` | 光标指示缩小功能。 |

## 备注

此枚举提供了一系列可应用于 SVG 元素的光标样式。这些样式有助于指示可用的交互类型或光标所在元素的状态。

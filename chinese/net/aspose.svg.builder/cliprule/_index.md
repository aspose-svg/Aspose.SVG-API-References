## ClipRule enumeration

定义在 SVG 图形中如何裁剪路径的规则。

```csharp
public enum ClipRule
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Nonzero | `0` | 非零环绕规则用于裁剪路径。 |
| Evenodd | `1` | 奇偶环绕规则用于裁剪路径。 |

## 备注

SVG 中的 clip rule 属性决定路径的裁剪方式。当路径自相交或多个路径组合时，这一点尤为重要。该规则帮助决定路径的哪些部分是 \"内部\" 并应填充（或可见），哪些部分是 \"外部\" 并应被裁剪（或不可见）。

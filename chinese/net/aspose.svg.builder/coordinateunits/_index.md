## CoordinateUnits enumeration

指定各种 SVG 元素（如遮罩、绘画服务器和滤镜）的坐标系统单位。

```csharp
public enum CoordinateUnits
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| UserSpaceOnUse | `0` | 对 SVG 元素使用用户坐标系统。 |
| ObjectBoundingBox | `1` | 对 SVG 元素使用对象的边界框。 |

## 备注

坐标单位决定在不同 SVG 环境中如何解释数值。它们可以设置为使用用户空间坐标，或相对于对象的边界框。

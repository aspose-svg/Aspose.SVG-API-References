## AlignmentBaseline enumeration

指定 SVG 中文本和其他行内内容的对齐基线。

```csharp
public enum AlignmentBaseline
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Baseline | `0` | 将盒子的基线与父盒子的基线对齐。 |
| TextBottom | `1` | 将盒子的底部与父元素内容区域的底部对齐。 |
| Middle | `2` | 将盒子的中部与父元素内容区域的中部对齐。 |
| Central | `3` | 将盒子的中心基线与父盒子的中心基线对齐。 |
| TextTop | `4` | 将盒子的顶部与父元素内容区域的顶部对齐。 |
| Ideographic | `5` | 将盒子的表意基线与父元素的表意基线对齐。 |
| Alphabetic | `6` | 将盒子的字母基线与父元素的字母基线对齐。 |
| Mathematical | `7` | 将盒子的数学基线与父元素的数学基线对齐。 |

## 备注

‘alignment-baseline’属性在 CSS 行布局模块 3 规范中定义。SVG 2 对该属性的定义进行了更改。

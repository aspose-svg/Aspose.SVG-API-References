## ColorInterpolation enumeration

指定 SVG 元素和滤镜的颜色插值模式。

```csharp
public enum ColorInterpolation
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Auto | `0` | 自动确定颜色插值模式。 |
| SRGB | `1` | 使用标准 RGB 色彩空间（sRGB）进行颜色插值。 |
| LinearRGB | `2` | 使用线性 RGB 色彩空间进行颜色插值。 |

## 备注

SVG 中的颜色插值影响图形元素和滤镜效果中颜色的计算和混合方式。不同的模式会显著影响颜色过渡、渐变以及整体颜色渲染的外观。此设置对于在 SVG 图形中实现期望的视觉效果至关重要。

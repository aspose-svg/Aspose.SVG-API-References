## RepeatStyle enumeration

指定 SVG 中背景图像或图案的重复样式。

```csharp
public enum RepeatStyle
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| RepeatX | `0` | 图像或图案仅水平重复。 |
| RepeatY | `1` | 图像或图案仅垂直重复。 |
| Repeat | `2` | 图像或图案在水平和垂直方向上都重复。 |
| Space | `3` | 图像或图案在不裁剪的情况下尽可能多次重复，剩余空间在图像之间均匀分配。 |
| Round | `4` | 图像或图案被缩放以适配并在不裁剪的情况下重复，保持其宽高比。 |
| NoRepeat | `5` | 图像或图案不重复，只绘制一份图像。 |

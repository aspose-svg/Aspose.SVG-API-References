## ColorRendering enumeration

指定 SVG 元素的颜色渲染模式。

```csharp
public enum ColorRendering
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Auto | `0` | 允许浏览器或查看器选择颜色渲染模式，在速度和质量之间取得平衡。 |
| OptimizeSpeed | `1` | 优先考虑渲染速度，而非颜色精度和视觉质量。 |
| OptimizeQuality | `2` | 优先考虑颜色准确性和视觉质量，而非渲染速度。 |

## 备注

此属性决定颜色的渲染方式，尤其是在处理颜色渐变、图案和图像渲染时。不同的模式会影响颜色渲染过程的性能和质量。

## MorphologyOperator enumeration

指定在 SVG 滤镜中应用的形态学操作类型。

```csharp
public enum MorphologyOperator
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Erode | `0` | 侵蚀图形，使形状变小且边缘更平滑。 |
| Dilate | `1` | 膨胀图形，使形状变大且边缘更明显。 |

## 备注

此枚举在 SVG 滤镜的上下文中用于定义形态学操作的类型。形态学操作用于处理图像中元素的形状和结构，通常用于侵蚀或膨胀图形。

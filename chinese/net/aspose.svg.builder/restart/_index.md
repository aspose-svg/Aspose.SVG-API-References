## Restart enumeration

指定 SVG 动画的重新启动行为。

```csharp
public enum Restart
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Always | `0` | 动画可以在任何时候重新启动，即使它当前正处于活动状态。 |
| WhenNotActive | `1` | 动画只能在未处于活动状态时重新启动。 |
| Never | `2` | 动画一旦开始就无法重新启动；它将运行至完成。 |

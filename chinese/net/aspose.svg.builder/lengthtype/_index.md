## LengthType enumeration

指定 SVG 中长度的计量单位。

```csharp
public enum LengthType
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Number | `1` | 表示没有任何单位的数值。它通常在其他值或默认单位的上下文中解释。 |
| Percentage | `2` | 表示相对于其他值或边界尺寸的百分比值。 |
| Ems | `3` | 表示以 'ems' 为单位的长度，这是一种相对于当前字体大小的可伸缩单位。 |
| Exs | `4` | 表示以 'exs' 为单位的长度， 与当前字体的 x 高度相关。 |
| Px | `5` | 表示以像素为单位的长度，这是一种基于图像数字表示的计量单位。 |
| Cm | `6` | 表示以厘米为单位的长度。 |
| Mm | `7` | 表示以毫米为单位的长度。 |
| In | `8` | 表示以英寸为单位的长度。 |
| Pt | `9` | 表示以点为单位的长度，点是排版中的传统单位。1 点约等于 1/72 英寸。 |
| Pc | `10` | 表示以派卡为单位的长度，派卡是排版测量单位。1 派卡等于 12 点。 |

## 备注

此枚举定义了可用于在 SVG 元素中指定长度的各种单位。这些单位包括像素和厘米等绝对测量，以及百分比和 em 等相对测量。

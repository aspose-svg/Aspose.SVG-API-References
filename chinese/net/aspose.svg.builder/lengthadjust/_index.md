## LengthAdjust enumeration

指定在 SVG 中文本长度的调整方式。

```csharp
public enum LengthAdjust
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Spacing | `0` | 调整字符之间的间距以实现所需的长度。 |
| SpacingAndGlyphs | `1` | 同时调整间距和字形大小以实现所需的长度。 |

## 备注

SVG 文本元素中的 'lengthAdjust' 属性控制在文本必须适应指定长度时如何进行文本缩放。

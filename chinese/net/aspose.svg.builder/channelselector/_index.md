## ChannelSelector enumeration

指定 SVG 滤镜操作中使用的通道选择器。

```csharp
public enum ChannelSelector
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| R | `0` | 选择图像的红色通道。 |
| G | `1` | 选择图像的绿色通道。 |
| B | `2` | 选择图像的蓝色通道。 |
| A | `3` | 选择图像的 Alpha（透明度）通道。 |

## 备注

通道选择器在各种 SVG 滤镜基元中用于定位特定的颜色通道（红、绿、蓝）或图像的 Alpha 通道。这使得在滤镜处理期间能够精确地操作这些通道。

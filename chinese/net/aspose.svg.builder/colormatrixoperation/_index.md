## ColorMatrixOperation enumeration

指定在颜色矩阵滤镜中应用的操作类型。

```csharp
public enum ColorMatrixOperation
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Matrix | `0` | 对颜色数据应用矩阵变换。 |
| Saturate | `1` | 调整图像的饱和度水平。 |
| HueRotate | `2` | 对图像应用色相旋转。 |
| LuminanceToAlpha | `3` | 根据图像的亮度将颜色转换为灰度。 |

## 备注

SVG 中的颜色矩阵过滤器允许对图像的颜色数据进行各种操作。每种操作类型以特定方式操控颜色，提供一系列视觉效果。

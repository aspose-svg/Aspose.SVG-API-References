## CompositeOperator enumeration

指定在 SVG 合成操作中应用的合成操作类型。

```csharp
public enum CompositeOperator
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Over | `0` | 将源图形放置在目标图形之上。 |
| In | `1` | 在源图形与目标图形重叠的区域显示源图形。 |
| Out | `2` | 在源图形未与目标图形重叠的区域显示源图形。 |
| Atop | `3` | 在目标图形之上显示源图形。 |
| Xor | `4` | 在源图形与目标图形不重叠的区域以及相反的情况下显示源图形。 |
| Arithmetic | `5` | 允许自定义算术合成操作。 |

## 备注

SVG 中的合成操作决定了两个图形元素如何合并为单个图像。每个操作符定义了一种独特的混合或组合这些元素的方法。

## EdgeMode enumeration

指定 SVG 中 feConvolveMatrix 滤镜原语的边缘模式。

```csharp
public enum EdgeMode
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Duplicate | `0` | 输入图像会在必要时沿其每个边缘扩展，通过复制输入图像在给定边缘的颜色值。 |
| Wrap | `1` | 输入图像在概念上被包装（或平铺），卷积使用这些包装后的值。这为图像创建了环形拓扑结构。 |
| None | `2` | 未定义边缘模式，滤镜的效果由实现决定。 |

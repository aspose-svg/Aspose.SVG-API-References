## IAttributeSetter.Attribute method

设置或更新 SVG 元素的属性。

```csharp
public void Attribute(string name, string value)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| name | String | 要设置的属性名称。这应该是有效的 SVG 属性名称。 |
| value | String | 要分配给属性的值。该值应为适用于特定 SVG 属性的字符串表示。 |

## 备注

此方法用于在构建过程中动态添加或修改 SVG 元素的属性。通过根据各种条件或输入设置属性，它提供了定义和自定义 SVG 元素的灵活性。

## SVGBuilderExtensions.FormatSvgLengths method

将 double 数组格式化为 SVG 长度的字符串表示。

```csharp
public static string FormatSvgLengths(double[] values, LengthType type)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| values | Double[] | 表示长度的 double 值数组。 |
| type | LengthType | 要使用的长度单位类型（例如，像素）。 |

### 返回值

SVG 长度的格式化字符串。

## 备注

此实用方法用于格式化 SVG 属性的长度值，为每个值附加适当的单位（如 'px'）。

## Overflow enumeration

指定 SVG 元素的溢出行为。

```csharp
public enum Overflow
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Visible | `0` | 超出元素边界的内容是可见的。 |
| Hidden | `1` | 超出元素边界的内容被裁剪且不可见。 |
| Scroll | `2` | 为超出元素边界的内容提供滚动条。 |

## 备注

此枚举控制超出 SVG 元素边界的内容的显示方式。它决定超出内容是可见、被裁剪，还是提供滚动条。

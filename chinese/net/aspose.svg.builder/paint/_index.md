## Paint enumeration

指定 SVG 元素中 fill 和 stroke 属性的绘制选项。

```csharp
public enum Paint
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| None | `0` | 表示不应应用任何绘制。 |
| ContextFill | `1` | 使用当前上下文的填充颜色进行绘制。 |
| ContextStroke | `2` | 使用当前上下文的描边颜色进行绘制。 |

## 备注

此枚举定义了可以应用于 SVG 元素的 fill 和 stroke 属性的绘制类型。它允许使用标准颜色、基于上下文的填充和描边，或完全不绘制。

## AngleUnits enumeration

指定用于定义 SVG 中标记方向的角度单位。

```csharp
public enum AngleUnits
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Degrees | `0` | 以度数指定角度。完整的圆为 360 度。 |
| Gradians | `1` | 以梯度指定角度。完整的圆为 400 梯度。 |
| Radians | `2` | 以弧度指定角度。完整的圆约为 6.283 弧度（2π 弧度）。 |
| None | `3` | 表示没有特定的角度单位。用于默认或基于上下文的设置。 |

## 备注

SVG 标记的 'orient' 属性可以使用各种角度单位指定。此枚举提供了设置这些单位的选项。

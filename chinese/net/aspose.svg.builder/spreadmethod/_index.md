## SpreadMethod enumeration


### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Pad | `0` | 使用最后一个渐变停点的颜色填充其余的渐变区域。 |
| Reflect | `1` | 渐变在其边界之外被反射（镜像）。 |
| Repeat | `2` | 渐变在其边界之外被重复。 |

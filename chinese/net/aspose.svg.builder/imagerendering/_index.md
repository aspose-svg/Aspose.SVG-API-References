## ImageRendering enumeration

指定在 SVG 中图像的渲染方式。

```csharp
public enum ImageRendering
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Auto | `0` | 浏览器在渲染图像时在速度和质量之间进行权衡。 |
| OptimizeSpeed | `1` | 浏览器更注重渲染速度而非图像质量。这通常意味着对图像进行缩放时可能会出现像素化或块状的效果。 |
| OptimizeQuality | `2` | 浏览器更注重图像质量而非渲染速度。这可能导致图像缩放更平滑、更高质量，但渲染速度可能会变慢。 |

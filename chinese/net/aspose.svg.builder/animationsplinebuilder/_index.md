## AnimationSplineBuilder class

用于使用三次贝塞尔曲线构建动画时间函数的构建器类。此类允许定义一个或多个三次贝塞尔曲线，每条曲线由两个控制点指定。生成的字符串可用于 CSS 动画或过渡，以控制动画的节奏。

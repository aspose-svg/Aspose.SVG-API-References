## IUserAgentService.ShowImagePlaceholders property

Görseller yedek içerik içerebilir: dış kaynak kullanılamadığında (örneğin, desteklenmeyen bir formatta olduğu için) kullanılacak içerik. `ShowImagePlaceholders` özelliği, yedek görüntünün gösterilip gösterilmeyeceğini belirler (varsayılan değer true'tir).

public bool ShowImagePlaceholders { get; set; }

## ToggleAttribute(*string*) {#toggleattribute}

force verilmezse, "toggles" qualifiedName, mevcutsa kaldırır ve mevcut değilse ekler. force true ise qualifiedName'i ekler. force false ise qualifiedName'i kaldırır.

```csharp
public bool ToggleAttribute(string qualifiedName)
```

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| qualifiedName | String | QualifiedName özniteliği. |

### Dönüş Değeri

qualifiedName artık mevcutsa true döndürür; aksi takdirde false.

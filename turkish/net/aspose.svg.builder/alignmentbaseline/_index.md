## AlignmentBaseline enumeration

```csharp
public enum AlignmentBaseline
```

| Ad | Değer | Açıklama |
| --- | --- | --- |

## Açıklamalar

'alignment-baseline' özelliği, CSS Line Layout Module 3 spesifikasyonunda tanımlanmıştır. SVG 2, bu özelliğin tanımında değişiklikler getirir.

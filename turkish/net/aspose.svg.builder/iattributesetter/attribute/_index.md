## IAttributeSetter.Attribute method

Bir SVG öğesinde bir özniteliği ayarlar veya günceller.

```csharp
public void Attribute(string name, string value)
```

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| ad | String | Ayarlanacak özniteliğin adı. Bu geçerli bir SVG öznitelik adı olmalıdır. |
| value | String | Özniteliğe atanacak değer. Değer, belirli SVG özniteliği için uygun bir dize temsili olmalıdır. |

## Açıklamalar

Bu yöntem, yapı sürecinde SVG öğelerinin özniteliklerini dinamik olarak eklemek veya değiştirmek için kullanılır. Özniteliklerin çeşitli koşullara veya girdilere göre ayarlanmasına izin vererek SVG öğelerinin tanımlanması ve özelleştirilmesinde esneklik sağlar.

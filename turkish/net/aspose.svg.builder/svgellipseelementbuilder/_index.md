## SVGEllipseElementBuilder class

SVG 'ellipse' öğesini oluşturmak için Builder sınıfı, bu öğe SVG grafiklerinde elips çizmek için kullanılır. 'ellipse' öğesi içinde içerik oluşturmayı sağlar ve SVG'de 'ellipse' öğesine özgü çeşitli öznitelikleri ayarlama yöntemleri sunar.

```csharp
public class SVGEllipseElementBuilder : SVGElementBuilder<SVGEllipseElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IShapeAttributeSetter, IShapeContentElementBuilder
```

## PathBuilder.Ar method

Yol verisine göreceli bir 'Elliptical Arc Curve' komutu ekler.

```csharp
public PathBuilder Ar(double r1, double r2, double angle, bool largeArcFlag, bool sweepFlag, 
    double x, double y)
```

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| r1 | Double | Mevcut konuma göre elipsin x yarıçapı. |
| r2 | Double | Mevcut konuma göre elipsin y yarıçapı. |
| angle | Double | Mevcut konuma göre elipsin derece cinsinden dönüş açısı. |
| largeArcFlag | Boolean | Arc'in 180 dereceye eşit veya daha büyük olup olmadığını gösteren işaret. |
| sweepFlag | Boolean | Arc'in pozitif açı yönünde çizilip çizilmeyeceğini gösteren işaret. |
| x | Double | Mevcut konuma göre yayının bitiş noktasının x koordinatı. |
| y | Double | Mevcut konuma göre yayının bitiş noktasının y koordinatı. |

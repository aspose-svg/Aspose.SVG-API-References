## SVGBuilderExtensions.FormatSvgLengths method

Çift değerlerden oluşan bir diziyi SVG uzunluklarının dize temsiline dönüştürür.

```csharp
public static string FormatSvgLengths(double[] values, LengthType type)
```

| Parametre | Tür | Açıklama |
| --- | --- | --- |
| values | Double[] | Uzunlukları temsil eden double değerlerinden oluşan dizi. |
| tip | LengthType | Kullanılacak uzunluk birimi türü (ör. piksel). |

### Dönüş Değeri

SVG uzunluklarının biçimlendirilmiş dizesi.

## Açıklamalar

Bu yardımcı metot, SVG öznitelikleri için uzunluk değerlerini biçimlendirmek amacıyla kullanılır; her değere uygun birim (ör. 'px') ekler.

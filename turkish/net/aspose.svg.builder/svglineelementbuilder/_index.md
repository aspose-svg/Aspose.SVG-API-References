## SVGLineElementBuilder class

SVG 'line' öğesini oluşturmak için Builder sınıfı, bu öğe SVG grafiklerinde düz çizgiler çizmek için kullanılır. 'line' öğesi içinde içerik oluşturmayı sağlar ve SVG'de 'line' öğesine özgü çeşitli öznitelikleri ayarlamak için yöntemler sunar.

```csharp
public class SVGLineElementBuilder : SVGElementBuilder<SVGLineElement>, IAnimationElementBuilder, 
    IDescriptiveElementBuilder, IPaintServerElementBuilder, IShapeAttributeSetter, 
    IShapeContentElementBuilder
```

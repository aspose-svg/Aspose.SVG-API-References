## ICSSRuleList indexer

Wird verwendet, um eine CSS‑Regel mit der Methode item() abzurufen (http://www.w3.org/TR/DOM-Level-2-Style/css.html#CSS-CSSRuleList). Die Reihenfolge in dieser Sammlung entspricht der Reihenfolge der Regeln im CSS‑Stylesheet. Wenn der Index größer oder gleich der Anzahl der Regeln in der Liste ist, wird null zurückgegeben.

```csharp
public ICSSRule this[int index] { get; }
```

| Parameter | Beschreibung |
| --- | --- |
| index | Der Regelindex |

### Rückgabewert

Die CSS-Regelinstanz.

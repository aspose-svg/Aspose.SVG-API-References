## ICSSStyleDeclaration.GetPropertyCSSValue method

Wird verwendet, um die Objektrepräsentation des Wertes einer CSS‑Eigenschaft abzurufen, wenn sie innerhalb dieses Deklarationsblocks explizit gesetzt wurde. Diese Methode gibt null zurück, wenn es sich bei der Eigenschaft um eine Kurzschreibweise handelt. Werte von Kurzschreibungs‑Eigenschaften können nur als Zeichenketten abgerufen und geändert werden, wobei die Methoden getPropertyValue und setProperty verwendet werden.

```csharp
public CSSValue GetPropertyCSSValue(string propertyName)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| propertyName | String | Name der Eigenschaft. |

### Rückgabewert

Gibt den Eigenschaftswert zurück.

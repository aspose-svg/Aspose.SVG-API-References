## ICSSStyleDeclaration.CSSText property

Die parsbare Textdarstellung des Deklarationsblocks (ohne die umgebenden geschweiften Klammern). Das Setzen dieses Attributs führt zur Analyse des neuen Wertes und zum Zurücksetzen aller Eigenschaften im Deklarationsblock, einschließlich des Entfernens oder Hinzufügens von Eigenschaften.

```csharp
public string CSSText { get; set; }
```

### Property Value

Der CSS-Text.

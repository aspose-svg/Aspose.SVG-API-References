## ICSSImportRule.StyleSheet property

Das von dieser Regel referenzierte Stylesheet, falls es geladen wurde. Der Wert dieses Attributs ist null, wenn das Stylesheet noch nicht geladen wurde oder nicht geladen wird (z. B. wenn das Stylesheet für einen Medientyp bestimmt ist, der vom User‑Agent nicht unterstützt wird).

public ICSSStyleSheet StyleSheet { get; }

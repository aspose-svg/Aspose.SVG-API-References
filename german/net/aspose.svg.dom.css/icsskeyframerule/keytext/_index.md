## ICSSKeyframeRule.KeyText property

Dieses Attribut stellt den Keyframe‑Selektor als kommagetrennte Liste von Prozentwerten dar. Die Schlüsselwörter ‘from’ und ‘to’ entsprechen ‘0%’ bzw. ‘100%’.

```csharp
public string KeyText { get; }
```

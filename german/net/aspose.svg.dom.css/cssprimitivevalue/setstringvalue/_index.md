## CSSPrimitiveValue.SetStringValue method

Eine Methode, um den Zeichenkettenwert mit der angegebenen Einheit zu setzen. Wenn die mit diesem Wert verbundene Eigenschaft die angegebene Einheit oder den Zeichenkettenwert nicht akzeptieren kann, bleibt der Wert unverändert und es wird eine DOMException ausgelöst.

```csharp
public abstract void SetStringValue(ushort stringType, string stringValue)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| stringType | UInt16 | Typ der Zeichenkette. |
| stringValue | String | Der Zeichenkettenwert. |

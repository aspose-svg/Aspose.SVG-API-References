## CSSValueList.Length property

Die schreibgeschützte Eigenschaft length des CSSValueList-Interfaces gibt die Anzahl der CSSValues in der Liste an. Der gültige Wertebereich der Indizes ist 0 bis length‑1 inklusive.

```csharp
public int Length { get; }
```

### Property Value

Ein int, das die Anzahl der CSSValues in der aktuellen Instanz darstellt.

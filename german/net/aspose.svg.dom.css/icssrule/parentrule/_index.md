## ICSSRule.ParentRule property

Wenn diese Regel innerhalb einer anderen Regel enthalten ist (z. B. eine Stilregel innerhalb eines @media‑Blocks), ist dies die umgebende Regel. Wenn diese Regel nicht in einer anderen Regel verschachtelt ist, wird null zurückgegeben.

public ICSSRule ParentRule { get; }

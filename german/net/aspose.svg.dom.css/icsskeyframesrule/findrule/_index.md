## ICSSKeyframesRule.FindRule method

Die Methode findRule gibt die Regel zurück, deren Schlüssel mit dem übergebenen Schlüssel übereinstimmt. Gibt es keine solche Regel, wird ein Nullwert zurückgegeben.

```csharp
public ICSSKeyframeRule FindRule(string key)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| Taste | String | Der Schlüssel, der die zu findende Regel beschreibt. Der Schlüssel muss zu einer Zahl zwischen 0 und 1 aufgelöst werden, andernfalls wird die Regel ignoriert. |

### Rückgabewert

Die gefundene Regel

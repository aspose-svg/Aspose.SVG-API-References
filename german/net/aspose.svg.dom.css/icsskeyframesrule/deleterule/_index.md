## ICSSKeyframesRule.DeleteRule method

Die Methode deleteRule löscht die CSSKeyframeRule mit dem übergebenen Schlüssel. Existiert keine Regel mit diesem Schlüssel, tut die Methode nichts.

```csharp
public void DeleteRule(string key)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| Taste | String | Der Schlüssel, der die zu löschende Regel beschreibt. Der Schlüssel muss zu einer Zahl zwischen 0 und 1 aufgelöst werden, andernfalls wird die Regel ignoriert. |

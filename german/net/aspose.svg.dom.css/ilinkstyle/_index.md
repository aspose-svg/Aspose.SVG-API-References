## ILinkStyle interface

Die LinkStyle-Schnittstelle bietet einen Mechanismus, mit dem ein Stylesheet von dem Knoten abgerufen werden kann, der für das Verknüpfen in ein Dokument verantwortlich ist. Eine Instanz der LinkStyle-Schnittstelle kann mittels bindungsspezifischer Cast-Methoden auf einer Instanz eines verknüpfenden Knotens (HTMLLinkElement, HTMLStyleElement oder ProcessingInstruction in DOM Level 2) erhalten werden.

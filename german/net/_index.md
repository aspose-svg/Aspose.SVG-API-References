## Namensräume

| Namensraum | Beschreibung |
| --- | --- |
| [Aspose.Svg](./aspose.svg/) | Alle Klassen im **Aspose.Svg.Dom.Svg** Namensraum basieren auf den w3c SVG2-Empfehlungen. Mit diesem Namensraum können Sie die SVG-Datei nach Ihren Anforderungen laden, navigieren oder rendern. |
| [Aspose.Svg.Builder](./aspose.svg.builder/) | Der **Aspose.Svg.Builder** Namensraum enthält Klassen und Schnittstellen zum Erstellen und Manipulieren von SVG (Scalable Vector Graphics)-Dokumenten mithilfe der Aspose.SVG-Bibliothek. Dieser Namensraum bietet einen umfangreichen Satz von Builder‑Klassen, die die Erstellung und Änderung von SVG‑Elementen und deren Attributen vereinfachen. Diese Builder bieten eine fluente API, die den Code lesbarer und wartbarer macht. |
| [Aspose.Svg.Collections](./aspose.svg.collections/) | Der **Aspose.Svg.Collections** Namensraum besteht aus Klassen, die Knoten und Elemente darstellen, speichern und manipulieren. |
| [Aspose.Svg.Converters](./aspose.svg.converters/) | Das Ziel des **Aspose.Svg.Converters** Namensraums ist ein einfacher Zugriff auf Konvertierungsmethoden. Er bietet eine breite Palette von Konvertierungen in gängige Formate wie PDF, XPS, Bildformate usw. Spezifischere Konvertierungs‑ (Render‑, Speicher‑) Anwendungsfälle werden durch bekannte und dokumentierte Low‑Level‑API‑Funktionen in fachorientierten Namensräumen bereitgestellt. |
| [Aspose.Svg.DataTypes](./aspose.svg.datatypes/) | Der Namensraum bietet Zugriff auf alle SVG-spezifischen Datentypen. |
| [Aspose.Svg.Diagnostics](./aspose.svg.diagnostics/) | Der **Aspose.Svg.Diagnostics** Namensraum enthält Schnittstellen zur Arbeit mit Metriken sowie zum Sammeln von Protokollen und Traces. |
| [Aspose.Svg.Dom](./aspose.svg.dom/) | Der **Aspose.Svg.Dom (Document Object Model)** Namensraum stellt eine API bereit, die beliebige HTML-, XML‑ oder SVG‑Dokumente darstellt und mit ihnen interagiert. Das DOM ist ein im Browser geladenes Dokumentenmodell, das das Dokument als Knotbaum darstellt, wobei jeder Knoten einen Teil des Dokuments repräsentiert (z. B. ein Element, eine Textzeichenfolge oder ein Kommentar). |
| [Aspose.Svg.Dom.Attributes](./aspose.svg.dom.attributes/) | Der **Aspose.Svg.Dom.Attributes** Namensraum enthält einheitliche Attributklassen, die Merkmale oder Verhaltensweisen eines beliebigen Objekts (Knoten, Element, …) festlegen oder qualifizieren. |
| [Aspose.Svg.Dom.Css](./aspose.svg.dom.css/) | Der **Aspose.Svg.Dom.Css** Namensraum dient allen CSS‑bezogenen Manipulationen. Er konzentriert sich auf von offiziellen CSS‑Dokumenten festgelegte CSS‑Eigenschafts‑Name‑Wert‑Paare. |
| [Aspose.Svg.Dom.Events](./aspose.svg.dom.events/) | Der **Aspose.Svg.Dom.Events** Namensraum stellt Objekte für alle Ereignisse im Zusammenhang mit DOM‑Aktualisierungen bereit. Er umfasst die Abonnierung spezifischer kontextbezogener Informationsbeobachtungen, die mit einem Ereignis verknüpft sind, sowie die Erstellung benutzerdefinierter Ereignisse. |
| [Aspose.Svg.Dom.Mutations](./aspose.svg.dom.mutations/) | Der **Aspose.Svg.Dom.Mutations** bietet die Möglichkeit, DOM‑Mutationen zu beobachten und spezifische Callback‑Informationen zu erhalten. |
| [Aspose.Svg.Dom.Traversal](./aspose.svg.dom.traversal/) | Der **Aspose.Svg.Dom.Traversal** Namensraum enthält Methoden, die Iteratoren und Baum‑Walker erzeugen, um zwischen Elementen zu navigieren und einen Knoten sowie dessen Kinder in Dokumentreihenfolge zu durchlaufen. |
| [Aspose.Svg.Dom.Traversal.Filters](./aspose.svg.dom.traversal.filters/) | Der Namensraum wird durch die Knoten‑Filterfunktionalität repräsentiert. Filter sind Objekte, die wissen, wie man Knoten „herausfiltert“. Wenn einem Knoten‑Iterator oder Baum‑Walker ein Knoten‑Filter übergeben wird, wendet er den Filter an, bevor er den nächsten Knoten zurückgibt. Gibt der Filter an, den Knoten zu akzeptieren, gibt die Traversallogik ihn zurück; andernfalls sucht die Traversal nach dem nächsten Knoten und tut so, als wäre der abgelehnte Knoten nicht vorhanden. |
| [Aspose.Svg.Dom.Views](./aspose.svg.dom.views/) | **Aspose.Svg.Dom.Views** Namespace beschreibt die AbstractView- und DocumentView-Schnittstellen gemäß der Document Object Model Views-Spezifikation. |
| [Aspose.Svg.Dom.XPath](./aspose.svg.dom.xpath/) | Der **Aspose.Svg.Dom.XPath** Namespace enthält Methoden, um durch Elemente und Attribute in einem XML-Dokument zu navigieren. |
| [Aspose.Svg.Drawing](./aspose.svg.drawing/) | Der **Aspose.Svg.Drawing** Namespace enthält Objekte und Schnittstellen zur Angabe von Messungen und Einheiten sowie Zeichenattribut-Objekte wie Pinsel, Farben und Schriften. |
| [Aspose.Svg.Events](./aspose.svg.events/) | Der Namespace besteht aus Klassen für ereignisbasierte Interaktivität wie Zeitevents und Zoom. |
| [Aspose.Svg.Filters](./aspose.svg.filters/) | Der **Aspose.Svg.Dom.Svg.Filters** Namespace enthält Klassen und Schnittstellen, die sich auf Filtereffekte in der SVG-Spezifikation beziehen. |
| [Aspose.Svg.ImageVectorization](./aspose.svg.imagevectorization/) | Der **Aspose.Svg.ImageVectorization** Namespace enthält Klassen zum Vektorisieren von Rasterbildern und deren Umwandlung in SVG‑Dokumente. Dieser Vorgang beinhaltet das Reduzieren von Bitmaps zu geometrischen Formen, die aus Pfadelementen bestehen, und deren Speicherung als SVG. Der Namespace umfasst Klassen zum Erstellen von Pfadsegmenten, zum Vereinfachen und Glätten von Trace‑Punkten sowie zum Konfigurieren von Vektorisierungsoptionen. |
| [Aspose.Svg.IO](./aspose.svg.io/) | Zusätzlich zu den Standard‑IO (Input‑Output)-Werkzeugen enthält der **Aspose.Svg.IO** Namespace Hilfsklassen und Schnittstellen. |
| [Aspose.Svg.Net](./aspose.svg.net/) | Der **Aspose.Svg.Net** Namespace wird durch Klassen und Schnittstellen bereitgestellt, die für die einfache Netzwerkverarbeitung verantwortlich sind. |
| [Aspose.Svg.Net.Headers](./aspose.svg.net.headers/) | Der **Aspose.Svg.Net.Headers** bietet einige Datenklassen zur Beschreibung von Header‑Inhalten im Netzwerk. |
| [Aspose.Svg.Net.MessageFilters](./aspose.svg.net.messagefilters/) | Der **Aspose.Svg.Net.MessageFilters** Namespace stellt Klassen bereit, die die Nachrichtenfilter‑Abstraktion implementieren. |
| [Aspose.Svg.Net.MessageHandlers](./aspose.svg.net.messagehandlers/) | Der **Aspose.Svg.Net.MessageHandlers** Namespace wird durch Klassen präsentiert – Nachrichten‑Handler verschiedener Protokolle. |
| [Aspose.Svg.Paths](./aspose.svg.paths/) | Der **Aspose.Svg.Dom.Svg.Paths** Namespace beschreibt Klassen zur Darstellung der Kontur einer Form, die gefüllt oder gestrichen werden kann. Ein Pfad kann auch als Beschneidungspfad verwendet werden, um Animationen zu beschreiben oder Text zu positionieren. |
| [Aspose.Svg.Rendering](./aspose.svg.rendering/) | Der **Aspose.Svg.Rendering** Namespace besteht aus zahlreichen Renderer‑Objekten sowie passenden Low‑Level‑Optionen‑Klassen, die für das Rendern von Dokumenten/Dateien in eine IDevice‑Implementierung verantwortlich sind. |
| [Aspose.Svg.Rendering.Fonts](./aspose.svg.rendering.fonts/) | Der **Aspose.Svg.Rendering.Fonts** Namespace enthält Klassen und Methoden, die es ermöglichen, bestimmte Teile des Schriftabgleichs‑Algorithmus zu steuern. |
| [Aspose.Svg.Rendering.Image](./aspose.svg.rendering.image/) | Der **Aspose.Svg.Rendering.Image** Namespace stellt eine spezifische Geräteklasse sowie einige Rendering‑Optionen‑Klassen bereit, die für das Rendern in Rasterformate verantwortlich sind: jpeg, png, bmp, gif, tiff. |
| [Aspose.Svg.Rendering.Pdf](./aspose.svg.rendering.pdf/) | Der **Aspose.Svg.Rendering.Pdf** Namespace stellt eine spezifische Geräteklasse sowie einige Rendering‑Optionen‑Klassen bereit, die für das Rendern in ein PDF‑Dokument verantwortlich sind. |
| [Aspose.Svg.Rendering.Pdf.Encryption](./aspose.svg.rendering.pdf.encryption/) | Der **Aspose.Svg.Rendering.Pdf.Encryption** Namespace enthält Datenklassen, die PDF‑Verschlüsselungsdetails wie Passwort, Verschlüsselungsalgorithmus usw. beschreiben. |
| [Aspose.Svg.Rendering.Xps](./aspose.svg.rendering.xps/) | Der **Aspose.Svg.Rendering.Xps** Namespace stellt eine spezifische Geräteklasse sowie einige Rendering‑Optionen‑Klassen bereit, die für das Rendern in ein XPS‑Dokument verantwortlich sind. |
| [Aspose.Svg.Saving](./aspose.svg.saving/) | Der **Aspose.Svg.Saving** Namespace wird durch Datenklassen präsentiert, die spezifische Speicheroptionen im Konvertierungs‑/Speicherprozess beschreiben. |
| [Aspose.Svg.Saving.ResourceHandlers](./aspose.svg.saving.resourcehandlers/) | Der **Aspose.Svg.Saving.ResourceHandlers** Namespace enthält Klassen, die für die Verarbeitung von Ressourcen verantwortlich sind. |
| [Aspose.Svg.Services](./aspose.svg.services/) | Der **Aspose.Svg.Services** Namespace enthält Schnittstellen als Protokolle für Service-Implementierungen. |
| [Aspose.Svg.Toolkit.Optimizers](./aspose.svg.toolkit.optimizers/) | Der **Aspose.Svg.Toolkit.Optimizers** Namespace enthält Klassen zur Optimierung von SVG-Dokumenten. Der Optimierungsprozess umfasst das Entfernen unbenutzter oder unsichtbarer Elemente und ihrer Attribute, das Zusammenführen von Gruppen und die Reduzierung der Größe von Pfadsegmenten. |
| [Aspose.Svg.Window](./aspose.svg.window/) | Der **Aspose.Svg.Window** Namespace bezieht sich auf das Fensterobjekt, das ein Fenster darstellt, das ein DOM-Dokument enthält. Er enthält Klassen und Schnittstellen, die mit der Adresse des aktiven Dokuments und dem Browserverlauf zusammenhängen. |

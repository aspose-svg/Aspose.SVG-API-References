## ITraversal.WhatToShow property

Dieses Attribut bestimmt, welche Knotentypen über den Iterator präsentiert werden. Die verfügbare Menge an Konstanten ist im NodeFilter interface definiert. Knoten, die von whatToShow nicht akzeptiert werden, werden übersprungen, aber ihre Kinder können weiterhin berücksichtigt werden. Beachten Sie, dass dieses Überspringen Vorrang vor dem Filter hat, falls vorhanden.

```csharp
public long WhatToShow { get; }
```

### Property Value

Das, was angezeigt werden soll.

## ShapeRendering enumeration

Gibt den Formdarstellungsmodus für SVG-Elemente an.

```csharp
public enum ShapeRendering
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Auto | `0` | Der Browser macht Kompromisse zwischen Geschwindigkeit, Glätte und geometrischer Präzision beim Rendern von Formen. |
| OptimizeSpeed | `1` | Der Browser legt mehr Wert auf Rendergeschwindigkeit als auf geometrische Präzision und Glätte. Dieser Modus kann zu schnellerem Rendering, aber weniger genauen Formen führen. |
| CrispEdges | `2` | Der Browser versucht, scharfe Kanten und Ecken beizubehalten. Dieser Modus ist nützlich für das Rendern von Grafiken mit geraden Linien und Kanten. |
| GeometricPrecision | `3` | Der Browser legt beim Rendern Wert auf geometrische Präzision zulasten der Geschwindigkeit. Dieser Modus eignet sich für hochwertige Renderings, bei denen präzise Geometrie wichtig ist. |

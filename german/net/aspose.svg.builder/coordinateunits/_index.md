## CoordinateUnits enumeration

Gibt die Einheiten des Koordinatensystems für verschiedene SVG-Elemente wie Masken, Farbserver und Filter an.

```csharp
public enum CoordinateUnits
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| UserSpaceOnUse | `0` | Verwendet das Benutzerkoordinatensystem für das SVG-Element. |
| ObjectBoundingBox | `1` | Verwendet die Begrenzungsbox des Objekts für das SVG-Element. |

## Hinweise

Die Koordinateneinheiten bestimmen, wie Werte in verschiedenen SVG-Kontexten interpretiert werden. Sie können entweder das Benutzerraumkoordinatensystem verwenden oder relativ zur Begrenzungsbox des Objekts sein.

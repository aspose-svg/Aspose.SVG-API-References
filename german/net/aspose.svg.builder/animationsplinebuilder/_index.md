## AnimationSplineBuilder class

Eine Builder‑Klasse zum Erstellen von Animations‑Timing‑Funktionen mithilfe kubischer Bézier‑Kurven. Diese Klasse ermöglicht die Definition von einer oder mehreren kubischen Bézier‑Kurven, wobei jede durch zwei Kontrollpunkte angegeben wird. Der resultierende String kann in CSS‑Animationen oder -Transitionen verwendet werden, um das Tempo der Animation zu steuern.

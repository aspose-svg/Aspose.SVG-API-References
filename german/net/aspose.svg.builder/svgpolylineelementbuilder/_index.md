## SVGPolylineElementBuilder class

Builder-Klasse zum Erstellen eines SVG 'polyline'-Elements. Das 'polyline'-Element wird verwendet, um eine Reihe gerader Linien zu erzeugen, die mehrere Punkte in SVG-Grafiken verbinden. Diese Klasse bietet Methoden zum Festlegen verschiedener Attribute und zur Animation des 'polyline'-Elements.

```csharp
public class SVGPolylineElementBuilder : SVGElementBuilder<SVGPolylineElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IPointsAttributeSetter, IShapeAttributeSetter, IShapeContentElementBuilder
```

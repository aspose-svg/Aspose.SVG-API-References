## DominantBaseline enumeration

Gibt die dominante Grundlinie an, die zum Ausrichten von Text verwendet wird.

```csharp
public enum DominantBaseline
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Auto | `0` | Bestimmt die dominante Grundlinie automatisch basierend auf der Schriftart und/oder der Sprache. |
| TextBottom | `1` | Richtet den Text am unteren Rand des Em-Quadrats aus. |
| Alphabetic | `2` | Richtet den Text auf der Grundlinie aus, die von alphabetischen Zeichen verwendet wird. |
| Ideographic | `3` | Richtet den Text auf der Grundlinie aus, die von ideografischen Zeichen verwendet wird. |
| Middle | `4` | Richtet den Text in der Mitte des Em-Quadrats aus. |
| Central | `5` | Richtet den Text auf der zentralen Grundlinie des Em-Quadrats aus. |
| Mathematical | `6` | Richtet den Text auf der Grundlinie aus, die von mathematischen Zeichen verwendet wird. |
| Hanging | `7` | Richtet den Text auf der hängenden Grundlinie aus, die typischerweise für tibetische oder andere asiatische Schriften verwendet wird. |
| TextTop | `8` | Richtet den Text am oberen Rand des Em-Quadrats aus. |

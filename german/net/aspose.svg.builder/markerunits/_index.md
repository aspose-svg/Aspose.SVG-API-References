## MarkerUnits enumeration

Gibt das Koordinatensystem für die Markergöße in SVG an.

```csharp
public enum MarkerUnits
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| StrokeWidth | `0` | Die Größe des Markers ist relativ zur Strichbreite des Pfads. |
| UserSpaceOnUse | `1` | Die Größe des Markers basiert auf dem Benutzerkoordinatensystem, wodurch sie unabhängig von der Strichbreite ist. |

## Hinweise

Diese Aufzählung definiert das Koordinatensystem, das zur Berechnung der Größe von Markern in SVG verwendet wird. Sie bestimmt, ob die Markergröße relativ zur Strichbreite oder basierend auf dem Benutzerkoordinatensystem ist.

## SVGDefsElementBuilder class

Builder-Klasse zum Erstellen eines SVG-'defs'-Elements, das zum Definieren wiederverwendbarer Elemente verwendet wird. Sie ermöglicht das Erstellen von Inhalt innerhalb des 'defs'-Elements und stellt Methoden zum Festlegen verschiedener, für das 'defs'-Element in SVG spezifischer Attribute bereit.

```csharp
public class SVGDefsElementBuilder : SVGElementBuilder<SVGDefsElement>, ICompositeElementBuilder, 
    ICoreAttributeSetter, IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, 
    IGraphicalEventAttributeSetter, IPresentationAttributeSetter
```

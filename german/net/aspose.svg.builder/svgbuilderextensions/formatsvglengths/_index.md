## SVGBuilderExtensions.FormatSvgLengths method

Formatiert ein Array von Double-Werten in eine Zeichenkettenrepräsentation von SVG-Längen.

```csharp
public static string FormatSvgLengths(double[] values, LengthType type)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| values | Double[] | Das Array von double-Werten, das Längen darstellt. |
| type | LengthType | Der Typ der zu verwendenden Längeneinheit (z. B. Pixel). |

### Rückgabewert

Eine formatierte Zeichenkette von SVG-Längen.

## Hinweise

Diese Hilfsmethode wird verwendet, um Längenwerte für SVG-Attribute zu formatieren, indem die passende Einheit (wie 'px') an jeden Wert angehängt wird.

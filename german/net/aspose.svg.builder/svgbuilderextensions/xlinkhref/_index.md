## SVGBuilderExtensions.XlinkHref<TBuilder> method

Setzt das Attribut 'xlink:href' für ein SVG-Element. Dieses Attribut wird verwendet, um eine Referenz zu einer Ressource als Link zu definieren.

```csharp
public static TBuilder XlinkHref<TBuilder>(this TBuilder builder, string value)
    where TBuilder : ISVGElementBuilder, IXLinkAttributeSetter
```

| Parameter | Beschreibung |
| --- | --- |
| TBuilder | Der Typ des SVG-Element-Builders. |
| builder | Die Builder-Instanz. |
| value | Der URI der Ressource, zu der verlinkt werden soll. |

### Rückgabewert

Die Builder-Instanz für das Chaining.

## SVGBuilderExtensions.SystemLanguage<TBuilder> method

Setzt das Attribut 'systemLanguage' am SVG-Element. Dieses Attribut gibt die Sprachpräferenzen an, für die das SVG-Dokumentfragment bestimmt ist.

```csharp
public static TBuilder SystemLanguage<TBuilder>(this TBuilder builder, string value)
    where TBuilder : ISVGElementBuilder, IConditionalProcessingAttributeSetter
```

| Parameter | Beschreibung |
| --- | --- |
| TBuilder | Der Typ des SVG-Element-Builders. |
| builder | Der SVG-Element-Builder, an dem das Attribut gesetzt wird. |
| value | Ein String-Wert, der die Sprachpräferenzen darstellt, typischerweise in Form von Sprach-Tags. |

### Rückgabewert

Der ursprüngliche SVG-Element-Builder für Methodenverkettung.

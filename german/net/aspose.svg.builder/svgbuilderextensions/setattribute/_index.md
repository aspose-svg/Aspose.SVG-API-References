## SVGBuilderExtensions.SetAttribute<TBuilder> method

Setzt ein Attribut am SVG-Element. Diese Methode wird verwendet, um ein Attribut des zu erstellenden SVG-Elements hinzuzufügen oder zu ändern.

```csharp
public static TBuilder SetAttribute<TBuilder>(this TBuilder builder, string name, string value)
    where TBuilder : IAttributeSetter
```

| Parameter | Beschreibung |
| --- | --- |
| TBuilder | Der Typ des SVG-Element-Builders. |
| builder | Der SVG-Element-Builder, an dem das Attribut gesetzt wird. |
| name | Der Name des zu setzenden Attributs. |
| value | Der Wert des Attributs. |

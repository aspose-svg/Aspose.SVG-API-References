## FontStyle enumeration

Gibt die verschiedenen Schriftstile für SVG-Text-Elemente an.

```csharp
public enum FontStyle
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Normal | `0` | Stellt den normalen Schriftstil dar, ohne Hervorhebung oder Schrägstellung. |
| Italic | `1` | Stellt einen Schriftstil mit kursiver Darstellung dar, der typischerweise für Hervorhebungen verwendet wird. |
| Oblique | `2` | Stellt einen Schriftstil mit schräger Darstellung dar, ähnlich wie kursiv, jedoch mit weniger ausgeprägter Schrägstellung. |

## MaskBuilder class

Eine Builder‑Klasse zum Erstellen von CSS‑Masken‑Eigenschaften. Diese Klasse ermöglicht die Konstruktion komplexer Masken‑Stile mithilfe verschiedener Eigenschaften wie Masken‑Quelle, Position, Größe, Wiederholungsstil und mehr. Der resultierende String kann in CSS verwendet werden, um das Maskierungsverhalten eines Elements zu definieren.

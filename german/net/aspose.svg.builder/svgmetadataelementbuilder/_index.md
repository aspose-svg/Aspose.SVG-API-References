## SVGMetadataElementBuilder class

Builder-Klasse zum Erstellen eines SVG 'metadata'-Elements, das verwendet wird, um Metadaten zu einem SVG-Dokument hinzuzufügen. Diese Klasse ermöglicht das Hinzufügen von Metadaten-Inhalten und bietet Methoden zum Festlegen verschiedener Attribute, die speziell für das 'metadata'-Element in SVG gelten.

```csharp
public class SVGMetadataElementBuilder : SVGElementBuilder<SVGMetadataElement>, 
    ICoreAttributeSetter, IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, 
    ITextContentSetter
```

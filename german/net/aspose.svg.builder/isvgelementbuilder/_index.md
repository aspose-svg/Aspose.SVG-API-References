## ISVGElementBuilder interface

Schnittstelle zum Erstellen von SVG (Scalable Vector Graphics)-Elementen. Diese Schnittstelle definiert die wesentlichen Methoden und Eigenschaften, die zum programmgesteuerten Erzeugen von SVG-Elementen erforderlich sind. Sie erweitert die IAttributeSetter-Schnittstelle, um Fähigkeiten zum Setzen von Attributen einzuschließen.

```csharp
public interface ISVGElementBuilder : IAttributeSetter
```

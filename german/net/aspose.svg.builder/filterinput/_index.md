## FilterInput enumeration

Gibt vordefinierte Eingabebilder für einen SVG-Filter an.

```csharp
public enum FilterInput
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| SourceGraphic | `0` | Bezieht sich auf das Grafikelement, auf das der Filter angewendet wird. |
| SourceAlpha | `1` | Bezieht sich auf den Alphakanal des Grafikelements, auf das der Filter angewendet wird. |
| BackgroundImage | `2` | Bezieht sich auf das Hintergrundbild, das direkt unter dem Grafikelement liegt, auf das der Filter angewendet wird. |
| BackgroundAlpha | `3` | Bezieht sich auf den Alphakanal des Hintergrundbildes, das direkt unter dem Grafikelement liegt, auf das der Filter angewendet wird. |
| FillPaint | `4` | Bezieht sich auf die Füllfarbe des Grafikelements, auf das der Filter angewendet wird. |
| StrokePaint | `5` | Bezieht sich auf die Konturfarbe des Grafikelements, auf das der Filter angewendet wird. |

## SVGRadialGradientElementBuilder class

Builder-Klasse zum Erstellen eines SVG 'radialGradient'-Elements, das verwendet wird, um einen radialen Farbverlauf innerhalb von SVG-Grafiken zu definieren. Diese Klasse ermöglicht das Erstellen von Inhalten innerhalb des 'radialGradient'-Elements und bietet Methoden zum Festlegen verschiedener Attribute, die speziell für das 'radialGradient'-Element in SVG gelten.

```csharp
public class SVGRadialGradientElementBuilder : SVGElementBuilder<SVGRadialGradientElement>, 
    IBaseAnimationElementBuilder, ICoreAttributeSetter, IDescriptiveElementBuilder, 
    IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, IGradientStopElementBuilder, 
    IPresentationAttributeSetter
```

## Paint enumeration

Gibt die Maloptionen für die Attribute fill und stroke in SVG-Elementen an.

```csharp
public enum Paint
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| None | `0` | Gibt an, dass keine Malung angewendet werden soll. |
| ContextFill | `1` | Verwendet die aktuelle Kontext-Füllfarbe zum Zeichnen. |
| ContextStroke | `2` | Verwendet die aktuelle Kontext-Strichfarbe zum Zeichnen. |

## Hinweise

Diese Aufzählung definiert die Arten von Farbe, die auf die Füll- und Stricheigenschaften von SVG-Elementen angewendet werden können. Sie ermöglicht Standardfarben, kontextbasierte Füllungen und Striche oder gar keine Farbe.

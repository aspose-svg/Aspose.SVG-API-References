## SpreadMethod enumeration

Gibt an, wie die Farben in einem Farbverlauf über dessen Grenzen hinaus verteilt werden.

```csharp
public enum SpreadMethod
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Pad | `0` | Die Farbe des letzten Farbverlaufsstopps wird verwendet, um den Rest des Farbverlaufsbereichs zu füllen. |
| Reflect | `1` | Der Farbverlauf wird außerhalb seiner Grenzen reflektiert (gespiegelt). |
| Repeat | `2` | Der Farbverlauf wird außerhalb seiner Grenzen wiederholt. |

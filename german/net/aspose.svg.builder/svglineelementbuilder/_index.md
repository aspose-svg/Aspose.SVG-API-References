## SVGLineElementBuilder class

Builder-Klasse zum Erstellen eines SVG 'line'-Elements, das verwendet wird, um gerade Linien innerhalb von SVG-Grafiken zu zeichnen. Diese Klasse ermöglicht das Erstellen von Inhalten innerhalb des 'line'-Elements und bietet Methoden zum Festlegen verschiedener Attribute, die speziell für das 'line'-Element in SVG gelten.

```csharp
public class SVGLineElementBuilder : SVGElementBuilder<SVGLineElement>, IAnimationElementBuilder, 
    IDescriptiveElementBuilder, IPaintServerElementBuilder, IShapeAttributeSetter, 
    IShapeContentElementBuilder
```

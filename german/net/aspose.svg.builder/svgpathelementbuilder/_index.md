## SVGPathElementBuilder class

Builder-Klasse zum Erstellen eines SVG 'path'-Elements, das verwendet wird, um einen Pfad in einem SVG-Dokument zu definieren. Diese Klasse bietet Methoden zum Festlegen verschiedener Attribute, die speziell für das 'path'-Element gelten, und zum Erstellen seines Inhalts.

```csharp
public class SVGPathElementBuilder : SVGElementBuilder<SVGPathElement>, IAnimationElementBuilder, 
    IDescriptiveElementBuilder, IPaintServerElementBuilder, IShapeAttributeSetter, 
    IShapeContentElementBuilder
```

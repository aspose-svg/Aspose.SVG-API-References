## FontWeight enumeration

Gibt die verschiedenen Schriftstärken für SVG-Text-Elemente an.

```csharp
public enum FontWeight
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Normal | `0` | Stellt das normale Schriftgewicht dar, das das Standardgewicht ist. |
| Bold | `1` | Stellt ein fettes Schriftgewicht dar, das typischerweise für Hervorhebungen verwendet wird. |
| Bolder | `2` | Stellt ein Schriftgewicht dar, das stärker ist als das des übergeordneten Elements. |
| Lighter | `3` | Stellt ein Schriftgewicht dar, das leichter ist als das des übergeordneten Elements. |
| W100 | `4` | Stellt das Schriftgewicht 100 dar, das dünnste verfügbare. |
| W200 | `5` | Stellt das Schriftgewicht 200 dar. |
| W300 | `6` | Stellt das Schriftgewicht 300 dar. |
| W400 | `7` | Stellt das Schriftgewicht 400 dar, gleichbedeutend mit „normal“.  |
| W500 | `8` | Stellt das Schriftgewicht 500 dar. |
| W600 | `9` | Stellt das Schriftgewicht 600 dar. |
| W700 | `10` | Stellt das Schriftgewicht 700 dar, gleichbedeutend mit „fett“.  |
| W800 | `11` | Stellt das Schriftgewicht 800 dar. |
| W900 | `12` | Stellt das Schriftgewicht 900 dar, das stärkste verfügbare. |

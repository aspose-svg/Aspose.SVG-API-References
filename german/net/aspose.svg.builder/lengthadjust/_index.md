## LengthAdjust enumeration

Gibt an, wie Textlängenanpassungen in SVG vorgenommen werden.

```csharp
public enum LengthAdjust
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Spacing | `0` | Passt den Abstand zwischen Zeichen an, um die gewünschte Länge zu erreichen. |
| SpacingAndGlyphs | `1` | Passt sowohl den Abstand als auch die Größe der Glyphen an, um die gewünschte Länge zu erreichen. |

## Hinweise

Das Attribut 'lengthAdjust' in SVG-Text-Elementen steuert, wie die Textskalierung angewendet wird, wenn der Text in eine vorgegebene Länge passen muss.

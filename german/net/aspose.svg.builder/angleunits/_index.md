## AngleUnits enumeration

Gibt die Einheiten für Winkel an, die bei der Definition der Orientierung von Markern in SVG verwendet werden.

```csharp
public enum AngleUnits
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Degrees | `0` | Gibt den Winkel in Grad an. Ein voller Kreis hat 360 Grad. |
| Gradians | `1` | Gibt den Winkel in Gon an. Ein voller Kreis hat 400 Gon. |
| Radians | `2` | Gibt den Winkel in Radianten an. Ein voller Kreis hat ungefähr 6,283 Radianten (2π Radianten). |
| None | `3` | Gibt an, dass keine spezifische Winkelseinheit verwendet wird. Wird für Standard- oder kontextbasierte Einstellungen verwendet. |

## Hinweise

Das 'orient'-Attribut von SVG-Markern kann in verschiedenen Winkelseinheiten angegeben werden. Dieses Enum bietet Optionen zum Festlegen dieser Einheiten.

## TransformationType enumeration

Gibt den Typ der auf ein SVG-Element angewendeten Transformation an.

```csharp
public enum TransformationType
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Translate | `0` | Verschiebt (bewegt) ein Element um eine bestimmte Distanz. |
| Scale | `1` | Skaliert ein Element in der Größe nach oben oder unten. |
| Rotate | `2` | Dreht ein Element um einen gegebenen Punkt. |

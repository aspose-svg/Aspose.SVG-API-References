## XmlSpace enumeration

Gibt an, wie Leerzeichen innerhalb von Elementen in XML-Dokumenten behandelt werden.

```csharp
public enum XmlSpace
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Default | `0` | Zeigt an, dass Leerzeichen gemäß dem Standardverhalten des XML‑Processors behandelt werden sollten, typischerweise durch Normalisierung der Leerzeichen, also das Entfernen von Zeilenumbrüchen und zusätzlichen Leerzeichen. |
| Preserve | `1` | Zeigt an, dass Leerzeichen so erhalten bleiben sollen, wie sie im XML-Dokument erscheinen. Dies ist nützlich, um die Formatierung von Text zu bewahren, bei dem Leerzeichen eine Bedeutung haben. |

## Hinweise

Das Attribut 'xml:space' in XML wird verwendet, um zu steuern, ob Leerzeichen innerhalb von Elementen erhalten oder normalisiert werden sollen. Diese Aufzählung bietet Optionen zum Festlegen dieses Verhaltens in XML- und SVG-Dokumenten.

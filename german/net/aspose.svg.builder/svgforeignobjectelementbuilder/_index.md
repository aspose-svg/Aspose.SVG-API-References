## SVGForeignObjectElementBuilder class

Builder-Klasse zum Erstellen eines SVG‑'foreignObject'-Elements, das die Einbindung externer Inhalte in ein SVG‑Dokument ermöglicht. Dieses Element kann verschiedene Inhaltstypen enthalten, wie HTML und XHTML, und erlaubt komplexere grafische Darstellungen innerhalb von SVG.

```csharp
public class SVGForeignObjectElementBuilder : SVGElementBuilder<SVGForeignObjectElement>, 
    ICompositeAttributeSetter, IRectAttributeSetter, ITextContentSetter
```

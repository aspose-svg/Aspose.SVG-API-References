## Restart enumeration

Gibt das Neustartverhalten für SVG-Animationen an.

```csharp
public enum Restart
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Always | `0` | Die Animation kann jederzeit neu gestartet werden, selbst wenn sie gerade aktiv ist. |
| WhenNotActive | `1` | Die Animation kann nur neu gestartet werden, wenn sie nicht gerade aktiv ist. |
| Never | `2` | Die Animation kann nach dem Start nicht neu gestartet werden; sie läuft bis zum Abschluss. |

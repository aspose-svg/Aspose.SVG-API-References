## SVGCircleElementBuilder class

Builder-Klasse zum Erstellen eines SVG-'circle'-Elements, das zum Zeichnen von Kreisen innerhalb von SVG-Grafiken verwendet wird. Sie ermöglicht das Erstellen von Inhalt innerhalb des 'circle'-Elements und stellt Methoden zum Festlegen verschiedener, für das 'circle'-Element in SVG spezifischer Attribute bereit.

```csharp
public class SVGCircleElementBuilder : SVGElementBuilder<SVGCircleElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IShapeAttributeSetter, IShapeContentElementBuilder
```

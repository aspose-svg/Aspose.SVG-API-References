## UnicodeBidi enumeration

Gibt die Handhabung von bidirektionalem Text in SVG an.

```csharp
public enum UnicodeBidi
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Normal | `0` | Normale Handhabung von bidirektionalem Text. |
| Embed | `1` | Bettet einen Textabschnitt mit einer anderen oder expliziten Schreibrichtung ein. |
| Isolate | `2` | Isoliert einen Textabschnitt von seiner Umgebung für die Handhabung von bidirektionalem Text. |
| BidiOverride | `3` | Überschreibt die inhärente Schreibrichtung der Zeichen in einem Textabschnitt. |
| IsolateOverride | `4` | Isoliert einen Textabschnitt und überschreibt seine Schreibrichtung. |
| Plaintext | `5` | Behandelt den Textabschnitt als Klartext ohne spezielle bidirektionale Handhabung. |

## ClipPathBuilder class

Eine Builder‑Klasse zum Erstellen von CSS‑clip‑path‑Werten. Diese Klasse bietet Methoden zur Definition von Clip‑Paths mittels Grundformen, externer Referenzen oder Geometrie‑Boxen. Sie ermöglicht die Erstellung komplexer Clipping‑Pfade in einer strukturierten und lesbaren Weise.

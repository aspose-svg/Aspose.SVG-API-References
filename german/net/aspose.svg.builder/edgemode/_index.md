## EdgeMode enumeration

Gibt den Randmodus für die Filterprimitive feConvolveMatrix in SVG an.

```csharp
public enum EdgeMode
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Duplicate | `0` | Das Eingabebild wird bei Bedarf entlang jeder seiner Ränder erweitert, indem die Farbwerte am jeweiligen Rand des Eingabebildes dupliziert werden. |
| Wrap | `1` | Das Eingabebild wird konzeptionell gewrappt (oder gekachelt) und die Faltung verwendet diese gewrappten Werte. Dadurch entsteht eine toroidale Topologie für das Bild. |
| None | `2` | Der Randmodus ist nicht definiert, und die Wirkung des Filters wird durch die Implementierung festgelegt. |

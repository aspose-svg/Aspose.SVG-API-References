## Kerning enumeration

Gibt das Kerning-Verhalten für Text in SVG an.

```csharp
public enum Kerning
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Auto | `0` | Ermöglicht dem Browser zu bestimmen, ob Kerning angewendet werden soll. |
| Normal | `1` | Wendet das standardmäßige Kerning an, wie in der Schriftdatei definiert. |
| None | `2` | Deaktiviert Kerning und ignoriert jegliche Kerning-Informationen in der Schrift. |

## Hinweise

Die Eigenschaft 'font-kerning' in SVG steuert die Verwendung der in einer Schrift gespeicherten Kerning-Informationen. Kerning passt den Abstand zwischen einzelnen Buchstabenpaaren an, um das visuelle Erscheinungsbild von Text zu verbessern. Dieses Enum bietet Optionen zur Steuerung des Kerning-Verhaltens in SVG-Text-Elementen.

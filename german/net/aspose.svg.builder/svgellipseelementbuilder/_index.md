## SVGEllipseElementBuilder class

Builder-Klasse zum Erstellen eines SVG-'ellipse'-Elements, das zum Zeichnen von Ellipsen innerhalb von SVG-Grafiken verwendet wird. Sie ermöglicht das Erstellen von Inhalt innerhalb des 'ellipse'-Elements und stellt Methoden zum Festlegen verschiedener, für das 'ellipse'-Element in SVG spezifischer Attribute bereit.

```csharp
public class SVGEllipseElementBuilder : SVGElementBuilder<SVGEllipseElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IShapeAttributeSetter, IShapeContentElementBuilder
```

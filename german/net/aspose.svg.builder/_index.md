Der **Aspose.Svg.Builder** Namensraum enthält Klassen und Schnittstellen zum Erstellen und Manipulieren von SVG (Scalable Vector Graphics)-Dokumenten mithilfe der Aspose.SVG-Bibliothek. Dieser Namensraum bietet einen umfangreichen Satz von Builder‑Klassen, die die Erstellung und Änderung von SVG‑Elementen und deren Attributen vereinfachen. Diese Builder bieten eine fluente API, die den Code lesbarer und wartbarer macht.

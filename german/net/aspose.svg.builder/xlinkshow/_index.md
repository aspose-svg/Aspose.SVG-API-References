## XLinkShow enumeration

Gibt das Verhalten an, wenn ein SVG-Link ausgelöst wird.

```csharp
public enum XLinkShow
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| New | `0` | Öffnet den Link in einem neuen Fenster oder Tab. |
| Replace | `1` | Ersetzt das aktuelle SVG-Dokument durch das verlinkte Dokument. |
| Embed | `2` | Bettet das verlinkte Dokument in das aktuelle SVG-Dokument ein. |
| Other | `3` | Gibt ein Verhalten an, das von den vordefinierten Verhaltensweisen abweicht. |
| None | `4` | Gibt an, dass kein spezifisches Verhalten angefordert wird. |

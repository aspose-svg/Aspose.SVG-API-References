## ColorMatrixOperation enumeration

Gibt den Typ der Operation an, die in einem Farbmatrixfilter angewendet wird.

```csharp
public enum ColorMatrixOperation
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Matrix | `0` | Wendet eine Matrixtransformation auf die Farbdaten an. |
| Saturate | `1` | Passt den Sättigungsgrad des Bildes an. |
| HueRotate | `2` | Wendet eine Farbtonrotation auf das Bild an. |
| LuminanceToAlpha | `3` | Konvertiert die Farben des Bildes basierend auf ihrer Luminanz in Graustufen. |

## Hinweise

Der Farbmatrixfilter in SVG ermöglicht verschiedene Operationen an den Farbdaten eines Bildes. Jeder Operationstyp manipuliert die Farben auf eine bestimmte Weise und bietet eine Reihe von visuellen Effekten.

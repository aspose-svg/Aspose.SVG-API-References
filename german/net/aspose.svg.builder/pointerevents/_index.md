## PointerEvents enumeration

Gibt an, wie Zeigerereignisse von grafischen Elementen in SVG verarbeitet werden.

```csharp
public enum PointerEvents
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| BoundingBox | `0` | Zeigereignisse richten sich auf die Begrenzungsbox des Elements. |
| VisiblePainted | `1` | Zeigereignisse richten sich ausschließlich auf die sichtbaren (bemalten) Teile des Elements. |
| VisibleFill | `2` | Zeigereignisse richten sich ausschließlich auf die sichtbaren (gefüllten) Teile des Elements. |
| VisibleStroke | `3` | Zeigereignisse richten sich ausschließlich auf die sichtbaren (strichgezeichneten) Teile des Elements. |
| Visible | `4` | Zeigereignisse richten sich auf alle sichtbaren Teile des Elements. |
| Painted | `5` | Zeigereignisse richten sich auf alle bemalten Teile des Elements, einschließlich Füllung und Kontur. |
| Fill | `6` | Zeigereignisse richten sich ausschließlich auf die gefüllten Teile des Elements. |
| Stroke | `7` | Zeigereignisse richten sich ausschließlich auf die strichgezeichneten Teile des Elements. |
| All | `8` | Zeigereignisse richten sich auf alle Teile des Elements, unabhängig von ihrer Sichtbarkeit. |
| None | `9` | Das Element wird nicht zum Ziel von Pointer-Ereignissen. |

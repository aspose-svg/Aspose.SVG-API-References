## CalcMode enumeration

Gibt die Berechnungsmodi für die Interpolation von Werten in SVG-Animationen an.

```csharp
public enum CalcMode
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Discrete | `0` | Die Animation springt von einem Wert zum nächsten ohne jegliche Interpolation. |
| Linear | `1` | Die Animationswerte werden linear über die Dauer der Animation interpoliert. |
| Paced | `2` | Die Animation ist so getaktet, dass der Fortschritt über die gesamte Animation gleichmäßig ist. |
| Spline | `3` | Die Animation verwendet kubische Bézier‑Splines, um Werte zu interpolieren. |

## Hinweise

Der Berechnungsmodus bestimmt, wie eine SVG‑Animation im Verlauf der Animation zwischen Werten übergeht. Verschiedene Modi können verwendet werden, um verschiedene Effekte zu erzeugen und das Timing sowie die Glätte der Animation zu steuern.

## Cursor enumeration

Definiert Cursor-Typen für SVG-Elemente, wodurch die Anpassung des Cursor‑Aussehens beim Überfahren dieser Elemente ermöglicht wird.

```csharp
public enum Cursor
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Auto | `0` | Der Browser bestimmt den anzuzeigenden Cursor basierend auf dem aktuellen Kontext. |
| Default | `1` | Standard‑Cursor, typischerweise ein Pfeil. |
| None | `2` | Kein Cursor wird angezeigt. |
| ContextMenu | `3` | Cursor, der anzeigt, dass ein Kontextmenü verfügbar ist. |
| Help | `4` | Cursor, der anzeigt, dass Hilfsinformationen verfügbar sind. |
| Pointer | `5` | Cursor, der ein anklickbares Element anzeigt, typischerweise ein Handzeiger. |
| Progress | `6` | Cursor, der einen laufenden Vorgang oder eine Aufgabe anzeigt. |
| Wait | `7` | Cursor, der anzeigt, dass das System beschäftigt ist und der Benutzer warten sollte. |
| Cell | `8` | Cursor, der eine Zelle oder ein Tabellenelement anzeigt. |
| Crosshair | `9` | Cursor, der eine präzise Auswahl anzeigt, typischerweise ein Fadenkreuz. |
| Text | `10` | Cursor, der eine Textauswahl anzeigt. |
| VerticalText | `11` | Cursor, der eine vertikale Textauswahl anzeigt. |
| Alias | `12` | Cursor, der anzeigt, dass ein Alias oder eine Verknüpfung erstellt wird. |
| Copy | `13` | Cursor, der einen Kopiervorgang anzeigt. |
| Move | `14` | Cursor, der ein bewegliches Objekt oder Gebiet anzeigt. |
| NoDrop | `15` | Cursor, der anzeigt, dass Ablegen nicht erlaubt ist. |
| NotAllowed | `16` | Cursor, der anzeigt, dass eine Aktion nicht erlaubt ist. |
| Grab | `17` | Cursor, der anzeigt, dass ein Element gegriffen werden kann. |
| Grabbing | `18` | Cursor, der anzeigt, dass ein Element gerade gegriffen wird. |
| EResize | `19` | Cursor, der eine Größenänderung nach Osten anzeigt. |

| ColResize | `31` | Cursor, der eine Spaltengrößenänderung anzeigt. |
| RowResize | `32` | Cursor, der eine Zeilen­größenänderung anzeigt. |
| AllScroll | `33` | Cursor, der das Scrollen in alle Richtungen anzeigt. |
| ZoomIn | `34` | Cursor, der die Zoom‑In‑Funktion anzeigt. |

## Hinweise

Diese Aufzählung bietet eine Reihe von Cursor‑Stilen, die auf SVG‑Elemente angewendet werden können. Diese Stile helfen, die Art der verfügbaren Interaktion oder den Status des Elements unter dem Cursor anzuzeigen.

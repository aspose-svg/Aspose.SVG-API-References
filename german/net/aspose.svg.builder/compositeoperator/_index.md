## CompositeOperator enumeration

Gibt den Typ der zu verwendenden Kompositoperation in SVG-Kompositoperationen an.

```csharp
public enum CompositeOperator
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Over | `0` | Platziert die Quellgrafik über der Zielgrafik. |
| In | `1` | Zeigt die Quellgrafik dort an, wo sie die Zielgrafik überlappt. |
| Out | `2` | Zeigt die Quellgrafik dort an, wo sie die Zielgrafik nicht überlappt. |
| Atop | `3` | Zeigt die Quellgrafik oben auf der Zielgrafik an. |
| Xor | `4` | Zeigt die Quellgrafik dort an, wo sie die Zielgrafik nicht überlappt, und umgekehrt. |
| Arithmetic | `5` | Ermöglicht eine benutzerdefinierte arithmetische Kompositionsoperation. |

## Hinweise

Kompositionsoperationen in SVG bestimmen, wie zwei grafische Elemente zu einem einzigen Bild kombiniert werden. Jeder Operator definiert eine unterschiedliche Methode zum Mischen oder Kombinieren dieser Elemente.

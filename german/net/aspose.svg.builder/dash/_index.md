## Dash enumeration

Definiert das Muster aus Strichen und Lücken, das zum Zeichnen der Kontur von Formen (Strich) in SVG-Elementen verwendet wird.

```csharp
public enum Dash
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| None | `0` | Zeigt einen durchgezogenen Strich ohne Striche an. Dies ist das Standardverhalten, wenn 'stroke-dasharray' nicht angegeben ist. |

## Hinweise

Das Attribut 'stroke-dasharray' in SVG wird verwendet, um gestrichelte Linien zu erzeugen, indem das Muster aus Strichen und Lücken angegeben wird. Diese Aufzählung bietet Optionen zum Festlegen dieses Musters.

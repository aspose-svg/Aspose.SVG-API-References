## SVGGElementBuilder class

Builder-Klasse zum Erstellen eines SVG‑'g'-Elements (Gruppe). Das 'g'-Element wird verwendet, um SVG‑Formen zu gruppieren. Das Gruppieren von Elementen ermöglicht eine einfachere Manipulation und Stilgebung mehrerer Elemente als eine Einheit innerhalb von SVG‑Grafiken.

```csharp
public class SVGGElementBuilder : SVGElementBuilder<SVGGElement>, ICompositeAttributeSetter, 
    ICompositeElementBuilder
```

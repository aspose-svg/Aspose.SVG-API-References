## AnimationFill enumeration

Gibt das Verhalten der Animation vor und nach ihrer Ausführung an.

```csharp
public enum AnimationFill
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Freeze | `0` | Die Animation wendet die Eigenschaftswerte für die Zeit an, in der die Animation beendet wurde. |
| Remove | `1` | Die Animation wendet nach dem Abschluss ihrer Ausführung keine Werte mehr an. |

## Hinweise

Das Attribut 'fill' in SVG-Animationen steuert, welche Werte von der Animation außerhalb der Ausführungszeit angewendet werden. Dieses Enum bietet Optionen zur Steuerung dieses Verhaltens.

## ImageRendering enumeration

Gibt an, wie ein Bild in SVG gerendert werden soll.

```csharp
public enum ImageRendering
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Auto | `0` | Der Browser macht beim Rendern des Bildes einen Kompromiss zwischen Geschwindigkeit und Qualität. |
| OptimizeSpeed | `1` | Der Browser legt mehr Wert auf Rendergeschwindigkeit als auf Bildqualität. Das bedeutet häufig, dass Bilder so skaliert werden, dass sie pixelig oder blockartig aussehen können. |
| OptimizeQuality | `2` | Der Browser legt mehr Wert auf Bildqualität als auf Rendergeschwindigkeit. Das kann zu einer glatteren, qualitativ hochwertigeren Skalierung von Bildern führen, jedoch kann das Rendern langsamer sein. |

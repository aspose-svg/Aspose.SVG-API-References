## RepeatStyle enumeration

Gibt den Wiederholungsstil für Hintergrundbilder oder Muster in SVG an.

```csharp
public enum RepeatStyle
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| RepeatX | `0` | Das Bild oder Muster wird nur horizontal wiederholt. |
| RepeatY | `1` | Das Bild oder Muster wird nur vertikal wiederholt. |
| Repeat | `2` | Das Bild oder Muster wird sowohl horizontal als auch vertikal wiederholt. |
| Space | `3` | Das Bild oder Muster wird so oft wie möglich ohne Abschneiden wiederholt, und der verbleibende Raum wird gleichmäßig zwischen den Bildern verteilt. |
| Round | `4` | Das Bild oder Muster wird skaliert, sodass es passt und ohne Abschneiden wiederholt wird, wobei das Seitenverhältnis beibehalten wird. |
| NoRepeat | `5` | Das Bild oder Muster wird nicht wiederholt, und es wird nur eine Kopie des Bildes gezeichnet. |

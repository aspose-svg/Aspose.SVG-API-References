## DisplayType enumeration

Gibt das Anzeigeverhalten von Elementen in SVG-Dokumenten an.

```csharp
public enum DisplayType
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Inline | `0` | Das Element erzeugt ein oder mehrere Inline-Boxen. |
| Block | `1` | Das Element erzeugt eine Block-Box. |
| ListItem | `2` | Das Element erzeugt eine Block-Box für den Inhalt und eine separate list-item Inline-Box. |
| InlineBlock | `3` | Das Element erzeugt eine Block-Box für den Inhalt und eine Inline-Box für den Container. |
| Table | `4` | Das Element verhält sich wie ein Tabellenelement. |
| InlineTable | `5` | Das Element verhält sich wie eine Inline-Tabelle. |
| TableRowGroup | `6` | Das Element verhält sich wie eine Tabellenzeilengruppe. |
| TableHeaderGroup | `7` | Das Element verhält sich wie eine Tabellenkopfgruppe. |
| TableFooterGroup | `8` | Das Element verhält sich wie eine Tabellenfußgruppe. |
| TableRow | `9` | Das Element verhält sich wie eine Tabellenzeile. |
| TableColumnGroup | `10` | Das Element verhält sich wie eine Tabellenspaltengruppe. |
| TableColumn | `11` | Das Element verhält sich wie eine Tabellenspalte. |
| TableCell | `12` | Das Element verhält sich wie eine Tabellenzelle. |
| TableCaption | `13` | Das Element verhält sich wie eine Tabellenbeschriftung. |
| None | `14` | Das Element erzeugt keine Box und wird nicht gerendert. Es beeinflusst das Layout nicht. |
| Flex | `15` | Das Element verhält sich wie ein Flex-Container. |
| InlineFlex | `16` | Das Element verhält sich wie ein Inline-Flex-Container. |
| Grid | `17` | Das Element verhält sich wie ein Grid-Container. |
| InlineGrid | `18` | Das Element verhält sich wie ein Inline-Grid-Container. |

## Hinweise

Die 'display'-Eigenschaft in SVG und CSS bestimmt, wie ein Element im Dokumentlayout angezeigt wird. Diese Aufzählung bietet verschiedene Optionen zum Festlegen des Anzeigetyps und beeinflusst, wie Elemente gerendert werden und mit dem Layout interagieren.

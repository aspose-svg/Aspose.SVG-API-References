## SVGDescElementBuilder class

Builder-Klasse zum Erstellen eines SVG-'desc'-Elements, das zur Bereitstellung einer Beschreibung für SVG-Container-Elemente verwendet wird. Sie ermöglicht das Erstellen von Inhalt innerhalb des 'desc'-Elements und stellt Methoden zum Festlegen verschiedener, für das 'desc'-Element in SVG spezifischer Attribute bereit.

```csharp
public class SVGDescElementBuilder : SVGElementBuilder<SVGDescElement>, ICoreAttributeSetter, 
    IDescriptiveElementBuilder, IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, 
    ITextContentSetter
```

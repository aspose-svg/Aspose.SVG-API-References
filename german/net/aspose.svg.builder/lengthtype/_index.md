## LengthType enumeration

Gibt die Maßeinheiten für Längen in SVG an.

```csharp
public enum LengthType
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Number | `1` | Stellt einen numerischen Wert ohne Einheit dar. Er wird häufig im Kontext anderer Werte oder Standardeinheiten interpretiert. |
| Percentage | `2` | Stellt einen Prozentwert dar, relativ zu einem anderen Wert oder einer Begrenzungsdimension. |
| Ems | `3` | Stellt eine Länge in 'ems' dar, einer skalierbaren Einheit, die relativ zur aktuellen Schriftgröße ist. |
| Exs | `4` | Stellt eine Länge in 'exs' dar, bezogen auf die x‑Höhe der aktuellen Schrift. |
| Px | `5` | Stellt eine Länge in Pixeln dar, einer Maßeinheit, die auf der digitalen Darstellung eines Bildes basiert. |
| Cm | `6` | Stellt eine Länge in Zentimetern dar. |
| Mm | `7` | Stellt eine Länge in Millimetern dar. |
| In | `8` | Stellt eine Länge in Zoll dar. |
| Pt | `9` | Stellt eine Länge in Punkten dar, einer traditionellen Einheit in der Typografie. 1 Punkt entspricht ungefähr 1/72 Zoll. |
| Pc | `10` | Stellt eine Länge in Picas dar, einer typografischen Maßeinheit. 1 Pica entspricht 12 Punkten. |

## Hinweise

Diese Aufzählung definiert verschiedene Einheiten, die zur Angabe von Längen in SVG-Elementen verwendet werden können. Diese Einheiten umfassen absolute Messungen wie Pixel und Zentimeter sowie relative Messungen wie Prozentsätze und ems.

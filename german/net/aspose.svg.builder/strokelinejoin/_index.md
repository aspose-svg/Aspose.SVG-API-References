## StrokeLineJoin enumeration

Gibt die Form an, die an den Ecken von Pfaden oder Grundformen verwendet wird, wenn sie gestrichen werden.

```csharp
public enum StrokeLineJoin
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Miter | `0` | Eine spitze Ecke wird verwendet, um Pfadsegmente zu verbinden. |
| MiterClip | `1` | Ähnlich wie 'miter', aber wenn die Verbindung über ein Limit hinausgehen würde, wird sie abgeschnitten. |
| Round | `2` | Eine abgerundete Ecke wird verwendet, um Pfadsegmente zu verbinden. |
| Bevel | `3` | Eine abgeschrägte Ecke wird verwendet, um Pfadsegmente zu verbinden. |
| Arcs | `4` | Die Ecke wird durch Bögen verbunden. |

## Rotate enumeration

Gibt das Rotationsverhalten für Elemente während einer Bewegungsanimation in SVG an.

```csharp
public enum Rotate
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Auto | `0` | Dreht das Element automatisch in Richtung des Pfads. |
| AutoReverse | `1` | Dreht das Element automatisch in Richtung des Pfads und erlaubt es, umzukehren. |

## Hinweise

Das Attribut 'rotate' im SVG-Element 'animateMotion' steuert die Drehung eines Elements entlang eines Bewegungswegs. Dieses Enum bietet Optionen dafür, wie das Element rotieren soll, während es dem Pfad folgt.

## WhiteSpace enumeration

Gibt an, wie Leerzeichen innerhalb eines SVG-Elements behandelt werden.

```csharp
public enum WhiteSpace
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Normal | `0` | Leerzeichen werden zusammengefasst; Zeilenumbruchzeichen erzeugen neue Zeilen. |
| Pre | `1` | Leerzeichen werden beibehalten; Text wird nur umbrochen, wo Zeilenumbruchzeichen vorkommen. |
| NoWrap | `2` | Leerzeichen werden zusammengefasst; Text wird nicht umbrochen. |
| PreWrap | `3` | Leerzeichen werden beibehalten; Text wird bei Bedarf und bei Zeilenumbruchzeichen umbrochen. |
| BreakSpaces | `4` | Leerzeichen werden beibehalten; Zeilenumbrüche werden hinzugefügt, um Zeilenboxen zu füllen. |
| PreLine | `5` | Leerzeichen werden beibehalten; Text wird bei Bedarf umbrochen, jedoch ohne Zeilenumbruchzeichen. |

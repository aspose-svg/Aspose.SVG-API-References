## SVGRectElementBuilder class

Builder-Klasse zum Erstellen eines SVG 'rect'-Elements. Das 'rect'-Element wird verwendet, um Rechtecke innerhalb von SVG-Grafiken zu erzeugen. Diese Klasse bietet Methoden zum Festlegen verschiedener Attribute, die speziell für das 'rect'-Element gelten, einschließlich Eckradien und Abmessungen.

```csharp
public class SVGRectElementBuilder : SVGElementBuilder<SVGRectElement>, IAnimationElementBuilder, 
    IDescriptiveElementBuilder, IPaintServerElementBuilder, IRectAttributeSetter, 
    IShapeAttributeSetter, IShapeContentElementBuilder
```

## SVGPolygonElementBuilder class

Builder-Klasse zum Erstellen eines SVG 'polygon'-Elements. Das 'polygon'-Element wird verwendet, um eine Grafik zu erzeugen, die mindestens drei Seiten enthält. Diese Klasse bietet Methoden zum Festlegen verschiedener Attribute und zur Animation des 'polygon'-Elements.

```csharp
public class SVGPolygonElementBuilder : SVGElementBuilder<SVGPolygonElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IPointsAttributeSetter, IShapeAttributeSetter, IShapeContentElementBuilder
```

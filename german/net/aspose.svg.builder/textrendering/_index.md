## TextRendering enumeration

Gibt die Textdarstellungsstrategie in SVG an.

```csharp
public enum TextRendering
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| Auto | `0` | Ermöglicht dem Browser, einen optimierten Text-Rendermodus zu wählen. |
| OptimizeSpeed | `1` | Legt mehr Wert auf Rendergeschwindigkeit als auf Textlesbarkeit und geometrische Präzision. |
| OptimizeLegibility | `2` | Legt mehr Wert auf Lesbarkeit als auf Rendergeschwindigkeit und geometrische Präzision. |
| GeometricPrecision | `3` | Legt mehr Wert auf geometrische Präzision als auf Rendergeschwindigkeit und Lesbarkeit. |

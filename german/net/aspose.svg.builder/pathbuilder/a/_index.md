## PathBuilder.A method

Fügt dem Pfaddaten einen 'Elliptical Arc Curve'-Befehl hinzu.

```csharp
public PathBuilder A(double r1, double r2, double angle, bool largeArcFlag, bool sweepFlag, 
    double x, double y)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| r1 | Double | Der x-Radius der Ellipse. |
| r2 | Double | Der y-Radius der Ellipse. |
| angle | Double | Der Rotationswinkel der Ellipse in Grad. |
| largeArcFlag | Boolean | Flag, das angibt, ob der Bogen größer oder gleich 180 Grad sein soll. |
| sweepFlag | Boolean | Flag, das angibt, ob der Bogen in positiver Winkelrichtung gezeichnet werden soll. |
| x | Double | Die x-Koordinate des Endpunkts des Bogens. |
| y | Double | Die y-Koordinate des Endpunkts des Bogens. |

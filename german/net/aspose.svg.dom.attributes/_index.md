Der **Aspose.Svg.Dom.Attributes** Namensraum enthält einheitliche Attributklassen, die Merkmale oder Verhaltensweisen eines beliebigen Objekts (Knoten, Element, …) festlegen oder qualifizieren.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [DOMConstructorAttribute](./domconstructorattribute/) | Gibt einen Konstruktor an, der vom W3C definiert ist. |
| [DOMNameAttribute](./domnameattribute/) | Gibt den offiziellen DOM-Objektnamen an, wie er vom W3C definiert wurde. |
| [DOMNamedPropertyGetterAttribute](./domnamedpropertygetterattribute/) | Gibt an, dass die Methode als benannter Property-Getter verwendet wird. |
| [DOMNoInterfaceObjectAttribute](./domnointerfaceobjectattribute/) | Wenn das erweiterte Attribut [NoInterfaceObject] auf einem Interface erscheint, bedeutet dies, dass für das Interface im ECMAScript-Binding kein Interface-Objekt existieren wird. |
| [DOMNullableAttribute](./domnullableattribute/) | Gibt an, dass einem DOM-Objekt ein Nullwert zugewiesen werden kann. |
| [DOMObjectAttribute](./domobjectattribute/) | Gibt an, dass das Objekt mit diesem Attribut vom W3C definiert ist. |
| [DOMTreatNullAsAttribute](./domtreatnullasattribute/) | Zeigt an, dass ein Nullwert des Member-Werts als der angegebene Wert behandelt wird. |

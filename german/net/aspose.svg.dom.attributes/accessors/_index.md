## Accessors enumeration

Stellt die Aufzählung von Member-Accessoren dar, die vom W3C definiert ist.

```csharp
[Flags]
public enum Accessors : byte
```

### Werte

| Name | Wert | Beschreibung |
| --- | --- | --- |
| None | `0` | Gibt an, dass die Eigenschaft keine besondere Bedeutung hat. |
| Getter | `1` | Gibt an, dass die Eigenschaft oder Methode als Getter behandelt werden soll. |
| Setter | `2` | Gibt an, dass die Eigenschaft oder Methode als Setter behandelt werden soll. |
| Deleter | `4` | Gibt an, dass die Eigenschaft oder Methode durch delete behandelt werden soll. |

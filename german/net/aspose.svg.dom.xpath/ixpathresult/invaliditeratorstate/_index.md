## IXPathResult.InvalidIteratorState property

Zeigt an, dass der Iterator ungültig geworden ist. True, wenn `resultType` vom Typ `UnorderedNodeIterator` oder `OrderedNodeIterator` ist und das Dokument seit der Rückgabe dieses Ergebnisses geändert wurde.

```csharp
public bool InvalidIteratorState { get; }
```

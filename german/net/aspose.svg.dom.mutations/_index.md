Der **Aspose.Svg.Dom.Mutations** bietet die Möglichkeit, DOM‑Mutationen zu beobachten und spezifische Callback‑Informationen zu erhalten.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [MutationCallback](./mutationcallback/) | Stellt die Methode dar, die Mutationsereignisse verarbeitet. |
| [MutationObserver](./mutationobserver/) | Ein [`MutationObserver`](../aspose.svg.dom.mutations/mutationobserver/)‑Objekt kann verwendet werden, um Mutationen am Baum von [`Node`](../aspose.svg.dom/node/) zu beobachten. |
| [MutationObserverInit](./mutationobserverinit/) | Diese Klasse stellt eine Optionssammlung dar, die verwendet wird, um [`MutationObserver`](../aspose.svg.dom.mutations/mutationobserver/) zu konfigurieren. |
| [MutationRecord](./mutationrecord/) | Ein MutationRecord stellt eine einzelne DOM‑Mutation dar. Es ist das Objekt, das an [`MutationObserver`](../aspose.svg.dom.mutations/mutationobserver/)'s [`MutationCallback`](../aspose.svg.dom.mutations/mutationcallback/) übergeben wird. |

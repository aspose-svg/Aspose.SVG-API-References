## SVGMarkerElement.OrientAngle property

Entspricht dem Attribut ‘orient’ im angegebenen ‘marker’-Element. Wenn markerUnits SVG_MARKER_ORIENT_ANGLE ist, der Winkelwert für das Attribut ‘orient’; andernfalls wird er auf Null gesetzt.

```csharp
public SVGAnimatedAngle OrientAngle { get; }
```

### Property Value

Das Attribut ‘orient’ des angegebenen ‘marker’-Elements.

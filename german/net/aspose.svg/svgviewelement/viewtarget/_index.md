## SVGViewElement.ViewTarget property

Entspricht dem Attribut ‘viewTarget’ im angegebenen ‘view’-Element. Eine Liste von DOMString‑Werten, die die im ‘viewTarget’-Attribut aufgeführten Namen enthalten. Jeder der DOMString‑Werte kann mittels des Aufrufs der Methode getElementById() dem entsprechenden Element zugeordnet werden.

```csharp
public SVGStringList ViewTarget { get; }
```

### Property Value

Das Attribut ‘viewTarget’ des angegebenen ‘view’-Elements.

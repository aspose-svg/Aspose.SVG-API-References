## SVGDocument.Referrer property

Gibt die URI der Seite zurück, die auf diese Seite verlinkt hat. Der Wert ist ein leerer String, wenn der Benutzer direkt zur Seite navigiert ist (nicht über einen Link, sondern beispielsweise über ein Lesezeichen).

```csharp
public string Referrer { get; }
```

### Property Value

Der Referrer.

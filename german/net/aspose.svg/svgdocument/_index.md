## SVGDocument class

Ein `SVGDocument` ist die Wurzel der SVG‑Hierarchie und enthält den gesamten Inhalt. Neben dem Zugriff auf die Hierarchie bietet es auch einige Komfortmethoden zum Abrufen bestimmter Informationssätze aus dem Dokument. Zusätzlich zum Laden von Standard-.svg-Dateien können sowohl die Konstruktoren als auch die [`Navigate`](../../aspose.svg.dom/document/navigate/)‑Methode gzip‑komprimierte .svgz‑Dateien laden. Wenn ein ‘svg’-Element inline als Bestandteil eines Dokuments aus einem anderen Namensraum eingebettet wird, beispielsweise wenn ein ‘svg’-Element inline in ein XHTML‑Dokument [XHTML] eingebettet wird, dann wird kein SVGDocument‑Objekt existieren; stattdessen ist das Wurzelobjekt in der Dokumentobjekt‑Hierarchie ein Document‑Objekt eines anderen Typs, wie ein HTMLDocument‑Objekt. Ein SVGDocument‑Objekt wird jedoch tatsächlich existieren, wenn das Wurzelelement der XML‑Dokumenthierarchie ein ‘svg’-Element ist, beispielsweise beim Betrachten einer eigenständigen SVG‑Datei (i.d.R. eine Datei mit dem MIME‑Typ "image/svg+xml"). In diesem Fall ist das SVGDocument‑Objekt das Wurzelobjekt der Dokumentobjekt‑Modell‑Hierarchie.

```csharp
public class SVGDocument : Document, IDocumentCSS
```

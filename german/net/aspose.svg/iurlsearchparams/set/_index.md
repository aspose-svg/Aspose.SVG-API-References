## IUrlSearchParams.Set method

Setzt den Wert des zuerst gefundenen Namens‑Wert‑Paares auf den angegebenen Wert und entfernt die übrigen. Wenn kein Namens‑Wert‑Paar mit dem angegebenen Namen gefunden wird, wird ein neues an die Liste angehängt.

```csharp
public void Set(string name, string value)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| name | String | Schlüssel, der zum Auffinden von Namens‑Wert‑Paaren verwendet wird. |
| value | String | Wert, der gesetzt wird. |

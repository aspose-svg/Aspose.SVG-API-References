## SVGSVGElement.CreateSVGTransformFromMatrix method

Erstellt ein SVGTransform-Objekt außerhalb aller Dokumentbäume. Das Objekt wird mit der angegebenen Matrix-Transformation (d.h. SVG_TRANSFORM_MATRIX) initialisiert. Die Werte aus der Parameter‑Matrix werden kopiert, der Matrix‑Parameter wird nicht als SVGTransform::matrix übernommen.

```csharp
public SVGTransform CreateSVGTransformFromMatrix(SVGMatrix matrix)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| Matrix | SVGMatrix | Die Transformationsmatrix. |

### Rückgabewert

Ein SVGTransform-Objekt.

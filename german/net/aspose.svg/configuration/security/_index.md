## Configuration.Security property

Diese Eigenschaft ermöglicht es Ihnen, eine Reihe von Einschränkungen für den im Rahmen geladenen Inhalt festzulegen, zum Beispiel Formulare und Skripte zu blockieren. Siehe den Artikel über [sandboxing](https://docs.aspose.com/html/net/environment-configuration/#sandboxing).

```csharp
public Sandbox Security { get; set; }
```

### Property Value

Ein [`Sandbox`](../../sandbox/) Flag-Set ist eine Menge von null oder mehr Flags, die verwendet werden, um die Fähigkeiten potenziell nicht vertrauenswürdiger Ressourcen einzuschränken.

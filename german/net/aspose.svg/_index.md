Zusätzlich zum Laden von Standard‑.svg‑Dateien können sowohl die Konstruktoren als auch die [`Navigate`](../aspose.svg.dom/document/navigate/)‑Methode gzip‑komprimierte .svgz‑Dateien laden. Wenn ein ‘svg’-Element inline als Komponente eines Dokuments aus einem anderen Namensraum eingebettet ist, etwa wenn ein ‘svg’-Element inline in ein XHTML‑Dokument [XHTML] eingebettet wird, existiert kein SVGDocument‑Objekt; stattdessen ist das Wurzelobjekt in der Dokumentobjekt‑Hierarchie ein Document‑Objekt eines anderen Typs, z. B. ein HTMLDocument‑Objekt. Ein SVGDocument‑Objekt existiert jedoch, wenn das Wurzelelement der XML‑Dokumenthierarchie ein ‘svg’-Element ist, etwa beim Anzeigen einer eigenständigen SVG‑Datei (d. h. einer Datei mit dem MIME‑Typ "image/svg+xml").

## SVGTextContentElement.GetNumberOfChars method

Gibt die Gesamtzahl der für das Rendern im aktuellen Element verfügbaren Zeichen zurück, einschließlich der über ‘tref’-Referenzen referenzierten Zeichen, unabhängig davon, ob sie gerendert werden. Im Wesentlichen entspricht dies der Länge des Node::textContent-Attributs aus DOM Level 3 Core ([DOM3], Abschnitt 1.4), falls dieses Attribut auch ‘tref’-Elemente erweitert.

```csharp
public long GetNumberOfChars()
```

### Rückgabewert

Gesamtzahl der Zeichen.

## DOMException.VALIDATION_ERR field

Wenn ein Aufruf einer Methode wie insertBefore oder removeChild den Node in Bezug auf \"partial validity\" ungültig machen würde, wird diese Ausnahme ausgelöst und der Vorgang nicht ausgeführt. Dieser Code wird in [DOM Level 3 Validation] verwendet. Weitere Informationen finden Sie in dieser Spezifikation.

```csharp
public const ushort VALIDATION_ERR;
```

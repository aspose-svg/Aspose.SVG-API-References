## Node.BaseURI property

Gibt die absolute Basis‑URL des Dokuments zurück, das den Knoten enthält.

Die Basis‑URL wird verwendet, um relative URLs aufzulösen, wenn der Browser eine absolute URL ermitteln muss, zum Beispiel beim Verarbeiten des src‑Attributs des HTML‑img‑Elements oder der xlink:href‑ bzw. href‑Attribute in SVG.

```csharp
public virtual string BaseURI { get; }
```

### Property Value

Der baseURI‑Getter gibt die Basis‑URL des Dokuments dieses Knotens zurück, serialisiert.

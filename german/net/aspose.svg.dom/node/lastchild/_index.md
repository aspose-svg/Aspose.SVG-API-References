## Node.LastChild property

Gibt das letzte Kind des Knotens zurück. Wenn dessen übergeordnetes Element ein Element ist, ist das Kind in der Regel ein Elementknoten, ein Textknoten oder ein Kommentar­knoten. Es wird null zurückgegeben, wenn keine Kind‑Elemente vorhanden sind.

```csharp
public Node LastChild { get; }
```

### Property Value

Ein [`Node`](../), das das letzte Kind des Knotens ist, oder null, wenn keine Kindelemente vorhanden sind.

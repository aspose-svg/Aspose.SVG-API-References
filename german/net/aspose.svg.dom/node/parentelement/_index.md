## Node.ParentElement property

Gibt das übergeordnete [`Element`](../../element/) des DOM‑Knotens zurück, oder null, wenn der Knoten keinen Elternteil hat oder sein Elternteil kein DOM‑Element ist.

```csharp
public Element ParentElement { get; }
```

### Property Value

Ein [`Element`](../../element/), das das übergeordnete Element des aktuellen Knotens ist, oder null, falls keines vorhanden ist.

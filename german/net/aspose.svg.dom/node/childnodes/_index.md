## Node.ChildNodes property

Gibt eine Live-[`NodeList`](../../../aspose.svg.collections/nodelist/) der Kindknoten des angegebenen Elements zurück, wobei dem ersten Kindknoten der Index 0 zugewiesen wird. Kindknoten umfassen Elemente, Text und Kommentare.

Hinweis: Das [`NodeList`](../../../aspose.svg.collections/nodelist/) ist live, das bedeutet, dass sein Inhalt jedes Mal geändert wird, wenn neue Kinder hinzugefügt oder entfernt werden.

```csharp
public NodeList ChildNodes { get; }
```

### Property Value

Ein live [`NodeList`](../../../aspose.svg.collections/nodelist/) enthält die Kinder des Knotens.

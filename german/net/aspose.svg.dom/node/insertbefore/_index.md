## Node.InsertBefore method

Fügt den Knoten vor dem vorhandenen Kindknoten child ein. Wenn child null ist, wird der Knoten am Ende der Kindliste eingefügt. Wenn child ein DocumentFragment-Objekt ist, werden all seine Kinder in derselben Reihenfolge vor child eingefügt. Wenn das Kind bereits im Baum ist, wird es zuerst entfernt.

```csharp
public Node InsertBefore(Node node, Node child)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| node | Node | Das neue Kind. |
| child | Node | Das Referenz-Kind. |

### Rückgabewert

Gibt den eingefügten Knoten zurück

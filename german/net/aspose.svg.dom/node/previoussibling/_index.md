## Node.PreviousSibling property

Gibt den Knoten zurück, der dem angegebenen Knoten in der [`ChildNodes`](../childnodes/)‑Liste seines Elternteils unmittelbar vorausgeht, oder null, wenn der angegebene Knoten der erste in dieser Liste ist.

```csharp
public Node PreviousSibling { get; }
```

### Property Value

Ein [`Node`](../) der den vorherigen Geschwisterknoten des aktuellen Knotens darstellt, oder null, wenn keiner vorhanden ist.

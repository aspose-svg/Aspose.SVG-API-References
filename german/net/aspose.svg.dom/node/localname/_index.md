## Node.LocalName property

Gibt den lokalen Teil des qualifizierten Namens dieses Knotens zurück. Für Knoten jeglichen Typs, die nicht [`ELEMENT_NODE`](../element_node/) oder [`ATTRIBUTE_NODE`](../attribute_node/) sind, und für mit einer DOM‑Level‑1‑Methode erstellte Knoten, wie [`CreateElement`](../../document/createelement/), ist dies immer null.

```csharp
public virtual string LocalName { get; }
```

### Property Value

Eine Zeichenkette, die den lokalen Teil des qualifizierten Namens des Elements darstellt.

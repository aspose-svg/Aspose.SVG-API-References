## Element.GetElementsByTagNameNS method

Gibt ein [`HTMLCollection`](../../../aspose.svg.collections/htmlcollection/) Objekt zurück, das alle [`elements`](../) mit einem angegebenen lokalen Namen und Namespace-URI-String in Dokumentreihenfolge enthält.

```csharp
public HTMLCollection GetElementsByTagNameNS(string namespaceURI, string localName)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| namespaceURI | String | Die String-Darstellung des Namespace-URI. |
| localName | String | String-Darstellung des lokalen Namens. |

### Rückgabewert

Eine Live-[`HTMLCollection`](../../../aspose.svg.collections/htmlcollection/) gefundener Elemente.

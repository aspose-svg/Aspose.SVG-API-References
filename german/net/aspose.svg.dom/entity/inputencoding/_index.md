## Entity.InputEncoding property

Ein Attribut, das die beim Parsen verwendete Kodierung für diese Entität angibt, wenn es sich um eine externe geparste Entität handelt. Dieser Wert ist null, wenn es sich um eine Entität aus dem internen Subset handelt oder wenn sie nicht bekannt ist.

```csharp
public string InputEncoding { get; }
```

### Property Value

Die Eingabekodierung.

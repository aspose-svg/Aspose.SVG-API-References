## Document.XmlVersion property

Ein Attribut, das im Rahmen der XML‑Deklaration die Versionsnummer dieses Dokuments angibt. Gibt es keine Deklaration und unterstützt das Dokument das Feature "XML", ist der Wert "1.0". Unterstützt das Dokument das Feature "XML" nicht, ist der Wert immer null.

```csharp
public string XmlVersion { get; set; }
```

### Property Value

Die XML‑Version.

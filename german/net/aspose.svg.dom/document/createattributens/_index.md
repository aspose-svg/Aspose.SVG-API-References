## Document.CreateAttributeNS method

Diese Methode erstellt einen neuen Attributknoten und gibt ihn zurück. Das erstellte Objekt ist ein Knoten, der die [`Attr`](../../attr/)‑Klasse implementiert. Das DOM erzwingt nicht, welche Art von Attributen auf diese Weise zu einem bestimmten Element hinzugefügt werden können.

```csharp
public Attr CreateAttributeNS(string namespaceURI, string qualifiedName)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| namespaceURI | String | Der Namespace‑URI des Attributs. |
| qualifiedName | String | ist ein String, der den Namen des Attributs enthält. |

## Document.XmlStandalone property

Ein Attribut, das im Rahmen der XML‑Deklaration angibt, ob dieses Dokument eigenständig ist. Wenn nicht angegeben, ist es false.

```csharp
public bool XmlStandalone { get; set; }
```

### Property Value

`true`, wenn XML eigenständig; andernfalls `false`.

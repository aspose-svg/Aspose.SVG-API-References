## ImageVectorizerConfiguration.ImageSizeLimit property

Liest oder setzt die maximale Bilddimension, bestimmt durch die Multiplikation von Bildbreite und -höhe. Die Bildgröße wird basierend auf dieser Eigenschaft skaliert. Der Standardwert ist 1800000.

```csharp
public int ImageSizeLimit { get; set; }
```

## ImageVectorizerConfiguration class

Die `ImageVectorizerConfiguration` Klasse definiert eine Konfiguration von Bildvektorisierungsmethoden und -optionen. Die Konfiguration wird verwendet, um einen ImageVectorizer zu initialisieren und bietet die Konfigurationsoptionen für die Vektorisierung von Bildern.

```csharp
public class ImageVectorizerConfiguration
```

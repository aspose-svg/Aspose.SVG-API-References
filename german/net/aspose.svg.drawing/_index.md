Der **Aspose.Svg.Drawing** Namespace enthält Objekte und Schnittstellen zur Angabe von Messungen und Einheiten sowie Zeichenattribut-Objekte wie Pinsel, Farben und Schriften.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [Angle](./angle/) | Der Winkel‑Datentyp |
| [Color](./color/) | Die Color‑Klasse ermöglicht es, Farben als Rot‑Grün‑Blau (RGB)-Werte, Farbton‑Sättigung‑Luminanz (HSL)-Werte, Farbton‑Sättigung‑Wert (HSV)-Werte, Farbton‑Weiß‑Schwarz (HWB)-Werte, Lightness‑A‑B (LAB)-Werte, Luminanz‑Chroma‑Farbton (LCH)-Werte, Cyan‑Magenta‑Yellow‑Key (CMYK)-Werte, Natürliche Farben (NCOL)-Werte oder über einen Farbnamen anzugeben. Ein Alpha‑Kanal ist ebenfalls verfügbar, um Transparenz anzugeben. |
| [Dimension](./dimension/) | Stellt die Basisklasse für Dimensionen bereit. Der allgemeine Begriff 'Dimension' bezeichnet eine Zahl mit einer zugehörigen Einheit und wird durch [`UnitType`](../aspose.svg.drawing/unittype/) dargestellt. |
| [Frequency](./frequency/) | Die Einheit 'frequency'. |
| [Length](./length/) | Stellt eine Längeneinheit dar. |
| [LengthOrAuto](./lengthorauto/) | Stellt einen Container für Speicherlänge oder 'auto'-Einheiten dar. |
| [Margin](./margin/) | Stellt Seitenrand dar. |
| [Numeric](./numeric/) | Stellt die Basisklasse für numerische Typen bereit. |
| [Page](./page/) | Stellt ein Seitenobjekt dar, das für die Konfiguration der Ausgabeseite verwendet wird. Der Standardwert für die Seitengröße ist A4 (210 × 297 mm) |
| [Resolution](./resolution/) | Stellt eine Auflösungseinheit dar. |
| [Size](./size/) | Speichert Werte, die eine Höhe und Breite angeben. |
| [Time](./time/) | Stellt eine Zeiteinheit dar. |
| [Unit](./unit/) | Stellt die Basisklasse für Maßeinheiten bereit. |
| [UnitType](./unittype/) | Gibt die Maßeinheit an. |

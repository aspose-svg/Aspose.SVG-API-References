## ITrueTypeFont.SubFamilyName property

Der Subfamily-Name unterscheidet die Schrift in einer Gruppe mit demselben Family-Namen. Es wird angenommen, dass er Stil (italic, oblique) und Gewicht (light, bold, black usw.) adressiert. Eine Schrift ohne besondere Unterschiede in Gewicht oder Stil sollte die Zeichenkette "Regular" haben.

```csharp
public string SubFamilyName { get; }
```

### Rückgabewert

Der Subfamilienname der Schrift.

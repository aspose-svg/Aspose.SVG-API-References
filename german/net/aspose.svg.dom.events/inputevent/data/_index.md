## InputEvent.Data property

Die Daten enthalten den Wert der von einer Eingabemethode erzeugten Zeichen. Dies KANN ein einzelnes Unicode‑Zeichen oder eine nicht leere Sequenz von Unicode‑Zeichen sein [Unicode]. Zeichen SOLLTEN gemäß der Unicode‑Normalisierungsform NFC, definiert in [UAX15], normalisiert werden. Dieses Attribut KANN die leere Zeichenkette enthalten.

```csharp
public string Data { get; }
```

### Property Value

Die Ereignisdaten.

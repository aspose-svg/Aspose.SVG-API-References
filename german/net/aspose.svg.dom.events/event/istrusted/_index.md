## Event.IsTrusted property

Das isTrusted-Attribut muss den Wert zurückgeben, auf den es initialisiert wurde. Wenn ein Ereignis erstellt wird, muss das Attribut auf false initialisiert werden.

```csharp
public bool IsTrusted { get; }
```

### Property Value

`true`, wenn diese Instanz vertrauenswürdig ist; andernfalls `false`.

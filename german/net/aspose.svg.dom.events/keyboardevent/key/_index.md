## KeyboardEvent.Key property

Der Schlüssel enthält den Tastwert der gedrückten Taste. Wenn der Wert eine druckbare Darstellung hat, MUSS er eine nicht leere Unicode‑Zeichenkette sein, die dem in dieser Spezifikation definierten Algorithmus zur Bestimmung des Tastwerts entspricht. Wenn der Wert eine Steuerungstaste ohne druckbare Darstellung ist, MUSS er einer der im Schlüsselwert‑Set definierten Tastwerte sein, wie durch den Algorithmus zur Bestimmung des Tastwerts ermittelt. Implementierungen, die eine Taste nicht identifizieren können, MÜSSEN den Tastwert Unidentified verwenden.

```csharp
public string Key { get; }
```

### Property Value

Der Tastwert.

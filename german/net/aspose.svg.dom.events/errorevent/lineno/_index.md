## ErrorEvent.LineNo property

Das lineno-Attribut muss den Wert zurückgeben, auf den es initialisiert wurde. Wenn das Objekt erstellt wird, muss dieses Attribut auf 0 initialisiert werden. Es stellt die Zeilennummer dar, in der der Fehler im Skript aufgetreten ist.

```csharp
public uint LineNo { get; }
```

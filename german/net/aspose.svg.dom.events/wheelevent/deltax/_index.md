## WheelEvent.DeltaX property

In Benutzeragenten, bei denen die Standardaktion des Wheel-Events das Scrollen ist, MUSS der Wert die Messung entlang der x-Achse (in Pixeln, Zeilen oder Seiten) sein, die gescrollt wird, falls das Ereignis nicht abgebrochen wird. Andernfalls handelt es sich um eine implementierungsspezifische Messung (in Pixeln, Zeilen oder Seiten) der Bewegung eines Wheel-Geräts um die x-Achse.

```csharp
public double DeltaX { get; }
```

Das deltaX-Attribut.

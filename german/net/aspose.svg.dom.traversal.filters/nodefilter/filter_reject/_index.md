## NodeFilter.FILTER_REJECT field

Den Knoten ablehnen. Navigationsmethoden, die für NodeIterator oder TreeWalker definiert sind, geben diesen Knoten nicht zurück. Für TreeWalker werden auch die Kinder dieses Knotens abgelehnt. NodeIterators behandeln dies als Synonym für FILTER_SKIP.

```csharp
public const short FILTER_REJECT;
```

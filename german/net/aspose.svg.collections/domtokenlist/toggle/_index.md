## Toggle(*string, bool*) {#toggle_1}

Entfernt das Token aus der Liste, falls es existiert, oder fügt das Token zur Liste hinzu, falls es nicht existiert.

```csharp
public bool Toggle(string token, bool force)
```

| Parameter | Typ | Beschreibung |
| --- | --- | --- |
| token | String | Das Token, das Sie umschalten möchten. |
| force | Boolean | Ein Boolescher Wert, der, falls angegeben, den Schalter in eine einseitige Operation verwandelt. Wenn er auf false gesetzt ist, wird das Token nur entfernt, aber nicht hinzugefügt. Wenn er auf true gesetzt ist, wird das Token nur hinzugefügt, aber nicht entfernt. |

### Rückgabewert

Ein Boolescher Wert, der angibt, ob das Token nach dem Aufruf in der Liste ist.

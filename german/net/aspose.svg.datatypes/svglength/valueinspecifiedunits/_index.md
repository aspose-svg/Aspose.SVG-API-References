## SVGLength.ValueInSpecifiedUnits property

Der Wert als Gleitkommazahl, in den durch unitType ausgedrückten Einheiten. Das Setzen dieses Attributs führt dazu, dass value und valueAsString automatisch aktualisiert werden, um diese Einstellung widerzuspiegeln.

```csharp
public float ValueInSpecifiedUnits { get; set; }
```

### Property Value

Der Wert in den angegebenen Einheiten.

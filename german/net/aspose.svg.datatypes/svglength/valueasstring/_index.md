## SVGLength.ValueAsString property

Der Wert als Zeichenkette, in den durch unitType ausgedrückten Einheiten. Das Setzen dieses Attributs führt dazu, dass value, valueInSpecifiedUnits und unitType automatisch aktualisiert werden, um diese Einstellung widerzuspiegeln.

```csharp
public string ValueAsString { get; set; }
```

### Property Value

Der Wert als Zeichenkette.

### Ausnahmen

| Ausnahme | Bedingung |
| --- | --- |
| [DOMException](../../../aspose.svg.dom/domexception/) | Code [`SYNTAX_ERR`](../../../aspose.svg.dom/domexception/syntax_err/) ausgelöst, wenn die zugewiesene Zeichenkette nicht als gültige Länge geparst werden kann. |
| [DOMException](../../../aspose.svg.dom/domexception/) | Code [`NO_MODIFICATION_ALLOWED_ERR`](../../../aspose.svg.dom/domexception/no_modification_allowed_err/) Wird ausgelöst, wenn die Länge einem schreibgeschützten Attribut entspricht oder das Objekt selbst schreibgeschützt ist. |

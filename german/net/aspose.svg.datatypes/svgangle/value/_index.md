## SVGAngle.Value property

Der Winkelwert als Gleitkommawert in Grad. Das Setzen dieses Attributs führt dazu, dass valueInSpecifiedUnits und valueAsString automatisch aktualisiert werden, um diese Einstellung widerzuspiegeln.

public float Value { get; set; }

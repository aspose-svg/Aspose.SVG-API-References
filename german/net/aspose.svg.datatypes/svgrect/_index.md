## SVGRect class

Stellt rechteckige Geometrie dar. Rechtecke werden definiert als ein (x,y)-Koordinatenpaar, das einen minimalen X-Wert, einen minimalen Y-Wert sowie Breite und Höhe angibt, die in der Regel nicht negativ sein dürfen.

public class SVGRect : SVGValueType

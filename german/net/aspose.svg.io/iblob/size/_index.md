## IBlob.Size property

Gibt die Größe der Byte‑Sequenz in Bytes zurück. Beim Abrufen müssen konforme Benutzeragenten die Gesamtzahl der Bytes zurückgeben, die von einem FileReader‑ oder FileReaderSync‑Objekt gelesen werden können, oder 0, wenn der Blob keine zu lesenden Bytes enthält.

public ulong Size { get; }

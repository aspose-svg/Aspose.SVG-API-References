Der **Aspose.Svg.Rendering** Namespace besteht aus zahlreichen Renderer‑Objekten sowie passenden Low‑Level‑Optionen‑Klassen, die für das Rendern von Dokumenten/Dateien in eine IDevice‑Implementierung verantwortlich sind.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [CssOptions](./cssoptions/) | Stellt CSS-Rendering-Optionen dar. |
| [Device](./device/) | Stellt eine Basisklasse für die Implementierung von Rendering-Geräten dar, die zum Zeichnen von Grafiken in verschiedenen Formaten und Umgebungen verwendet werden. |
| [Device<TGraphicContext,TRenderingOptions>](./device-2/) | Stellt die Basisklasse für die Implementierung bestimmter Rendering-Geräte dar. |
| [GraphicContext](./graphiccontext/) | Enthält aktuelle Grafiksteuerungsparameter. Diese Parameter definieren das globale Framework, innerhalb dessen die Grafikoperatoren ausgeführt werden. |
| [PageSetup](./pagesetup/) | Stellt ein Seiten-Setup-Objekt dar, das zur Konfiguration der Ausgabeseite verwendet wird. |
| [Renderer](./renderer/) | Stellt eine Basisklasse für alle Renderer dar und implementiert das IDisposable-Interface. |
| [Renderer<TSource>](./renderer-1/) | Die abstrakte Basisklasse für alle Renderer. |
| [RenderingOptions](./renderingoptions/) | Stellt Rendering-Optionen dar. |
| [SvgRenderer](./svgrenderer/) | Stellt einen SVG-Dokument-Renderer dar. |
| [TextInfo](./textinfo/) | Enthält Informationen über gerenderten Text. |

| [MediaType](./mediatype/) | Gibt mögliche Medientypen an, die beim Rendering verwendet werden. |

## IUserAgentService.ShowImagePlaceholders property

Bilder können Ersatzinhalt haben: Inhalt, der verwendet werden soll, wenn eine externe Ressource nicht genutzt werden kann (zum Beispiel, weil sie in einem nicht unterstützten Format vorliegt). Die Eigenschaft `ShowImagePlaceholders` gibt an, ob das Ersatzbild angezeigt werden soll (standardmäßig ist true).

```csharp
public bool ShowImagePlaceholders { get; set; }
```

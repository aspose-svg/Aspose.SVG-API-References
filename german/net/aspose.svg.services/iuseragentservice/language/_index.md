## IUserAgentService.Language property

Der `Language` gibt die primäre Sprache für den Inhalt des Elements und für alle Attribute des Elements an, die Text enthalten. Sein Wert muss ein gültiger BCP 47‑Sprachcode sein oder die leere Zeichenkette. Das Setzen des Attributs auf die leere Zeichenkette bedeutet, dass die primäre Sprache unbekannt ist.

```csharp
public string Language { get; set; }
```

### Property Value

Die Sprache des User‑Agents.

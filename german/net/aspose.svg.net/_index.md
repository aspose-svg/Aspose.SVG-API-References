Der **Aspose.Svg.Net** Namespace wird durch Klassen und Schnittstellen bereitgestellt, die für die einfache Netzwerkverarbeitung verantwortlich sind.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [ByteArrayContent](./bytearraycontent/) | Stellt Inhalt basierend auf einem Byte-Array dar. |
| [Content](./content/) | Stellt eine Basisklasse für einen HTTP-Entitätskörper und Inhaltsheader dar. |
| [ContentHeaders](./contentheaders/) | Enthält die mit einem Inhalt verbundenen Header. |
| [FormUrlEncodedContent](./formurlencodedcontent/) | Ein Container für Name/Wert‑Tupel, die mit dem MIME-Typ application/x-www-form-urlencoded codiert sind. |
| [HttpMethod](./httpmethod/) | Stellt eine Hilfsklasse zum Abrufen und Vergleichen von Standard‑HTTP‑Methoden dar. |
| [MessageFilter](./messagefilter/) | Stellt eine abstrakte Basisklasse für verschiedene Filterklassen dar, die zum Abfragen von Nachrichten verwendet werden. |
| [MessageHandler](./messagehandler/) | Stellt einen Basistyp für Nachrichtenhandler dar. |
| [MessageHandlerCollection](./messagehandlercollection/) | Stellt eine Sammlung der [`MessageHandler`](../aspose.svg.net/messagehandler/) dar. |
| [MultipartContent](./multipartcontent/) | Stellt einen multipart/*‑Inhalt dar. |
| [MultipartFormDataContent](./multipartformdatacontent/) | Stellt Inhalt für den multipart/form-data‑Kodierungsalgorithmus dar. |
| [RequestHeaders](./requestheaders/) | Enthält Protokoll-Header, die mit einer Anforderung verbunden sind. |
| [RequestMessage](./requestmessage/) | Stellt eine Anforderungsnachricht dar. |
| [ResponseHeaders](./responseheaders/) | Enthält Protokoll‑Header, die mit einer Antwort verbunden sind. |
| [ResponseMessage](./responsemessage/) | Stellt eine Antwortnachricht dar. |
| [StreamContent](./streamcontent/) | Stellt Inhalt basierend auf einem Stream dar. |
| [StringContent](./stringcontent/) | Stellt Inhalt basierend auf einer Zeichenkette dar. |
| [UrlResolver](./urlresolver/) | Stellt eine Hilfsklasse zum Auflösen einer absoluten URL anhand eines Uniform Resource Identifier (URI) dar. |
## Schnittstellen

| Schnittstelle | Beschreibung |
| --- | --- |
| [INetwork](./inetwork/) | Stellt eine Schnittstelle für Netzwerkdienste bereit. |
| [INetworkOperationContext](./inetworkoperationcontext/) | Stellt kontextbezogene Informationen für die Netzwerkdienste bereit. |

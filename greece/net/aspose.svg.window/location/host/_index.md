## Location.Host property

Επιστρέφει το Location object's URL's host and port (εάν είναι διαφορετικό από την προεπιλεγμένη θύρα για το σχήμα). Μπορεί να οριστεί, για να μεταβείτε στην ίδια URL με αλλαγμένο host και port.

```csharp
public string Host { get; set; }
```

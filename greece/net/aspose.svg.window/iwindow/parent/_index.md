## IWindow.Parent property

Το χαρακτηριστικό IDL parent στο αντικείμενο Window ενός Document σε ένα περιβάλλον περιήγησης b πρέπει να επιστρέφει το αντικείμενο WindowProxy του γονικού περιβάλλοντος περιήγησης, εάν υπάρχει (π.χ. εάν το b είναι παιδικό περιβάλλον περιήγησης), ή το αντικείμενο WindowProxy του ίδιου περιβάλλοντος περιήγησης b, διαφορετικά (π.χ. εάν είναι ένα ανώτερο επίπεδο περιβάλλοντος περιήγησης ή ένα αποσπασμένο ένθετο περιβάλλον περιήγησης).

```csharp
public IWindow Parent { get; }
```

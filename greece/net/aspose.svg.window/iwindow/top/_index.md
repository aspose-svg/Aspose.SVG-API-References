## IWindow.Top property

Το χαρακτηριστικό IDL top στο αντικείμενο Window ενός Document σε ένα περιβάλλον περιήγησης b πρέπει να επιστρέφει το αντικείμενο WindowProxy του ανώτερου επιπέδου περιβάλλοντος περιήγησης (το οποίο θα ήταν το δικό του αντικείμενο WindowProxy εάν ήταν ανώτερο επίπεδο περιβάλλοντος περιήγησης), εάν υπάρχει, ή το δικό του αντικείμενο WindowProxy διαφορετικά (π.χ. εάν ήταν αποσπασμένο ένθετο περιβάλλον περιήγησης).

```csharp
public IWindow Top { get; }
```

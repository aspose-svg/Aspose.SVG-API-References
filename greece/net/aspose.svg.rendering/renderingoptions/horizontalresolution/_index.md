## RenderingOptions.HorizontalResolution property

Ορίζει ή λαμβάνει την οριζόντια ανάλυση για εσωτερικές (που χρησιμοποιούνται κατά την επεξεργασία φίλτρων) εικόνες, σε pixel ανά ίντσα. Από προεπιλογή αυτή η ιδιότητα είναι 300 dpi.

public virtual Resolution HorizontalResolution { get; set; }

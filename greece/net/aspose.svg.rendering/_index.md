| [Device<TGraphicContext,TRenderingOptions>](./device-2/) | Αναπαριστά τη βασική κλάση για την υλοποίηση συγκεκριμένων συσκευών απόδοσης. |

| [PageSetup](./pagesetup/) | Αναπαριστά ένα αντικείμενο ρύθμισης σελίδας που χρησιμοποιείται για τη διαμόρφωση του συνόλου εξόδου σελίδας. |

| [SvgRenderer](./svgrenderer/) | Αναπαριστά τον renderer εγγράφου SVG. |
| [TextInfo](./textinfo/) | Περιέχει πληροφορίες σχετικά με το αποδομένο κείμενο. |

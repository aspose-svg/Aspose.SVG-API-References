## RequestMessage.PreAuthenticate property

Λαμβάνει ή ορίζει μια τιμή που υποδεικνύει εάν θα σταλεί κεφαλίδα Authorization με το αίτημα.

```csharp
public bool PreAuthenticate { get; set; }
```

### Property Value

`true` για αποστολή μιας κεφαλίδας HTTP Authorization με τα αιτήματα μετά την ολοκλήρωση του ελέγχου ταυτότητας· διαφορετικά, `false`. Η προεπιλογή είναι `false`.

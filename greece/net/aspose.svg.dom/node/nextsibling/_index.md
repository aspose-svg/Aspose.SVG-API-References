## Node.NextSibling property

Επιστρέφει τον κόμβο που ακολουθεί αμέσως τον καθορισμένο στον γονέα του [`ChildNodes`](../childnodes/), ή επιστρέφει null εάν ο καθορισμένος κόμβος είναι το τελευταίο παιδί στο γονικό στοιχείο.

```csharp
public Node NextSibling { get; }
```

### Property Value

Ένα [`Node`](../) που αντιπροσωπεύει το επόμενο αδερφικό του τρέχοντος κόμβου, ή null εάν δεν υπάρχουν.

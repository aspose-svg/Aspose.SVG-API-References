## Node.ChildNodes property

Επιστρέφει μια ζωντανή [`NodeList`](../../../aspose.svg.collections/nodelist/) των κόμβων-παιδιών του δεδομένου στοιχείου, όπου ο πρώτος κόμβος-παιδί έχει δείκτη 0. Οι κόμβοι-παιδιά περιλαμβάνουν στοιχεία, κείμενο και σχόλια.

Σημείωση: Το ότι το [`NodeList`](../../../aspose.svg.collections/nodelist/) είναι ζωντανό σημαίνει ότι το περιεχόμενό του αλλάζει κάθε φορά που προστίθενται ή αφαιρούνται νέοι κόμβοι-παιδιά.

```csharp
public NodeList ChildNodes { get; }
```

### Property Value

Μια ζωντανή [`NodeList`](../../../aspose.svg.collections/nodelist/) που περιέχει τα παιδιά του κόμβου.

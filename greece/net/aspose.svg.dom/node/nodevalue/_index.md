## Node.NodeValue property

Επιστρέφει ή ορίζει την τιμή του τρέχοντος κόμβου.

```csharp
public virtual string NodeValue { get; set; }
```

### Property Value

Μια συμβολοσειρά που περιέχει την τιμή του τρέχοντος κόμβου, εάν υπάρχει. Για το ίδιο το έγγραφο, `NodeValue` επιστρέφει null. Για κόμβους κειμένου, σχολίου και CDATA, `NodeValue` επιστρέφει το περιεχόμενο του κόμβου. Για κόμβους χαρακτηριστικού, επιστρέφεται η τιμή του χαρακτηριστικού.

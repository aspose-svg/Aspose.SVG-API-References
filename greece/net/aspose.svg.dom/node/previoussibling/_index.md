## Node.PreviousSibling property

Επιστρέφει τον κόμβο που βρίσκεται αμέσως πριν από τον καθορισμένο στη λίστα [`ChildNodes`](../childnodes/) του γονέα του, ή null εάν ο καθορισμένος κόμβος είναι ο πρώτος σε αυτή τη λίστα.

```csharp
public Node PreviousSibling { get; }
```

### Property Value

Ένα [`Node`](../) που αντιπροσωπεύει το προηγούμενο αδερφό του τρέχοντος κόμβου, ή null εάν δεν υπάρχει κανένα.

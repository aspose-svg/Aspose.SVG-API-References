## Node.IsSameNode method

Η μέθοδος είναι ένας παλαιός ψευδώνυμος για τον τελεστή αυστηρής ισότητας ===. Δηλαδή, ελέγχει εάν δύο κόμβοι είναι τα ίδια (με άλλα λόγια, εάν αναφέρονται στο ίδιο αντικείμενο).

Σημείωση: Δεν υπάρχει ανάγκη να χρησιμοποιήσετε το `IsSameNode`; αντίθετα, χρησιμοποιήστε τον τελεστή αυστηρής ισότητας ===.

```csharp
public bool IsSameNode(Node otherNode)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| otherNode | Node | Ο κόμβος προς δοκιμή. |

### Τιμή Επιστροφής

Μια λογική τιμή που είναι true εάν και οι δύο κόμβοι είναι αυστηρά ίσοι, false εάν όχι.

## Document.GetElementsByClassName method

Αυτή η μέθοδος επιστρέφει ένα αντικείμενο παρόμοιο με πίνακα όλων των θυγατρικών στοιχείων που έχουν όλα τα δοσμένα ονόματα κλάσης.

Όταν κληθεί στο αντικείμενο εγγράφου, γίνεται αναζήτηση σε ολόκληρο το έγγραφο, συμπεριλαμβανομένου του ριζικού κόμβου. Μπορείτε επίσης να καλέσετε αυτή τη μέθοδο σε οποιοδήποτε στοιχείο· θα επιστρέψει μόνο τα στοιχεία που είναι απόγονοι του καθορισμένου ριζικού στοιχείου με τα δεδομένα class name(s).

```csharp
public HTMLCollection GetElementsByClassName(string classNames)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| classNames | String | Η συμβολοσειρά που περιέχει ένα αταξινόμητο σύνολο μοναδικών διαστηματικών διακριτών που αντιπροσωπεύουν κλάσεις (class names) |

## Document.CreateAttributeNS method

Αυτή η μέθοδος δημιουργεί έναν νέο κόμβο χαρακτηριστικού και τον επιστρέφει. Το δημιουργημένο αντικείμενο είναι ένας κόμβος που υλοποιεί την κλάση [`Attr`](../../attr/). Το DOM δεν επιβάλλει ποιοι τύποι χαρακτηριστικών μπορούν να προστεθούν σε ένα συγκεκριμένο στοιχείο με αυτόν τον τρόπο.

```csharp
public Attr CreateAttributeNS(string namespaceURI, string qualifiedName)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| namespaceURI | String | Το URI ονόματος χώρου του χαρακτηριστικού. |
| qualifiedName | String | είναι μια συμβολοσειρά που περιέχει το όνομα του χαρακτηριστικού. |

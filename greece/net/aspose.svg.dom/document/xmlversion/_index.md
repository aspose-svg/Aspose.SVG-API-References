## Document.XmlVersion property

Ένα χαρακτηριστικό που καθορίζει, ως μέρος της δήλωσης XML, τον αριθμό έκδοσης αυτού του εγγράφου. Εάν δεν υπάρχει δήλωση και το έγγραφο υποστηρίζει τη δυνατότητα "XML", η τιμή είναι "1.0". Εάν το έγγραφο δεν υποστηρίζει τη δυνατότητα "XML", η τιμή είναι πάντα null.

```csharp
public string XmlVersion { get; set; }
```

### Property Value

Η έκδοση XML.

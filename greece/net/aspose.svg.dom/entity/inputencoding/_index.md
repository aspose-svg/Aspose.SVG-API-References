## Entity.InputEncoding property

Ένα χαρακτηριστικό που καθορίζει την κωδικοποίηση που χρησιμοποιείται για αυτήν την οντότητα κατά την ανάλυση, όταν είναι εξωτερική αναλυμένη οντότητα. Είναι null εάν είναι οντότητα από το εσωτερικό υποσύνολο ή εάν δεν είναι γνωστή.

public string InputEncoding { get; }

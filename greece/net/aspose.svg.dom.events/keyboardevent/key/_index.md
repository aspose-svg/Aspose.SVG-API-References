## KeyboardEvent.Key property

Το κλειδί περιέχει την τιμή κλειδιού του πατημένου κλειδιού. Εάν η τιμή έχει εκτυπωμένη αναπαράσταση, ΠΡΕΠΕΙ να είναι μια μη κενή συμβολοσειρά χαρακτήρων Unicode, σύμφωνη με τον αλγόριθμο για τον προσδιορισμό της τιμής κλειδιού που ορίζεται σε αυτήν την προδιαγραφή. Εάν η τιμή είναι ένα πλήκτρο ελέγχου που δεν έχει εκτυπωμένη αναπαράσταση, ΠΡΕΠΕΙ να είναι μία από τις τιμές κλειδιού που ορίζονται στο σύνολο τιμών κλειδιού, όπως καθορίζεται από τον αλγόριθμο για τον προσδιορισμό της τιμής κλειδιού. Οι υλοποιήσεις που δεν μπορούν να αναγνωρίσουν ένα κλειδί ΠΡΕΠΕΙ να χρησιμοποιούν την τιμή κλειδιού Unidentified.

```csharp
public string Key { get; }
```

### Property Value

Η τιμή του πλήκτρου.

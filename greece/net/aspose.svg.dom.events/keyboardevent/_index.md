## KeyboardEvent class

Η διεπαφή KeyboardEvent παρέχει συγκεκριμένες πληροφορίες συμφραζομένων που σχετίζονται με συσκευές πληκτρολογίου. Κάθε γεγονός πληκτρολογίου αναφέρεται σε ένα πλήκτρο χρησιμοποιώντας μια τιμή. Τα γεγονότα πληκτρολογίου συνήθως κατευθύνονται προς το στοιχείο που έχει την εστίαση.

```csharp
public class KeyboardEvent : UIEvent
```

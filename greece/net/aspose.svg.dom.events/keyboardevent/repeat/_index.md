## KeyboardEvent.Repeat property

αληθές εάν το κλειδί έχει πατηθεί με διαρκή τρόπο. Η κράτηση ενός κλειδιού ΠΡΕΠΕΙ να έχει ως αποτέλεσμα την επανάληψη των γεγονότων keydown, beforeinput, input με αυτή τη σειρά, με ρυθμό που καθορίζεται από τη διαμόρφωση του συστήματος. Για κινητές συσκευές που έχουν συμπεριφορά παρατεταμένου πατήματος, το πρώτο γεγονός κλειδιού με τιμή χαρακτηριστικού repeat ίσο με αληθές ΠΡΕΠΕΙ να λειτουργεί ως ένδειξη παρατεταμένου πατήματος. Το χρονικό διάστημα που ΠΡΕΠΕΙ να κρατηθεί το κλειδί για να αρχίσει η επανάληψη εξαρτάται από τη διαμόρφωση.

```csharp
public bool Repeat { get; }
```

### Property Value

`true` εάν επαναλαμβάνεται· διαφορετικά, `false`.

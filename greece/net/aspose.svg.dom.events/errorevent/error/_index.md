## ErrorEvent.Error property

Το χαρακτηριστικό error πρέπει να επιστρέφει την τιμή στην οποία αρχικοποιήθηκε. Όταν δημιουργείται το αντικείμενο, αυτό το χαρακτηριστικό πρέπει να αρχικοποιηθεί σε null. Όπου είναι κατάλληλο, ορίζεται στο αντικείμενο που αντιπροσωπεύει το σφάλμα (π.χ. το αντικείμενο εξαίρεσης σε περίπτωση μη πιασμένης εξαίρεσης DOM).

```csharp
public object Error { get; }
```

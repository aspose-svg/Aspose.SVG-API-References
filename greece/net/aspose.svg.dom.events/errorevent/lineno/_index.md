## ErrorEvent.LineNo property

Το χαρακτηριστικό lineno πρέπει να επιστρέφει την τιμή στην οποία αρχικοποιήθηκε. Όταν δημιουργείται το αντικείμενο, αυτό το χαρακτηριστικό πρέπει να αρχικοποιηθεί σε μηδέν. Αντιπροσωπεύει τον αριθμό γραμμής όπου συνέβη το σφάλμα στο script.

```csharp
public uint LineNo { get; }
```

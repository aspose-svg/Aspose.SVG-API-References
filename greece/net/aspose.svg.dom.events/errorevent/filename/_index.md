## ErrorEvent.FileName property

Το χαρακτηριστικό filename πρέπει να επιστρέφει την τιμή στην οποία αρχικοποιήθηκε. Όταν δημιουργείται το αντικείμενο, αυτό το χαρακτηριστικό πρέπει να αρχικοποιηθεί σε κενή συμβολοσειρά. Αντιπροσωπεύει το απόλυτο URL του script στο οποίο εμφανίστηκε αρχικά το σφάλμα.

```csharp
public string FileName { get; }
```

### Property Value

Το όνομα αρχείου.

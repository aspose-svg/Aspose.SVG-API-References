## InputEvent.Data property

Τα δεδομένα περιέχουν την τιμή των χαρακτήρων που παράγονται από μια μέθοδο εισόδου. Αυτό ΜΠΟΡΕΙ να είναι ένας μοναδικός χαρακτήρας Unicode ή μια μη κενή ακολουθία χαρακτήρων Unicode [Unicode]. Οι χαρακτήρες ΠΡΕΠΕΙ να είναι κανονικοποιημένοι σύμφωνα με τη μορφή κανονικοποίησης Unicode NFC, όπως ορίζεται στο [UAX15]. Αυτό το χαρακτηριστικό ΜΠΟΡΕΙ να περιέχει το κενό string.

```csharp
public string Data { get; }
```

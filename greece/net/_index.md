## Χώροι ονομάτων

| Χώρος ονομάτων | Περιγραφή |
| --- | --- |
| [Aspose.Svg](./aspose.svg/) | Όλες οι κλάσεις στον χώρο ονομάτων **Aspose.Svg.Dom.Svg** βασίζονται στις προτάσεις w3c SVG2. Χρησιμοποιώντας αυτόν τον χώρο ονομάτων, μπορείτε να φορτώσετε, να περιηγηθείτε ή να αποδώσετε το αρχείο SVG σύμφωνα με τις απαιτήσεις σας. |
| [Aspose.Svg.Builder](./aspose.svg.builder/) | Ο χώρος ονομάτων **Aspose.Svg.Builder** περιέχει κλάσεις και διεπαφές για τη δημιουργία και τη διαχείριση εγγράφων SVG (Scalable Vector Graphics) χρησιμοποιώντας τη βιβλιοθήκη Aspose.SVG. Αυτός ο χώρος ονομάτων παρέχει ένα πλούσιο σύνολο κλάσεων δημιουργίας που απλοποιούν τη δημιουργία και την τροποποίηση στοιχείων SVG και των χαρακτηριστικών τους. Αυτοί οι δημιουργοί προσφέρουν ένα ευέλικτο API, καθιστώντας τον κώδικα πιο ευανάγνωστο και συντηρήσιμο. |
| [Aspose.Svg.Collections](./aspose.svg.collections/) | Ο χώρος ονομάτων **Aspose.Svg.Collections** αποτελείται από κλάσεις για την αναπαράσταση, αποθήκευση και διαχείριση κόμβων και στοιχείων. |
| [Aspose.Svg.Converters](./aspose.svg.converters/) | Ο σκοπός του χώρου ονομάτων **Aspose.Svg.Converters** είναι η εύκολη πρόσβαση σε μεθόδους μετατροπής. Παρέχει ένα ευρύ φάσμα μετατροπών σε δημοφιλείς μορφές, όπως PDF, XPS, μορφές εικόνας κ.λπ. Πιο συγκεκριμένες περιπτώσεις χρήσης μετατροπής (απόδοση, αποθήκευση) παρουσιάζονται από καλά γνωστές και τεκμηριωμένες λειτουργίες χαμηλού επιπέδου API σε εξειδικευμένους χώρους ονομάτων. |
| [Aspose.Svg.DataTypes](./aspose.svg.datatypes/) | Ο χώρος ονομάτων παρέχει πρόσβαση σε όλους τους τύπους δεδομένων που είναι ειδικοί για SVG. |
| [Aspose.Svg.Diagnostics](./aspose.svg.diagnostics/) | Ο χώρος ονομάτων **Aspose.Svg.Diagnostics** περιέχει διεπαφές για εργασία με μετρικές και συλλογή αρχείων καταγραφής και ιχνηλασιών. |
| [Aspose.Svg.Dom](./aspose.svg.dom/) | Ο χώρος ονομάτων **Aspose.Svg.Dom (Document Object Model)** παρέχει API που αντιπροσωπεύει και αλληλεπιδρά με οποιαδήποτε έγγραφα HTML, XML ή SVG. Το DOM είναι ένα μοντέλο εγγράφου που φορτώνεται στο πρόγραμμα περιήγησης και αντιπροσωπεύει το έγγραφο ως δέντρο κόμβων, όπου κάθε κόμβος αντιπροσωπεύει ένα μέρος του εγγράφου (π.χ. ένα στοιχείο, μια συμβολοσειρά κειμένου ή ένα σχόλιο). |
| [Aspose.Svg.Dom.Attributes](./aspose.svg.dom.attributes/) | Ο χώρος ονομάτων **Aspose.Svg.Dom.Attributes** περιέχει ενοποιημένες κλάσεις χαρακτηριστικών που καθορίζουν ή προσδιορίζουν οποιοδήποτε χαρακτηριστικό ή συμπεριφορά αντικειμένου (κόμβου, στοιχείου, ...). |
| [Aspose.Svg.Dom.Css](./aspose.svg.dom.css/) | Ο χώρος ονομάτων **Aspose.Svg.Dom.Css** αφορά όλες τις επεμβάσεις σχετικές με CSS. Επικεντρώνεται στα ζεύγη όνομα‑τιμή ιδιοτήτων CSS που ορίζονται από τα επίσημα έγγραφα CSS. |
| [Aspose.Svg.Dom.Events](./aspose.svg.dom.events/) | Ο χώρος ονομάτων **Aspose.Svg.Dom.Events** παρέχει αντικείμενα για οποιαδήποτε γεγονότα σχετιζόμενα με την ενημέρωση του DOM. Περιλαμβάνει συνδρομή σε συγκεκριμένη παρατήρηση συμφραζομένων που σχετίζονται με το γεγονός, καθώς και δημιουργία προσαρμοσμένων γεγονότων. |
| [Aspose.Svg.Dom.Mutations](./aspose.svg.dom.mutations/) | Το **Aspose.Svg.Dom.Mutations** προσφέρει τη δυνατότητα παρατήρησης μεταβολών του DOM και λήψης συγκεκριμένων πληροφοριών κλήσης επιστροφής. |
| [Aspose.Svg.Dom.Traversal](./aspose.svg.dom.traversal/) | Ο χώρος ονομάτων **Aspose.Svg.Dom.Traversal** περιέχει μεθόδους που δημιουργούν επαναλήπτες και διασχίτες δέντρων για την πλοήγηση μεταξύ στοιχείων και τη διάσχιση ενός κόμβου και των παιδιών του με τη σειρά του εγγράφου. |
| [Aspose.Svg.Dom.Traversal.Filters](./aspose.svg.dom.traversal.filters/) | Ο χώρος ονομάτων αντιπροσωπεύει τη λειτουργία φιλτραρίσματος κόμβων. Τα φίλτρα είναι αντικείμενα που γνωρίζουν πώς να «φιλτράρουν» κόμβους. Εάν ένας επαναλήπτης κόμβων ή ένας διασχίτης δέντρου λαμβάνει ένα φίλτρο κόμβων, εφαρμόζει το φίλτρο πριν επιστρέψει τον επόμενο κόμβο. Εάν το φίλτρο δηλώνει αποδοχή του κόμβου, η λογική διάσχισης τον επιστρέφει· διαφορετικά, η διάσχιση αναζητά τον επόμενο κόμβο και προσποιείται ότι ο απορριφθέντας κόμβος δεν υπάρχει. |
| [Aspose.Svg.Dom.Views](./aspose.svg.dom.views/) | Ο χώρος ονομάτων **Aspose.Svg.Dom.Views** περιγράφει τις διεπαφές AbstractView και DocumentView σύμφωνα με την προδιαγραφή Document Object Model Views. |
| [Aspose.Svg.Dom.XPath](./aspose.svg.dom.xpath/) | Ο χώρος ονομάτων **Aspose.Svg.Dom.XPath** περιέχει μεθόδους για πλοήγηση μέσω στοιχείων και χαρακτηριστικών σε ένα έγγραφο XML. |
| [Aspose.Svg.Drawing](./aspose.svg.drawing/) | Ο χώρος ονομάτων **Aspose.Svg.Drawing** περιέχει αντικείμενα και διεπαφές για τον καθορισμό μετρήσεων και μονάδων, καθώς και αντικείμενα χαρακτηριστικών σχεδίασης όπως πινέλα, χρώματα και γραμματοσειρές. |
| [Aspose.Svg.Events](./aspose.svg.events/) | Ο χώρος ονομάτων αποτελείται από κλάσεις για διαδραστικότητα βασισμένη σε γεγονότα, όπως χρονικά γεγονότα και ζουμ. |
| [Aspose.Svg.Filters](./aspose.svg.filters/) | Ο χώρος ονομάτων **Aspose.Svg.Dom.Svg.Filters** περιέχει κλάσεις και διεπαφές σχετικές με τα εφέ φίλτρων στην προδιαγραφή SVG. |
| [Aspose.Svg.ImageVectorization](./aspose.svg.imagevectorization/) | Ο χώρος ονομάτων **Aspose.Svg.ImageVectorization** περιέχει κλάσεις για τη διανυσματοποίηση ραστερ εικόνων και τη μετατροπή τους σε έγγραφα SVG. Αυτή η διαδικασία περιλαμβάνει τη μείωση των bitmap σε γεωμετρικά σχήματα που αποτελούνται από στοιχεία διαδρομής και την αποθήκευσή τους ως SVG. Ο χώρος ονομάτων περιλαμβάνει κλάσεις για την κατασκευή τμημάτων διαδρομής, την απλοποίηση και εξομάλυνση σημείων ίχνους, καθώς και τη διαμόρφωση επιλογών διανυσματοποίησης. |
| [Aspose.Svg.IO](./aspose.svg.io/) | Εκτός από τα τυπικά εργαλεία IO (εισόδου-εξόδου), το **Aspose.Svg.IO** namespace περιέχει βοηθητικές κλάσεις και διεπαφές. |
| [Aspose.Svg.Net](./aspose.svg.net/) | Το **Aspose.Svg.Net** namespace παρουσιάζεται από κλάσεις και διεπαφές που είναι υπεύθυνες για τη διευκόλυνση της εύκολης επεξεργασίας δικτύου. |
| [Aspose.Svg.Net.Headers](./aspose.svg.net.headers/) | Το **Aspose.Svg.Net.Headers** παρέχει λίγες κλάσεις δεδομένων για την περιγραφή του περιεχομένου των κεφαλίδων στο δίκτυο. |

| [Aspose.Svg.Net.MessageHandlers](./aspose.svg.net.messagehandlers/) | Το **Aspose.Svg.Net.MessageHandlers** namespace παρουσιάζεται από κλάσεις - χειριστές μηνυμάτων διαφορετικών πρωτοκόλλων. |
| [Aspose.Svg.Paths](./aspose.svg.paths/) | Το **Aspose.Svg.Dom.Svg.Paths** namespace περιγράφει κλάσεις για την αναπαράσταση του περιγράμματος ενός σχήματος που μπορεί να γεμίσει ή να περιγράψεται. | [Aspose.Svg.Rendering.Xps](./aspose.svg.rendering.xps/) | Το **Aspose.Svg.Rendering.Xps** namespace παρέχει συγκεκριμένη κλάση συσκευής καθώς και λίγες κλάσεις επιλογών απόδοσης υπεύθυνες για την απόδοση σε έγγραφο xps. |

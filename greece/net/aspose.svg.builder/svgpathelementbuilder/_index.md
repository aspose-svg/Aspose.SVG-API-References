## SVGPathElementBuilder class

Κλάση Builder για την κατασκευή ενός στοιχείου SVG 'path', που χρησιμοποιείται για τον ορισμό διαδρομής σε ένα έγγραφο SVG. Αυτή η κλάση παρέχει μεθόδους για τον ορισμό διαφόρων χαρακτηριστικών ειδικών για το στοιχείο 'path' και για τη δημιουργία του περιεχομένου του.

```csharp
public class SVGPathElementBuilder : SVGElementBuilder<SVGPathElement>, IAnimationElementBuilder,
```

## SVGRectElementBuilder class

Κατηγορία Builder για τη δημιουργία ενός στοιχείου SVG 'rect'. Το στοιχείο 'rect' χρησιμοποιείται για τη δημιουργία ορθογωνίων μέσα σε γραφικά SVG. Αυτή η κατηγορία παρέχει μεθόδους για τον ορισμό διαφόρων χαρακτηριστικών ειδικών για το στοιχείο 'rect', συμπεριλαμβανομένων των ακτίνων γωνιών και των διαστάσεων.

```csharp
public class SVGRectElementBuilder : SVGElementBuilder<SVGRectElement>, IAnimationElementBuilder, 
    IDescriptiveElementBuilder, IPaintServerElementBuilder, IRectAttributeSetter, 
    IShapeAttributeSetter, IShapeContentElementBuilder
```

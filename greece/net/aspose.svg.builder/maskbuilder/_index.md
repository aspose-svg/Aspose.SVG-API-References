## MaskBuilder class

Μια κλάση builder για τη δημιουργία ιδιοτήτων CSS mask. Αυτή η κλάση επιτρέπει τη δημιουργία σύνθετων στυλ μάσκας χρησιμοποιώντας διάφορες ιδιότητες όπως πηγή μάσκας, θέση, μέγεθος, στυλ επανάληψης και άλλα. Η παραγόμενη συμβολοσειρά μπορεί να χρησιμοποιηθεί σε CSS για τον ορισμό της συμπεριφοράς μάσκας ενός στοιχείου.

## SVGLineElementBuilder class

Κλάση Builder για την κατασκευή ενός στοιχείου SVG 'line', που χρησιμοποιείται για τη σχεδίαση ευθείων γραμμών μέσα σε γραφικά SVG. Αυτή η κλάση επιτρέπει τη δημιουργία περιεχομένου μέσα στο στοιχείο 'line' και παρέχει μεθόδους για τον ορισμό διαφόρων χαρακτηριστικών ειδικών για το στοιχείο 'line' στο SVG.

```csharp
public class SVGLineElementBuilder : SVGElementBuilder<SVGLineElement>, IAnimationElementBuilder, 
    IDescriptiveElementBuilder, IPaintServerElementBuilder, IShapeAttributeSetter, 
    IShapeContentElementBuilder
```

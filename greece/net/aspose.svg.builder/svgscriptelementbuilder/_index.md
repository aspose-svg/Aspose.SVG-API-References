## SVGScriptElementBuilder class

Κατηγορία Builder για τη δημιουργία ενός στοιχείου SVG 'script'. Το στοιχείο 'script' χρησιμοποιείται για την ενσωμάτωση ή την αναφορά εκτελέσιμων σεναρίων μέσα σε έγγραφα SVG. Αυτή η κατηγορία παρέχει μεθόδους για τον ορισμό διαφόρων χαρακτηριστικών ειδικών για το στοιχείο 'script', όπως τύπος, πηγή και ρυθμίσεις διασταυρούμενης προέλευσης.

```csharp
public class SVGScriptElementBuilder : SVGElementBuilder<SVGScriptElement>, ICoreAttributeSetter, 
    IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter
```

## PathBuilder.Ar method

Προσθέτει μια σχετική εντολή 'Elliptical Arc Curve' στα δεδομένα διαδρομής.

```csharp
public PathBuilder Ar(double r1, double r2, double angle, bool largeArcFlag, bool sweepFlag, 
    double x, double y)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| r1 | Double | Η ακτίνα x του έλλειψα, σχετικά με την τρέχουσα θέση. |
| r2 | Double | Η ακτίνα y του έλλειψα, σχετικά με την τρέχουσα θέση. |
| angle | Double | Η γωνία περιστροφής του έλλειψα σε μοίρες, σχετικά με την τρέχουσα θέση. |
| largeArcFlag | Boolean | Σημαία που υποδεικνύει εάν το τόξο πρέπει να είναι μεγαλύτερο ή ίσο με 180 μοίρες. |
| sweepFlag | Boolean | Σημαία που υποδεικνύει εάν το τόξο πρέπει να σχεδιαστεί σε θετική κατεύθυνση γωνίας. |
| x | Double | Η συντεταγμένη x του τελικού σημείου της καμπύλης, σχετικά με την τρέχουσα θέση. |
| y | Double | Η συντεταγμένη y του τελικού σημείου της καμπύλης, σχετικά με την τρέχουσα θέση. |

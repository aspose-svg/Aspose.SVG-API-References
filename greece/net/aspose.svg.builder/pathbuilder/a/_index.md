```csharp
    double x, double y)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| r1 | Double | Η ακτίνα x του ellipse. |
| r2 | Double | Η ακτίνα y του ellipse. |
| angle | Double | Η γωνία περιστροφής του ellipse σε μοίρες. |
| largeArcFlag | Boolean | Σημαία που υποδεικνύει εάν το τόξο πρέπει να είναι μεγαλύτερο ή ίσο με 180 μοίρες. |
| sweepFlag | Boolean | Σημαία που υποδεικνύει εάν το τόξο πρέπει να σχεδιαστεί σε θετική κατεύθυνση γωνίας. |
| x | Double | Η συντεταγμένη x του τελικού σημείου του τόξου. |
| y | Double | Η συντεταγμένη y του τελικού σημείου του τόξου. |

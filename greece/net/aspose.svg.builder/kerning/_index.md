## Kerning enumeration

Καθορίζει τη συμπεριφορά του kerning για κείμενο σε SVG.

```csharp
public enum Kerning
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| Auto | `0` | Επιτρέπει στο πρόγραμμα περιήγησης να καθορίσει εάν πρέπει να εφαρμοστεί το kerning. |
| Normal | `1` | Εφαρμόζει το τυπικό kerning, όπως ορίζεται στο αρχείο γραμματοσειράς. |
| None | `2` | Απενεργοποιεί το kerning, αγνοώντας οποιαδήποτε πληροφορία kerning στη γραμματοσειρά. |

## Παρατηρήσεις

Η ιδιότητα 'font-kerning' στο SVG ελέγχει τη χρήση των πληροφοριών kerning που αποθηκεύονται σε μια γραμματοσειρά. Το kerning ρυθμίζει το διάστημα μεταξύ ατομικών ζευγών γραμμάτων για να βελτιώσει την οπτική εμφάνιση του κειμένου. Αυτή η απαρίθμηση παρέχει επιλογές για τον έλεγχο της συμπεριφοράς του kerning σε στοιχεία κειμένου SVG.

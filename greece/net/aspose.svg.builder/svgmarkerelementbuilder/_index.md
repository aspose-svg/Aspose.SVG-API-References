## SVGMarkerElementBuilder class

Κλάση Builder για την κατασκευή ενός στοιχείου SVG 'marker', που χρησιμοποιείται για τον ορισμό γραφικών σημειωτών, όπως κεφαλές βέλους ή κουκίδες, που μπορούν να προσαρτηθούν στα στοιχεία 'path', 'line', 'polyline' και 'polygon'. Αυτή η κλάση επιτρέπει τη δημιουργία περιεχομένου μέσα στο στοιχείο 'marker' και παρέχει μεθόδους για τον ορισμό διαφόρων χαρακτηριστικών ειδικών για το στοιχείο 'marker' στο SVG.

```csharp
public class SVGMarkerElementBuilder : SVGElementBuilder<SVGMarkerElement>, 
    ICompositeElementBuilder, ICoreAttributeSetter, IDocumentElementEventAttributeSetter, 
    IGlobalEventAttributeSetter, IPresentationAttributeSetter, IPreserveAspectRatioAttributeSetter, 
    IRefCoordinatesAttributeSetter, IViewBoxAttributeSetter
```

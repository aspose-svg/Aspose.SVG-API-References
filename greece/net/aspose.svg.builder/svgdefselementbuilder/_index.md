## SVGDefsElementBuilder class

Κατηγορία Builder για τη δημιουργία ενός στοιχείου SVG 'defs', το οποίο χρησιμοποιείται για τον ορισμό επαναχρησιμοποιήσιμων στοιχείων. Επιτρέπει την κατασκευή περιεχομένου μέσα στο στοιχείο 'defs' και παρέχει μεθόδους για τον ορισμό διαφόρων χαρακτηριστικών ειδικών για το στοιχείο 'defs' σε SVG.

```csharp
public class SVGDefsElementBuilder : SVGElementBuilder<SVGDefsElement>, ICompositeElementBuilder, 
    ICoreAttributeSetter, IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, 
    IGraphicalEventAttributeSetter, IPresentationAttributeSetter
```

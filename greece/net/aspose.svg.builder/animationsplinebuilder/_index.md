## AnimationSplineBuilder class

Μια κλάση builder για τη δημιουργία συναρτήσεων χρονομέτρησης animation χρησιμοποιώντας κυρτές Bézier. Αυτή η κλάση επιτρέπει τον ορισμό μιας ή περισσότερων κυρτών Bézier, καθεμία καθορισμένη από δύο σημεία ελέγχου. Η παραγόμενη συμβολοσειρά μπορεί να χρησιμοποιηθεί σε CSS animations ή transitions για τον έλεγχο του ρυθμού της animation.

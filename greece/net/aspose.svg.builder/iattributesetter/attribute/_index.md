## IAttributeSetter.Attribute method

Ορίζει ή ενημερώνει ένα χαρακτηριστικό σε ένα στοιχείο SVG.

```csharp
public void Attribute(string name, string value)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| name | String | Το όνομα του χαρακτηριστικού προς ορισμό. Αυτό πρέπει να είναι ένα έγκυρο όνομα χαρακτηριστικού SVG. |
| τιμή | String | Η τιμή που θα εκχωρηθεί στο χαρακτηριστικό. Η τιμή πρέπει να είναι μια αναπαράσταση συμβολοσειράς κατάλληλη για το συγκεκριμένο χαρακτηριστικό SVG. |

## Παρατηρήσεις

Αυτή η μέθοδος χρησιμοποιείται για τη δυναμική προσθήκη ή τροποποίηση χαρακτηριστικών στοιχείων SVG κατά τη διαδικασία κατασκευής. Παρέχει ευελιξία στον ορισμό και την προσαρμογή στοιχείων SVG επιτρέποντας τον ορισμό χαρακτηριστικών βάσει διαφόρων συνθηκών ή εισροών.

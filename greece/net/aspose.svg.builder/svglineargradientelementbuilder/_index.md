## SVGLinearGradientElementBuilder class

Κλάση Builder για την κατασκευή ενός στοιχείου SVG 'linearGradient', που χρησιμοποιείται για τον ορισμό γραμμικού διαβάθμισης μέσα σε γραφικά SVG. Επιτρέπει τη δημιουργία περιεχομένου μέσα στο στοιχείο 'linearGradient' και παρέχει μεθόδους για τον ορισμό διαφόρων χαρακτηριστικών ειδικών για το στοιχείο 'linearGradient' στο SVG.

```csharp
public class SVGLinearGradientElementBuilder : SVGElementBuilder<SVGLinearGradientElement>, 
    IBaseAnimationElementBuilder, ICoreAttributeSetter, IDescriptiveElementBuilder, 
    IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, IGradientStopElementBuilder, 
    IPresentationAttributeSetter
```

## CalcMode enumeration

Καθορίζει τις λειτουργίες υπολογισμού για την παρεμβολή τιμών σε κινήσεις SVG.

```csharp
public enum CalcMode
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| Discrete | `0` | Η animation μεταβαίνει από μια τιμή στην επόμενη χωρίς καμία παρεμβολή. |
| Linear | `1` | Οι τιμές της animation παρεμβάλλονται γραμμικά κατά τη διάρκεια της animation. |
| Paced | `2` | Η animation ρυθμίζεται έτσι ώστε η πρόοδος να είναι ομοιόμορφη σε όλη τη διάρκεια της animation. |
| Spline | `3` | Η κίνηση χρησιμοποιεί κυβικές καμπύλες Bézier για την παρεμβολή τιμών. |

## Παρατηρήσεις

Η λειτουργία υπολογισμού καθορίζει πώς μια SVG κίνηση μεταβαίνει μεταξύ τιμών κατά τη διάρκεια της κίνησης. Διαφορετικές λειτουργίες μπορούν να χρησιμοποιηθούν για τη δημιουργία διαφόρων εφέ και τον έλεγχο του ρυθμού και της ομαλότητας της κίνησης.

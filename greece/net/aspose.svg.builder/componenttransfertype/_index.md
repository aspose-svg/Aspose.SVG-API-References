## ComponentTransferType enumeration

Καθορίζει τον τύπο συνάρτησης μεταφοράς στοιχείου που θα εφαρμοστεί στην αρχική λειτουργία φίλτρου FeComponentTransfer ενός SVG.

```csharp
public enum ComponentTransferType
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| Identity | `0` | Αναπαριστά καμία αλλαγή στο εισερχόμενο γραφικό. Αυτός είναι ο προεπιλεγμένος τύπος. |
| Table | `1` | Χρησιμοποιεί πίνακα αναζήτησης για τον ορισμό της λειτουργίας μέσα στο φίλτρο. |
| Discrete | `2` | Χρησιμοποιεί ένα σύνολο διακριτών τιμών για τον ορισμό της λειτουργίας στο φίλτρο. |
| Linear | `3` | Ορίζει έναν γραμμικό μετασχηματισμό του στοιχείου μέσα στο φίλτρο. |
| Gamma | `4` | Ορίζει έναν μετασχηματισμό διόρθωσης γάμμα στο φίλτρο. |

## Παρατηρήσεις

Το primitive φίλτρου FeComponentTransfer επιτρέπει την ατομική διαχείριση των συνιστωσών χρώματος (RGB και άλφα) των γραφικών στοιχείων χρησιμοποιώντας διαφορετικούς τύπους συναρτήσεων μεταφοράς. Κάθε τύπος ορίζει μια ξεχωριστή μέθοδο υπολογισμού για τη μετατροπή των συνιστωσών χρώματος εντός του φίλτρου.

## BlendMode enumeration

Καθορίζει τις διαθέσιμες λειτουργίες ανάμειξης για τη συνένωση εικόνων ή στοιχείων σε SVG.

```csharp
public enum BlendMode
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| Normal | `0` | Εμφανίζει την πηγαία εικόνα όπως είναι, χωρίς καμία ανάμειξη. |
| Multiply | `1` | Πολλαπλασιάζει τα χρώματα της εικόνας προέλευσης και του φόντου. Το αποτέλεσμα είναι μια πιο σκοτεινή εικόνα. |
| Screen | `2` | Κάνει τα σκοτεινά μέρη της εικόνας προέλευσης πιο φωτεινά και τα φωτεινά μέρη αμετάβλητα. |
| Overlay | `3` | Συνδυάζει τις λειτουργίες ανάμειξης Multiply και Screen για να ενισχύσει την αντίθεση. |
| Darken | `4` | Σκοτεινώνει το φόντο βάσει των χρωμάτων της εικόνας προέλευσης. |
| Lighten | `5` | Φωτίζει το φόντο βάσει των χρωμάτων της εικόνας προέλευσης. |
| ColorDodge | `6` | Φωτίζει το φόντο ώστε να αντανακλά την εικόνα προέλευσης. |
| ColorBurn | `7` | Σκοτεινώνει το φόντο ώστε να αντανακλά την εικόνα προέλευσης. |
| HardLight | `8` | Δημιουργεί ένα εφέ σκληρού φωτός βάσει της φωτεινότητας της εικόνας προέλευσης. |
| SoftLight | `9` | Δημιουργεί ένα εφέ ήπιου φωτός βάσει της φωτεινότητας της εικόνας προέλευσης. |
| Difference | `10` | Τονίζει τις διαφορές μεταξύ της εικόνας προέλευσης και του φόντου. |
| Exclusion | `11` | Δημιουργεί ένα εφέ παρόμοιο με το Difference, αλλά με χαμηλότερη αντίθεση. |
| Hue | `12` | Χρησιμοποιεί την απόχρωση της εικόνας προέλευσης σε συνδυασμό με τη φωτεινότητα και τον κορεσμό του φόντου. |
| Saturation | `13` | Χρησιμοποιεί τον κορεσμό της εικόνας προέλευσης σε συνδυασμό με την απόχρωση και τη φωτεινότητα του φόντου. |
| Color | `14` | Χρησιμοποιεί την απόχρωση και τον κορεσμό της εικόνας προέλευσης σε συνδυασμό με τη φωτεινότητα του φόντου. |
| Luminosity | `15` | Χρησιμοποιεί τη φωτεινότητα της εικόνας προέλευσης σε συνδυασμό με την απόχρωση και τον κορεσμό του φόντου. |

## Παρατηρήσεις

Οι λειτουργίες ανάμειξης στο SVG χρησιμοποιούνται για να καθορίσουν πώς δύο στρώματα αναμειγνύονται μεταξύ τους. Αυτό το enum παρέχει μια ποικιλία επιλογών που ελέγχουν πώς τα χρώματα των αναμεμειγμένων στρωμάτων συνδυάζονται και παράγουν διαφορετικά οπτικά εφέ.

## AngleUnits enumeration

Καθορίζει τις μονάδες γωνιών που χρησιμοποιούνται για τον ορισμό του προσανατολισμού των σημειωτών σε SVG.

```csharp
public enum AngleUnits
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| Degrees | `0` | Καθορίζει τη γωνία σε μοίρες. Ένας πλήρης κύκλος είναι 360 μοίρες. |
| Gradians | `1` | Καθορίζει τη γωνία σε γρενίτες. Ένας πλήρης κύκλος είναι 400 γρενίτες. |
| Radians | `2` | Καθορίζει τη γωνία σε ακτίνια. Ένας πλήρης κύκλος είναι περίπου 6,283 ακτίνια (2π ακτίνια). |
| None | `3` | Δείχνει ότι δεν υπάρχει συγκεκριμένη μονάδα γωνίας. Χρησιμοποιείται για προεπιλεγμένες ή συμφραζόμενες ρυθμίσεις. |

## Παρατηρήσεις

Το χαρακτηριστικό 'orient' των σημειωτών SVG μπορεί να καθοριστεί σε διάφορες μονάδες γωνίας. Αυτή η απαρίθμηση παρέχει επιλογές για τον ορισμό αυτών των μονάδων.

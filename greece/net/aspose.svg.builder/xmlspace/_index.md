## XmlSpace enumeration

Καθορίζει πώς διαχειρίζεται το κενό διάστημα μέσα σε στοιχεία σε έγγραφα XML.

```csharp
public enum XmlSpace
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| Default | `0` | Δηλώνει ότι το κενό διάστημα πρέπει να διαχειρίζεται σύμφωνα με τη προεπιλεγμένη συμπεριφορά του επεξεργαστή XML, συνήθως κανονικοποιώντας το κενό διάστημα αφαιρώντας αλλαγές γραμμής και επιπλέον κενά. |
| Preserve | `1` | Δηλώνει ότι τα κενά πρέπει να διατηρούνται όπως εμφανίζονται στο έγγραφο XML. Αυτό είναι χρήσιμο για τη διατήρηση της μορφοποίησης του κειμένου όπου τα κενά είναι σημαντικά. |

## Παρατηρήσεις

Το χαρακτηριστικό 'xml:space' στο XML χρησιμοποιείται για τον έλεγχο του αν τα κενά μέσα στα στοιχεία πρέπει να διατηρούνται ή να κανονικοποιούνται. Αυτή η απαρίθμηση παρέχει επιλογές για τον καθορισμό αυτής της συμπεριφοράς σε έγγραφα XML και SVG.

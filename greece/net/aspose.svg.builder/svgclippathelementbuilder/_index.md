## SVGClipPathElementBuilder class

Κατηγορία Builder για τη δημιουργία ενός στοιχείου SVG 'clipPath', το οποίο χρησιμοποιείται για τον ορισμό διαδρομής αποκοπής. Επιτρέπει την κατασκευή περιεχομένου μέσα στο στοιχείο 'clipPath' και παρέχει μεθόδους για τον ορισμό διαφόρων χαρακτηριστικών ειδικών για το στοιχείο 'clipPath' σε SVG.

```csharp
public class SVGClipPathElementBuilder : SVGElementBuilder<SVGClipPathElement>, 
    IAnimationElementBuilder, ICompositeAttributeSetter, IDescriptiveElementBuilder, 
    IShapeElementBuilder
```

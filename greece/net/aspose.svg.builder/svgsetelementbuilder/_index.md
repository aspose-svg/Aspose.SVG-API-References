## SVGSetElementBuilder class

Κατηγορία Builder για τη δημιουργία ενός στοιχείου SVG 'set'. Το στοιχείο 'set' χρησιμοποιείται για τον ορισμό μιας απλής κίνησης όπου μια μοναδική τιμή χαρακτηριστικού αλλάζει κατά τη διάρκεια ενός χρονικού διαστήματος. Αυτή η κατηγορία παρέχει μεθόδους για τον ορισμό διαφόρων χαρακτηριστικών ειδικών για το στοιχείο 'set', όπως το χαρακτηριστικό-στόχος και η τιμή που θα οριστεί.

```csharp
public class SVGSetElementBuilder : SVGElementBuilder<SVGSetElement>, 
    IAnimationEventAttributeSetter, IAnimationTargetAttributeSetter, 
    IAnimationTargetElementAttributeSetter, IAnimationTimingAttributeSetter, 
    IConditionalProcessingAttributeSetter, ICoreAttributeSetter, IDescriptiveElementBuilder, 
    IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter
```

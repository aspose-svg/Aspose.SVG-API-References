## SVGDescElementBuilder class

Κατηγορία Builder για τη δημιουργία ενός στοιχείου SVG 'desc', το οποίο χρησιμοποιείται για την παροχή περιγραφής για στοιχεία περιέκτη SVG. Επιτρέπει την κατασκευή περιεχομένου μέσα στο στοιχείο 'desc' και παρέχει μεθόδους για τον ορισμό διαφόρων χαρακτηριστικών ειδικών για το στοιχείο 'desc' σε SVG.

```csharp
public class SVGDescElementBuilder : SVGElementBuilder<SVGDescElement>, ICoreAttributeSetter,
```

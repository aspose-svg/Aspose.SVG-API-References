## SVGCircleElementBuilder class

Κατηγορία Builder για τη δημιουργία ενός στοιχείου SVG 'circle', το οποίο χρησιμοποιείται για τη σχεδίαση κύκλων μέσα σε γραφικά SVG. Επιτρέπει την κατασκευή περιεχομένου μέσα στο στοιχείο 'circle' και παρέχει μεθόδους για τον ορισμό διαφόρων χαρακτηριστικών ειδικών για το στοιχείο 'circle' σε SVG.

```csharp
public class SVGCircleElementBuilder : SVGElementBuilder<SVGCircleElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IShapeAttributeSetter, IShapeContentElementBuilder
```

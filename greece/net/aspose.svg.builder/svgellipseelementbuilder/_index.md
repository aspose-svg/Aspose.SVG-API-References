## SVGEllipseElementBuilder class

Κατηγορία Builder για τη δημιουργία ενός στοιχείου SVG 'ellipse', το οποίο χρησιμοποιείται για τη σχεδίαση ελλείψεων μέσα σε γραφικά SVG. Επιτρέπει την κατασκευή περιεχομένου μέσα στο στοιχείο 'ellipse' και παρέχει μεθόδους για τον ορισμό διαφόρων χαρακτηριστικών ειδικών για το στοιχείο 'ellipse' σε SVG.

```csharp
public class SVGEllipseElementBuilder : SVGElementBuilder<SVGEllipseElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IShapeAttributeSetter, IShapeContentElementBuilder
```

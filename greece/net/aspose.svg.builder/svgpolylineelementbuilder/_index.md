## SVGPolylineElementBuilder class

Κατηγορία Builder για τη δημιουργία ενός στοιχείου SVG 'polyline'. Το στοιχείο 'polyline' χρησιμοποιείται για τη δημιουργία μιας σειράς ευθείων γραμμών που συνδέουν πολλαπλά σημεία σε γραφικά SVG. Αυτή η κατηγορία παρέχει μεθόδους για τον ορισμό διαφόρων χαρακτηριστικών και την κίνηση του στοιχείου polyline.

```csharp
public class SVGPolylineElementBuilder : SVGElementBuilder<SVGPolylineElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IPointsAttributeSetter, IShapeAttributeSetter, IShapeContentElementBuilder
```

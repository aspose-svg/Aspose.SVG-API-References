## SVGForeignObjectElementBuilder class

Κλάση Builder για την κατασκευή ενός στοιχείου SVG 'foreignObject', που επιτρέπει την ένταξη εξωτερικού περιεχομένου σε ένα έγγραφο SVG. Αυτό το στοιχείο μπορεί να περιέχει διάφορους τύπους περιεχομένου, όπως HTML και XHTML, επιτρέποντας πιο σύνθετες γραφικές αναπαραστάσεις μέσα στο SVG.

```csharp
public class SVGForeignObjectElementBuilder : SVGElementBuilder<SVGForeignObjectElement>, 
    ICompositeAttributeSetter, IRectAttributeSetter, ITextContentSetter
```

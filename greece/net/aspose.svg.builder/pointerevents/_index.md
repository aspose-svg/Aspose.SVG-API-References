## PointerEvents enumeration

Καθορίζει πώς διαχειρίζονται τα συμβάντα δείκτη από τα γραφικά στοιχεία στο SVG.

```csharp
public enum PointerEvents
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| BoundingBox | `0` | Τα συμβάντα δείκτη στοχεύουν στο πλαίσιο περιγράμματος του στοιχείου. |
| VisiblePainted | `1` | Τα συμβάντα δείκτη στοχεύουν μόνο στα ορατά (ζωγραφισμένα) μέρη του στοιχείου. |
| VisibleFill | `2` | Τα συμβάντα δείκτη στοχεύουν μόνο στα ορατά (γεμισμένα) μέρη του στοιχείου. |
| VisibleStroke | `3` | Τα συμβάντα δείκτη στοχεύουν μόνο στα ορατά (περιγραμμισμένα) μέρη του στοιχείου. |
| Visible | `4` | Τα συμβάντα δείκτη στοχεύουν σε όλα τα ορατά μέρη του στοιχείου. |
| Painted | `5` | Τα συμβάντα δείκτη στοχεύουν σε όλα τα ζωγραφισμένα μέρη του στοιχείου, συμπεριλαμβανομένου του γεμίσματος και της γραμμής. |
| Fill | `6` | Τα συμβάντα δείκτη στοχεύουν μόνο στα γεμισμένα μέρη του στοιχείου. |
| Stroke | `7` | Τα συμβάντα δείκτη στοχεύουν μόνο στα περιγραμμισμένα μέρη του στοιχείου. |
| All | `8` | Τα συμβάντα δείκτη στοχεύουν σε όλα τα μέρη του στοιχείου, ανεξάρτητα από την ορατότητα. |
| None | `9` | Το στοιχείο δεν γίνεται στόχος των συμβάντων δείκτη. |

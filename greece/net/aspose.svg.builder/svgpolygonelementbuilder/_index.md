## SVGPolygonElementBuilder class

Κατηγορία Builder για τη δημιουργία ενός στοιχείου SVG 'polygon'. Το στοιχείο 'polygon' χρησιμοποιείται για τη δημιουργία ενός γραφικού που περιέχει τουλάχιστον τρεις πλευρές. Αυτή η κατηγορία παρέχει μεθόδους για τον ορισμό διαφόρων χαρακτηριστικών και την κίνηση του στοιχείου polygon.

```csharp
public class SVGPolygonElementBuilder : SVGElementBuilder<SVGPolygonElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IPointsAttributeSetter, IShapeAttributeSetter, IShapeContentElementBuilder
```

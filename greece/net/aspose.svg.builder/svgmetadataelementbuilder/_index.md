## SVGMetadataElementBuilder class

Κλάση Builder για την κατασκευή ενός στοιχείου SVG 'metadata', που χρησιμοποιείται για την προσθήκη μεταδεδομένων σε ένα έγγραφο SVG. Αυτή η κλάση επιτρέπει την προσθήκη περιεχομένου μεταδεδομένων και παρέχει μεθόδους για τον ορισμό διαφόρων χαρακτηριστικών ειδικών για το στοιχείο 'metadata' στο SVG.

```csharp
public class SVGMetadataElementBuilder : SVGElementBuilder<SVGMetadataElement>, 
    ICoreAttributeSetter, IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, 
    ITextContentSetter
```

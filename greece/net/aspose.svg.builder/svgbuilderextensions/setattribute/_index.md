## SVGBuilderExtensions.SetAttribute<TBuilder> method

Ορίζει ένα χαρακτηριστικό στο στοιχείο SVG. Αυτή η μέθοδος χρησιμοποιείται για την προσθήκη ή τροποποίηση ενός χαρακτηριστικού του στοιχείου SVG που κατασκευάζεται.

```csharp
public static TBuilder SetAttribute<TBuilder>(this TBuilder builder, string name, string value)
    where TBuilder : IAttributeSetter
```

| Παράμετρος | Περιγραφή |
| --- | --- |
| TBuilder | Ο τύπος του builder στοιχείου SVG. |
| builder | Ο δημιουργός στοιχείου SVG στον οποίο ορίζεται το χαρακτηριστικό. |
| name | Το όνομα του χαρακτηριστικού που θα οριστεί. |
| τιμή | Η τιμή του χαρακτηριστικού. |

### Τιμή Επιστροφής

Ο αρχικός δημιουργός στοιχείου SVG για αλυσίδωση μεθόδων.

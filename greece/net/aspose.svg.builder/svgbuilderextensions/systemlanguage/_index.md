## SVGBuilderExtensions.SystemLanguage<TBuilder> method

Ορίζει το χαρακτηριστικό 'systemLanguage' στο στοιχείο SVG. Αυτό το χαρακτηριστικό καθορίζει τις προτιμήσεις γλώσσας για τις οποίες προορίζεται το τμήμα του εγγράφου SVG.

```csharp
public static TBuilder SystemLanguage<TBuilder>(this TBuilder builder, string value)
    where TBuilder : ISVGElementBuilder, IConditionalProcessingAttributeSetter
```

| Παράμετρος | Περιγραφή |
| --- | --- |
| TBuilder | Ο τύπος του builder στοιχείου SVG. |
| builder | Ο δημιουργός στοιχείου SVG στον οποίο ορίζεται το χαρακτηριστικό. |
| τιμή | Μια τιμή συμβολοσειράς που αντιπροσωπεύει τις προτιμήσεις γλώσσας, συνήθως με τη μορφή ετικετών γλώσσας. |

## LengthType enumeration

Καθορίζει τις μονάδες μέτρησης για τα μήκη στο SVG.

```csharp
public enum LengthType
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| Number | `1` | Αναπαριστά μια αριθμητική τιμή χωρίς μονάδα. Συχνά ερμηνεύεται στο πλαίσιο άλλων τιμών ή προεπιλεγμένων μονάδων. |
| Percentage | `2` | Αναπαριστά μια τιμή ποσοστού, σχετική με άλλη τιμή ή μια διαστατική διάσταση. |
| Ems | `3` | Αναπαριστά ένα μήκος σε 'ems', μια κλιμακώσιμη μονάδα που σχετίζεται με το τρέχον μέγεθος γραμματοσειράς. |
| Exs | `4` | Αναπαριστά ένα μήκος σε 'exs', σχετικό με το ύψος x της τρέχουσας γραμματοσειράς. |
| Px | `5` | Αναπαριστά ένα μήκος σε εικονοστοιχεία (pixels), μια μονάδα μέτρησης βασισμένη στην ψηφιακή αναπαράσταση μιας εικόνας. |
| Cm | `6` | Αναπαριστά ένα μήκος σε εκατοστά. |
| Mm | `7` | Αναπαριστά ένα μήκος σε χιλιοστά. |
| In | `8` | Αναπαριστά ένα μήκος σε ίντσες. |
| Pt | `9` | Αναπαριστά ένα μήκος σε πόντους, μια παραδοσιακή μονάδα στην τυπογραφία. 1 πόντος είναι περίπου 1/72 της ίντσας. |
| Pc | `10` | Αντιπροσωπεύει ένα μήκος σε picas, μια τυπογραφική μονάδα μέτρησης. 1 pica ισοδυναμεί με 12 σημεία. |

## Παρατηρήσεις

Αυτή η απαρίθμηση ορίζει διάφορες μονάδες που μπορούν να χρησιμοποιηθούν για τον καθορισμό μηκών σε στοιχεία SVG. Αυτές οι μονάδες περιλαμβάνουν απόλυτες μετρήσεις όπως pixel και εκατοστά, καθώς και σχετικές μετρήσεις όπως ποσοστά και em.

## CompositingOperator enumeration

Καθορίζει τον τύπο λειτουργίας σύνθεσης που θα εφαρμοστεί σε λειτουργίες masking SVG.

```csharp
public enum CompositingOperator
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| Add | `0` | Προσθέτει τις τιμές χρώματος του πηγαίου γραφικού στο προορισμένο γραφικό. |
| Subtract | `1` | Αφαιρεί τις τιμές χρώματος του πηγαίου γραφικού από το προορισμένο γραφικό. |
| Intersect | `2` | Εμφανίζει μόνο τις περιοχές όπου τα πηγαία και προορισμένα γραφικά επικαλύπτονται. |
| Exclude | `3` | Εξαιρεί τις επικαλυπτόμενες περιοχές των πηγαίων και προορισμένων γραφικών. |

## Παρατηρήσεις

Οι τελεστές σύνθεσης σε μάσκες SVG καθορίζουν πώς διαφορετικά γραφικά στοιχεία συνδυάζονται για να δημιουργήσουν ένα εφέ μάσκας. Κάθε τελεστής ορίζει μια μοναδική μέθοδο ανάμειξης ή συνδυασμού αυτών των στοιχείων για την επίτευξη διαφόρων εφέ μάσκας.

## SVGStopElementBuilder class

Κατηγορία Builder για τη δημιουργία ενός στοιχείου SVG 'stop'. Το στοιχείο 'stop' χρησιμοποιείται μέσα σε έναν ορισμό διαβάθμισης (γραμμική ή ακτινική) για τον ορισμό των σημείων χρώματος. Αυτή η κατηγορία παρέχει μεθόδους για τον ορισμό διαφόρων χαρακτηριστικών ειδικών για το στοιχείο 'stop', όπως η απόσταση και το χρώμα.

```csharp
public class SVGStopElementBuilder : SVGElementBuilder<SVGStopElement>, 
    IBaseAnimationElementBuilder, ICoreAttributeSetter, IDocumentElementEventAttributeSetter, 
    IGlobalEventAttributeSetter, IPresentationAttributeSetter
```

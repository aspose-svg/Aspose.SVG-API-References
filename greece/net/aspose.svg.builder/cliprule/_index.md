## ClipRule enumeration

Ορίζει τον κανόνα για τον καθορισμό του τρόπου αποκοπής διαδρομών σε γραφικά SVG.

```csharp
public enum ClipRule
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| Nonzero | `0` | Ο κανόνας μη μηδενικής περιδίνησης για αποκοπή διαδρομών. |
| Evenodd | `1` | Ο κανόνας περιδίνησης ζυγός-μονός για αποκοπή διαδρομών. |

## Παρατηρήσεις

Η ιδιότητα clip rule στο SVG καθορίζει πώς αποκόπτονται οι διαδρομές. Είναι ιδιαίτερα σημαντική όταν μια διαδρομή διασταυρώνεται με τον εαυτό της ή όταν συνδυάζονται πολλαπλές διαδρομές. Ο κανόνας βοηθά στην απόφαση ποια τμήματα της διαδρομής είναι "inside" και πρέπει να γεμίσουν (ή να είναι ορατά) και ποια είναι "outside" και πρέπει να αποκοπούν (ή να είναι αόρατα).

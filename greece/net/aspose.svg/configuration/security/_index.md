## Configuration.Security property

Αυτή η ιδιότητα σας επιτρέπει να ορίσετε έναν αριθμό περιορισμών στο περιεχόμενο που φορτώνεται στο πλαίσιο, για παράδειγμα, μπλοκάρισμα φορμών και σεναρίων. Αναφερθείτε στο άρθρο σχετικά με [sandboxing](https://docs.aspose.com/html/net/environment-configuration/#sandboxing).

```csharp
public Sandbox Security { get; set; }
```

### Property Value

Ένα σύνολο σημαιών [`Sandbox`](../../sandbox/) είναι ένα σύνολο μηδέν ή περισσότερων σημαιών, που χρησιμοποιούνται για τον περιορισμό των δυνατοτήτων πιθανώς μη αξιόπιστων πόρων.

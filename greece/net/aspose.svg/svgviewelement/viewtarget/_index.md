## SVGViewElement.ViewTarget property

Αντιστοιχεί στο χαρακτηριστικό ‘viewTarget’ του δεδομένου στοιχείου ‘view’. Μια λίστα τιμών DOMString που περιέχουν τα ονόματα που αναφέρονται στο χαρακτηριστικό ‘viewTarget’. Κάθε τιμή DOMString μπορεί να συσχετιστεί με το αντίστοιχο στοιχείο χρησιμοποιώντας την κλήση μεθόδου getElementById().

```csharp
public SVGStringList ViewTarget { get; }
```

### Property Value

Το χαρακτηριστικό ‘viewTarget’ του συγκεκριμένου στοιχείου ‘view’.

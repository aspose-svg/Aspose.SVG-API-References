## Sandbox enumeration

Ένα σύνολο σημαιών απομονωτικού περιβάλλοντος είναι ένα σύνολο από μηδέν ή περισσότερες από τις παρακάτω σημαίες, οι οποίες χρησιμοποιούνται για τον περιορισμό των δυνατοτήτων που ενδέχεται να έχουν μη αξιόπιστοι πόροι.

```csharp
[Flags]
public enum Sandbox
```

### Τιμές

| Όνομα | Τιμή | Περιγραφή |
| --- | --- | --- |
| None | `0` | Δεν έχει οριστεί καμία σημαία, κάθε δυνατότητα απομόνωσης γίνεται αποδεκτή. |
| Navigation | `1` | Αυτή η σημαία εμποδίζει το περιεχόμενο να πλοηγείται σε περιβάλλοντα περιήγησης διαφορετικά από το απομονωμένο περιβάλλον περιήγησης (ή σε περιβάλλοντα περιήγησης που είναι περαιτέρω ενσωματωμένα μέσα σε αυτό), σε βοηθητικά περιβάλλοντα περιήγησης (που προστατεύονται από την επόμενη σημαία απομονωμένου βοηθητικού πλοήγησης περιβάλλοντος), και στο ανώτερο περιβάλλον περιήγησης (που προστατεύεται από την παρακάτω σημαία απομονωμένου ανώτερου πλοήγησης περιβάλλοντος). Εάν η σημαία απομονωμένου βοηθητικού πλοήγησης περιβάλλοντος δεν είναι ορισμένη, τότε σε ορισμένες περιπτώσεις οι περιορισμοί επιτρέπουν ωστόσο τα αναδυόμενα παράθυρα (νέα ανώτερα περιβάλλοντα περιήγησης) να ανοίγουν. Αυτά τα περιβάλλοντα περιήγησης έχουν πάντα έναν επιτρεπόμενο απομονωμένο περιηγητή, ο οποίος ορίζεται όταν δημιουργείται το περιβάλλον περιήγησης, και επιτρέπει στο περιβάλλον που τα δημιούργησε να τα πλοηγηθεί πραγματικά. (Διαφορετικά, η σημαία απομονωμένου πλοήγησης περιβάλλοντος θα τα εμπόδιζε να πλοηγηθούν ακόμη και αν ανοίχτηκαν.) |
| AuxiliaryNavigation | `2` | Αυτή η σημαία εμποδίζει το περιεχόμενο να δημιουργεί νέα βοηθητικά περιβάλλοντα περιήγησης, π.χ. χρησιμοποιώντας το χαρακτηριστικό target ή τη μέθοδο window.open(). |
| TopLevelNavigation | `4` | Αυτή η σημαία εμποδίζει το περιεχόμενο να πλοηγείται στο ανώτερο περιβάλλον περιήγησης του και να κλείνει το ανώτερο περιβάλλον περιήγησης του. Όταν η σημαία απομονωμένου ανώτερου πλοήγησης περιβάλλοντος δεν είναι ορισμένη, το περιεχόμενο μπορεί να πλοηγηθεί στο ανώτερο περιβάλλον περιήγησης του, αλλά άλλα περιβάλλοντα περιήγησης παραμένουν προστατευμένα από τη σημαία απομονωμένου πλοήγησης περιβάλλοντος και ενδεχομένως από τη σημαία απομονωμένου βοηθητικού πλοήγησης περιβάλλοντος. |
| Plugins | `8` | Αυτή η σημαία εμποδίζει το περιεχόμενο να δημιουργεί plugins, είτε χρησιμοποιώντας το στοιχείο embed, το στοιχείο object, το στοιχείο applet, είτε μέσω πλοήγησης σε ενσωματωμένο περιβάλλον περιήγησης, εκτός εάν αυτά τα plugins μπορούν να ασφαλιστούν. |
| Origin | `10` | Αυτή η σημαία αναγκάζει το περιεχόμενο σε μοναδική προέλευση, εμποδίζοντάς το έτσι από την πρόσβαση σε άλλο περιεχόμενο με την ίδια προέλευση. |
| Forms | `20` | Αυτή η σημαία εμποδίζει την υποβολή φόρμας. |
| PointerLock | `40` | Αυτή η σημαία απενεργοποιεί το API κλειδώματος δείκτη. |
| Scripts | `80` | Αυτή η σημαία εμποδίζει την εκτέλεση σεναρίου. |
| AutomaticFeatures | `100` | Αυτή η σημαία εμποδίζει λειτουργίες που ενεργοποιούνται αυτόματα, όπως η αυτόματη αναπαραγωγή βίντεο ή η αυτόματη εστίαση σε στοιχείο φόρμας. |
| Fullscreen | `200` | Αυτή η σημαία εμποδίζει το περιεχόμενο να χρησιμοποιεί τη μέθοδο requestFullscreen(). |
| DocumentDomain | `400` | Αυτή η σημαία εμποδίζει το περιεχόμενο να χρησιμοποιεί τη λειτουργία document.domain για να αλλάξει την αποτελεσματική προέλευση του σεναρίου. |
| Images | `800` | Αυτή η σημαία απενεργοποιεί τη φόρτωση εικόνων. |

## SVGSVGElement.GetElementById method

Αναζητά σε αυτό το τμήμα εγγράφου SVG (δηλαδή, η αναζήτηση περιορίζεται σε ένα υποσύνολο του δέντρου εγγράφου) ένα Element του οποίου το id δίνεται από το elementId. Εάν βρεθεί ένα Element, αυτό το Element επιστρέφεται. Εάν δεν υπάρχει τέτοιο στοιχείο, επιστρέφει null. Η συμπεριφορά δεν ορίζεται εάν περισσότερα από ένα στοιχεία έχουν αυτό το id.

```csharp
public Element GetElementById(string elementId)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| elementId | String | Η μοναδική τιμή id για ένα στοιχείο. |

## SVGDocument class

Ένα `SVGDocument` είναι η ρίζα της ιεραρχίας SVG και περιέχει όλο το περιεχόμενο. Εκτός από την παροχή πρόσβασης στην ιεραρχία, παρέχει επίσης κάποιες μεθόδους ευκολίας για την πρόσβαση σε συγκεκριμένα σύνολα πληροφοριών από το έγγραφο. Εκτός από τη φόρτωση τυπικών αρχείων .svg, τόσο οι κατασκευαστές όσο και η μέθοδος [`Navigate`](../../aspose.svg.dom/document/navigate/) μπορούν να φορτώσουν συμπιεσμένα gzip αρχεία .svgz. Όταν ένα στοιχείο ‘svg’ ενσωματώνεται εντός μιας γραμμής ως στοιχείο ενός εγγράφου από διαφορετικό namespace, όπως όταν ένα στοιχείο ‘svg’ ενσωματώνεται εντός ενός εγγράφου XHTML [XHTML], τότε δεν θα υπάρχει αντικείμενο SVGDocument· αντίθετα, το ριζικό αντικείμενο στην ιεραρχία αντικειμένων του εγγράφου θα είναι ένα αντικείμενο Document διαφορετικού τύπου, όπως ένα αντικείμενο HTMLDocument. Ωστόσο, ένα αντικείμενο SVGDocument θα υπάρχει πράγματι όταν το ριζικό στοιχείο της ιεραρχίας του XML εγγράφου είναι ένα στοιχείο ‘svg’, όπως όταν προβάλλεται ένα αυτόνομο αρχείο SVG (δηλαδή, ένα αρχείο με MIME τύπο \"image/svg+xml\"). Σε αυτήν την περίπτωση, το αντικείμενο SVGDocument θα είναι το ριζικό αντικείμενο του μοντέλου αντικειμένων του εγγράφου.

```csharp
public class SVGDocument : Document, IDocumentCSS
```

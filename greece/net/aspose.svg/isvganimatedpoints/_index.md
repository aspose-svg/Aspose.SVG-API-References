## ISVGAnimatedPoints interface

Η διεπαφή SVGAnimatedPoints υποστηρίζει στοιχεία που διαθέτουν χαρακτηριστικό ‘points’ που περιέχει λίστα τιμών συντεταγμένων και που υποστηρίζουν τη δυνατότητα animation αυτού του χαρακτηριστικού. Επιπλέον, το χαρακτηριστικό ‘points’ στο αρχικό στοιχείο που προσπελάζεται μέσω του XML DOM (π.χ., χρησιμοποιώντας την κλήση μεθόδου getAttribute()) θα αντικατοπτρίζει τυχόν αλλαγές που έγιναν στα points.

```csharp
public interface ISVGAnimatedPoints
```

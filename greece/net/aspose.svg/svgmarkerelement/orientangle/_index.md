## SVGMarkerElement.OrientAngle property

Αντιστοιχεί στο χαρακτηριστικό ‘orient’ του δεδομένου στοιχείου ‘marker’. Εάν το markerUnits είναι SVG_MARKER_ORIENT_ANGLE, η τιμή γωνίας για το χαρακτηριστικό ‘orient’; διαφορετικά, θα οριστεί στο μηδέν.

```csharp
public SVGAnimatedAngle OrientAngle { get; }
```

### Property Value

Η ιδιότητα ‘orient’ του συγκεκριμένου στοιχείου ‘marker’.

## SVGPolygonElement.AnimatedPoints property

Παρέχει πρόσβαση στα τρέχοντα κινούμενα περιεχόμενα του χαρακτηριστικού ‘points’. Εάν το δεδομένο χαρακτηριστικό ή ιδιότητα είναι σε κίνηση, περιέχει την τρέχουσα κινούμενη τιμή του χαρακτηριστικού ή της ιδιότητας. Εάν το δεδομένο χαρακτηριστικό ή ιδιότητα δεν είναι αυτή τη στιγμή σε κίνηση, περιέχει την ίδια τιμή με το points.

```csharp
public SVGPointList AnimatedPoints { get; }
```

### Property Value

Τα κινούμενα points.

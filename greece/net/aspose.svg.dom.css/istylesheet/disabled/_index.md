## IStyleSheet.Disabled property

false εάν το φύλλο στυλ εφαρμόζεται στο έγγραφο. true εάν δεν εφαρμόζεται. Η τροποποίηση αυτού του χαρακτηριστικού μπορεί να προκαλέσει νέα επίλυση στυλ για το έγγραφο. Ένα φύλλο στυλ εφαρμόζεται μόνο εάν υπάρχει τόσο ο κατάλληλος ορισμός μέσου όσο και το χαρακτηριστικό disabled είναι false. Έτσι, εάν το μέσο δεν εφαρμόζεται στον τρέχοντα πράκτορα χρήστη, το χαρακτηριστικό disabled αγνοείται.

```csharp
public bool Disabled { get; set; }
```

### Property Value

`true` εάν είναι disabled· διαφορετικά, `false`.

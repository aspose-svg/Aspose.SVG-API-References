## IStyleSheet interface

Η διεπαφή StyleSheet είναι η αφηρημένη βασική διεπαφή για οποιονδήποτε τύπο φύλλου στυλ. Αντιπροσωπεύει ένα μοναδικό φύλλο στυλ που συνδέεται με ένα δομημένο έγγραφο.

```csharp
public interface IStyleSheet
```

## Ιδιότητες

| Όνομα | Περιγραφή |
| --- | --- |
| [Disabled](../../aspose.svg.dom.css/istylesheet/disabled/) { get; set; } | false εάν το φύλλο στυλ εφαρμόζεται στο έγγραφο. true εάν δεν εφαρμόζεται. Η τροποποίηση αυτού του χαρακτηριστικού μπορεί να προκαλέσει νέα επίλυση στυλ για το έγγραφο. Ένα φύλλο στυλ εφαρμόζεται μόνο εάν υπάρχει τόσο ο κατάλληλος ορισμός μέσου όσο και το χαρακτηριστικό disabled είναι false. Έτσι, εάν το μέσο δεν εφαρμόζεται στον τρέχοντα πράκτορα χρήστη, το χαρακτηριστικό disabled αγνοείται. |
| [Href](../../aspose.svg.dom.css/istylesheet/href/) { get; } | Αν το φύλλο στυλ είναι συνδεδεμένο φύλλο στυλ, η τιμή του χαρακτηριστικού του είναι η θέση του. Για ενσωματωμένα φύλλα στυλ, η τιμή αυτού του χαρακτηριστικού είναι null. |
| [Media](../../aspose.svg.dom.css/istylesheet/media/) { get; } | Το προοριζόμενο μέσο προορισμού για τις πληροφορίες στυλ. |
| [OwnerNode](../../aspose.svg.dom.css/istylesheet/ownernode/) { get; } | Ο κόμβος που συνδέει αυτό το φύλλο στυλ με το έγγραφο. Για HTML, αυτό μπορεί να είναι το αντίστοιχο στοιχείο LINK ή STYLE. Για XML, μπορεί να είναι η οδηγική οδηγία επεξεργασίας. Για φύλλα στυλ που περιλαμβάνονται από άλλα φύλλα στυλ, η τιμή αυτού του χαρακτηριστικού είναι null. |
| [ParentStyleSheet](../../aspose.svg.dom.css/istylesheet/parentstylesheet/) { get; } | Για γλώσσες φύλλων στυλ που υποστηρίζουν την έννοια της ένταξης φύλλων στυλ, αυτό το χαρακτηριστικό αντιπροσωπεύει το φύλλο στυλ που περιλαμβάνει, εάν υπάρχει. Εάν το φύλλο στυλ είναι φύλλο στυλ ανώτερου επιπέδου ή η γλώσσα φύλλων στυλ δεν υποστηρίζει ένταξη, η τιμή αυτού του χαρακτηριστικού είναι null. |
| [Title](../../aspose.svg.dom.css/istylesheet/title/) { get; } | Ο συμβουλευτικός τίτλος. |
| [Type](../../aspose.svg.dom.css/istylesheet/type/) { get; } | Καθορίζει τη γλώσσα του φύλλου στυλ για αυτό το φύλλο στυλ. Η γλώσσα του φύλλου στυλ καθορίζεται ως τύπος περιεχομένου (π.χ. \"text/css\"). |

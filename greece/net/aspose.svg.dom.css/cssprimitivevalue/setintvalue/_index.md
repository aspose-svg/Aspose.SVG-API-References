## CSSPrimitiveValue.SetIntValue method

Μέθοδος για ορισμό της τιμής int με συγκεκριμένη μονάδα. Εάν η ιδιότητα που συνδέεται με αυτήν την τιμή δεν μπορεί να αποδεχθεί τη συγκεκριμένη μονάδα ή την τιμή int, η τιμή θα παραμείνει αμετάβλητη και θα προκληθεί μια DOMException.

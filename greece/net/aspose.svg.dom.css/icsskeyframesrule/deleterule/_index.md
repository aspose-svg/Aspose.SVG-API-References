## ICSSKeyframesRule.DeleteRule method

Η μέθοδος deleteRule διαγράφει το CSSKeyframeRule με το δοσμένο κλειδί. Εάν δεν υπάρχει κανένας κανόνας με αυτό το κλειδί, η μέθοδος δεν κάνει τίποτα

```csharp
public void DeleteRule(string key)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| κλειδί | String | Το κλειδί που περιγράφει τον κανόνα προς διαγραφή. Το κλειδί πρέπει να αντιστοιχεί σε αριθμό μεταξύ 0 και 1, διαφορετικά ο κανόνας αγνοείται. |

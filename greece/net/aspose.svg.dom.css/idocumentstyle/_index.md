## IDocumentStyle interface

Η διεπαφή DocumentStyle παρέχει έναν μηχανισμό με τον οποίο τα φύλλα στυλ ενσωματωμένα σε ένα έγγραφο μπορούν να ανακτηθούν. Η προσδοκία είναι ότι μια παρουσία της διεπαφής DocumentStyle μπορεί να ληφθεί χρησιμοποιώντας μεθόδους μετατροπής ειδικές για το binding σε μια παρουσία της διεπαφής Document.

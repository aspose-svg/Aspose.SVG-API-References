## ILinkStyle interface

Η διεπαφή LinkStyle παρέχει έναν μηχανισμό με τον οποίο ένα φύλλο στυλ μπορεί να ανακτηθεί από τον κόμβο που είναι υπεύθυνος για τη σύνδεσή του σε ένα έγγραφο. Μια παρουσία της διεπαφής LinkStyle μπορεί να ληφθεί χρησιμοποιώντας μεθόδους μετατροπής ειδικές για το binding σε μια παρουσία ενός κόμβου σύνδεσης (HTMLLinkElement, HTMLStyleElement ή ProcessingInstruction στο DOM Level 2).

## CSSValueList.Length property

Η ιδιότητα length μόνο για ανάγνωση της διεπαφής CSSValueList αντιπροσωπεύει τον αριθμό των CSSValues στη λίστα. Το εύρος των έγκυρων τιμών των δεικτών είναι από 0 έως length-1, συμπεριλαμβανομένου.

```csharp
public int Length { get; }
```

### Property Value

Ένας int που αντιπροσωπεύει τον αριθμό των CSSValues στην τρέχουσα παρουσία.

## ICSSRule.ParentRule property

Εάν αυτός ο κανόνας περιέχεται μέσα σε έναν άλλο κανόνα (π.χ. ένας κανόνας στυλ μέσα σε ένα μπλοκ @media), αυτός είναι ο περιέχων κανόνας. Εάν αυτός ο κανόνας δεν είναι ενσωματωμένος σε κανέναν άλλο κανόνα, επιστρέφει null.

```csharp
public ICSSRule ParentRule { get; }
```

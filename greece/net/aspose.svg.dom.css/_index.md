Ο χώρος ονομάτων **Aspose.Svg.Dom.Css** αφορά όλες τις επεμβάσεις σχετικές με CSS. Επικεντρώνεται στα ζεύγη όνομα‑τιμή ιδιοτήτων CSS που ορίζονται από τα επίσημα έγγραφα CSS.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [Counter](./counter/) | Η διεπαφή Counter χρησιμοποιείται για την αναπαράσταση οποιασδήποτε τιμής μετρητή ή συνάρτησης counters. Αυτή η διεπαφή αντικατοπτρίζει τις τιμές στην υποκείμενη ιδιότητα στυλ. |
| [CSSPrimitiveValue](./cssprimitivevalue/) | Η διεπαφή CSSPrimitiveValue αντιπροσωπεύει μια μοναδική τιμή CSS. Αυτή η διεπαφή μπορεί να χρησιμοποιηθεί για τον καθορισμό της τιμής μιας συγκεκριμένης ιδιότητας στυλ που είναι αυτή τη στιγμή ορισμένη σε ένα μπλοκ ή για τον ορισμό μιας συγκεκριμένης ιδιότητας στυλ ρητά μέσα στο μπλοκ. Μια παρουσία αυτής της διεπαφής μπορεί να ληφθεί από τη μέθοδο getPropertyCSSValue της διεπαφής CSSStyleDeclaration. Ένα αντικείμενο CSSPrimitiveValue εμφανίζεται μόνο σε ένα πλαίσιο ιδιότητας CSS. |
| [CSSValue](./cssvalue/) | Αντιπροσωπεύει μια απλή ή σύνθετη τιμή. Ένα αντικείμενο CSSValue εμφανίζεται μόνο σε ένα πλαίσιο ιδιότητας CSS. |
| [CSSValueList](./cssvaluelist/) | Η διεπαφή CSSValueList παρέχει την αφαιρετική αναπαράσταση μιας διατεταγμένης συλλογής τιμών CSS. |
| [Rect](./rect/) | Η διεπαφή Rect χρησιμοποιείται για την αναπαράσταση οποιασδήποτε τιμής rect. Αυτή η διεπαφή αντικατοπτρίζει τις τιμές στην υποκείμενη ιδιότητα στυλ. Συνεπώς, οι τροποποιήσεις που γίνονται στα αντικείμενα CSSPrimitiveValue τροποποιούν την ιδιότητα στυλ. |
| [RGBColor](./rgbcolor/) | Η διεπαφή RGBColor χρησιμοποιείται για την αναπαράσταση οποιασδήποτε τιμής χρώματος RGB. Αυτή η διεπαφή αντικατοπτρίζει τις τιμές στην υποκείμενη ιδιότητα στυλ. Συνεπώς, οι τροποποιήσεις που γίνονται στα αντικείμενα CSSPrimitiveValue τροποποιούν την ιδιότητα στυλ. |

Η τιμή του χαρακτηριστικού encoding μπορεί επίσης να χρησιμοποιηθεί ως υπόδειξη για την κωδικοποίηση που χρησιμοποιείται κατά τη σειριοποίηση του φύλλου στυλ. |

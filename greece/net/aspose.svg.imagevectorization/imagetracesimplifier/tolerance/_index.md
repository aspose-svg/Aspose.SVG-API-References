## ImageTraceSimplifier.Tolerance property

Η τιμή της ανοχής καθορίζει τη μέγιστη επιτρεπόμενη ανοχή σφάλματος για την αφαίρεση ενός σημείου από το ίχνος. Πρέπει να βρίσκεται στο εύρος από 0 έως 4. Οποιαδήποτε υψηλότερη ή χαμηλότερη τιμή θα ευθυγραμμιστεί με τις ελάχιστες και μέγιστες τιμές αυτού του εύρους, αντίστοιχα. Η προεπιλεγμένη τιμή είναι 0,3.

```csharp
public float Tolerance { get; set; }
```

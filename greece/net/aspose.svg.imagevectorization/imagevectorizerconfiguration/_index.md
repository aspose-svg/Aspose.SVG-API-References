## ImageVectorizerConfiguration class

Η κλάση `ImageVectorizerConfiguration` ορίζει μια διαμόρφωση μεθόδων και επιλογών διανυσματισμού εικόνας. Η διαμόρφωση χρησιμοποιείται για την αρχικοποίηση ενός ImageVectorizer και παρέχει τις επιλογές διαμόρφωσης για τον διανυσματισμό εικόνων.

## IXPathResult.SnapshotLength property

Ο αριθμός των κόμβων στη λήψη στιγμιότυπου του αποτελέσματος. Έγκυρες τιμές για τα ευρετήρια snapshotItem είναι από `0` έως `snapshotLength-1` συμπεριλαμβανομένα.

public int SnapshotLength { get; }

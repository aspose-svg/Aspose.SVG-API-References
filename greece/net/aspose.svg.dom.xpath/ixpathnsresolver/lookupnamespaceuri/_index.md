## IXPathNSResolver.LookupNamespaceURI method

Αναζητήστε το namespace URI που σχετίζεται με το δεδομένο πρόθεμα namespace. Ο αξιολογητής XPath δεν πρέπει ποτέ να καλέσει αυτό με ένα `null` ή κενό όρισμα, επειδή το αποτέλεσμα αυτής της κλήσης είναι ακαθόριστο.

```csharp
public string LookupNamespaceURI(string prefix)
```

| Παράμετρος | Τύπος | Περιγραφή |
| --- | --- | --- |
| prefix | String | Το πρόθεμα προς αναζήτηση. |

### Τιμή Επιστροφής

Επιστρέφει το σχετικό URI ονοματοχώρου ή `null` εάν δεν βρεθεί κανένα.

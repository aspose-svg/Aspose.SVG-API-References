## NodeFilter.FILTER_SKIP field

Παράλειψη αυτού του μοναδικού κόμβου. Οι μέθοδοι πλοήγησης που ορίζονται για NodeIterator ή TreeWalker δεν θα επιστρέψουν αυτόν τον κόμβο. Για τόσο το NodeIterator όσο και το TreeWalker, τα παιδιά αυτού του κόμβου θα εξακολουθούν να λαμβάνονται υπόψη.

```csharp
public const short FILTER_SKIP;
```

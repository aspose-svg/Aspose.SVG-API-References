## NodeFilter.FILTER_REJECT field

Απόρριψη του κόμβου. Οι μέθοδοι πλοήγησης που ορίζονται για NodeIterator ή TreeWalker δεν θα επιστρέψουν αυτόν τον κόμβο. Για το TreeWalker, τα παιδιά αυτού του κόμβου θα απορριφθούν επίσης. Οι NodeIterators θεωρούν αυτό ως συνώνυμο του FILTER_SKIP.

```csharp
public const short FILTER_REJECT;
```

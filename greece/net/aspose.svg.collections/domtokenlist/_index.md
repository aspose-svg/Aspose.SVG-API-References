## DOMTokenList class

Η κλάση DOMTokenList αντιπροσωπεύει ένα σύνολο διαχωρισμένων διαστήματος διακριτικών. Είναι ευρετηριασμένη ξεκινώντας από το 0 όπως στα αντικείμενα JavaScript Array. Η DOMTokenList είναι πάντα ευαίσθητη σε πεζά-κεφαλαία.

```csharp
public class DOMTokenList : DOMObject, IEnumerable<string>
```

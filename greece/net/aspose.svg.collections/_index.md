Ο χώρος ονομάτων **Aspose.Svg.Collections** αποτελείται από κλάσεις για την αναπαράσταση, αποθήκευση και διαχείριση κόμβων και στοιχείων.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [DOMTokenList](./domtokenlist/) | Η κλάση DOMTokenList αντιπροσωπεύει ένα σύνολο διαχωρισμένων διαστήματος διακριτικών. Είναι ευρετηριασμένη ξεκινώντας από το 0 όπως στα αντικείμενα JavaScript Array. Η DOMTokenList είναι πάντα ευαίσθητη σε πεζά-κεφαλαία. |
| [HTMLCollection](./htmlcollection/) | Το [`HTMLCollection`](../aspose.svg.collections/htmlcollection/) αντιπροσωπεύει μια γενική συλλογή από [`Element`](../aspose.svg.dom/element/). |
| [NamedNodeMap](./namednodemap/) | Αντιπροσωπεύει συλλογές χαρακτηριστικών που μπορούν να προσπελαστούν με όνομα. |
| [NodeList](./nodelist/) | Η NodeList παρέχει την αφαίρεση μιας διατεταγμένης συλλογής κόμβων, χωρίς να ορίζει ή περιορίζει πώς υλοποιείται αυτή η συλλογή. |
| [SVGListBase<T>](./svglistbase-1/) | Αυτό το interface ορίζει μια βασική λίστα όλων των λιστών SVG. |

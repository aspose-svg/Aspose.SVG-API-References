**Aspose.Svg.Dom.Views** namespace describes AbstractView and DocumentView interfaces according Document Object Model Views specification.

## Διεπαφές

| Διεπαφή | Περιγραφή |
| --- | --- |
| [IAbstractView](./iabstractview/) | Μια βασική διεπαφή από την οποία θα κληρονομούν όλες οι προβολές. |
| [IDocumentView](./idocumentview/) | Η διεπαφή DocumentView υλοποιείται από αντικείμενα Document σε υλοποιήσεις DOM που υποστηρίζουν DOM Views. Παρέχει μια ιδιότητα για την ανάκτηση της προεπιλεγμένης προβολής ενός εγγράφου. |

Το **Aspose.Svg.Rendering.Image** namespace παρέχει συγκεκριμένη κλάση συσκευής καθώς και λίγες κλάσεις επιλογών απόδοσης υπεύθυνες για την απόδοση σε μορφές raster: jpeg, png, bmp, gif, tiff.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [ImageDevice](./imagedevice/) | Αντιπροσωπεύει την απόδοση σε μορφές raster: jpeg, png, bmp, gif, tiff. |
| [ImageRenderingOptions](./imagerenderingoptions/) | Αντιπροσωπεύει τις επιλογές απόδοσης για [`ImageDevice`](../aspose.svg.rendering.image/imagedevice/). Αυτές οι επιλογές χρησιμοποιούνται για τον καθορισμό της μορφής εξόδου εικόνας, της συμπίεσης, της ανάλυσης κ.λπ. |
| [TextOptions](./textoptions/) | Αντιπροσωπεύει τις επιλογές απόδοσης κειμένου για [`ImageDevice`](../aspose.svg.rendering.image/imagedevice/). |
## Απαρίθμηση

| Απαρίθμηση | Περιγραφή |
| --- | --- |
| [Compression](./compression/) | Καθορίζει τα πιθανά σχήματα συμπίεσης για εικόνες bitmap σε μορφή Tagged Image File Format (TIFF). |
| [ImageFormat](./imageformat/) | Καθορίζει τη μορφή αρχείου της εικόνας. |

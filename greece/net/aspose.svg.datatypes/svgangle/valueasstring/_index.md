## SVGAngle.ValueAsString property

Η τιμή της γωνίας ως συμβολοσειρά, στις μονάδες που εκφράζονται από το unitType. Ο καθορισμός αυτού του χαρακτηριστικού θα προκαλέσει την αυτόματη ενημέρωση των value, valueInSpecifiedUnits και unitType ώστε να αντανακλούν αυτή τη ρύθμιση.

```csharp
public string ValueAsString { get; set; }
```

### Property Value

Η τιμή ως συμβολοσειρά.

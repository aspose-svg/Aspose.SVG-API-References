## SVGAngle.ValueInSpecifiedUnits property

Η τιμή της γωνίας ως δεκαδική τιμή, στις μονάδες που εκφράζονται από το unitType. Ο καθορισμός αυτού του χαρακτηριστικού θα προκαλέσει την αυτόματη ενημέρωση των value και valueAsString ώστε να αντανακλούν αυτή τη ρύθμιση.

```csharp
public float ValueInSpecifiedUnits { get; set; }
```

Ο χώρος ονομάτων παρέχει πρόσβαση σε όλους τους τύπους δεδομένων που είναι ειδικοί για SVG.

| --- | --- |

| [SVGAnimatedAngle](./svganimatedangle/) | Χρησιμοποιείται για ιδιότητες του βασικού τύπου δεδομένων γωνίας που μπορούν να ανιμαριστούν. |

| [SVGAnimatedPreserveAspectRatio](./svganimatedpreserveaspectratio/) | Χρησιμοποιείται για ιδιότητες τύπου SVGPreserveAspectRatio που μπορούν να ανιμαριστούν. |
| [SVGAnimatedRect](./svganimatedrect/) | Χρησιμοποιείται για ιδιότητες τύπου SVGRect που μπορούν να ανιμαριστούν. |
| [SVGAnimatedString](./svganimatedstring/) | Χρησιμοποιείται για ιδιότητες τύπου DOMString που μπορούν να ανιμαριστούν. |
| [SVGAnimatedTransformList](./svganimatedtransformlist/) | Χρησιμοποιείται για τις διάφορες ιδιότητες που καθορίζουν ένα σύνολο μετασχηματισμών, όπως η ιδιότητα ‘transform’ που είναι διαθέσιμη για πολλά στοιχεία του SVG, και που μπορούν να ανιμαριστούν. |
| [SVGAnimatedValue<T>](./svganimatedvalue-1/) | Χρησιμοποιείται για ιδιότητες τύπων που μπορούν να ανιμαριστούν. |
| [SVGLength](./svglength/) | Η διεπαφή SVGLength αντιστοιχεί στον βασικό τύπο δεδομένων length. Ένα αντικείμενο SVGLength μπορεί να οριστεί ως μόνο για ανάγνωση, πράγμα που σημαίνει ότι οι προσπάθειες τροποποίησης του αντικειμένου θα προκαλέσουν την εκκίνηση μιας εξαίρεσης, όπως περιγράφεται παρακάτω. |
| [SVGLengthList](./svglengthlist/) | Αυτή η διεπαφή ορίζει μια λίστα αντικειμένων SVGLength. |
| [SVGMatrix](./svgmatrix/) | Πολλές από τις γραφικές λειτουργίες του SVG χρησιμοποιούν πίνακες 2x3 της μορφής: [a c e] [b d f] οι οποίοι, όταν επεκταθούν σε πίνακα 3x3 για σκοπούς αριθμητικών πράξεων με πίνακες, γίνονται: [a c e] [b d f] [0 0 1] |
| [SVGNumber](./svgnumber/) | Χρησιμοποιείται για ιδιότητες του βασικού τύπου number. |
| [SVGNumberList](./svgnumberlist/) | Αυτή η διεπαφή ορίζει μια λίστα αντικειμένων SVGNumber. |
| [SVGPoint](./svgpoint/) | Πολλές από τις διεπαφές SVG DOM αναφέρονται σε αντικείμενα της κλάσης SVGPoint. Ένα SVGPoint είναι ένα ζεύγος συντεταγμένων (x, y). Όταν χρησιμοποιείται σε λειτουργίες με πίνακες, ένα SVGPoint αντιμετωπίζεται ως διάνυσμα της μορφής: [x] [y] [1] Εάν ένα αντικείμενο SVGRect οριστεί ως μόνο για ανάγνωση, τότε η προσπάθεια ανάθεσης σε μία από τις ιδιότητές του θα προκαλέσει την εκκίνηση μιας εξαίρεσης. |
| [SVGPointList](./svgpointlist/) | Αυτή η διεπαφή ορίζει μια λίστα αντικειμένων SVGPoint. |
| [SVGPreserveAspectRatio](./svgpreserveaspectratio/) | Η διεπαφή SVGPreserveAspectRatio αντιστοιχεί στην ιδιότητα ‘preserveAspectRatio’, η οποία είναι διαθέσιμη για ορισμένα στοιχεία του SVG. |
| [SVGRect](./svgrect/) | Αντιπροσωπεύει ορθογώνια γεωμετρία. Τα ορθογώνια ορίζονται ως ένα ζεύγος συντεταγμένων (x,y) που προσδιορίζει μια ελάχιστη τιμή X, μια ελάχιστη τιμή Y, καθώς και πλάτος και ύψος, τα οποία συνήθως περιορίζονται ώστε να είναι μη αρνητικά. |
| [SVGStringList](./svgstringlist/) | Το SVGStringList έχει τα ίδια χαρακτηριστικά και μεθόδους με άλλα interfaces SVGxxxList. Οι υλοποιητές μπορεί να εξετάσουν το ενδεχόμενο χρήσης μιας ενιαίας βασικής κλάσης για την υλοποίηση των διαφόρων interfaces SVGxxxList. |
| [SVGTransform](./svgtransform/) | Το SVGTransform είναι το interface για μία από τις μετασχηματιστικές συνιστώσες μέσα σε ένα SVGTransformList· έτσι, ένα αντικείμενο SVGTransform αντιστοιχεί σε μία μόνο συνιστώσα (π.χ., 'scale(…)' ή 'matrix(…)') μέσα σε μια προδιαγραφή του χαρακτηριστικού ‘transform’. |
| [SVGTransformList](./svgtransformlist/) | Αυτό το interface ορίζει μια λίστα αντικειμένων SVGTransform. |
| [SVGValueType](./svgvaluetype/) | Ο τύπος SVGValueType χρησιμοποιείται για την αναπαράσταση ενός βασικού τύπου τιμής SVG. |

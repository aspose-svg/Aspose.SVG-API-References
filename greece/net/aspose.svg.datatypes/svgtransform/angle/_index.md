## SVGTransform.Angle property

Ένα χαρακτηριστικό ευκολίας για SVG_TRANSFORM_ROTATE, SVG_TRANSFORM_SKEWX και SVG_TRANSFORM_SKEWY. Κρατά τη γωνία που καθορίστηκε. Για SVG_TRANSFORM_MATRIX, SVG_TRANSFORM_TRANSLATE και SVG_TRANSFORM_SCALE, η γωνία θα είναι μηδέν.

```csharp
public float Angle { get; }
```

### Property Value

Η γωνία που καθορίστηκε.

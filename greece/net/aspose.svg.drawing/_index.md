Ο χώρος ονομάτων **Aspose.Svg.Drawing** περιέχει αντικείμενα και διεπαφές για τον καθορισμό μετρήσεων και μονάδων, καθώς και αντικείμενα χαρακτηριστικών σχεδίασης όπως πινέλα, χρώματα και γραμματοσειρές.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [Angle](./angle/) | Ο τύπος δεδομένων γωνίας |
| [Color](./color/) | Η κλάση Color σας επιτρέπει να καθορίζετε χρώματα ως τιμές Red-Green-Blue (RGB), Hue-Saturation-Luminosity (HSL), Hue-Saturation-Value (HSV), Hue-Whiteness-Blackness (HWB), lightness-A-B (LAB), Luminance-Chroma-Hue (LCH), Cyan-Magenta-Yellow-Key (CMYK), Natural colors (NCOL) ή με όνομα χρώματος. Ένα κανάλι Alpha είναι επίσης διαθέσιμο για να υποδεικνύει τη διαφάνεια. |
| [Dimension](./dimension/) | Παρέχει τη βασική κλάση για διαστάσεις. Ο γενικός όρος «διάσταση» αναφέρεται σε έναν αριθμό με συνδεδεμένη μονάδα, και σημειώνεται από [`UnitType`](../aspose.svg.drawing/unittype/). |
| [Frequency](./frequency/) | Η μονάδα «frequency». |
| [Length](./length/) | Αντιπροσωπεύει μια μονάδα μέτρησης μήκους. |
| [LengthOrAuto](./lengthorauto/) | Αντιπροσωπεύει ένα δοχείο για αποθήκευση μήκους ή μονάδων 'auto'.. |
| [Margin](./margin/) | Αντιπροσωπεύει το περιθώριο της σελίδας. |
| [Numeric](./numeric/) | Παρέχει τη βασική κλάση για αριθμητικούς τύπους. |
| [Page](./page/) | Αντιπροσωπεύει ένα αντικείμενο σελίδας που χρησιμοποιείται για τη διαμόρφωση της εξόδου της σελίδας. Η τιμή κενής περιοχής για το μέγεθος της σελίδας είναι A4 (210x297mm). |
| [Resolution](./resolution/) | Αντιπροσωπεύει μια μονάδα ανάλυσης. |
| [Size](./size/) | Αποθηκεύει τιμές που καθορίζουν το Ύψος και το Πλάτος. |
| [Time](./time/) | Αντιπροσωπεύει μια μονάδα χρόνου. |
| [Unit](./unit/) | Παρέχει τη βασική κλάση για μονάδες μέτρησης. |
| [UnitType](./unittype/) | Καθορίζει τη μονάδα μέτρησης. |

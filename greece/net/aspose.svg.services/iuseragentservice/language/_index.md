## IUserAgentService.Language property

Η `Language` καθορίζει τη βασική γλώσσα για το περιεχόμενο του στοιχείου και για τυχόν χαρακτηριστικά του στοιχείου που περιέχουν κείμενο. Η τιμή της πρέπει να είναι μια έγκυρη ετικέτα γλώσσας BCP 47 (), ή το κενό string. Ο ορισμός του χαρακτηριστικού στο κενό string υποδεικνύει ότι η βασική γλώσσα είναι άγνωστη.

```csharp
public string Language { get; set; }
```

### Property Value

Η γλώσσα του user agent.

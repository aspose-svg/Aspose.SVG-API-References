## IBlob.Type property

Η συμβολοσειρά κωδικοποιημένη σε ASCII σε πεζά που αντιπροσωπεύει τον τύπο μέσου του Blob. Κατά την ανάκτηση, οι πράκτορες χρήστη πρέπει να επιστρέφουν τον τύπο ενός Blob ως συμβολοσειρά ASCII σε πεζά, ώστε όταν μετατραπεί σε ακολουθία byte, να είναι ένας αναγνώσιμος τύπος MIME, ή η κενή συμβολοσειρά – 0 byte – εάν δεν μπορεί να προσδιοριστεί ο τύπος.

```csharp
public string Type { get; }
```

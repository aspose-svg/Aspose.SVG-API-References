## IBlob interface

Ένα αντικείμενο Blob αναφέρεται σε μια ακολουθία byte και έχει ένα χαρακτηριστικό size που είναι ο συνολικός αριθμός των byte στην ακολουθία, καθώς και ένα χαρακτηριστικό type, το οποίο είναι μια συμβολοσειρά κωδικοποιημένη σε ASCII με πεζά γράμματα που αντιπροσωπεύει τον τύπο μέσου της ακολουθίας byte.

## Ιδιότητες

| Όνομα | Περιγραφή |
| --- | --- |
| [Size](../../aspose.svg.io/iblob/size/) { get; } | Επιστρέφει το μέγεθος της ακολουθίας byte σε αριθμό byte. Κατά την ανάκτηση, οι συμβατοί πράκτορες χρήστη πρέπει να επιστρέφουν τον συνολικό αριθμό byte που μπορούν να διαβαστούν από ένα αντικείμενο FileReader ή FileReaderSync, ή 0 εάν το Blob δεν έχει byte προς ανάγνωση. |
| [Type](../../aspose.svg.io/iblob/type/) { get; } | Η συμβολοσειρά κωδικοποιημένη σε ASCII σε πεζά που αντιπροσωπεύει τον τύπο μέσου του Blob. Κατά την ανάκτηση, οι πράκτορες χρήστη πρέπει να επιστρέφουν τον τύπο ενός Blob ως συμβολοσειρά ASCII σε πεζά, ώστε όταν μετατραπεί σε ακολουθία byte, να είναι ένας αναγνώσιμος τύπος MIME, ή η κενή συμβολοσειρά – 0 byte – εάν δεν μπορεί να προσδιοριστεί ο τύπος. |

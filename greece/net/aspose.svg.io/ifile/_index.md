## IFile interface

Ένα αντικείμενο File είναι ένα αντικείμενο Blob με χαρακτηριστικό name, το οποίο είναι συμβολοσειρά· μπορεί να δημιουργηθεί μέσα στην εφαρμογή ιστού μέσω κατασκευαστή ή είναι μια αναφορά σε μια ακολουθία byte από ένα αρχείο του υποκείμενου (OS) συστήματος αρχείων.

```csharp
public interface IFile : IBlob
```

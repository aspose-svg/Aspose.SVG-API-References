Εκτός από τα τυπικά εργαλεία IO (εισόδου-εξόδου), το **Aspose.Svg.IO** namespace περιέχει βοηθητικές κλάσεις και διεπαφές.

## Κλάσεις

| Κλάση | Περιγραφή |
| --- | --- |
| [FileCreateStreamProvider](./filecreatestreamprovider/) | Αναπαριστά την υλοποίηση FileStream για την παροχή ροών στις συσκευές απόδοσης. |
## Διεπαφές

| Διεπαφή | Περιγραφή |
| --- | --- |
| [IBlob](./iblob/) | Ένα αντικείμενο Blob αναφέρεται σε μια ακολουθία byte και έχει ένα χαρακτηριστικό size που είναι ο συνολικός αριθμός των byte στην ακολουθία, καθώς και ένα χαρακτηριστικό type, το οποίο είναι μια συμβολοσειρά κωδικοποιημένη σε ASCII με πεζά γράμματα που αντιπροσωπεύει τον τύπο μέσου της ακολουθίας byte. |
| [ICreateStreamProvider](./icreatestreamprovider/) | Αναπαριστά μια διεπαφή που μπορεί να υλοποιηθεί από κλάσεις που παρέχουν ροές στις συσκευές απόδοσης. |
| [IFile](./ifile/) | Ένα αντικείμενο File είναι ένα αντικείμενο Blob με χαρακτηριστικό name, το οποίο είναι συμβολοσειρά· μπορεί να δημιουργηθεί μέσα στην εφαρμογή ιστού μέσω κατασκευαστή ή είναι μια αναφορά σε μια ακολουθία byte από ένα αρχείο του υποκείμενου (OS) συστήματος αρχείων. |
| [IFileList](./ifilelist/) | Αναπαριστά τη διεπαφή για τη λίστα αρχείων. |

## ImageVectorizerConfiguration class

`ImageVectorizerConfiguration`-klassen definierar en konfiguration av bildvektoriseringsmetoder och alternativ. Konfigurationen används för att initiera en ImageVectorizer och tillhandahåller konfigurationsalternativen för att vektorisera bilder.

```csharp
public class ImageVectorizerConfiguration
```

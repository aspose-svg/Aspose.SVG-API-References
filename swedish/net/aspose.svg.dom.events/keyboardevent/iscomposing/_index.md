## KeyboardEvent.IsComposing property

true om tangentbords‑eventet inträffar som en del av en kompositionssession, d.v.s. efter ett compositionstart‑event och före motsvarande compositionend‑event. Det oinitierade värdet för detta attribut MÅSTE vara false.

```csharp
public bool IsComposing { get; }
```

### Property Value

`true` om detta objekt är i komposition; annars, `false`.

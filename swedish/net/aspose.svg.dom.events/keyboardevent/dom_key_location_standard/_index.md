## KeyboardEvent.DOM_KEY_LOCATION_STANDARD field

Tangentaktiveringen FÅR INTE särskiljas som den vänstra eller högra versionen av tangenten, och (förutom NumLock‑tangenten) härstammade inte från det numeriska tangentbordet (eller från en virtuell tangent som motsvarar det numeriska tangentbordet).

public const ulong DOM_KEY_LOCATION_STANDARD;

## KeyboardEvent.Code property

Koden innehåller en sträng som identifierar den fysiska tangent som trycks ned. Värdet påverkas inte av det aktuella tangentbordslayouten eller modifierartillståndet, så en viss tangent kommer alltid att returnera samma värde.

public string Code { get; }

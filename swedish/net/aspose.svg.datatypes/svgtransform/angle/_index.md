## SVGTransform.Angle property

Ett bekvämt attribut för SVG_TRANSFORM_ROTATE, SVG_TRANSFORM_SKEWX och SVG_TRANSFORM_SKEWY. Det lagrar den angivna vinkeln. För SVG_TRANSFORM_MATRIX, SVG_TRANSFORM_TRANSLATE och SVG_TRANSFORM_SCALE kommer vinkeln att vara noll.

```csharp
public float Angle { get; }
```

### Property Value

Den angivna vinkeln.

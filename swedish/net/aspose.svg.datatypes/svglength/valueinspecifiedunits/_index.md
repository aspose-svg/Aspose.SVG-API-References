## SVGLength.ValueInSpecifiedUnits property

Värdet som ett flyttal, i de enheter som uttrycks av unitType. Att sätta detta attribut kommer att göra att value och valueAsString uppdateras automatiskt för att återspegla denna inställning.

```csharp
public float ValueInSpecifiedUnits { get; set; }
```

### Property Value

Värdet i angivna enheter.

## Node.PreviousSibling property

Returnerar noden som omedelbart föregår den angivna i dess förälders [`ChildNodes`](../childnodes/)‑lista, eller null om den angivna noden är den första i listan.

```csharp
public Node PreviousSibling { get; }
```

### Property Value

En [`Node`](../) som representerar den föregående syskonnoden till den aktuella noden, eller null om det inte finns någon.

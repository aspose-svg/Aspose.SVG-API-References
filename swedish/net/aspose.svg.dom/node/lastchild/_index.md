## Node.LastChild property

Returnerar nodens sista barn. Om dess förälder är ett element är barnet vanligtvis ett elementnod, ett textnod eller ett kommentarnod. Den returnerar null om det inte finns några barn-element.

```csharp
public Node LastChild { get; }
```

### Property Value

En [`Node`](../) som är den sista barnet till noden, eller null om det inte finns några barn-element.

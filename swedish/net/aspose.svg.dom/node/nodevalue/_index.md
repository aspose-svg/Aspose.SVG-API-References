## Node.NodeValue property

Returnerar eller anger värdet för den aktuella noden.

```csharp
public virtual string NodeValue { get; set; }
```

### Property Value

En sträng som innehåller värdet för den aktuella noden, om något. För själva dokumentet returnerar `NodeValue` null. För text-, kommentar- och CDATA-noder returnerar `NodeValue` nodens innehåll. För attributnoder returneras attributets värde.

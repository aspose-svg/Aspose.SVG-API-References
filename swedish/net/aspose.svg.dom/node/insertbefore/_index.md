## Node.InsertBefore method

Infogar noden före den befintliga barnnoden child. Om child är null infogas noden i slutet av listan med barn. Om child är ett DocumentFragment‑objekt infogas alla dess barn, i samma ordning, före child. Om barnet redan finns i trädet tas det först bort.

```csharp
public Node InsertBefore(Node node, Node child)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| nod | Node | Det nya barnet. |
| child | Node | Den refererade child. |

### Returvärde

Returnerar infogad nod

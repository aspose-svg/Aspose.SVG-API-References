## Node.NextSibling property

Returnerar noden som omedelbart följer den angivna i deras förälders [`ChildNodes`](../childnodes/), eller returnerar null om den angivna noden är det sista barnet i föräldraelementet.

```csharp
public Node NextSibling { get; }
```

### Property Value

En [`Node`](../) som representerar nästa syskon till den aktuella noden, eller null om det inte finns några.

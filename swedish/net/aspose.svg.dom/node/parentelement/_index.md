## Node.ParentElement property

Returnerar DOM‑nodens förälder [`Element`](../../element/), eller null om noden antingen saknar förälder, eller dess förälder inte är ett DOM‑Element.

```csharp
public Element ParentElement { get; }
```

### Property Value

Ett [`Element`](../../element/) som är föräldraelementet till den aktuella noden, eller null om det inte finns något.

## Node.LocalName property

Returnerar den lokala delen av det kvalificerade namnet för denna nod. För noder av någon typ annat än [`ELEMENT_NODE`](../element_node/) och [`ATTRIBUTE_NODE`](../attribute_node/) samt noder skapade med en DOM Level 1-metod, såsom [`CreateElement`](../../document/createelement/), är detta alltid null.

```csharp
public virtual string LocalName { get; }
```

### Property Value

En sträng som representerar den lokala delen av elementets kvalificerade namn.

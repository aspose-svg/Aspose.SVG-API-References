## Document.XmlStandalone property

Ett attribut som anger, som en del av XML‑deklarationen, om detta dokument är fristående. Detta är false när det inte anges.

```csharp
public bool XmlStandalone { get; set; }
```

### Property Value

`true` om XML är fristående; annars `false`.

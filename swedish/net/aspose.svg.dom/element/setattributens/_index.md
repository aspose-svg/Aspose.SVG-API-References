## Element.SetAttributeNS method

Lägger till ett nytt attribut. Om ett attribut med samma lokala namn och namnrymds‑URI redan finns på elementet ändras dess prefix till prefixdelen av qualifiedName, och dess värde ändras till värde‑parametern.

```csharp
public void SetAttributeNS(string namespaceURI, string qualifiedName, string value)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| namespaceURI | String | Namnrymd‑URI:n. |
| qualifiedName | String | Namnet på den kvalificerade. |
| value | String | Värdet. |

## ToggleAttribute(*string*) {#toggleattribute}

Om force inte anges, "toggles" qualifiedName, tar bort det om det finns och lägger till det om det saknas. Om force är true läggs qualifiedName till. Om force är false tas qualifiedName bort.

```csharp
public bool ToggleAttribute(string qualifiedName)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| qualifiedName | String | Attributet QualifiedName. |

### Returvärde

Returnerar true om qualifiedName nu är närvarande; annars false.

Namnrummet **Aspose.Svg.Dom.Mutations** ger möjlighet att observera DOM‑mutationer och erhålla specifik återuppringningsinformation.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [MutationCallback](./mutationcallback/) | Representerar metoden som kommer att hantera en mutationshändelse. |
| [MutationObserver](./mutationobserver/) | Ett [`MutationObserver`](../aspose.svg.dom.mutations/mutationobserver/)‑objekt kan användas för att observera mutationer i trädet av [`Node`](../aspose.svg.dom/node/). |
| [MutationObserverInit](./mutationobserverinit/) | Denna klass representerar en samling av alternativ som används för att konfigurera [`MutationObserver`](../aspose.svg.dom.mutations/mutationobserver/). |
| [MutationRecord](./mutationrecord/) | Ett MutationRecord representerar en enskild DOM‑mutation. Det är objektet som skickas till [`MutationObserver`](../aspose.svg.dom.mutations/mutationobserver/)'s [`MutationCallback`](../aspose.svg.dom.mutations/mutationcallback/). |

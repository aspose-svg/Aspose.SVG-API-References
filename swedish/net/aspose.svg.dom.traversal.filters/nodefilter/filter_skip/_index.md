## NodeFilter.FILTER_SKIP field

Hoppa över denna enskilda nod. Navigationsmetoder definierade för NodeIterator eller TreeWalker kommer inte att returnera denna nod. För både NodeIterator och TreeWalker kommer barnen till denna nod fortfarande att beaktas.

```csharp
public const short FILTER_SKIP;
```

## ICSSStyleDeclaration.CSSText property

Den parsbara textrepresentationen av deklarationsblocket (exklusive de omgivande klammerparenteserna). Att sätta detta attribut kommer att leda till att det nya värdet parsas och att alla egenskaper i deklarationsblocket återställs, inklusive borttagning eller tillägg av egenskaper.

```csharp
public string CSSText { get; set; }
```

### Property Value

CSS-texten.

## ICSSStyleDeclaration.GetPropertyCSSValue method

Används för att hämta objektrepresentationen av värdet för en CSS-egenskap om den har satts explicit inom detta deklarationsblock. Denna metod returnerar null om egenskapen är en förkortningsegenskap. Värden för förkortningsegenskaper kan endast nås och modifieras som strängar, med hjälp av metoderna getPropertyValue och setProperty.

```csharp
public CSSValue GetPropertyCSSValue(string propertyName)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| propertyName | String | Namnet på egenskapen. |

### Returvärde

Returnerar egenskapsvärdet

## IStyleSheet.Disabled property

false om stilmallen tillämpas på dokumentet. true om den inte gör det. Att ändra detta attribut kan leda till en ny stilupplösning för dokumentet. En stilmall tillämpas endast om både en lämplig mediumdefinition är närvarande och attributet disabled är false. Så, om mediet inte gäller för den aktuella användaragenten, ignoreras attributet disabled.

```csharp
public bool Disabled { get; set; }
```

### Property Value

`true` om inaktiverad; annars, `false`.

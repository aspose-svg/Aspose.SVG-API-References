## IStyleSheet.OwnerNode property

Noden som kopplar denna stilmall till dokumentet. För HTML kan detta vara motsvarande LINK- eller STYLE-element. För XML kan det vara den länkande processinstruktionen. För stilmallar som inkluderas av andra stilmallar är värdet på detta attribut null.

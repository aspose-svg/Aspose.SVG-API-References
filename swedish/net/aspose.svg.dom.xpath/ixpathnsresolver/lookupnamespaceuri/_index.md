## IXPathNSResolver.LookupNamespaceURI method

Slå upp den namnrymds-URI som är associerad med den givna namnrymdsprefixen. XPath‑utvärderaren får aldrig anropa detta med ett `null`‑ eller tomt argument, eftersom resultatet av detta är odefinierat.

```csharp
public string LookupNamespaceURI(string prefix)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| prefix | String | Prefixet att söka efter. |

### Returvärde

Returnerar den associerade namnrymdens URI eller `null` om ingen hittas.

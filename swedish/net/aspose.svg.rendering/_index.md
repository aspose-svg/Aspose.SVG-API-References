Den **Aspose.Svg.Rendering**-namnrymden består av många renderarobjekt samt lämpliga låg‑nivå‑alternativklasser som ansvarar för att rendera dokument/filer till en IDevice‑implementation.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [CssOptions](./cssoptions/) | Representerar CSS‑renderingsalternativ. |
| [Device](./device/) | Representerar en basklass för implementering av renderingsenheter som används för att rita grafik i olika format och miljöer. |
| [Device<TGraphicContext,TRenderingOptions>](./device-2/) | Representerar basklass för implementering av specifika renderingsenheter. |
| [GraphicContext](./graphiccontext/) | Innehåller aktuella grafikstyrningsparametrar. Dessa parametrar definierar det globala ramverket inom vilket grafikoperatorerna körs. |
| [PageSetup](./pagesetup/) | Representerar ett sidinställningsobjekt som används för att konfigurera utskriftssiduppsättningen. |
| [Renderer](./renderer/) | Representerar en basklass för alla renderare och implementerar IDisposable‑gränssnittet. |
| [Renderer<TSource>](./renderer-1/) | Den abstrakta basklassen för alla renderare. |
| [RenderingOptions](./renderingoptions/) | Representerar renderingsalternativ. |
| [SvgRenderer](./svgrenderer/) | Representerar SVG-dokumentrenderare. |
| [TextInfo](./textinfo/) | Innehåller information om renderad text. |

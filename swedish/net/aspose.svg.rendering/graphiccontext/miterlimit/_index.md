## GraphicContext.MiterLimit property

Ställer in eller hämtar den maximala längden på snedställda linjeskarvar för strokade banor. Denna parameter begränsar längden på \"spikes\" som bildas när linjesegment möts i skarpa vinklar.

```csharp
public virtual float MiterLimit { get; set; }
```

Den **Aspose.Svg.Drawing**-namnrymden innehåller objekt och gränssnitt för att specificera mått och enheter samt ritningsattributobjekt som penslar, färger och teckensnitt.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [Angle](./angle/) | Vinkeldatatypen |
| [Color](./color/) | Color-klassen låter dig specificera färger som Red-Green-Blue (RGB)-värden, Hue-Saturation-Luminosity (HSL)-värden, Hue-Saturation-Value (HSV)-värden, Hue-Whiteness-Blackness (HWB)-värden, lightness-A-B (LAB)-värden, Luminance-Chroma-Hue (LCH)-värden, Cyan-Magenta-Yellow-Key (CMYK)-värden, Natural colors (NCOL)-värden, eller med ett färgnamn. En Alpha-kanal är också tillgänglig för att ange transparens. |
| [Dimension](./dimension/) | Tillhandahåller basklassen för dimensioner. Den allmänna termen 'dimension' avser ett tal med en enhet kopplad till sig, och betecknas av [`UnitType`](../aspose.svg.drawing/unittype/). |
| [Frequency](./frequency/) | Enheten 'frequency'. |
| [Length](./length/) | Representerar en längdmåttenhet. |
| [LengthOrAuto](./lengthorauto/) | Representerar en behållare för lagringslängd eller 'auto'-enheter.. |
| [Margin](./margin/) | Representerar sidmarginal. |
| [Numeric](./numeric/) | Tillhandahåller basklassen för numeriska typer. |
| [Page](./page/) | Representerar ett sidobjekt som används för konfiguration av utskriftssida. Standardvärdet för sidstorlek är A4 (210x297 mm). |
| [Resolution](./resolution/) | Representerar en upplösningsenhet. |
| [Size](./size/) | Lagrar värden som specificerar en höjd och bredd. |
| [Time](./time/) | Representerar en tidsenhet. |
| [Unit](./unit/) | Tillhandahåller basklassen för måttenheter. |
| [UnitType](./unittype/) | Anger enheten för mätning. |

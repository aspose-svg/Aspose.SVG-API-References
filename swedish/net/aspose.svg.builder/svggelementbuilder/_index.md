## SVGGElementBuilder class

Builder-klass för att konstruera ett SVG 'g' (grupp)-element. 'g'-elementet används för att gruppera SVG-former tillsammans. Gruppering av element möjliggör enklare manipulation och styling av flera element som en enhet inom SVG-grafik.

```csharp
public class SVGGElementBuilder : SVGElementBuilder<SVGGElement>, ICompositeAttributeSetter, 
    ICompositeElementBuilder
```

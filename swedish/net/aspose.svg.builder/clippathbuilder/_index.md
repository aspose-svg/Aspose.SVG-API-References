## ClipPathBuilder class

En builder‑klass för att konstruera CSS clip‑path‑värden. Klassen tillhandahåller metoder för att definiera clip‑paths med grundformer, externa referenser eller geometriska lådor. Den möjliggör skapandet av komplexa beskärningsvägar på ett strukturerat och läsbart sätt.

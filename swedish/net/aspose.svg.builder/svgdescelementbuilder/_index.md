## SVGDescElementBuilder class

Byggarklass för att konstruera ett SVG 'desc'-element, som används för att ge en beskrivning av SVG-behållarelement. Den möjliggör byggandet av innehåll inom 'desc'-elementet och tillhandahåller metoder för att ange olika attribut som är specifika för 'desc'-elementet i SVG.

```csharp
public class SVGDescElementBuilder : SVGElementBuilder<SVGDescElement>, ICoreAttributeSetter, 
    IDescriptiveElementBuilder, IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, 
    ITextContentSetter
```

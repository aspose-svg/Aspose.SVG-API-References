## WhiteSpace enumeration

Anger hur blanksteg inuti ett SVG-element hanteras.

```csharp
public enum WhiteSpace
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Normal | `0` | Blanksteg kollapsas; radbrytningstecken skapar nya rader. |
| Pre | `1` | Blanksteg bevaras; text radbryts endast där den innehåller radbrytningstecken. |
| NoWrap | `2` | Blanksteg kollapsas; text radbryts inte. |
| PreWrap | `3` | Blanksteg bevaras; text radbryts där det behövs och vid radbrytningstecken. |
| BreakSpaces | `4` | Blanksteg bevaras; radbrytningar läggs till för att fylla radboxar. |
| PreLine | `5` | Blanksteg bevaras; text radbryts där det behövs, men utan radbrytningstecken. |

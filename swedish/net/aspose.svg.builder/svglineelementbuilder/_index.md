## SVGLineElementBuilder class

Builder-klass för att konstruera ett SVG 'line'-element, som används för att rita raka linjer i SVG-grafik. Denna klass möjliggör byggandet av innehåll inom 'line'-elementet och tillhandahåller metoder för att ställa in olika attribut specifika för 'line'-elementet i SVG.

```csharp
public class SVGLineElementBuilder : SVGElementBuilder<SVGLineElement>, IAnimationElementBuilder, 
    IDescriptiveElementBuilder, IPaintServerElementBuilder, IShapeAttributeSetter, 
    IShapeContentElementBuilder
```

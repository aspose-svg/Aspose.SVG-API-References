## BaseLineShift enumeration

Anger det vertikala läget för ett element relativt dess baslinje i SVG.

```csharp
public enum BaseLineShift
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Sub | `0` | Justerar elementets baslinje med subskriptbaslinjen för förälderns text. |
| Super | `1` | Justerar elementets baslinje med superskriptbaslinjen för förälderns text. |
| Top | `2` | Justerar elementets topp med toppen av radboxen. |
| Center | `3` | Centrerar elementet i radboxen. |
| Bottom | `4` | Justerar elementets botten med botten av radboxen. |

## Anmärkningar

'baseline-shift'-attributet i SVG används för att justera ett elements vertikala position i förhållande till dess baslinje, vilket är särskilt användbart vid textrendering. Detta enum erbjuder olika alternativ för att förskjuta baslinjen för att uppnå olika texteffekter.

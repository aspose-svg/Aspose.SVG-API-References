## RepeatStyle enumeration

Anger upprepningsstilen för bakgrundsbilder eller mönster i SVG.

```csharp
public enum RepeatStyle
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| RepeatX | `0` | Bilden eller mönstret upprepas endast horisontellt. |
| RepeatY | `1` | Bilden eller mönstret upprepas endast vertikalt. |
| Repeat | `2` | Bilden eller mönstret upprepas både horisontellt och vertikalt. |
| Space | `3` | Bilden eller mönstret upprepas så mycket som möjligt utan beskärning, och det återstående utrymmet fördelas jämnt mellan bilderna. |
| Round | `4` | Bilden eller mönstret skalas så att det passar och upprepas utan beskärning, samtidigt som bildförhållandet bevaras. |
| NoRepeat | `5` | Bilden eller mönstret upprepas inte, och endast en kopia av bilden kommer att ritas. |

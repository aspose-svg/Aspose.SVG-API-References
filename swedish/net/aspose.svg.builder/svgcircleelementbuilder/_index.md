## SVGCircleElementBuilder class

Byggarklass för att konstruera ett SVG 'circle'-element, som används för att rita cirklar i SVG-grafik. Den möjliggör byggandet av innehåll inom 'circle'-elementet och tillhandahåller metoder för att ange olika attribut som är specifika för 'circle'-elementet i SVG.

```csharp
public class SVGCircleElementBuilder : SVGElementBuilder<SVGCircleElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IShapeAttributeSetter, IShapeContentElementBuilder
```

## CoordinateUnits enumeration

Anger enheterna för koordinatsystemet för olika SVG-element såsom masker, färgservrar och filter.

```csharp
public enum CoordinateUnits
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| UserSpaceOnUse | `0` | Använder användarens koordinatsystem för SVG‑elementet. |
| ObjectBoundingBox | `1` | Använder objektets omgivningsruta för SVG‑elementet. |

## Anmärkningar

Koordinatenheterna bestämmer hur värden tolkas i olika SVG‑sammanhang. De kan ställas in för att antingen använda användarrymdens koordinater eller vara relativa mot objektets omgivningsruta.

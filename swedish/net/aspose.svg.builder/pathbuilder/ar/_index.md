## PathBuilder.Ar method

Lägger till ett relativt 'Elliptical Arc Curve'-kommando till sökvägsdata.

```csharp
public PathBuilder Ar(double r1, double r2, double angle, bool largeArcFlag, bool sweepFlag, 
    double x, double y)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| r1 | Double | X-radien för ellipsen, relativt den aktuella positionen. |
| r2 | Double | Y-radien för ellipsen, relativt den aktuella positionen. |
| angle | Double | Rotationsvinkeln för ellipsen i grader, relativt den aktuella positionen. |
| largeArcFlag | Boolean | Flagga som indikerar om bågen ska vara större än eller lika med 180 grader. |
| sweepFlag | Boolean | Flagga som indikerar om bågen ska ritas i positiv vinkelriktning. |
| x | Double | x-koordinaten för slutpunkten på bågen, relativt den aktuella positionen. |
| y | Double | y-koordinaten för slutpunkten på bågen, relativt den aktuella positionen. |

### Returvärde

Den aktuella PathBuilder-instansen.

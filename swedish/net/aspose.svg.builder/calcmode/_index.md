## CalcMode enumeration

Anger beräkningslägena för interpolering av värden i SVG-animationer.

```csharp
public enum CalcMode
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Discrete | `0` | Animationen hoppar från ett värde till nästa utan någon interpolering. |
| Linear | `1` | Animationsvärdena interpoleras linjärt över animationens varaktighet. |
| Paced | `2` | Animationen är tidsinställd så att framstegen är jämna över hela animationen. |
| Spline | `3` | Animationen använder kubiska Bézier-kurvor för att interpolera värden. |

## Anmärkningar

Beräkningsläget bestämmer hur en SVG-animation övergår mellan värden under animationens gång. Olika lägen kan användas för att skapa olika effekter och kontrollera animationens tempo och mjukhet.

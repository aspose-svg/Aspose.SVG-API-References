## Kerning enumeration

Anger kerningbeteendet för text i SVG.

```csharp
public enum Kerning
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Auto | `0` | Gör det möjligt för webbläsaren att avgöra om kerning ska tillämpas. |
| Normal | `1` | Tillämpar standardkerning, enligt definitionen i teckensnittsfilen. |
| None | `2` | Inaktiverar kerning och ignorerar all kerninginformation i teckensnittet. |

## Anmärkningar

Egenskapen 'font-kerning' i SVG styr användningen av kerninginformation som lagras i ett teckensnitt. Kerning justerar avståndet mellan enskilda bokstavspar för att förbättra den visuella utseendet på text. Detta enum erbjuder alternativ för att kontrollera kerningbeteendet i SVG-textelement.

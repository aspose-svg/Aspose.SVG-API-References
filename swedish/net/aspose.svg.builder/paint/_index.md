## Paint enumeration

Anger färginställningarna för fyllnings- och linjeattribut i SVG-element.

```csharp
public enum Paint
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| None | `0` | Indikerar att ingen färg ska tillämpas. |
| ContextFill | `1` | Använder den aktuella kontextens fyllningsfärg för målning. |
| ContextStroke | `2` | Använder den aktuella kontextens stroke-färg för målning. |

## Anmärkningar

Denna uppräkning definierar de typer av färg som kan tillämpas på fill- och stroke-egenskaperna hos SVG-element. Den möjliggör standardfärg, kontextbaserade fyllningar och strokes, eller ingen färg alls.

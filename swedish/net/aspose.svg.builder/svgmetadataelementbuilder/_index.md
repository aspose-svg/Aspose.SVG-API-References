## SVGMetadataElementBuilder class

Builder-klass för att konstruera ett SVG 'metadata'-element, som används för att lägga till metadata i ett SVG-dokument. Denna klass möjliggör tillägg av metadata-innehåll och tillhandahåller metoder för att ange olika attribut som är specifika för 'metadata'-elementet i SVG.

```csharp
public class SVGMetadataElementBuilder : SVGElementBuilder<SVGMetadataElement>, 
    ICoreAttributeSetter, IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, 
    ITextContentSetter
```

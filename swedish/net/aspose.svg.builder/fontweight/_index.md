## FontWeight enumeration

Anger de olika vikterna för teckensnitt i SVG-textelement.

```csharp
public enum FontWeight
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Normal | `0` | Representerar den normala teckensnittsvikten, som är standardvikten. |
| Bold | `1` | Representerar en fet teckensnittsvikt, vanligtvis använd för betoning. |
| Bolder | `2` | Representerar en teckensnittsvikt som är fetare än förälderelementets vikt. |
| Lighter | `3` | Representerar en teckensnittsvikt som är lättare än förälderelementets vikt. |
| W100 | `4` | Representerar teckensnittsvikten 100, den tunnaste som finns. |
| W200 | `5` | Representerar teckensnittsvikten 200. |
| W300 | `6` | Representerar teckensnittsvikten 300. |
| W400 | `7` | Representerar teckensnittsvikten 400, motsvarande 'normal'. |
| W500 | `8` | Representerar teckensnittsvikten 500. |
| W600 | `9` | Representerar teckensnittsvikten 600. |
| W700 | `10` | Representerar teckensnittsvikten 700, motsvarande 'bold'. |
| W800 | `11` | Representerar teckensnittsvikten 800. |
| W900 | `12` | Representerar teckensnittsvikten 900, den fetaste som finns. |

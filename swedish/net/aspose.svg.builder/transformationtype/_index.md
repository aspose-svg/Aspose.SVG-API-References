## TransformationType enumeration

Anger typen av transformation som tillämpas på ett SVG-element.

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Translate | `0` | Översätter (flyttar) ett element en viss sträcka. |
| Scale | `1` | Skalar ett element upp eller ner i storlek. |
| Rotate | `2` | Roterar ett element runt en given punkt. |

## SVGBuilderExtensions.FormatSvgLengths method

Formaterar en array av dubbelvärden till en strängrepresentation av SVG-längder.

```csharp
public static string FormatSvgLengths(double[] values, LengthType type)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| values | Double[] | Arrayen av double-värden som representerar längder. |
| type | LengthType | Typen av längdenhet att använda (t.ex. pixlar). |

### Returvärde

En formaterad sträng av SVG-längder.

## Anmärkningar

Denna verktygsmethod används för att formatera längdvärden för SVG-attribut, genom att lägga till lämplig enhet (t.ex. 'px') till varje värde.

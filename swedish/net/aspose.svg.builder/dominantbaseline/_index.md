## DominantBaseline enumeration

Anger den dominerande baslinjen som används för att justera text.

```csharp
public enum DominantBaseline
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Auto | `0` | Bestämmer automatiskt den dominerande baslinjen baserat på teckensnittet och/eller språket. |
| TextBottom | `1` | Justera texten till botten av em-kvadraten. |
| Alphabetic | `2` | Justera texten på baslinjen som används av alfabetiska tecken. |
| Ideographic | `3` | Justera texten på baslinjen som används av ideografiska tecken. |
| Middle | `4` | Justera texten i mitten av em-kvadraten. |
| Central | `5` | Justerar texten i den centrala baslinjen för em-kvadraten. |
| Mathematical | `6` | Justerar texten på den baslinje som används av matematiska tecken. |
| Hanging | `7` | Justerar texten på den hängande baslinjen, som vanligtvis används för tibetanska eller andra asiatiska skript. |
| TextTop | `8` | Justerar texten till toppen av em-kvadraten. |

## PointerEvents enumeration

Anger hur pekarhändelser hanteras av grafiska element i SVG.

```csharp
public enum PointerEvents
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| BoundingBox | `0` | Pekarhändelser riktas mot elementets omgivande ruta. |
| VisiblePainted | `1` | Pekarhändelser riktas endast mot de synliga (målade) delarna av elementet. |
| VisibleFill | `2` | Pekarhändelser riktas endast mot de synliga (fyllda) delarna av elementet. |
| VisibleStroke | `3` | Pekarhändelser riktas endast mot de synliga (streckade) delarna av elementet. |
| Visible | `4` | Pekarhändelser riktas mot alla synliga delar av elementet. |
| Painted | `5` | Pekarhändelser riktas mot alla målade delar av elementet, inklusive fyllning och linje. |
| Fill | `6` | Pekarhändelser riktas endast mot de fyllda delarna av elementet. |
| Stroke | `7` | Pekarhändelser riktas endast mot de streckade delarna av elementet. |
| All | `8` | Pekarhändelser riktas mot alla delar av elementet, oavsett synlighet. |
| None | `9` | Elementet blir inte målet för pekarhändelser. |

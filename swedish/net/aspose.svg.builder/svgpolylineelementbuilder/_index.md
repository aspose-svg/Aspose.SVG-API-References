## SVGPolylineElementBuilder class

Builder-klass för att konstruera ett SVG 'polyline'-element. 'Polyline'-elementet används för att skapa en serie raka linjer som förbinder flera punkter i SVG-grafik. Denna klass tillhandahåller metoder för att ange olika attribut och animera polyline-elementet.

```csharp
public class SVGPolylineElementBuilder : SVGElementBuilder<SVGPolylineElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IPointsAttributeSetter, IShapeAttributeSetter, IShapeContentElementBuilder
```

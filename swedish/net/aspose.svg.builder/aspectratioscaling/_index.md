## AspectRatioScaling enumeration

Anger skalningsbeteendet för SVG-element när deras bildförhållande bevaras.

```csharp
public enum AspectRatioScaling
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Meet | `0` | Skalar SVG-elementet så att det passar inom visningsområdet samtidigt som bildförhållandet bevaras. Om visningsområdets bildförhållande inte matchar elementet kommer extra utrymme att fördelas jämnt längs den axel som har mer utrymme. |
| Slice | `1` | Skalar SVG-elementet så att det fyller visningsområdet samtidigt som bildförhållandet bevaras. Om visningsområdets bildförhållande inte matchar elementet kommer elementet att beskäras för att passa. |

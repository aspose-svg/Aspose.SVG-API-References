## ColorInterpolation enumeration

Anger färginterpolationsläget för SVG-element och filter.

```csharp
public enum ColorInterpolation
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Auto | `0` | Bestämmer automatiskt färginterpolationsläget. |
| SRGB | `1` | Använder det standard RGB-färgrymden (sRGB) för färginterpolation. |
| LinearRGB | `2` | Använder ett linjärt RGB-färgrymd för färginterpolation. |

## Anmärkningar

Färginterpolation i SVG påverkar hur färger beräknas och blandas i både grafiska element och filtereffekter. Olika lägen kan avsevärt påverka utseendet på färgövergångar, gradienter och den övergripande färgåtergivningen. Denna inställning är avgörande för att uppnå önskat visuellt resultat i SVG-grafik.

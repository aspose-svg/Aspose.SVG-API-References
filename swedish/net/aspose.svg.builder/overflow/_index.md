## Overflow enumeration

Anger översvämningsbeteendet för SVG-element.

```csharp
public enum Overflow
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Visible | `0` | Innehåll som överskrider elementets gränser är synligt. |
| Hidden | `1` | Innehåll som överskrider elementets gränser beskärs och är inte synligt. |
| Scroll | `2` | Tillhandahåller rullningslister för innehåll som överskrider elementets gränser. |

## Anmärkningar

Denna uppräkning styr hur innehåll som överskrider gränserna för ett SVG-element visas. Den bestämmer om överskjutande innehåll är synligt, beskuret eller får rullningslister.

## SVGPathElementBuilder class

Builder-klass för att konstruera ett SVG 'path'-element, som används för att definiera en bana i ett SVG-dokument. Denna klass tillhandahåller metoder för att ange olika attribut som är specifika för 'path'-elementet och för att bygga dess innehåll.

```csharp
public class SVGPathElementBuilder : SVGElementBuilder<SVGPathElement>, IAnimationElementBuilder, 
    IDescriptiveElementBuilder, IPaintServerElementBuilder, IShapeAttributeSetter, 
    IShapeContentElementBuilder
```

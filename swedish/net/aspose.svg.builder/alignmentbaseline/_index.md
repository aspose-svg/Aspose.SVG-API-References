## AlignmentBaseline enumeration

Anger justeringsbaslinjen för text och annat inline-innehåll i SVG.

```csharp
public enum AlignmentBaseline
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Baseline | `0` | Justera baslinjen för rutan med baslinjen för förälderrutan. |
| TextBottom | `1` | Justera botten av rutan med botten av förälderns innehållsområde. |
| Middle | `2` | Justera mitten av rutan med mitten av förälderns innehållsområde. |
| Central | `3` | Justera den centrala baslinjen för rutan med den centrala baslinjen för förälderrutan. |
| TextTop | `4` | Justera toppen av rutan med toppen av förälderns innehållsområde. |
| Ideographic | `5` | Justera rutans ideografiska baslinje med förälderns ideografiska baslinje. |
| Alphabetic | `6` | Justera rutans alfabetiska baslinje med förälderns alfabetiska baslinje. |
| Mathematical | `7` | Justera rutans matematiska baslinje med förälderns matematiska baslinje. |

## Anmärkningar

Egenskapen 'alignment-baseline' är definierad i specifikationen CSS Line Layout Module 3. SVG 2 introducerar förändringar i definitionen av denna egenskap.

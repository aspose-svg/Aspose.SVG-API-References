## SVGEllipseElementBuilder class

Byggarklass för att konstruera ett SVG 'ellipse'-element, som används för att rita ellipser i SVG-grafik. Den möjliggör byggandet av innehåll inom 'ellipse'-elementet och tillhandahåller metoder för att ange olika attribut som är specifika för 'ellipse'-elementet i SVG.

```csharp
public class SVGEllipseElementBuilder : SVGElementBuilder<SVGEllipseElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IShapeAttributeSetter, IShapeContentElementBuilder
```

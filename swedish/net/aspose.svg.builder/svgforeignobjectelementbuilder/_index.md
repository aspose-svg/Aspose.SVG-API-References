## SVGForeignObjectElementBuilder class

Builder-klass för att konstruera ett SVG 'foreignObject'-element, som möjliggör inkludering av externt innehåll i ett SVG-dokument. Detta element kan innehålla olika typer av innehåll, såsom HTML och XHTML, vilket möjliggör mer komplexa grafiska representationer inom SVG.

```csharp
public class SVGForeignObjectElementBuilder : SVGElementBuilder<SVGForeignObjectElement>, 
    ICompositeAttributeSetter, IRectAttributeSetter, ITextContentSetter
```

## SVGDefsElementBuilder class

Byggarklass för att konstruera ett SVG 'defs'-element, som används för att definiera återanvändbara element. Den möjliggör byggandet av innehåll inom 'defs'-elementet och tillhandahåller metoder för att ange olika attribut som är specifika för 'defs'-elementet i SVG.

```csharp
public class SVGDefsElementBuilder : SVGElementBuilder<SVGDefsElement>, ICompositeElementBuilder, 
    ICoreAttributeSetter, IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, 
    IGraphicalEventAttributeSetter, IPresentationAttributeSetter
```

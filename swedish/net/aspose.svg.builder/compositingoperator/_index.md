## CompositingOperator enumeration

Anger vilken typ av sammanslagningsoperation som ska tillämpas i SVG-maskeringsoperationer.

```csharp
public enum CompositingOperator
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Add | `0` | Lägger till färgvärdena från källgrafiken till destinationsgrafiken. |
| Subtract | `1` | Subtraherar färgvärdena från källgrafiken från destinationsgrafiken. |
| Intersect | `2` | Visar endast de områden där både käll- och destinationsgrafiken överlappar. |
| Exclude | `3` | Exkluderar de överlappande områdena för käll- och destinationsgrafiken. |

## Anmärkningar

Sammanslagningsoperatorer i SVG‑masker bestämmer hur olika grafiska element kombineras för att skapa en maskeffekt. Varje operator definierar en unik metod för att blanda eller kombinera dessa element för att uppnå olika maskeringseffekter.

## MaskBuilder class

En builder‑klass för att skapa CSS‑mask‑egenskaper. Klassen möjliggör konstruktion av komplexa maskstilar med olika egenskaper såsom maskkälla, position, storlek, repetitionsstil och mer. Den resulterande strängen kan användas i CSS för att definiera maskningsbeteendet för ett element.

## CompositeOperator enumeration

Anger vilken typ av sammanslagningsoperation som ska tillämpas i SVG-sammanslagningsoperationer.

```csharp
public enum CompositeOperator
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Over | `0` | Placera källgrafiken över destinationsgrafiken. |
| In | `1` | Visar källgrafiken där den överlappar destinationsgrafiken. |
| Out | `2` | Visar källgrafiken där den inte överlappar destinationsgrafiken. |
| Atop | `3` | Visar källgrafiken ovanpå destinationsgrafiken. |
| Xor | `4` | Visar källgrafiken där den inte överlappar destinationen och vice versa. |
| Arithmetic | `5` | Tillåter en anpassad aritmetisk sammansättningsoperation. |

## Anmärkningar

Sammansättningsoperationer i SVG bestämmer hur två grafiska element kombineras till en enda bild. Varje operator definierar en särskild metod för att blanda eller kombinera dessa element.

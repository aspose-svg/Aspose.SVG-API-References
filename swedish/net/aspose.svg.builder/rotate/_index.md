## Rotate enumeration

Anger rotationsbeteendet för element under rörelsesanimation i SVG.

```csharp
public enum Rotate
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Auto | `0` | Roterar automatiskt elementet i riktning mot banan. |
| AutoReverse | `1` | Roterar automatiskt elementet i riktning mot banan och tillåter det att vända. |

## Anmärkningar

Attributet 'rotate' i SVG:s 'animateMotion'-element styr rotationen av ett element längs en rörelsesträcka. Detta enum ger alternativ för hur elementet ska rotera när det följer banan.

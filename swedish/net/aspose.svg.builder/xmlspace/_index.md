## XmlSpace enumeration

Anger hur blanksteg inuti element hanteras i XML-dokument.

```csharp
public enum XmlSpace
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| Default | `0` | Indikerar att blanksteg ska hanteras enligt XML-processorns standardbeteende, vanligtvis genom att normalisera blanksteg genom att ta bort radbrytningar och extra mellanslag. |
| Preserve | `1` | Indikerar att blanksteg ska bevaras som de förekommer i XML-dokumentet. Detta är användbart för att behålla formateringen av text där blanksteg är betydelsefulla. |

## Anmärkningar

Attributet 'xml:space' i XML används för att kontrollera om blanksteg inom element ska bevaras eller normaliseras. Denna uppräkning erbjuder alternativ för att ställa in detta beteende i XML- och SVG-dokument.

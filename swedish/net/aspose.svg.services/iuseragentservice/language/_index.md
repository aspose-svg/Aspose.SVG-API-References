## IUserAgentService.Language property

`Language` specificerar huvudspråket för elementets innehåll och för alla elementets attribut som innehåller text. Dess värde måste vara en giltig BCP 47‑språktagg, eller en tom sträng. Att sätta attributet till en tom sträng indikerar att huvudspråket är okänt.

```csharp
public string Language { get; set; }
```

### Property Value

Användaragentspråket.

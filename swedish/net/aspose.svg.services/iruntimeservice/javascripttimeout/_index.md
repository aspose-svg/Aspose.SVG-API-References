## IRuntimeService.JavaScriptTimeout property

Hämtar eller anger TimeSpan som begränsar JavaScript‑exekveringstid. Om skriptet körs längre än den angivna TimeSpan avbryts det. Du kan ange oändlig tidsgräns genom att sätta TimeSpan till -1 millisekund. Standardvärdet är 1 minut.

```csharp
public TimeSpan JavaScriptTimeout { get; set; }
```

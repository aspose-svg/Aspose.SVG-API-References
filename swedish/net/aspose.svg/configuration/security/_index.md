## Configuration.Security property

Denna egenskap låter dig ange ett antal begränsningar för innehållet som laddas i ramen, till exempel blockera formulär och skript. Se artikeln om [sandboxing](https://docs.aspose.com/html/net/environment-configuration/#sandboxing).

```csharp
public Sandbox Security { get; set; }
```

### Property Value

Ett [`Sandbox`](../../sandbox/) flaggsätt är en samling av noll eller fler flaggor, som används för att begränsa möjligheterna hos potentiellt opålitliga resurser.

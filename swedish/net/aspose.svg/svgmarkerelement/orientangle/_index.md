## SVGMarkerElement.OrientAngle property

Motsvarar attributet ‘orient’ på det angivna ‘marker’-elementet. Om markerUnits är SVG_MARKER_ORIENT_ANGLE, används vinkelvärdet för attributet ‘orient’; annars sätts det till noll.

```csharp
public SVGAnimatedAngle OrientAngle { get; }
```

### Property Value

Attributet ‘orient’ för det angivna ‘marker’-elementet.

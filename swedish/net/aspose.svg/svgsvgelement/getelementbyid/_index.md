## SVGSVGElement.GetElementById method

Söker i detta SVG-dokumentfragment (dvs. sökningen är begränsad till en delmängd av dokumentträdet) efter ett Element vars id ges av elementId. Om ett Element hittas returneras det Elementet. Om ett sådant element inte finns returneras null. Beteendet är inte definierat om mer än ett element har detta id.

```csharp
public Element GetElementById(string elementId)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| elementId | String | Det unika id-värdet för ett element. |

### Returvärde

Det matchande elementet.

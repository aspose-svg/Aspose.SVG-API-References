Den **Aspose.Svg.Net**-namnrymden presenteras av klasser och gränssnitt som ansvarar för att underlätta enkel nätverksbehandling.

| Klass | Beskrivning |
| --- | --- |
| [ByteArrayContent](./bytearraycontent/) | Representerar innehåll baserat på en bytearray. |
| [Content](./content/) | Representerar en basklass för en HTTP-entitetskropp och innehållshuvuden. |
| [ContentHeaders](./contentheaders/) | Innehåller huvuden som är associerade med ett innehåll. |
| [FormUrlEncodedContent](./formurlencodedcontent/) | En behållare för namn/värde‑par kodade med MIME-typen application/x-www-form-urlencoded. |
| [HttpMethod](./httpmethod/) | Representerar en verktygsklass för att hämta och jämföra standard‑HTTP‑metoder. |
| [MessageFilter](./messagefilter/) | Representerar en abstrakt basklass för olika filterklasser som används för att fråga meddelanden |
| [MessageHandler](./messagehandler/) | Representerar en bastyp för meddelandehanterare. |
| [MessageHandlerCollection](./messagehandlercollection/) | Representerar en samling av [`MessageHandler`](../aspose.svg.net/messagehandler/). |
| [MultipartContent](./multipartcontent/) | Representerar ett multipart/*‑innehåll. |
| [MultipartFormDataContent](./multipartformdatacontent/) | Representerar innehåll för multipart/form-data‑kodningsalgoritmen |
| [RequestHeaders](./requestheaders/) | Innehåller protokollhuvuden som är associerade med en begäran. |
| [RequestMessage](./requestmessage/) | Representerar ett förfrågningsmeddelande. |
| [ResponseHeaders](./responseheaders/) | Innehåller protokollhuvuden som är associerade med ett svar. |
| [ResponseMessage](./responsemessage/) | Representerar ett svarmeddelande. |
| [StreamContent](./streamcontent/) | Representerar innehåll baserat på en ström. |
| [StringContent](./stringcontent/) | Representerar innehåll baserat på en sträng. |
| [UrlResolver](./urlresolver/) | Representerar en verktygsklass för att lösa en absolut URL med en Uniform Resource Identifier (URI). |

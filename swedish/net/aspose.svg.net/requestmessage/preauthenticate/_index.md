## RequestMessage.PreAuthenticate property

Hämtar eller anger ett värde som indikerar om en Authorization‑header ska skickas med begäran.

```csharp
public bool PreAuthenticate { get; set; }
```

### Property Value

`true` för att skicka en HTTP Authorization-header med förfrågningar efter att autentisering har ägt rum; annars `false`. Standardvärdet är `false`.

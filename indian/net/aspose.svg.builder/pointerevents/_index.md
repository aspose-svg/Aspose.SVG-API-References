## PointerEvents enumeration

SVG में ग्राफ़िकल तत्वों द्वारा पॉइंटर इवेंट्स को कैसे संभाला जाता है, इसे निर्दिष्ट करता है।

```csharp
public enum PointerEvents
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| BoundingBox | `0` | पॉइंटर इवेंट्स तत्व के बाउंडिंग बॉक्स को लक्षित करते हैं। |
| VisiblePainted | `1` | पॉइंटर इवेंट्स केवल तत्व के दृश्यमान (पेंटेड) भागों को लक्षित करते हैं। |
| VisibleFill | `2` | पॉइंटर इवेंट्स केवल तत्व के दृश्यमान (भरे हुए) भागों को लक्षित करते हैं। |
| VisibleStroke | `3` | पॉइंटर इवेंट्स केवल तत्व के दृश्यमान (स्ट्रोक्ड) भागों को लक्षित करते हैं। |
| Visible | `4` | पॉइंटर इवेंट्स तत्व के सभी दृश्यमान भागों को लक्षित करते हैं। |
| Painted | `5` | पॉइंटर इवेंट्स तत्व के सभी पेंट किए गए भागों को लक्षित करते हैं, जिसमें फ़िल और स्ट्रोक शामिल हैं। |
| Fill | `6` | पॉइंटर इवेंट्स केवल तत्व के भरे हुए भागों को लक्षित करते हैं। |
| Stroke | `7` | पॉइंटर इवेंट्स केवल तत्व के स्ट्रोक किए गए भागों को लक्षित करते हैं। |
| All | `8` | पॉइंटर इवेंट्स तत्व के सभी भागों को लक्षित करते हैं, चाहे वे दृश्यमान हों या न हों। |
| None | `9` | तत्व पॉइंटर इवेंट्स का लक्ष्य नहीं बनता है। |

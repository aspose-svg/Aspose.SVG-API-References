## IAttributeSetter.Attribute method

SVG तत्व पर एट्रिब्यूट को सेट या अपडेट करता है।

```csharp
public void Attribute(string name, string value)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| नाम | String | सेट करने के लिए विशेषता का नाम। यह एक वैध SVG विशेषता नाम होना चाहिए। |
| value | String | विशेषता को सौंपने के लिए मान। मान को उस विशिष्ट SVG विशेषता के लिए उपयुक्त स्ट्रिंग प्रतिनिधित्व होना चाहिए। |

## टिप्पणियाँ

यह मेथड निर्माण प्रक्रिया के दौरान SVG तत्वों की विशेषताओं को गतिशील रूप से जोड़ने या संशोधित करने के लिए उपयोग किया जाता है। यह विभिन्न स्थितियों या इनपुट के आधार पर विशेषताओं को सेट करने की अनुमति देकर SVG तत्वों को परिभाषित और अनुकूलित करने में लचीलापन प्रदान करता है।

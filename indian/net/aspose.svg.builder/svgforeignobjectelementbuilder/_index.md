## SVGForeignObjectElementBuilder class

SVG 'foreignObject' तत्व बनाने के लिए Builder क्लास, जो SVG दस्तावेज़ में बाहरी सामग्री को शामिल करने की अनुमति देती है। यह तत्व विभिन्न प्रकार की सामग्री, जैसे HTML और XHTML, रख सकता है, जिससे SVG में अधिक जटिल ग्राफ़िकल प्रतिनिधित्व संभव होते हैं।

```csharp
public class SVGForeignObjectElementBuilder : SVGElementBuilder<SVGForeignObjectElement>, 
    ICompositeAttributeSetter, IRectAttributeSetter, ITextContentSetter
```

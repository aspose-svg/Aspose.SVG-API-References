## SVGPathElementBuilder class

SVG 'path' तत्व बनाने के लिए Builder क्लास, जो SVG दस्तावेज़ में एक पाथ को परिभाषित करने के लिए उपयोग की जाती है। यह क्लास 'path' तत्व के विशिष्ट विभिन्न एट्रिब्यूट सेट करने के लिए मेथड्स प्रदान करती है और इसकी सामग्री बनाती है।

```csharp
public class SVGPathElementBuilder : SVGElementBuilder<SVGPathElement>, IAnimationElementBuilder, 
    IDescriptiveElementBuilder, IPaintServerElementBuilder, IShapeAttributeSetter, 
    IShapeContentElementBuilder
```

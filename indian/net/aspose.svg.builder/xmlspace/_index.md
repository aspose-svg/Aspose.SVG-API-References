## XmlSpace enumeration

XML दस्तावेज़ों में तत्वों के भीतर सफ़ेद स्थान को कैसे संभाला जाता है, यह निर्दिष्ट करता है।

```csharp
public enum XmlSpace
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| Default | `0` | इसे दर्शाता है कि सफ़ेद स्थान को XML प्रोसेसर के डिफ़ॉल्ट व्यवहार के अनुसार संभालना चाहिए, आमतौर पर लाइन ब्रेक और अतिरिक्त स्पेसेज़ हटाकर सफ़ेद स्थान को सामान्यीकृत किया जाता है। |
| Preserve | `1` | इसे दर्शाता है कि सफ़ेद स्थान को XML दस्तावेज़ में जैसा है वैसा ही संरक्षित किया जाना चाहिए। यह उन पाठों के फॉर्मेटिंग को बनाए रखने में उपयोगी है जहाँ सफ़ेद स्थान महत्वपूर्ण होता है। |

## टिप्पणियाँ

XML में 'xml:space' एट्रिब्यूट का उपयोग यह नियंत्रित करने के लिए किया जाता है कि तत्वों के भीतर सफ़ेद स्थान को संरक्षित किया जाए या सामान्यीकृत। यह एन्यूमरेशन XML और SVG दस्तावेज़ों में इस व्यवहार को सेट करने के विकल्प प्रदान करता है।

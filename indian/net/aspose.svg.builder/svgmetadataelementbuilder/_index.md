## SVGMetadataElementBuilder class

SVG 'metadata' तत्व बनाने के लिए Builder क्लास, जो SVG दस्तावेज़ में मेटाडाटा जोड़ने के लिए उपयोग की जाती है। यह क्लास मेटाडाटा सामग्री जोड़ने को सक्षम करती है और SVG में 'metadata' तत्व के विशिष्ट विभिन्न एट्रिब्यूट सेट करने के लिए मेथड्स प्रदान करती है।

```csharp
public class SVGMetadataElementBuilder : SVGElementBuilder<SVGMetadataElement>, 
    ICoreAttributeSetter, IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, 
    ITextContentSetter
```

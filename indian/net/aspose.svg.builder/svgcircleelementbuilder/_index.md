## SVGCircleElementBuilder class

SVG 'circle' तत्व को बनाने के लिए Builder क्लास, जिसका उपयोग SVG ग्राफिक्स में वृत्त खींचने के लिए किया जाता है। यह 'circle' तत्व के भीतर सामग्री बनाने को सक्षम करता है और SVG में 'circle' तत्व के विशिष्ट विभिन्न गुण सेट करने के लिए मेथड्स प्रदान करता है।

```csharp
public class SVGCircleElementBuilder : SVGElementBuilder<SVGCircleElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IShapeAttributeSetter, IShapeContentElementBuilder
```

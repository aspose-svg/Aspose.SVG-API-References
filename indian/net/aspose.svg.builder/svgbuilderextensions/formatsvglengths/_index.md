## SVGBuilderExtensions.FormatSvgLengths method

डबल मानों की एक एरे को SVG लंबाइयों के स्ट्रिंग प्रतिनिधित्व में फ़ॉर्मेट करता है।

```csharp
public static string FormatSvgLengths(double[] values, LengthType type)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| values | Double[] | लंबाइयों का प्रतिनिधित्व करने वाले डबल मानों की एरे। |
| प्रकार | LengthType | उपयोग करने के लिए लंबाई इकाई का प्रकार (जैसे, पिक्सेल)। |

### रिटर्न वैल्यू

SVG लंबाइयों की फ़ॉर्मेटेड स्ट्रिंग।

## टिप्पणियाँ

यह उपयोगिता मेथड SVG एट्रिब्यूट्स के लिए लंबाई मानों को फ़ॉर्मेट करने के लिए उपयोग की जाती है, प्रत्येक मान के अंत में उपयुक्त इकाई (जैसे 'px') जोड़ती है।

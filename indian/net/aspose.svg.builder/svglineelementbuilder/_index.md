## SVGLineElementBuilder class

SVG 'line' तत्व बनाने के लिए Builder क्लास, जो SVG ग्राफ़िक्स में सीधी रेखाएँ खींचने के लिए उपयोग की जाती है। यह क्लास 'line' तत्व के भीतर सामग्री बनाने को सक्षम करती है और SVG में 'line' तत्व के विशिष्ट विभिन्न एट्रिब्यूट सेट करने के लिए मेथड्स प्रदान करती है।

```csharp
public class SVGLineElementBuilder : SVGElementBuilder<SVGLineElement>, IAnimationElementBuilder, 
    IDescriptiveElementBuilder, IPaintServerElementBuilder, IShapeAttributeSetter, 
    IShapeContentElementBuilder
```

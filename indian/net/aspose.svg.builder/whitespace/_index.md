## WhiteSpace enumeration

निर्दिष्ट करता है कि SVG तत्व के भीतर सफ़ेद स्थान को कैसे संभाला जाता है।

```csharp
public enum WhiteSpace
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| Normal | `0` | सफ़ेद स्थान को संकुचित किया जाता है; नई पंक्ति अक्षर नई पंक्तियाँ बनाते हैं। |
| Pre | `1` | सफ़ेद स्थान को संरक्षित किया जाता है; पाठ केवल उन स्थानों पर ही लपेटा जाता है जहाँ इसमें नई पंक्ति अक्षर होते हैं। |
| NoWrap | `2` | सफ़ेद स्थान को संकुचित किया जाता है; पाठ लपेटा नहीं जाता। |
| PreWrap | `3` | सफ़ेद स्थान को संरक्षित किया जाता है; आवश्यकतानुसार और नई पंक्ति अक्षरों पर पाठ लपेटा जाता है। |
| BreakSpaces | `4` | सफ़ेद स्थान को संरक्षित किया जाता है; लाइन बॉक्स भरने के लिए लाइन ब्रेक जोड़े जाते हैं। |
| PreLine | `5` | सफ़ेद स्थान को संरक्षित किया जाता है; आवश्यकतानुसार पाठ लपेटा जाता है, लेकिन नई पंक्ति अक्षर नहीं होते। |

## DisplayType enumeration

SVG दस्तावेज़ों में तत्वों के प्रदर्शन व्यवहार को निर्दिष्ट करता है।

```csharp
public enum DisplayType
```

### मान

| नाम | मान | विवरण |
| --- | --- | --- |
| Inline | `0` | तत्व एक या अधिक इनलाइन बॉक्स उत्पन्न करता है। |
| Block | `1` | तत्व एक ब्लॉक बॉक्स उत्पन्न करता है। |
| ListItem | `2` | तत्व सामग्री के लिए एक ब्लॉक बॉक्स और एक अलग सूची-आइटम इनलाइन बॉक्स उत्पन्न करता है। |
| InlineBlock | `3` | तत्व सामग्री के लिए एक ब्लॉक बॉक्स और कंटेनर के लिए एक इनलाइन बॉक्स उत्पन्न करता है। |
| Table | `4` | तत्व एक टेबल तत्व की तरह व्यवहार करता है। |
| InlineTable | `5` | तत्व एक इनलाइन टेबल की तरह व्यवहार करता है। |
| TableRowGroup | `6` | तत्व एक टेबल रो ग्रुप की तरह व्यवहार करता है। |
| TableHeaderGroup | `7` | तत्व एक टेबल हेडर ग्रुप की तरह व्यवहार करता है। |
| TableFooterGroup | `8` | तत्व एक टेबल फुटर ग्रुप की तरह व्यवहार करता है। |
| TableRow | `9` | यह तत्व तालिका पंक्ति की तरह व्यवहार करता है। |
| TableColumnGroup | `10` | यह तत्व तालिका स्तंभ समूह की तरह व्यवहार करता है। |
| TableColumn | `11` | यह तत्व तालिका स्तंभ की तरह व्यवहार करता है। |
| TableCell | `12` | यह तत्व तालिका सेल की तरह व्यवहार करता है। |

| None | `14` | यह तत्व कोई बॉक्स उत्पन्न नहीं करता और रेंडर नहीं होता। यह लेआउट को प्रभावित नहीं करता। |
| Flex | `15` | यह तत्व फ्लेक्स कंटेनर की तरह व्यवहार करता है। |
| InlineFlex | `16` | यह तत्व इनलाइन फ्लेक्स कंटेनर की तरह व्यवहार करता है। |
| Grid | `17` | यह तत्व ग्रिड कंटेनर की तरह व्यवहार करता है। |
| InlineGrid | `18` | यह तत्व इनलाइन ग्रिड कंटेनर की तरह व्यवहार करता है। |

## टिप्पणियाँ

'display' प्रॉपर्टी SVG और CSS में निर्धारित करती है कि तत्व दस्तावेज़ लेआउट में कैसे प्रदर्शित होता है। यह एनेमरेशन डिस्प्ले प्रकार सेट करने के विभिन्न विकल्प प्रदान करता है, जो तत्वों के रेंडर होने और लेआउट के साथ इंटरैक्ट करने को प्रभावित करता है।

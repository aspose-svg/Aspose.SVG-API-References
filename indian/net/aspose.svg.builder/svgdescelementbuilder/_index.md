## SVGDescElementBuilder class

SVG 'desc' तत्व को बनाने के लिए Builder क्लास, जिसका उपयोग SVG कंटेनर तत्वों के लिए विवरण प्रदान करने के लिए किया जाता है। यह 'desc' तत्व के भीतर सामग्री बनाने को सक्षम करता है और SVG में 'desc' तत्व के विशिष्ट विभिन्न गुण सेट करने के लिए मेथड्स प्रदान करता है।

```csharp
public class SVGDescElementBuilder : SVGElementBuilder<SVGDescElement>, ICoreAttributeSetter,
```

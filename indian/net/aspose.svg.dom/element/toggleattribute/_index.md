## ToggleAttribute(*string*) {#toggleattribute}

यदि force दिया नहीं गया है, "toggles" qualifiedName, यदि यह मौजूद है तो उसे हटाता है और यदि नहीं है तो जोड़ता है। यदि force true है, qualifiedName जोड़ता है। यदि force false है, qualifiedName हटाता है।

```csharp
public bool ToggleAttribute(string qualifiedName)
```

| पैरामीटर | टाइप | विवरण |
| --- | --- | --- |
| qualifiedName | String | गुणधर्म QualifiedName। |

### रिटर्न वैल्यू

यदि qualifiedName अब मौजूद है तो true लौटाता है; अन्यथा false।

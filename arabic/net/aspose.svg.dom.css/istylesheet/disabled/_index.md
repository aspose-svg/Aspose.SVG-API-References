## IStyleSheet.Disabled property

false إذا تم تطبيق ورقة النمط على المستند. true إذا لم يتم ذلك. قد يؤدي تعديل هذه الخاصية إلى حل جديد للنمط للمستند. تُطبق ورقة النمط فقط إذا كان تعريف الوسيط المناسب موجودًا وكانت خاصية disabled تساوي false. لذا، إذا لم يكن الوسيط مناسبًا للوكيل المستخدم الحالي، يتم تجاهل خاصية disabled.

```csharp
public bool Disabled { get; set; }
```

### Property Value

`true` إذا كان معطَّل؛ وإلا `false`.

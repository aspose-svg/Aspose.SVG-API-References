## ICSSRule.ParentRule property

إذا كانت هذه القاعدة موجودة داخل قاعدة أخرى (مثال: قاعدة نمط داخل كتلة @media)، فهذه هي القاعدة الحاوية. إذا لم تكن هذه القاعدة متداخلة داخل أي قواعد أخرى، فإنها تُعيد null.

public ICSSRule ParentRule { get; }

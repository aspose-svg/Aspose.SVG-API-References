## IBlob interface

كائن Blob يشير إلى تسلسل بايتات، وله سمة size التي تمثل إجمالي عدد البايتات في التسلسل، وسمة type التي هي سلسلة مشفرة بـ ASCII بأحرف صغيرة تمثل نوع الوسائط للتسلسل.

```csharp
public interface IBlob
```

## الخصائص

| الاسم | الوصف |
| --- | --- |
| [Size](../../aspose.svg.io/iblob/size/) { get; } | يرجع حجم تسلسل البايتات بعدد البايتات. عند الحصول، يجب على وكلاء المستخدم المتوافقين إرجاع إجمالي عدد البايتات التي يمكن قراءتها بواسطة كائن FileReader أو FileReaderSync، أو 0 إذا لم يحتوي Blob على بايتات للقراءة. |
| [Type](../../aspose.svg.io/iblob/type/) { get; } | السلسلة المشفرة بـ ASCII بأحرف صغيرة التي تمثل نوع الوسائط للـ Blob. عند الحصول، يجب على وكلاء المستخدم إرجاع نوع الـ Blob كسلسلة مشفرة بـ ASCII بأحرف صغيرة، بحيث عند تحويلها إلى تسلسل بايتات تكون نوع MIME قابل للتحليل، أو السلسلة الفارغة – 0 بايت – إذا تعذر تحديد النوع. |

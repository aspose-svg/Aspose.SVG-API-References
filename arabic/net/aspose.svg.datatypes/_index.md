توفر المساحة وصولًا إلى جميع أنواع البيانات الخاصة بـ SVG.

## الفئات

| الفئة | الوصف |
| --- | --- |
| [SVGAngle](./svgangle/) | واجهة SVGAngle تتطابق مع نوع البيانات الأساسي angle. |
| [SVGAnimatedAngle](./svganimatedangle/) | تُستخدم لسمات نوع البيانات الأساسي angle التي يمكن تحريكها. |
| [SVGAnimatedBoolean](./svganimatedboolean/) | تُستخدم لسمات من النوع boolean التي يمكن تحريكها. |
| [SVGAnimatedEnumeration](./svganimatedenumeration/) | تُستخدم لسمات يجب أن تكون قيمتها ثابتًا من تعداد معين والتي يمكن تحريكها. |
| [SVGAnimatedInteger](./svganimatedinteger/) | تُستخدم لسمات من النوع الأساسي integer التي يمكن تحريكها. |
| [SVGAnimatedLength](./svganimatedlength/) | تُستخدم لسمات من النوع الأساسي length التي يمكن تحريكها. |
| [SVGAnimatedLengthList](./svganimatedlengthlist/) | تُستخدم لسمات من النوع SVGLengthList التي يمكن تحريكها. |
| [SVGAnimatedNumber](./svganimatednumber/) | تُستخدم لسمات من النوع الأساسي number التي يمكن تحريكها. |
| [SVGAnimatedNumberList](./svganimatednumberlist/) | تُستخدم لسمات تأخذ قائمة من الأعداد والتي يمكن تحريكها. |
| [SVGAnimatedPreserveAspectRatio](./svganimatedpreserveaspectratio/) | تُستخدم لسمات من النوع SVGPreserveAspectRatio التي يمكن تحريكها. |
| [SVGAnimatedRect](./svganimatedrect/) | تُستخدم لسمات من النوع SVGRect التي يمكن تحريكها. |
| [SVGAnimatedString](./svganimatedstring/) | تُستخدم لسمات من النوع DOMString التي يمكن تحريكها. |
| [SVGAnimatedTransformList](./svganimatedtransformlist/) | تُستخدم للسمات المختلفة التي تحدد مجموعة من التحويلات، مثل السمة ‘transform’ المتاحة للعديد من عناصر SVG، والتي يمكن تحريكها. |
| [SVGAnimatedValue<T>](./svganimatedvalue-1/) | تُستخدم لسمات من الأنواع التي يمكن تحريكها. |
| [SVGLength](./svglength/) | واجهة SVGLength تتطابق مع نوع البيانات الأساسي length. يمكن تعيين كائن SVGLength كقراءة فقط، مما يعني أن محاولات تعديل الكائن ستؤدي إلى رمي استثناء، كما هو موضح أدناه. |
| [SVGLengthList](./svglengthlist/) | هذه الواجهة تعرف قائمة من كائنات SVGLength. |
| [SVGMatrix](./svgmatrix/) | تستخدم العديد من عمليات رسومات SVG مصفوفات 2x3 بالشكل: [a c e] [b d f] والتي، عند توسيعها إلى مصفوفة 3x3 لأغراض حساب المصفوفات، تصبح: [a c e] [b d f] [0 0 1] |
| [SVGNumber](./svgnumber/) | تُستخدم لسمات من النوع الأساسي number. |
| [SVGNumberList](./svgnumberlist/) | هذه الواجهة تعرف قائمة من كائنات SVGNumber. |
| [SVGPoint](./svgpoint/) | تشير العديد من واجهات DOM الخاصة بـ SVG إلى كائنات من الفئة SVGPoint. الـ SVGPoint هو زوج إحداثيات (x, y). عند استخدامها في عمليات المصفوفة، يُعامل SVGPoint كمتجه بالشكل: [x] [y] [1] إذا تم تعيين كائن SVGRect كقراءة فقط، فإن محاولة تعيين أحد سماته ستؤدي إلى رمي استثناء. |
| [SVGPointList](./svgpointlist/) | هذه الواجهة تعرف قائمة من كائنات SVGPoint. |
| [SVGPreserveAspectRatio](./svgpreserveaspectratio/) | واجهة SVGPreserveAspectRatio تتطابق مع السمة ‘preserveAspectRatio’، المتاحة لبعض عناصر SVG. |
| [SVGRect](./svgrect/) | يمثل الهندسة المستطيلة. يتم تعريف المستطيلات على أنها تتكون من زوج إحداثيات (x,y) يحدد قيمة X الدنيا، قيمة Y الدنيا، والعرض والارتفاع، والتي عادةً ما تكون مقيدة بأن تكون غير سالبة. |
| [SVGStringList](./svgstringlist/) | تحتوي SVGStringList على نفس السمات والطرق مثل واجهات SVGxxxList الأخرى. قد يفكر المطورون في استخدام فئة أساسية واحدة لتنفيذ واجهات SVGxxxList المتنوعة. |
| [SVGTransform](./svgtransform/) | SVGTransform هي الواجهة لإحدى التحويلات المكوّنة داخل SVGTransformList؛ وبالتالي، يتطابق كائن SVGTransform مع مكوّن واحد (مثل 'scale(…)' أو 'matrix(…)') داخل تعريف سمة ‘transform’. |
| [SVGTransformList](./svgtransformlist/) | تحدد هذه الواجهة قائمة من كائنات SVGTransform. |
| [SVGValueType](./svgvaluetype/) | يُستخدم النوع SVGValueType لتمثيل نوع قيمة SVG أساسي. |

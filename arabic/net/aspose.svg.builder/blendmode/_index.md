## BlendMode enumeration

يحدد أوضاع الدمج المتاحة لدمج الصور أو العناصر في SVG.

```csharp
public enum BlendMode
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| Normal | `0` | يعرض الصورة المصدر كما هي، دون أي دمج. |
| Multiply | `1` | يضاعف ألوان الصورة المصدر والخلفية. النتيجة صورة أغمق. |
| Screen | `2` | يجعل الأجزاء الداكنة من الصورة المصدر أكثر إضاءة بينما يبقى الأجزاء الفاتحة دون تغيير. |
| Overlay | `3` | يجمع وضعيات الدمج Multiply و Screen لتعزيز التباين. |
| Darken | `4` | يُظلم الخلفية بناءً على ألوان الصورة المصدر. |
| Lighten | `5` | يفتح الخلفية بناءً على ألوان الصورة المصدر. |
| ColorDodge | `6` | يزيد إضاءة الخلفية لتطابق الصورة المصدر. |
| ColorBurn | `7` | يغيم الخلفية لتطابق الصورة المصدر. |
| HardLight | `8` | ينشئ تأثير إضاءة صلبة بناءً على سطوع الصورة المصدر. |
| SoftLight | `9` | ينشئ تأثير إضاءة ناعمة بناءً على سطوع الصورة المصدر. |
| Difference | `10` | يبرز الفروقات بين الصورة المصدر والخلفية. |
| Exclusion | `11` | ينشئ تأثيرًا مشابهًا لـ Difference، لكن بتباين أقل. |
| Hue | `12` | يستخدم درجة اللون (Hue) للصورة المصدر مدمجة مع الإضاءة (Luminance) والتشبع (Saturation) للخلفية. |
| Saturation | `13` | يستخدم تشبع الصورة المصدر مدمجًا مع درجة اللون والإضاءة للخلفية. |
| Color | `14` | يستخدم درجة اللون والتشبع للصورة المصدر مدمجين مع إضاءة الخلفية. |
| Luminosity | `15` | يستخدم إضاءة الصورة المصدر مدمجة مع درجة اللون والتشبع للخلفية. |

## ملاحظات

تُستخدم أوضاع الدمج في SVG لتحديد كيفية دمج طبقتين معًا. يوفر هذا التعداد مجموعة متنوعة من الخيارات التي تتحكم في كيفية خلط ألوان الطبقات المدمجة وإنتاج تأثيرات بصرية مختلفة.

public enum CompositeOperator

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| Over | `0` | يضع الرسم المصدر فوق الرسم الهدف. |
| In | `1` | يعرض الرسم المصدر حيث يتقاطع مع الرسم الهدف. |
| Out | `2` | يعرض الرسم المصدر حيث لا يتقاطع مع الهدف. |
| Atop | `3` | يعرض الرسم المصدر فوق الرسم الهدف. |
| Xor | `4` | يعرض الرسم المصدر حيث لا يتقاطع مع الهدف والعكس بالعكس. |
| Arithmetic | `5` | يسمح بعملية تركيب حسابية مخصصة. |

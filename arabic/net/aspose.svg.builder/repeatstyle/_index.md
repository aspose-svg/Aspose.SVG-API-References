## RepeatStyle enumeration

يحدد نمط التكرار للصور الخلفية أو الأنماط في SVG.

```csharp
public enum RepeatStyle
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| RepeatX | `0` | يتم تكرار الصورة أو النمط أفقياً فقط. |
| RepeatY | `1` | يتم تكرار الصورة أو النمط عمودياً فقط. |
| Repeat | `2` | يتم تكرار الصورة أو النمط أفقياً وعمودياً. |
| Space | `3` | يتم تكرار الصورة أو النمط بأقصى قدر ممكن دون قص، ويتم توزيع المساحة المتبقية بالتساوي بين الصور. |
| Round | `4` | يتم تحجيم الصورة أو النمط بحيث يتناسب ويتم تكراره دون قص، مع الحفاظ على نسبة العرض إلى الارتفاع. |
| NoRepeat | `5` | لا يتم تكرار الصورة أو النمط، وسيتم رسم نسخة واحدة فقط من الصورة. |

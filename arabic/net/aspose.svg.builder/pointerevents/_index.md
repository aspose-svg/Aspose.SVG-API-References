## PointerEvents enumeration

يحدد كيفية معالجة أحداث المؤشر بواسطة العناصر الرسومية في SVG.

```csharp
public enum PointerEvents
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| BoundingBox | `0` | تستهدف أحداث المؤشر صندوق الحدود للعنصر. |
| VisiblePainted | `1` | تستهدف أحداث المؤشر فقط الأجزاء المرئية (المرسومة) للعنصر. |
| VisibleFill | `2` | تستهدف أحداث المؤشر فقط الأجزاء المرئية (المملوءة) للعنصر. |
| VisibleStroke | `3` | تستهدف أحداث المؤشر فقط الأجزاء المرئية (المحددة بالخط) للعنصر. |
| Visible | `4` | تستهدف أحداث المؤشر جميع الأجزاء المرئية للعنصر. |
| Painted | `5` | تستهدف أحداث المؤشر جميع الأجزاء المرسومة للعنصر، بما في ذلك التعبئة والحد. |
| Fill | `6` | تستهدف أحداث المؤشر فقط الأجزاء المملوءة للعنصر. |
| Stroke | `7` | تستهدف أحداث المؤشر فقط الأجزاء المحددة بالخط للعنصر. |
| All | `8` | تستهدف أحداث المؤشر جميع أجزاء العنصر، بغض النظر عن الرؤية. |
| None | `9` | العنصر لا يصبح هدفًا لأحداث المؤشر. |

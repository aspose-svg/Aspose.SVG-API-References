## FontWeight enumeration

يحدد أوزان الخط المختلفة لعناصر نص SVG.

```csharp
public enum FontWeight
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| Normal | `0` | يمثل وزن الخط العادي، وهو الوزن الافتراضي. |
| Bold | `1` | يمثل وزن الخط العريض، يُستخدم عادة للتأكيد. |
| Bolder | `2` | يمثل وزن الخط الأثقل من وزن العنصر الأب. |
| Lighter | `3` | يمثل وزن الخط الأخف من وزن العنصر الأب. |
| W100 | `4` | يمثل وزن الخط 100، وهو الأرفع المتاح. |
| W200 | `5` | يمثل وزن الخط 200. |
| W300 | `6` | يمثل وزن الخط 300. |
| W400 | `7` | يمثل وزن الخط 400، ما يعادل 'normal'. |
| W500 | `8` | يمثل وزن الخط 500. |
| W600 | `9` | يمثل وزن الخط 600. |
| W700 | `10` | يمثل وزن الخط 700، ما يعادل 'bold'. |
| W800 | `11` | يمثل وزن الخط 800. |
| W900 | `12` | يمثل وزن الخط 900، وهو الأكثر سُمكًا المتاح. |

## SVGForeignObjectElementBuilder class

فئة Builder لإنشاء عنصر SVG 'foreignObject'، الذي يسمح بتضمين محتوى خارجي في مستند SVG. يمكن لهذا العنصر أن يحتوي على أنواع مختلفة من المحتوى، مثل HTML و XHTML، مما يتيح تمثيلات رسومية أكثر تعقيدًا داخل SVG.

```csharp
public class SVGForeignObjectElementBuilder : SVGElementBuilder<SVGForeignObjectElement>, 
    ICompositeAttributeSetter, IRectAttributeSetter, ITextContentSetter
```

المساحة تتكون من فئات للتفاعل القائم على الأحداث مثل أحداث الوقت والتكبير.

## الفئات

| الفئة | الوصف |
| --- | --- |
| [Angle](./angle/) | نوع البيانات الزاوية |
| [Color](./color/) | تتيح لك فئة Color تحديد الألوان كقيم الأحمر-الأخضر-الأزرق (RGB)، أو قيم الصبغة-التشبع-الإضاءة (HSL)، أو قيم الصبغة-التشبع-القيمة (HSV)، أو قيم الصبغة-البياض-السواد (HWB)، أو قيم الإضاءة-A-B (LAB)، أو قيم الإضاءة-اللون-الكروم (LCH)، أو قيم السيان-ماجنتا-أصفر-المفتاح (CMYK)، أو قيم الألوان الطبيعية (NCOL)، أو باستخدام اسم اللون. كما يتوفر قناة ألفا لتحديد الشفافية. |
| [Dimension](./dimension/) | يوفر الفئة الأساسية للأبعاد. المصطلح العام 'البُعد' يشير إلى عدد مع وحدة مرفقة به، ويتم الإشارة إليه بواسطة [`UnitType`](../aspose.svg.drawing/unittype/). |
| [Frequency](./frequency/) | وحدة 'التردد'. |
| [Length](./length/) | يمثل وحدة قياس الطول. |
| [LengthOrAuto](./lengthorauto/) | يمثل حاوية لتخزين الطول أو وحدات 'auto'.. |
| [Margin](./margin/) | يمثل هامش الصفحة. |
| [Numeric](./numeric/) | يوفر الفئة الأساسية لأنواع الأعداد. |
| [Page](./page/) | يمثل كائن صفحة يُستخدم لتكوين صفحة الإخراج. القيمة الفارغة لحجم الصفحة هي A4(210x297مم) |
| [Resolution](./resolution/) | يمثل وحدة الدقة. |
| [Size](./size/) | يخزن قيمًا تحدد الارتفاع والعرض. |
| [Time](./time/) | يمثل وحدة زمنية. |
| [Unit](./unit/) | يوفر الفئة الأساسية لوحدات القياس. |
| [UnitType](./unittype/) | يحدد وحدة القياس. |

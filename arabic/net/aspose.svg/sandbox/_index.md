## Sandbox enumeration

مجموعة علامات العزل هي مجموعة من صفر أو أكثر من العلامات التالية، تُستخدم لتقييد القدرات التي قد تكون للموارد غير الموثوقة.

```csharp
[Flags]
public enum Sandbox
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| None | `0` | لم يتم تعيين أي علم، تم قبول جميع ميزات الحماية |
| Navigation | `1` | هذه العلامة تمنع المحتوى من التنقل إلى سياقات التصفح غير سياق التصفح المعزول نفسه (أو سياقات التصفح المتداخلة داخله)، وسياقات التصفح المساعدة (التي تحميها علامة sandboxed auxiliary navigation browsing context المعرفة لاحقًا)، وسياق التصفح الأعلى مستوى (الذي تحميه علامة sandboxed top-level navigation browsing context المعرفة أدناه). إذا لم يتم تعيين علامة sandboxed auxiliary navigation browsing context، ففي بعض الحالات لا تزال القيود تسمح بفتح النوافذ المنبثقة (سياقات تصفح أعلى مستوى جديدة). هذه السياقات دائمًا ما يكون لها متصفح معزول مسموح واحد، يتم تعيينه عند إنشاء سياق التصفح، والذي يسمح لسياق التصفح الذي أنشأها بالتنقل إليها فعليًا. (وإلا، فإن علامة sandboxed navigation browsing context كانت ستمنع تنقلها حتى لو تم فتحها.) |
| AuxiliaryNavigation | `2` | هذه العلامة تمنع المحتوى من إنشاء سياقات تصفح مساعدة جديدة، على سبيل المثال باستخدام سمة target، أو الطريقة `window.open()` |
| TopLevelNavigation | `4` | هذه العلامة تمنع المحتوى من التنقل في سياق التصفح الأعلى الخاص به وتمنع المحتوى من إغلاق سياق التصفح الأعلى الخاص به. عندما لا يتم تعيين علامة سياق التصفح الأعلى المعزول للتنقل، يمكن للمحتوى التنقل في سياق التصفح الأعلى الخاص به، لكن سياقات التصفح الأخرى لا تزال محمية بعلامة سياق التصفح المعزول للتنقل وربما بعلامة سياق التصفح المعزول المساعد للتنقل. |
| Plugins | `8` | هذه العلامة تمنع المحتوى من إنشاء الإضافات، سواء باستخدام عنصر embed أو عنصر object أو عنصر applet أو عبر التنقل في سياق تصفح متداخل، ما لم يمكن تأمين تلك الإضافات. |
| Origin | `10` | هذه العلامة تجبر المحتوى على أصل فريد، وبالتالي تمنعه من الوصول إلى محتوى آخر من نفس الأصل. |
| Forms | `20` | هذه العلامة تمنع إرسال النماذج. |
| PointerLock | `40` | هذه العلامة تعطل واجهة برمجة التطبيقات Pointer Lock API. |
| Scripts | `80` | هذه العلامة تمنع تنفيذ النص البرمجي. |
| AutomaticFeatures | `100` | هذه العلامة تحظر الميزات التي تُفعَّل تلقائيًا، مثل تشغيل الفيديو تلقائيًا أو تركيز عنصر نموذج تلقائيًا. |
| Fullscreen | `200` | هذه العلامة تمنع المحتوى من استخدام طريقة requestFullscreen(). |
| DocumentDomain | `400` | هذه العلامة تمنع المحتوى من استخدام ميزة document.domain لتغيير أصل النص البرمجي الفعّال. |
| Images | `800` | هذه العلامة تعطل تحميل الصور. |

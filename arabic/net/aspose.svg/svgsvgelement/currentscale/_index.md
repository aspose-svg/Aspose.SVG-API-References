## SVGSVGElement.CurrentScale property

على عنصر svg الخارجي الأكثر، تشير هذه السمة إلى عامل المقياس الحالي بالنسبة إلى العرض الأولي لتأخذ في الاعتبار تكبير المستخدم وعمليات الإزاحة، كما هو موضح تحت التكبير والإزاحة. سمات DOM currentScale و currentTranslate تعادل مصفوفة 2x3 [a b c d e f] = [currentScale 0 0 currentScale currentTranslate.x currentTranslate.y]. إذا تم تمكين \"magnification\" (أي zoomAndPan=\"magnify\"), فإن التأثير يكون كما لو تم وضع تحويل إضافي على المستوى الخارجي في جزء مستند SVG (أي خارج عنصر svg الخارجي). عند الوصول إلى عنصر ‘svg’ ليس عنصر svg خارجي، يكون سلوك هذه السمة غير معرف.

```csharp
public float CurrentScale { get; set; }
```

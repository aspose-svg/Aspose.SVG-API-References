## Document.CreateAttributeNS method

هذه الطريقة تُنشئ عقدة صفة جديدة، وتُعيدها. الكائن المُنشأ هو عقدة تُطبق فئة [`Attr`](../../attr/). لا يفرض DOM نوع الصفات التي يمكن إضافتها إلى عنصر معين بهذه الطريقة.

```csharp
public Attr CreateAttributeNS(string namespaceURI, string qualifiedName)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| namespaceURI | String | معرّف URI للمساحة الاسمية للخاصية. |
| qualifiedName | String | سلسلة نصية تحتوي على اسم الخاصية. |

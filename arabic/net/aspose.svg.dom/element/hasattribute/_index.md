## Element.HasAttribute method

```csharp
public bool HasAttribute(string qualifiedName)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| qualifiedName | String | اسم السمة. |

### قيمة الإرجاع

`true` إذا كان الاسم المحدد لديه سمة؛ وإلا `false`.

## ToggleAttribute(*string*) {#toggleattribute}

إذا لم يتم تقديم force، "يقلب" qualifiedName، يزيله إذا كان موجودًا ويضيفه إذا لم يكن موجودًا. إذا كان force true، يضيف qualifiedName. إذا كان force false، يزيل qualifiedName.

```csharp
public bool ToggleAttribute(string qualifiedName)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| qualifiedName | String | السمة QualifiedName. |

### قيمة الإرجاع

تُعيد true إذا كان qualifiedName موجودًا الآن؛ وإلا false.

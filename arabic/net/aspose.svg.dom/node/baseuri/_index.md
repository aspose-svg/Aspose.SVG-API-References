## Node.BaseURI property

تُعيد عنوان URL الأساسي المطلق للمستند الذي يحتوي على العقدة.

يُستخدم عنوان URL الأساسي لحل عناوين URL النسبية عندما يحتاج المتصفح إلى الحصول على عنوان URL مطلق، على سبيل المثال عند معالجة سمة src لعنصر img في HTML أو سمات xlink:href أو href في SVG.

```csharp
public virtual string BaseURI { get; }
```

### Property Value

تُعيد الدالة getter للـ baseURI عنوان URL الأساسي للوثيقة الخاصة بالعقدة، بشكل مسلسل.

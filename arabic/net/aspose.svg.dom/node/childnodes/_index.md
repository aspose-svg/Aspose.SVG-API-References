## Node.ChildNodes property

إرجاع قائمة حية [`NodeList`](../../../aspose.svg.collections/nodelist/) من العقد الفرعية للعنصر المعطى حيث يتم تعيين الفهرس 0 للعقدة الفرعية الأولى. تشمل العقد الفرعية العناصر والنص والتعليقات.

ملاحظة: إن [`NodeList`](../../../aspose.svg.collections/nodelist/) الحية تعني أن محتواها يتغير في كل مرة يتم فيها إضافة أو إزالة عقد فرعية جديدة.

```csharp
public NodeList ChildNodes { get; }
```

### Property Value

قائمة حية [`NodeList`](../../../aspose.svg.collections/nodelist/) تحتوي على العقد الفرعية للعنصر.

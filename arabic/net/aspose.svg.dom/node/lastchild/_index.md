## Node.LastChild property

تُعيد آخر طفل للعقدة. إذا كان والدها عنصرًا، فإن الطفل يكون عادةً عقدة عنصر أو عقدة نص أو عقدة تعليق. تُعيد null إذا لم توجد عناصر طفل.

```csharp
public Node LastChild { get; }
```

### Property Value

كائن [`Node`](../) هو العنصر الفرعي الأخير للعقدة، أو null إذا لم يكن هناك عناصر فرعية.

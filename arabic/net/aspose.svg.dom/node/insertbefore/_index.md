## Node.InsertBefore method

يدرج العقدة قبل عقدة الطفل الموجودة child. إذا كان child null، يُدرج العقدة في نهاية قائمة الأطفال. إذا كان child كائن DocumentFragment، تُدرج جميع أطفاله، بنفس الترتيب، قبل child. إذا كان الطفل موجوداً بالفعل في الشجرة، يُزال أولاً.

```csharp
public Node InsertBefore(Node node, Node child)
```

| معامل | نوع | الوصف |
| --- | --- | --- |
| node | Node | العنصر الفرعي الجديد. |
| child | Node | العنصر الفرعي المرجعي. |

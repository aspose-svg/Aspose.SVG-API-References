## IUserAgentService.ShowImagePlaceholders property

Les images peuvent avoir un contenu de secours : le contenu qui doit être utilisé lorsqu'une ressource externe ne peut pas être utilisée (par exemple, parce qu'elle est dans un format non pris en charge). La propriété `ShowImagePlaceholders` indique s'il faut afficher l'image de secours (la valeur par défaut est true).

```csharp
public bool ShowImagePlaceholders { get; set; }
```

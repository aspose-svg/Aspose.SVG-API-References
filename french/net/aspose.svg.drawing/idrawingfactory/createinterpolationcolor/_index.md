## IDrawingFactory.CreateInterpolationColor method

Crée une couleur d'interpolation avec la couleur et la position spécifiées.

```csharp
public IInterpolationColor CreateInterpolationColor(Color color, float position)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| color | Couleur | Représente la couleur qui sera utilisée à la position correspondante du dégradé. |
| position | Single | La position, représentée comme un pourcentage de 0 à 1, à laquelle la couleur de dégradé correspondante sera utilisée. |

### Valeur de retour

L'objet créé [`IInterpolationColor`](../../iinterpolationcolor/).

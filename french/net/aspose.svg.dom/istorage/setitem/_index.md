## IStorage.SetItem method

Définit la valeur de la paire identifiée par la clé à la valeur, créant une nouvelle paire clé/valeur si aucune n’existait auparavant pour cette clé.

```csharp
public void SetItem(string key, string value)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| key | String | Chaîne de clé d'élément. |
| value | String | Chaîne de valeur d'élément. |

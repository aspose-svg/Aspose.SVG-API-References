## BooleanPathOp enumeration

Spécifie l’opération booléenne utilisée lors de la combinaison de deux chemins.

```csharp
public enum BooleanPathOp
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Union | `0` | Union : la zone combinée des deux chemins. |
| Difference | `1` | Différence : la zone du premier chemin moins le second chemin (A - B). |
| Intersection | `2` | Intersection : la zone commune aux deux chemins. |
| Exclusion | `3` | Exclusion : la différence symétrique des deux chemins (XOR). |

## WhiteSpace enumeration

Spécifie comment les espaces blancs à l'intérieur d'un élément SVG sont gérés.

```csharp
public enum WhiteSpace
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Normal | `0` | Les espaces blancs sont réduits ; les caractères de nouvelle ligne créent de nouvelles lignes. |
| Pre | `1` | Les espaces blancs sont conservés ; le texte ne se renvoie à la ligne que lorsqu'il contient des caractères de nouvelle ligne. |
| NoWrap | `2` | Les espaces blancs sont réduits ; le texte ne se renvoie pas à la ligne. |
| PreWrap | `3` | Les espaces blancs sont conservés ; le texte se renvoie à la ligne lorsque nécessaire et sur les caractères de nouvelle ligne. |
| BreakSpaces | `4` | Les espaces blancs sont conservés ; des sauts de ligne sont ajoutés pour remplir les boîtes de ligne. |
| PreLine | `5` | Les espaces blancs sont conservés ; le texte se renvoie à la ligne lorsque nécessaire, mais sans caractères de nouvelle ligne. |

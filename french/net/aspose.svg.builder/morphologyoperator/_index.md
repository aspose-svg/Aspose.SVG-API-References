## MorphologyOperator enumeration

Spécifie le type d'opération morphologique à appliquer dans les filtres SVG.

```csharp
public enum MorphologyOperator
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Erode | `0` | Érode les graphiques, rendant les formes plus petites et les bords plus lisses. |
| Dilate | `1` | Dilate les graphiques, rendant les formes plus grandes et les bords plus prononcés. |

## Remarques

Cette énumération est utilisée dans le contexte des filtres SVG pour définir le type d'opération morphologique. Les opérations morphologiques sont utilisées pour traiter la forme et la structure des éléments d'une image, généralement pour éroder ou dilater les graphiques.

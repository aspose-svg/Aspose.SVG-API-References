## SVGForeignObjectElementBuilder class

Classe Builder pour construire un élément SVG 'foreignObject', qui permet l'inclusion de contenu externe dans un document SVG. Cet élément peut contenir différents types de contenu, tels que HTML et XHTML, permettant des représentations graphiques plus complexes au sein du SVG.

```csharp
public class SVGForeignObjectElementBuilder : SVGElementBuilder<SVGForeignObjectElement>, 
    ICompositeAttributeSetter, IRectAttributeSetter, ITextContentSetter
```

## Overflow enumeration

Spécifie le comportement de débordement pour les éléments SVG.

```csharp
public enum Overflow
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Visible | `0` | Le contenu qui dépasse les limites de l'élément est visible. |
| Hidden | `1` | Le contenu qui dépasse les limites de l'élément est rogné et n'est pas visible. |
| Scroll | `2` | Fournit des barres de défilement pour le contenu qui dépasse les limites de l'élément. |

## Remarques

Cette énumération contrôle la façon dont le contenu qui dépasse les limites d'un élément SVG est affiché. Elle détermine si le contenu excédentaire est visible, rogné ou fourni avec des barres de défilement.

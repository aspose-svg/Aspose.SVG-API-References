## SpreadMethod enumeration

Spécifie comment les couleurs d'un dégradé sont étendues au-delà de ses limites.

```csharp
public enum SpreadMethod
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Pad | `0` | La couleur du dernier arrêt du dégradé est utilisée pour remplir le reste de la zone du dégradé. |
| Reflect | `1` | Le dégradé est reflété (miroir) en dehors de ses limites. |
| Repeat | `2` | Le dégradé est répété en dehors de ses limites. |

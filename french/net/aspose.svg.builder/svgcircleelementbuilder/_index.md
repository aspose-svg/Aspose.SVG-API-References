## SVGCircleElementBuilder class

Classe Builder pour construire un élément SVG 'circle', qui est utilisé pour dessiner des cercles dans les graphiques SVG. Elle permet la construction de contenu à l'intérieur de l'élément 'circle' et fournit des méthodes pour définir divers attributs spécifiques à l'élément 'circle' en SVG.

```csharp
public class SVGCircleElementBuilder : SVGElementBuilder<SVGCircleElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IShapeAttributeSetter, IShapeContentElementBuilder
```

## DisplayType enumeration

Spécifie le comportement d’affichage des éléments dans les documents SVG.

```csharp
public enum DisplayType
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Inline | `0` | L'élément génère une ou plusieurs boîtes en ligne. |
| Block | `1` | L'élément génère une boîte de bloc. |
| ListItem | `2` | L'élément génère une boîte de bloc pour le contenu et une boîte en ligne d'élément de liste séparée. |
| InlineBlock | `3` | L'élément génère une boîte de bloc pour le contenu et une boîte en ligne pour le conteneur. |
| Table | `4` | L'élément se comporte comme un élément de tableau. |
| InlineTable | `5` | L'élément se comporte comme un tableau en ligne. |
| TableRowGroup | `6` | L'élément se comporte comme un groupe de lignes de tableau. |
| TableHeaderGroup | `7` | L'élément se comporte comme un groupe d'en-tête de tableau. |
| TableFooterGroup | `8` | L'élément se comporte comme un groupe de pied de tableau. |
| TableRow | `9` | L'élément se comporte comme une ligne de tableau. |
| TableColumnGroup | `10` | L'élément se comporte comme un groupe de colonnes de tableau. |
| TableColumn | `11` | L'élément se comporte comme une colonne de tableau. |
| TableCell | `12` | L'élément se comporte comme une cellule de tableau. |
| TableCaption | `13` | L'élément se comporte comme une légende de tableau. |
| None | `14` | L'élément ne génère aucune boîte et n'est pas rendu. Il n'affecte pas la mise en page. |
| Flex | `15` | L'élément se comporte comme un conteneur flex. |
| InlineFlex | `16` | L'élément se comporte comme un conteneur flex en ligne. |
| Grid | `17` | L'élément se comporte comme un conteneur de grille. |
| InlineGrid | `18` | L'élément se comporte comme un conteneur de grille en ligne. |

## Remarques

La propriété 'display' dans SVG et CSS détermine comment un élément est affiché dans la mise en page du document. Cette énumération fournit diverses options pour définir le type d'affichage, influençant la façon dont les éléments sont rendus et interagissent avec la mise en page.

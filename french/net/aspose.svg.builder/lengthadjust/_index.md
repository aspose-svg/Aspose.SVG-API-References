## LengthAdjust enumeration

Spécifie comment les ajustements de longueur du texte sont effectués dans SVG.

```csharp
public enum LengthAdjust
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Spacing | `0` | Ajuste l'espacement entre les caractères pour obtenir la longueur souhaitée. |
| SpacingAndGlyphs | `1` | Ajuste à la fois l'espacement et la taille des glyphes pour obtenir la longueur souhaitée. |

## Remarques

L'attribut 'lengthAdjust' dans les éléments texte SVG contrôle la façon dont le redimensionnement du texte est appliqué lorsque le texte doit s'adapter à une longueur spécifiée.

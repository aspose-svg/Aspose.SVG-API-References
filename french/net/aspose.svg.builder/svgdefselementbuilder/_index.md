## SVGDefsElementBuilder class

Classe Builder pour construire un élément SVG 'defs', qui est utilisé pour définir des éléments réutilisables. Elle permet la construction de contenu à l'intérieur de l'élément 'defs' et fournit des méthodes pour définir divers attributs spécifiques à l'élément 'defs' en SVG.

```csharp
public class SVGDefsElementBuilder : SVGElementBuilder<SVGDefsElement>, ICompositeElementBuilder, 
    ICoreAttributeSetter, IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, 
    IGraphicalEventAttributeSetter, IPresentationAttributeSetter
```

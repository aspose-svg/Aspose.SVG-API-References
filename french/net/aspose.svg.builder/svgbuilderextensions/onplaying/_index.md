## SVGBuilderExtensions.OnPlaying<TBuilder> method

Définit l'attribut d'événement 'onplaying' pour gérer les événements lorsque le média est en cours de lecture active après une pause ou un arrêt pour mise en mémoire tampon.

```csharp
public static TBuilder OnPlaying<TBuilder>(this TBuilder builder, string value)
    where TBuilder : ISVGElementBuilder, IGlobalEventAttributeSetter
```

| Paramètre | Description |
| --- | --- |
| TBuilder | Le type du constructeur d'éléments SVG. |
| constructeur | Le constructeur d'éléments SVG. |
| value | La fonction ou le script JavaScript à exécuter lorsque le média est en cours de lecture. |

L'instance du constructeur pour l'enchaînement.

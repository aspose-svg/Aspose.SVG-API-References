## SVGBuilderExtensions.FormatSvgLengths method

Formate un tableau de valeurs double en une représentation sous forme de chaîne des longueurs SVG.

```csharp
public static string FormatSvgLengths(double[] values, LengthType type)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| valeurs | Double[] | Le tableau de valeurs double représentant les longueurs. |
| type | LengthType | Le type d'unité de longueur à utiliser (par ex., pixels). |

### Valeur de retour

Une chaîne formatée de longueurs SVG.

## Remarques

Cette méthode utilitaire est utilisée pour formater les valeurs de longueur pour les attributs SVG, en ajoutant l'unité appropriée (comme 'px') à chaque valeur.

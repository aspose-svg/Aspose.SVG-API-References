## UnicodeBidi enumeration

Spécifie la gestion du texte bidirectionnel dans SVG.

```csharp
public enum UnicodeBidi
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Normal | `0` | Gestion normale du texte bidirectionnel. |
| Embed | `1` | Intègre une section de texte avec une directionnalité différente ou explicite. |
| Isolate | `2` | Isole une section de texte de son environnement pour la gestion du texte bidirectionnel. |
| BidiOverride | `3` | Remplace la directionnalité inhérente des caractères dans une section de texte. |
| IsolateOverride | `4` | Isole une section de texte et remplace sa directionnalité. |
| Plaintext | `5` | Traite la section de texte comme du texte brut sans gestion bidirectionnelle spéciale. |

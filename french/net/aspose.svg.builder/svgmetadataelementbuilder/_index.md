## SVGMetadataElementBuilder class

Classe Builder pour construire un élément SVG 'metadata', qui est utilisé pour ajouter des métadonnées à un document SVG. Cette classe permet l'ajout de contenu de métadonnées et fournit des méthodes pour définir divers attributs spécifiques à l'élément 'metadata' dans SVG.

```csharp
public class SVGMetadataElementBuilder : SVGElementBuilder<SVGMetadataElement>, 
    ICoreAttributeSetter, IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, 
    ITextContentSetter
```

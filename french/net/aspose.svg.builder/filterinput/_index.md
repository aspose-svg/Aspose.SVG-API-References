## FilterInput enumeration

Spécifie les images d’entrée prédéfinies pour un filtre SVG.

```csharp
public enum FilterInput
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| SourceGraphic | `0` | Fait référence à l'élément graphique auquel le filtre est appliqué. |
| SourceAlpha | `1` | Fait référence au canal alpha de l'élément graphique auquel le filtre est appliqué. |
| BackgroundImage | `2` | Fait référence à l'image d'arrière-plan qui se trouve directement sous l'élément graphique auquel le filtre est appliqué. |
| BackgroundAlpha | `3` | Fait référence au canal alpha de l'image d'arrière-plan qui se trouve directement sous l'élément graphique auquel le filtre est appliqué. |
| FillPaint | `4` | Fait référence à la peinture de remplissage de l'élément graphique auquel le filtre est appliqué. |
| StrokePaint | `5` | Fait référence à la peinture de contour de l'élément graphique auquel le filtre est appliqué. |

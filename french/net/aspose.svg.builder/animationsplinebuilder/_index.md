## AnimationSplineBuilder class

Une classe de construction pour créer des fonctions de synchronisation d'animation utilisant des courbes de Bézier cubiques. Cette classe permet de définir une ou plusieurs courbes de Bézier cubiques, chacune spécifiée par deux points de contrôle. La chaîne résultante peut être utilisée dans les animations ou transitions CSS pour contrôler le rythme de l'animation.

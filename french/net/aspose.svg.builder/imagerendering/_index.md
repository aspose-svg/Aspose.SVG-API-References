## ImageRendering enumeration

Spécifie comment une image doit être rendue en SVG.

```csharp
public enum ImageRendering
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Auto | `0` | Le navigateur fait un compromis entre la vitesse et la qualité lors du rendu de l'image. |
| OptimizeSpeed | `1` | Le navigateur privilégie la vitesse de rendu au détriment de la qualité de l'image. Cela signifie souvent que les images sont agrandies d'une manière qui peut les rendre pixelisées ou en blocs. |
| OptimizeQuality | `2` | Le navigateur privilégie la qualité de l'image plutôt que la vitesse de rendu. Cela peut entraîner un redimensionnement plus fluide et de meilleure qualité des images, mais peut ralentir le rendu. |

## FontWeight enumeration

Spécifie les différentes graisses de police pour les éléments de texte SVG.

```csharp
public enum FontWeight
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Normal | `0` | Représente la graisse de police normale, qui est la graisse par défaut. |
| Bold | `1` | Représente une graisse de police en gras, généralement utilisée pour l'emphase. |
| Bolder | `2` | Représente une graisse de police plus épaisse que celle de l'élément parent. |
| Lighter | `3` | Représente une graisse de police plus légère que celle de l'élément parent. |
| W100 | `4` | Représente la graisse de police 100, la plus fine disponible. |
| W200 | `5` | Représente la graisse de police 200. |
| W300 | `6` | Représente la graisse de police 300. |
| W400 | `7` | Représente la graisse de police 400, équivalente à « normal ». |
| W500 | `8` | Représente la graisse de police 500. |
| W600 | `9` | Représente la graisse de police 600. |
| W700 | `10` | Représente la graisse de police 700, équivalente à « gras ». |
| W800 | `11` | Représente la graisse de police 800. |
| W900 | `12` | Représente la graisse de police 900, la plus grasse disponible. |

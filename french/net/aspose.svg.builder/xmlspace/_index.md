## XmlSpace enumeration

Spécifie comment les espaces blancs à l'intérieur des éléments sont gérés dans les documents XML.

```csharp
public enum XmlSpace
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Default | `0` | Indique que les espaces blancs doivent être gérés selon le comportement par défaut du processeur XML, généralement en normalisant les espaces blancs en supprimant les sauts de ligne et les espaces supplémentaires. |
| Preserve | `1` | Indique que les espaces blancs doivent être conservés tels qu'ils apparaissent dans le document XML. Cela est utile pour maintenir le formatage du texte lorsque les espaces blancs sont significatifs. |

## Remarques

L'attribut 'xml:space' dans XML est utilisé pour contrôler si les espaces blancs à l'intérieur des éléments doivent être conservés ou normalisés. Cette énumération fournit des options pour définir ce comportement dans les documents XML et SVG.

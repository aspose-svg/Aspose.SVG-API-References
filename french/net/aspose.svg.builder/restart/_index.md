## Restart enumeration

Spécifie le comportement de redémarrage pour les animations SVG.

```csharp
public enum Restart
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Always | `0` | L'animation peut être redémarrée à tout moment, même si elle est actuellement active. |
| WhenNotActive | `1` | L'animation ne peut être redémarrée que lorsqu'elle n'est pas actuellement active. |
| Never | `2` | L'animation ne peut pas être redémarrée une fois commencée ; elle s'exécutera jusqu'à son terme. |

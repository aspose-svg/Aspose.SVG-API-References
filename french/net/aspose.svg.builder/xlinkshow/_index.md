## XLinkShow enumeration

Spécifie le comportement lorsqu'un lien SVG est déclenché.

```csharp
public enum XLinkShow
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| New | `0` | Ouvre le lien dans une nouvelle fenêtre ou un nouvel onglet. |
| Replace | `1` | Remplace le document SVG actuel par le document lié. |
| Embed | `2` | Intègre le document lié dans le document SVG actuel. |
| Other | `3` | Spécifie un comportement différent des comportements prédéfinis. |
| None | `4` | Indique qu'aucun comportement spécifique n'est demandé. |

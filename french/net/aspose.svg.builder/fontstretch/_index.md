## FontStretch enumeration

Spécifie les différents niveaux d’étirement de police pour les éléments de texte SVG.

```csharp
public enum FontStretch
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Normal | `0` | Représente l'étirement de police normal (par défaut). |
| UltraCondensed | `1` | Représente l'étirement de police le plus condensé. |
| ExtraCondensed | `2` | Représente un étirement de police plus condensé que 'condensed' mais moins que 'ultra-condensed'. |
| Condensed | `3` | Représente un étirement de police condensé. |
| SemiCondensed | `4` | Représente un étirement de police légèrement condensé. |
| SemiExpanded | `5` | Représente un étirement de police légèrement élargi. |
| Expanded | `6` | Représente un étirement de police élargi. |
| ExtraExpanded | `7` | Représente un étirement de police plus étendu que « expanded » mais moins que « ultra-expanded ». |
| UltraExpanded | `8` | Représente l'étirement de police le plus étendu. |

## AngleUnits enumeration

Spécifie les unités des angles utilisées pour définir l'orientation des marqueurs dans SVG.

```csharp
public enum AngleUnits
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Degrees | `0` | Spécifie l'angle en degrés. Un cercle complet fait 360 degrés. |
| Gradians | `1` | Spécifie l'angle en grades. Un cercle complet fait 400 grades. |
| Radians | `2` | Spécifie l'angle en radians. Un cercle complet vaut environ 6,283 radians (2π radians). |
| None | `3` | Indique aucune unité d'angle spécifique. Utilisé pour les paramètres par défaut ou contextuels. |

## Remarques

L'attribut 'orient' des marqueurs SVG peut être spécifié dans différentes unités d'angle. Cet enum fournit des options pour définir ces unités.

## SVGStyleElementBuilder.Media method

Définit l'attribut 'media' de l'élément SVG 'style'. Cet attribut spécifie le média pour lequel les styles sont destinés, permettant aux styles d'être conditionnels en fonction du type de média.

```csharp
public SVGStyleElementBuilder Media(string mediaDescriptors)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| mediaDescriptors | String | La chaîne de descripteur média (par ex., "screen", "print"). |

### Valeur de retour

L'instance de SVGStyleElementBuilder pour le chaînage.

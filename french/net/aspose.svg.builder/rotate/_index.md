## Rotate enumeration

Spécifie le comportement de rotation des éléments pendant l'animation de mouvement dans SVG.

```csharp
public enum Rotate
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Auto | `0` | Fait pivoter automatiquement l'élément dans le sens du chemin. |
| AutoReverse | `1` | Fait pivoter automatiquement l'élément dans le sens du chemin et permet de le renverser. |

## Remarques

L'attribut « rotate » de l'élément « animateMotion » de SVG contrôle la rotation d'un élément le long d'un chemin de mouvement. Cette énumération fournit des options sur la façon dont l'élément doit pivoter en suivant le chemin.

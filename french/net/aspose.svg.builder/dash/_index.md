## Dash enumeration

Définit le motif de tirets et d’espaces utilisé pour peindre le contour des formes (trait) dans les éléments SVG.

```csharp
public enum Dash
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | `0` | Indique un trait plein sans tirets. C'est le comportement par défaut lorsque 'stroke-dasharray' n'est pas spécifié. |

## Remarques

L'attribut 'stroke-dasharray' dans SVG est utilisé pour créer des lignes en pointillés en spécifiant le motif des tirets et des espaces. Cette énumération fournit des options pour définir ce motif.

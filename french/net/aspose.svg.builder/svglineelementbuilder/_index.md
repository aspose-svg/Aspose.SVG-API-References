## SVGLineElementBuilder class

Classe Builder pour construire un élément SVG 'line', qui est utilisé pour tracer des lignes droites dans les graphiques SVG. Cette classe permet la création de contenu au sein de l'élément 'line' et fournit des méthodes pour définir divers attributs spécifiques à l'élément 'line' dans SVG.

```csharp
public class SVGLineElementBuilder : SVGElementBuilder<SVGLineElement>, IAnimationElementBuilder, 
    IDescriptiveElementBuilder, IPaintServerElementBuilder, IShapeAttributeSetter, 
    IShapeContentElementBuilder
```

## SVGScriptElementBuilder class

Classe de constructeur pour créer un élément SVG 'script'. L'élément 'script' est utilisé pour intégrer ou référencer des scripts exécutables dans les documents SVG. Cette classe fournit des méthodes pour définir divers attributs spécifiques à l'élément 'script', tels que le type, la source et les paramètres cross-origin.

```csharp
public class SVGScriptElementBuilder : SVGElementBuilder<SVGScriptElement>, ICoreAttributeSetter, 
    IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter
```

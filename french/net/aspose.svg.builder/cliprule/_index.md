## ClipRule enumeration

Définit la règle permettant de déterminer comment découper les chemins dans les graphiques SVG.

```csharp
public enum ClipRule
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Nonzero | `0` | La règle de remplissage non nulle pour le découpage des chemins. |
| Evenodd | `1` | La règle de remplissage pair-impaire pour le découpage des chemins. |

## Remarques

La propriété clip-rule dans SVG détermine comment les chemins sont découpés. Elle est particulièrement importante lorsqu'un chemin s'intersecte avec lui-même ou lorsque plusieurs chemins sont combinés. La règle aide à décider quelles parties du chemin sont "à l'intérieur" et doivent être remplies (ou visibles) et lesquelles sont "à l'extérieur" et doivent être découpées (ou invisibles).

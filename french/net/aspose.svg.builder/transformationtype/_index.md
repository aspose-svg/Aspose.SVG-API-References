## TransformationType enumeration

Spécifie le type de transformation appliqué à un élément SVG.

```csharp
public enum TransformationType
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Translate | `0` | Déplace (translate) un élément d'une certaine distance. |
| Scale | `1` | Redimensionne un élément en augmentant ou en réduisant sa taille. |
| Rotate | `2` | Fait pivoter un élément autour d'un point donné. |
| SkewX | `3` | Incline un élément le long de l'axe X. |
| SkewY | `4` | Incline un élément le long de l'axe Y. |

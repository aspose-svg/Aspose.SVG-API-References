## CompositeOperator enumeration

Spécifie le type d’opération de composition à appliquer dans les opérations de composition SVG.

```csharp
public enum CompositeOperator
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Over | `0` | Place le graphique source au-dessus du graphique de destination. |
| In | `1` | Affiche le graphique source là où il se superpose au graphique de destination. |
| Out | `2` | Affiche le graphique source là où il ne se superpose pas à la destination. |
| Atop | `3` | Affiche le graphique source au-dessus du graphique de destination. |
| Xor | `4` | Affiche le graphique source là où il ne se superpose pas à la destination et inversement. |
| Arithmetic | `5` | Permet une opération de composition arithmétique personnalisée. |

## Remarques

Les opérations de composition dans SVG déterminent comment deux éléments graphiques sont combinés en une seule image. Chaque opérateur définit une méthode distincte de fusion ou de combinaison de ces éléments.

## SVGEllipseElementBuilder class

Classe Builder pour construire un élément SVG 'ellipse', qui est utilisé pour dessiner des ellipses dans les graphiques SVG. Elle permet la construction de contenu à l'intérieur de l'élément 'ellipse' et fournit des méthodes pour définir divers attributs spécifiques à l'élément 'ellipse' en SVG.

```csharp
public class SVGEllipseElementBuilder : SVGElementBuilder<SVGEllipseElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IShapeAttributeSetter, IShapeContentElementBuilder
```

## SVGDescElementBuilder class

Classe Builder pour construire un élément SVG 'desc', qui est utilisé pour fournir une description des éléments conteneurs SVG. Elle permet la construction de contenu à l'intérieur de l'élément 'desc' et fournit des méthodes pour définir divers attributs spécifiques à l'élément 'desc' en SVG.

```csharp
public class SVGDescElementBuilder : SVGElementBuilder<SVGDescElement>, ICoreAttributeSetter, 
    IDescriptiveElementBuilder, IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, 
    ITextContentSetter
```

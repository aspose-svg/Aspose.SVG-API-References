## EdgeMode enumeration

Spécifie le mode de bord pour le primitive de filtre feConvolveMatrix en SVG.

```csharp
public enum EdgeMode
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Duplicate | `0` | L'image d'entrée est étendue le long de chacun de ses bords si nécessaire en dupliquant les valeurs de couleur au bord donné de l'image d'entrée. |
| Wrap | `1` | L'image d'entrée est conceptuellement enroulée (ou découpée) et la convolution utilise ces valeurs enroulées. Cela crée une topologie toroïdale pour l'image. |
| None | `2` | Le mode de bord n'est pas défini, et l'effet du filtre est défini par l'implémentation. |

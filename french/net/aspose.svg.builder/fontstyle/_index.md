## FontStyle enumeration

Spécifie les différents styles de police pour les éléments de texte SVG.

```csharp
public enum FontStyle
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Normal | `0` | Représente le style de police normal, sans emphase ni inclinaison. |
| Italic | `1` | Représente un style de police avec une apparence italique, généralement utilisé pour l'emphase. |
| Oblique | `2` | Représente un style de police avec une apparence oblique, similaire à l'italique mais avec une inclinaison moins prononcée. |

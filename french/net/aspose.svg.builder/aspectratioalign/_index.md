## AspectRatioAlign enumeration

Spécifie les types d'alignement pour l'attribut 'preserveAspectRatio' dans SVG.

```csharp
public enum AspectRatioAlign
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | `0` | Indique qu'aucune mise à l'échelle uniforme n'est appliquée ; le rapport d'aspect n'est pas conservé. |
| XMinYMin | `1` | Aligne le X minimum et le Y minimum du viewBox avec les plus petites valeurs X et Y du viewport. |
| XMidYMin | `2` | Aligne le X du point milieu et le Y minimum du viewBox avec le X du point milieu et la plus petite valeur Y du viewport. |
| XMaxYMin | `3` | Aligne le X maximum et le Y minimum du viewBox avec le plus grand X et la plus petite valeur Y du viewport. |
| XMinYMid | `4` | Aligne le X minimum et le Y du point milieu du viewBox avec le plus petit X et la valeur Y du point milieu du viewport. |
| XMidYMid | `5` | Aligne le X et le Y du point milieu du viewBox avec le X et le Y du point milieu du viewport. |
| XMaxYMid | `6` | Aligne le X maximum et le Y du point milieu du viewBox avec le plus grand X et la valeur Y du point milieu du viewport. |
| XMinYMax | `7` | Aligne le X minimum et le Y maximum du viewBox avec le plus petit X et la plus grande valeur Y du viewport. |
| XMidYMax | `8` | Aligne le X du point milieu et le Y maximum du viewBox avec le X du point milieu et la plus grande valeur Y du viewport. |
| XMaxYMax | `9` | Aligne le X maximum et le Y maximum du viewBox avec les plus grandes valeurs X et Y du viewport. |

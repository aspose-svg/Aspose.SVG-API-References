## CompositingOperator enumeration

Spécifie le type d’opération de composition à appliquer dans les opérations de masquage SVG.

```csharp
public enum CompositingOperator
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Add | `0` | Ajoute les valeurs de couleur du graphique source au graphique de destination. |
| Subtract | `1` | Soustrait les valeurs de couleur du graphique source du graphique de destination. |
| Intersect | `2` | Affiche uniquement les zones où les graphiques source et destination se chevauchent. |
| Exclude | `3` | Exclut les zones de chevauchement des graphiques source et destination. |

## Remarques

Les opérateurs de composition dans les masques SVG déterminent comment différents éléments graphiques sont combinés pour créer un effet de masque. Chaque opérateur définit une méthode unique de fusion ou de combinaison de ces éléments afin d'obtenir divers effets de masquage.

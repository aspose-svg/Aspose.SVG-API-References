## DominantBaseline enumeration

Spécifie la ligne de base dominante utilisée pour aligner le texte.

```csharp
public enum DominantBaseline
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Auto | `0` | Détermine automatiquement la ligne de base dominante en fonction de la police et/ou de la langue. |
| TextBottom | `1` | Aligne le texte au bas du carré em. |
| Alphabetic | `2` | Aligne le texte sur la ligne de base utilisée par les caractères alphabétiques. |
| Ideographic | `3` | Aligne le texte sur la ligne de base utilisée par les caractères idéographiques. |
| Middle | `4` | Aligne le texte au milieu du carré em. |
| Central | `5` | Aligne le texte sur la ligne de base centrale du carré em. |
| Mathematical | `6` | Aligne le texte sur la ligne de base utilisée par les caractères mathématiques. |
| Hanging | `7` | Aligne le texte sur la ligne de base suspendue, généralement utilisée pour le tibétain ou d'autres scripts asiatiques. |
| TextTop | `8` | Aligne le texte en haut du carré em. |

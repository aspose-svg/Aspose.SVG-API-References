## AnimationFill enumeration

Spécifie le comportement de l'animation avant et après son exécution.

```csharp
public enum AnimationFill
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Freeze | `0` | L'animation appliquera les valeurs des propriétés pendant le temps où l'animation s'est terminée. |
| Remove | `1` | L'animation n'appliquera aucune valeur après qu'elle ait terminé son exécution. |

## Remarques

L'attribut 'fill' dans les animations SVG contrôle quelles valeurs sont appliquées par l'animation en dehors de la période d'exécution. Cette énumération fournit des options pour contrôler ces comportements.

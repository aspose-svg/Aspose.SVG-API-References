## StrokeLineJoin enumeration

Spécifie la forme à utiliser aux coins des chemins ou des formes de base lorsqu'ils sont tracés.

```csharp
public enum StrokeLineJoin
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Miter | `0` | Un coin aigu est utilisé pour joindre les segments de chemin. |
| MiterClip | `1` | Similaire à « miter », mais si la jointure dépasse une limite, elle est découpée. |
| Round | `2` | Un coin arrondi est utilisé pour joindre les segments de chemin. |
| Bevel | `3` | Un coin biseauté est utilisé pour joindre les segments de chemin. |
| Arcs | `4` | Le coin est joint par des arcs. |

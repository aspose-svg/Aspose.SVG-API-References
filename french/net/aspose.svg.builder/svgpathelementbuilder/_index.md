## SVGPathElementBuilder class

Classe Builder pour construire un élément SVG 'path', qui est utilisé pour définir un chemin dans un document SVG. Cette classe fournit des méthodes pour définir divers attributs spécifiques à l'élément 'path' et pour créer son contenu.

```csharp
public class SVGPathElementBuilder : SVGElementBuilder<SVGPathElement>, IAnimationElementBuilder, 
    IDescriptiveElementBuilder, IPaintServerElementBuilder, IShapeAttributeSetter, 
    IShapeContentElementBuilder
```

## Paint enumeration

Spécifie les options de peinture pour les attributs de remplissage et de contour dans les éléments SVG.

```csharp
public enum Paint
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | `0` | Indique qu'aucune peinture ne doit être appliquée. |
| ContextFill | `1` | Utilise la couleur de remplissage du contexte actuel pour la peinture. |
| ContextStroke | `2` | Utilise la couleur de contour du contexte actuel pour la peinture. |

## Remarques

Cette énumération définit les types de peinture pouvant être appliqués aux propriétés de remplissage et de contour des éléments SVG. Elle permet des couleurs standard, des remplissages et des contours basés sur le contexte, ou aucune peinture du tout.

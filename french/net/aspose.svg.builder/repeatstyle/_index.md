## RepeatStyle enumeration

Spécifie le style de répétition pour les images d'arrière-plan ou les motifs dans SVG.

```csharp
public enum RepeatStyle
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| RepeatX | `0` | L'image ou le motif est répété uniquement horizontalement. |
| RepeatY | `1` | L'image ou le motif est répété uniquement verticalement. |
| Repeat | `2` | L'image ou le motif est répété à la fois horizontalement et verticalement. |
| Space | `3` | L'image ou le motif est répété autant que possible sans rognage, et l'espace restant est réparti uniformément entre les images. |
| Round | `4` | L'image ou le motif est mis à l'échelle pour qu'il s'adapte et soit répété sans rognage, en conservant son ratio d'aspect. |
| NoRepeat | `5` | L'image ou le motif n'est pas répété, et une seule copie de l'image sera dessinée. |

## SVGGElementBuilder class

Classe Builder pour construire un élément SVG 'g' (groupe). L'élément 'g' est utilisé pour regrouper des formes SVG. Le regroupement d'éléments permet une manipulation et un style plus faciles de plusieurs éléments en tant qu'unité unique dans les graphiques SVG.

public class SVGGElementBuilder : SVGElementBuilder<SVGGElement>, ICompositeAttributeSetter,

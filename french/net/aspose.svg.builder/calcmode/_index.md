## CalcMode enumeration

Spécifie les modes de calcul pour interpoler les valeurs dans les animations SVG.

```csharp
public enum CalcMode
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Discrete | `0` | L'animation saute d'une valeur à la suivante sans aucune interpolation. |
| Linear | `1` | Les valeurs de l'animation sont interpolées linéairement sur toute la durée de l'animation. |
| Paced | `2` | L'animation est cadencée de manière à ce que la progression soit uniforme sur l'ensemble de l'animation. |
| Spline | `3` | L'animation utilise des splines cubiques de Bézier pour interpoler les valeurs. |

## Remarques

Le mode de calcul détermine comment une animation SVG passe d'une valeur à l'autre au cours de l'animation. Différents modes peuvent être utilisés pour créer divers effets et contrôler le rythme et la fluidité de l'animation.

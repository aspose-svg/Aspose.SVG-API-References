## CoordinateUnits enumeration

Spécifie les unités du système de coordonnées pour divers éléments SVG tels que les masques, les serveurs de peinture et les filtres.

```csharp
public enum CoordinateUnits
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| UserSpaceOnUse | `0` | Utilise le système de coordonnées utilisateur pour l'élément SVG. |
| ObjectBoundingBox | `1` | Utilise la boîte englobante de l'objet pour l'élément SVG. |

## Remarques

Les unités de coordonnées déterminent comment les valeurs sont interprétées dans différents contextes SVG. Elles peuvent être définies pour utiliser les coordonnées de l'espace utilisateur ou être relatives à la boîte englobante de l'objet.

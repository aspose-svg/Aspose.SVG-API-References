## ColorMatrixOperation enumeration

Spécifie le type d’opération à appliquer dans un filtre à matrice de couleur.

```csharp
public enum ColorMatrixOperation
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Matrix | `0` | Applique une transformation matricielle aux données de couleur. |
| Saturate | `1` | Ajuste le niveau de saturation de l'image. |
| HueRotate | `2` | Applique une rotation de teinte sur l'image. |
| LuminanceToAlpha | `3` | Convertit les couleurs de l'image en niveaux de gris en fonction de leur luminance. |

## Remarques

Le filtre de matrice de couleur dans SVG permet diverses opérations sur les données de couleur d'une image. Chaque type d'opération manipule les couleurs d'une manière spécifique, offrant une gamme d'effets visuels.

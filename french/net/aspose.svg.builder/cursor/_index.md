## Cursor enumeration

Définit les types de curseur pour les éléments SVG, permettant la personnalisation de l’apparence du curseur lors du survol de ces éléments.

```csharp
public enum Cursor
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Auto | `0` | Le navigateur détermine le curseur à afficher en fonction du contexte actuel. |
| Default | `1` | Curseur par défaut, généralement une flèche. |
| None | `2` | Aucun curseur n'est affiché. |
| ContextMenu | `3` | Curseur indiquant qu'un menu contextuel est disponible. |
| Help | `4` | Curseur indiquant qu'une aide est disponible. |
| Pointer | `5` | Curseur indiquant un élément cliquable, généralement un pointeur en forme de main. |
| Progress | `6` | Curseur indiquant une opération ou une tâche en cours. |
| Wait | `7` | Curseur indiquant que le système est occupé et que l'utilisateur doit attendre. |
| Cell | `8` | Curseur indiquant une cellule ou un élément de tableau. |
| Crosshair | `9` | Curseur indiquant une sélection précise, généralement un réticule. |
| Text | `10` | Curseur indiquant la sélection de texte. |
| VerticalText | `11` | Curseur indiquant la sélection de texte verticale. |
| Alias | `12` | Curseur indiquant qu'un alias ou un raccourci est en cours de création. |
| Copy | `13` | Curseur indiquant une opération de copie. |
| Move | `14` | Curseur indiquant un élément ou une zone déplaçable. |
| NoDrop | `15` | Curseur indiquant que le dépôt n'est pas autorisé. |
| NotAllowed | `16` | Curseur indiquant qu'une action n'est pas autorisée. |
| Grab | `17` | Curseur indiquant qu'un élément peut être saisi. |
| Grabbing | `18` | Curseur indiquant qu'un élément est actuellement saisi. |
| EResize | `19` | Curseur indiquant un redimensionnement vers l'est. |
| NResize | `20` | Curseur indiquant un redimensionnement vers le nord. |
| NEResize | `21` | Curseur indiquant un redimensionnement vers le nord-est. |
| NWResize | `22` | Curseur indiquant un redimensionnement vers le nord-ouest. |
| SResize | `23` | Curseur indiquant un redimensionnement vers le sud. |

| WResize | `26` | Curseur indiquant un redimensionnement vers l'ouest. |
| EWResize | `27` | Curseur indiquant un redimensionnement est-ouest. |

| ColResize | `31` | Curseur indiquant un redimensionnement de colonne. |
| RowResize | `32` | Curseur indiquant un redimensionnement de ligne. |
| AllScroll | `33` | Curseur indiquant le défilement dans toutes les directions. |
| ZoomIn | `34` | Curseur indiquant la capacité de zoom avant. |
| ZoomOut | `35` | Curseur indiquant la capacité de zoom arrière. |

## Remarques

Cette énumération fournit une gamme de styles de curseur pouvant être appliqués aux éléments SVG. Ces styles aident à indiquer le type d'interaction disponible ou l'état de l'élément sous le curseur.

## SVGAElementBuilder class

Classe de construction pour créer un élément SVG 'a', qui sert à définir des hyperliens. Elle permet de construire le contenu à l'intérieur de l'élément 'a' et fournit des méthodes pour définir divers attributs spécifiques à l'élément 'a' dans SVG.

```csharp
public class SVGAElementBuilder : SVGElementBuilder<SVGAElement>, ICompositeAttributeSetter, 
    ICompositeElementBuilder
```

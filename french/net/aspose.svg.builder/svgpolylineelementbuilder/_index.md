## SVGPolylineElementBuilder class

Classe de constructeur pour créer un élément SVG 'polyline'. L'élément 'polyline' est utilisé pour créer une série de lignes droites reliant plusieurs points dans les graphiques SVG. Cette classe fournit des méthodes pour définir divers attributs et animer l'élément polyline.

```csharp
public class SVGPolylineElementBuilder : SVGElementBuilder<SVGPolylineElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IPointsAttributeSetter, IShapeAttributeSetter, IShapeContentElementBuilder
```

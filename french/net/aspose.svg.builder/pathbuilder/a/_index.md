## PathBuilder.A method

Ajoute une commande 'Elliptical Arc Curve' aux données du chemin.

```csharp
public PathBuilder A(double r1, double r2, double angle, bool largeArcFlag, bool sweepFlag, 
    double x, double y)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| r1 | Double | Le rayon x de l'ellipse. |
| r2 | Double | Le rayon y de l'ellipse. |
| angle | Double | L'angle de rotation de l'ellipse en degrés. |
| largeArcFlag | Boolean | Indicateur indiquant si l'arc doit être supérieur ou égal à 180 degrés. |
| sweepFlag | Boolean | Indicateur indiquant si l'arc doit être tracé dans le sens d'un angle positif. |
| x | Double | La coordonnée x du point final de l'arc. |
| y | Double | La coordonnée y du point final de l'arc. |

### Valeur de retour

L'instance actuelle de PathBuilder.

## PathBuilder.Ar method

Ajoute une commande relative 'Elliptical Arc Curve' aux données du chemin.

```csharp
public PathBuilder Ar(double r1, double r2, double angle, bool largeArcFlag, bool sweepFlag, 
    double x, double y)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| r1 | Double | Le rayon x de l'ellipse, relatif à la position actuelle. |
| r2 | Double | Le rayon y de l'ellipse, relatif à la position actuelle. |
| angle | Double | L'angle de rotation de l'ellipse en degrés, relatif à la position actuelle. |
| largeArcFlag | Boolean | Indicateur indiquant si l'arc doit être supérieur ou égal à 180 degrés. |
| sweepFlag | Boolean | Indicateur indiquant si l'arc doit être tracé dans le sens d'un angle positif. |
| x | Double | La coordonnée x du point final de l'arc, relative à la position actuelle. |
| y | Double | La coordonnée y du point final de l'arc, relative à la position actuelle. |

### Valeur de retour

L'instance actuelle de PathBuilder.

## IAttributeSetter.Attribute method

Définit ou met à jour un attribut sur un élément SVG.

```csharp
public void Attribute(string name, string value)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| nom | String | Le nom de l'attribut à définir. Cela doit être un nom d'attribut SVG valide. |
| value | String | La valeur à attribuer à l'attribut. La valeur doit être une représentation sous forme de chaîne adaptée à l'attribut SVG spécifique. |

## Remarques

Cette méthode est utilisée pour ajouter ou modifier dynamiquement les attributs des éléments SVG pendant le processus de construction. Elle offre une flexibilité dans la définition et la personnalisation des éléments SVG en permettant de définir les attributs en fonction de diverses conditions ou entrées.

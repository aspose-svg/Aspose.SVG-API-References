## Orient enumeration

Spécifie l'orientation du marqueur par rapport à la forme à laquelle il est attaché.

```csharp
public enum Orient
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Auto | `0` | Le marqueur est orienté de manière à pointer dans le sens du chemin. |
| AutoStartReverse | `1` | Le marqueur est orienté dans le sens inverse du départ du chemin. |

## Remarques

L'attribut 'orient' dans les marqueurs SVG détermine comment le marqueur est orienté lorsqu'il est placé à sa position sur la forme. Cette énumération fournit des options pour définir le comportement d'orientation des marqueurs.

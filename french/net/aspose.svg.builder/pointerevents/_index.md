## PointerEvents enumeration

Spécifie comment les événements de pointeur sont gérés par les éléments graphiques dans SVG.

```csharp
public enum PointerEvents
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| BoundingBox | `0` | Les événements de pointeur ciblent la boîte englobante de l'élément. |
| VisiblePainted | `1` | Les événements de pointeur ciblent uniquement les parties visibles (peintes) de l'élément. |
| VisibleFill | `2` | Les événements de pointeur ciblent uniquement les parties visibles (remplies) de l'élément. |
| VisibleStroke | `3` | Les événements de pointeur ciblent uniquement les parties visibles (contourées) de l'élément. |
| Visible | `4` | Les événements de pointeur ciblent toutes les parties visibles de l'élément. |
| Painted | `5` | Les événements de pointeur ciblent toutes les parties peintes de l'élément, y compris le remplissage et le contour. |
| Fill | `6` | Les événements de pointeur ciblent uniquement les parties remplies de l'élément. |
| Stroke | `7` | Les événements de pointeur ciblent uniquement les parties contournées de l'élément. |
| All | `8` | Les événements de pointeur ciblent toutes les parties de l'élément, quelle que soit leur visibilité. |
| None | `9` | L'élément ne devient pas la cible des événements de pointeur. |

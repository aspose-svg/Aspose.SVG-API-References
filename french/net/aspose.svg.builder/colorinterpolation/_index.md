## ColorInterpolation enumeration

Spécifie le mode d’interpolation des couleurs pour les éléments et filtres SVG.

```csharp
public enum ColorInterpolation
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Auto | `0` | Détermine automatiquement le mode d'interpolation des couleurs. |
| SRGB | `1` | Utilise l'espace colorimétrique RGB standard (sRGB) pour l'interpolation des couleurs. |
| LinearRGB | `2` | Utilise un espace colorimétrique RGB linéaire pour l'interpolation des couleurs. |

## Remarques

L'interpolation des couleurs dans SVG affecte la façon dont les couleurs sont calculées et mélangées à la fois dans les éléments graphiques et les effets de filtre. Différents modes peuvent influencer de manière significative l'apparence des transitions de couleur, des dégradés et du rendu global des couleurs. Ce paramètre est crucial pour obtenir le résultat visuel souhaité dans les graphiques SVG.

## ChannelSelector enumeration

Spécifie les sélecteurs de canaux à utiliser dans les opérations de filtre SVG.

```csharp
public enum ChannelSelector
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| R | `0` | Sélectionne le canal rouge de l'image. |
| G | `1` | Sélectionne le canal vert de l'image. |
| B | `2` | Sélectionne le canal bleu de l'image. |
| A | `3` | Sélectionne le canal Alpha (transparence) de l'image. |

## Remarques

Les sélecteurs de canal sont utilisés dans diverses primitives de filtre SVG pour cibler des canaux de couleur spécifiques (Rouge, Vert, Bleu) ou le canal alpha d'une image. Cela permet une manipulation précise de ces canaux lors du traitement du filtre.

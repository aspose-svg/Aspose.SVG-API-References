## BaseLineShift enumeration

Spécifie la position verticale d'un élément par rapport à sa ligne de base dans SVG.

```csharp
public enum BaseLineShift
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Sub | `0` | Aligne la ligne de base de l'élément avec la ligne de base en indice du texte du parent. |
| Super | `1` | Aligne la ligne de base de l'élément avec la ligne de base en exposant du texte du parent. |
| Top | `2` | Aligne le haut de l'élément avec le haut de la boîte de ligne. |
| Center | `3` | Centre l'élément dans la boîte de ligne. |
| Bottom | `4` | Aligne le bas de l'élément avec le bas de la boîte de ligne. |

## Remarques

L'attribut 'baseline-shift' dans SVG est utilisé pour ajuster la position verticale d'un élément par rapport à sa ligne de base, ce qui est particulièrement utile dans le rendu du texte. Cet enum propose diverses options pour déplacer la ligne de base afin d'obtenir différents effets de texte.

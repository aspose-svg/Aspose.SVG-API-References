## Kerning enumeration

Spécifie le comportement du crénage pour le texte dans SVG.

```csharp
public enum Kerning
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Auto | `0` | Permet au navigateur de déterminer si le crénage doit être appliqué. |
| Normal | `1` | Applique le crénage standard, tel que défini dans le fichier de police. |
| None | `2` | Désactive le crénage, en ignorant toute information de crénage dans la police. |

## Remarques

La propriété 'font-kerning' dans SVG contrôle l'utilisation des informations de crénage stockées dans une police. Le crénage ajuste l'espace entre les paires de lettres individuelles pour améliorer l'apparence visuelle du texte. Cet enum offre des options pour contrôler le comportement du crénage dans les éléments texte SVG.

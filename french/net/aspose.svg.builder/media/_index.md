## Media enumeration

Spécifie les conditions de synchronisation liées aux médias pour les animations SVG.

```csharp
public enum Media
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Media | `0` | Indique que le timing de l'animation dépend du timing du média. |

## Remarques

Cette énumération est utilisée pour définir les conditions de synchronisation liées aux médias dans les animations SVG. Elle est particulièrement pertinente pour les animations qui dépendent ou sont synchronisées avec des médias externes, tels que l'audio ou la vidéo.

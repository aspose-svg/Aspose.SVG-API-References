## MarkerPos enumeration

Spécifie la position des marqueurs dans SVG.

```csharp
public enum MarkerPos
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | `0` | Indique qu'aucun marqueur ne sera rendu sur l'élément. |

## Remarques

Cette énumération est utilisée pour définir la présence ou l'absence de marqueurs dans un élément SVG. Elle est généralement utilisée dans les attributs qui contrôlent le rendu des marqueurs aux sommets ou aux points de contrôle des formes.

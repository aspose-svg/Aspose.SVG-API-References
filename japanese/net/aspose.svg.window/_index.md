**Aspose.Svg.Window** 名前空間は、DOM ドキュメントを含むウィンドウを表すウィンドウオブジェクトに関連しています。アクティブなドキュメントのアドレスや閲覧履歴に関するクラスとインターフェイスが含まれます。

## クラス

| クラス | 説明 |
| --- | --- |
| [Location](./location/) | Location オブジェクトは、ドキュメントの閲覧コンテキスト内でアクティブなドキュメントのアドレスを表現し、履歴オブジェクトにエントリを追加または置換することで、閲覧コンテキストのセッション履歴の現在のエントリを変更できるようにします。 |
| [MediaQueryList](./mediaquerylist/) | MediaQueryList オブジェクトは、ドキュメントに適用されたメディアクエリに関する情報を保持し、ドキュメントの状態に対する即時およびイベント駆動のマッチングをサポートします。CSSOM View Module 仕様をご覧ください: [https://www.w3.org/TR/cssom-view/#the-mediaquerylist-interface](https://www.w3.org/TR/cssom-view/#the-mediaquerylist-interface) |
## インターフェイス

| インターフェイス | 説明 |
| --- | --- |
| [IWindow](./iwindow/) | window オブジェクトは、DOM ドキュメントを含むウィンドウを表します。 |
| [IWindowEventHandlers](./iwindoweventhandlers/) | window オブジェクトが継承しなければならないインターフェイスを表します。 |
| [IWindowTimers](./iwindowtimers/) | 作者がタイマーに基づくコールバックをスケジュールできるようにします。 |

## ImageTraceSimplifier.Tolerance property

許容誤差の値は、トレースから点を除去できる最大誤差許容範囲を決定します。範囲は 0 から 4 まででなければなりません。この範囲の最小値または最大値を超える場合は、それぞれ最小値または最大値に合わせられます。デフォルト値は 0.3 です。

```csharp
public float Tolerance { get; set; }
```

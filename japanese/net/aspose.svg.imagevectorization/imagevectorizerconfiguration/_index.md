## ImageVectorizerConfiguration class

`ImageVectorizerConfiguration` クラスは、画像ベクトル化の手法とオプションの構成を定義します。この構成は ImageVectorizer の初期化に使用され、画像をベクトル化するための構成オプションを提供します。

```csharp
public class ImageVectorizerConfiguration
```

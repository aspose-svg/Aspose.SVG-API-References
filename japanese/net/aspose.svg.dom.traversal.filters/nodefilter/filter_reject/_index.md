## NodeFilter.FILTER_REJECT field

ノードを拒否します。NodeIterator または TreeWalker 用に定義されたナビゲーションメソッドはこのノードを返しません。TreeWalker では、このノードの子ノードも拒否されます。NodeIterator はこれを FILTER_SKIP の同義語として扱います。

```csharp
public const short FILTER_REJECT;
```

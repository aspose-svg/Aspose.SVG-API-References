## NodeFilter.FILTER_SKIP field

この単一ノードをスキップします。NodeIterator または TreeWalker 用に定義されたナビゲーションメソッドはこのノードを返しません。NodeIterator と TreeWalker の両方で、このノードの子ノードは引き続き考慮されます。

```csharp
public const short FILTER_SKIP;
```

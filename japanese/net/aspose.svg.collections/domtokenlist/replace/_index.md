## DOMTokenList.Replace method

既存のトークンを新しいトークンに置き換えます。最初のトークンが存在しない場合は何もしません。

```csharp
public bool Replace(string token, string newToken)
```

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| token | String | 置き換えたいトークン。 |
| newToken | String | 古いトークンと置き換えるトークン。 |

### 戻り値

トークンが見つかり置き換えられた場合は Boolean `true`、それ以外の場合は `false`。

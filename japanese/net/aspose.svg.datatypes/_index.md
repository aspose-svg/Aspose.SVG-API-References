この名前空間は、すべての SVG 固有のデータ型へのアクセスを提供します。

## クラス

| クラス | 説明 |
| --- | --- |
| [SVGAngle](./svgangle/) | SVGAngle インターフェイスは、角度の基本データ型に対応します。 |
| [SVGAnimatedAngle](./svganimatedangle/) | アニメーション可能な基本データ型 angle の属性に使用されます。 |
| [SVGAnimatedBoolean](./svganimatedboolean/) | アニメーション可能な boolean 型の属性に使用されます。 |
| [SVGAnimatedEnumeration](./svganimatedenumeration/) | 特定の列挙体からの定数でなければならず、かつアニメーション可能な属性に使用されます。 |
| [SVGAnimatedInteger](./svganimatedinteger/) | アニメーション可能な基本型 integer の属性に使用されます。 |
| [SVGAnimatedLength](./svganimatedlength/) | アニメーション可能な基本型 length の属性に使用されます。 |
| [SVGAnimatedLengthList](./svganimatedlengthlist/) | アニメーション可能な SVGLengthList 型の属性に使用されます。 |
| [SVGAnimatedNumber](./svganimatednumber/) | アニメーション可能な基本型 number の属性に使用されます。 |
| [SVGAnimatedNumberList](./svganimatednumberlist/) | 数値のリストを取る、かつアニメーション可能な属性に使用されます。 |
| [SVGAnimatedPreserveAspectRatio](./svganimatedpreserveaspectratio/) | アニメーション可能な SVGPreserveAspectRatio 型の属性に使用されます。 |
| [SVGAnimatedRect](./svganimatedrect/) | アニメーション可能な SVGRect 型の属性に使用されます。 |
| [SVGAnimatedString](./svganimatedstring/) | アニメーション可能な DOMString 型の属性に使用されます。 |
| [SVGAnimatedTransformList](./svganimatedtransformlist/) | さまざまな変換のセットを指定する属性（例として、多くの SVG 要素で利用可能でアニメーション化できる ‘transform’ 属性）に使用されます。 |
| [SVGAnimatedValue<T>](./svganimatedvalue-1/) | アニメーション化可能な型の属性に使用されます。 |
| [SVGLength](./svglength/) | SVGLength インターフェイスは length 基本データ型に対応します。SVGLength オブジェクトは読み取り専用に指定でき、オブジェクトの変更を試みると例外がスローされます（以下参照）。 |
| [SVGLengthList](./svglengthlist/) | このインターフェイスは SVGLength オブジェクトのリストを定義します。 |
| [SVGMatrix](./svgmatrix/) | SVG の多くのグラフィック操作は、形式が [a c e] [b d f] の 2x3 行列を使用し、行列演算のために 3x3 行列に拡張すると [a c e] [b d f] [0 0 1] になります。 |
| [SVGNumber](./svgnumber/) | 基本型 number の属性に使用されます。 |
| [SVGNumberList](./svgnumberlist/) | このインターフェイスは SVGNumber オブジェクトのリストを定義します。 |
| [SVGPoint](./svgpoint/) | SVG DOM の多くのインターフェイスはクラス SVGPoint のオブジェクトを参照します。SVGPoint は (x, y) の座標ペアです。行列演算で使用される場合、SVGPoint は [x] [y] [1] の形のベクトルとして扱われます。SVGRect オブジェクトが読み取り専用に指定されている場合、その属性に代入しようとすると例外がスローされます。 |
| [SVGPointList](./svgpointlist/) | このインターフェイスは SVGPoint オブジェクトのリストを定義します。 |
| [SVGPreserveAspectRatio](./svgpreserveaspectratio/) | SVGPreserveAspectRatio インターフェイスは ‘preserveAspectRatio’ 属性に対応し、いくつかの SVG 要素で利用可能です。 |
| [SVGRect](./svgrect/) | 矩形ジオメトリを表します。矩形は、最小 X 値と最小 Y 値を示す (x,y) 座標ペアと、通常は非負に制限される幅と高さで構成されます。 |
| [SVGStringList](./svgstringlist/) | SVGStringList は他の SVGxxxList インターフェイスと同じ属性とメソッドを持ちます。実装者は、さまざまな SVGxxxList インターフェイスを実装するために単一の基底クラスの使用を検討できるでしょう。 |
| [SVGTransform](./svgtransform/) | SVGTransform は SVGTransformList 内の構成変換の一つのインターフェイスであり、SVGTransform オブジェクトは ‘transform’ 属性指定内の単一コンポーネント（例：'scale(…)' や 'matrix(…)') に対応します。 |
| [SVGTransformList](./svgtransformlist/) | このインターフェイスは SVGTransform オブジェクトのリストを定義します。 |
| [SVGValueType](./svgvaluetype/) | SVGValueType 型は基本的な SVG 値型を表すために使用されます。 |

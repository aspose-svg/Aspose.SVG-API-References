## ErrorEvent.FileName property

filename 属性は初期化された値を返す必要があります。オブジェクト作成時にこの属性は空文字列に初期化されます。これはエラーが元々発生したスクリプトの絶対 URL を表します。

```csharp
public string FileName { get; }
```

### Property Value

ファイル名です。

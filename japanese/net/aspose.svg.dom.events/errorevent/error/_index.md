## ErrorEvent.Error property

error 属性は初期化された値を返す必要があります。オブジェクト作成時にこの属性は null に初期化されます。適切な場合は、エラーを表すオブジェクト（例：捕捉されなかった DOM 例外の場合の例外オブジェクト）に設定されます。

```csharp
public object Error { get; }
```

### Property Value

エラーです。

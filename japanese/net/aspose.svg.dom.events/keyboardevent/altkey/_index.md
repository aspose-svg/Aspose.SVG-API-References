## KeyboardEvent.AltKey property

Alt（代替）キー（または \"Option\"）修飾子がアクティブな場合は true。属性の未初期化値は false である必要があります。

```csharp
public bool AltKey { get; }
```

### Property Value

`true` は Alt が有効な場合、そうでなければ `false`。

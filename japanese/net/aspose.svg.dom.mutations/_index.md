**Aspose.Svg.Dom.Mutations** は、DOM の変異を観測し、特定のコールバック情報を取得する機会を提供します。

## クラス

| クラス | 説明 |
| --- | --- |
| [MutationCallback](./mutationcallback/) | 変異イベントを処理するメソッドを表します。 |
| [MutationObserver](./mutationobserver/) | [`MutationObserver`](../aspose.svg.dom.mutations/mutationobserver/) オブジェクトは、[`Node`](../aspose.svg.dom/node/) ツリーの変異を観察するために使用できます。 |
| [MutationObserverInit](./mutationobserverinit/) | このクラスは、[`MutationObserver`](../aspose.svg.dom.mutations/mutationobserver/) を構成するために使用されるオプションコレクションを表します。 |
| [MutationRecord](./mutationrecord/) | MutationRecord は個々の DOM 変異を表します。これは、[`MutationObserver`](../aspose.svg.dom.mutations/mutationobserver/) の [`MutationCallback`](../aspose.svg.dom.mutations/mutationcallback/) に渡されるオブジェクトです。 |

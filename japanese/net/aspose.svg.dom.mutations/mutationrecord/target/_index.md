## MutationRecord.Target property

変異が影響したノードを返します。タイプに応じて異なります。"attributes" の場合、属性が変更された要素が返されます。"characterData" の場合、CharacterData ノードが返されます。"childList" の場合、子が変更されたノードが返されます。

public Node Target { get; }

## SVGSVGElement.GetElementById method

この SVG ドキュメントフラグメント（すなわち検索はドキュメントツリーのサブセットに限定されます）内で、elementId で指定された id を持つ要素を検索します。要素が見つかった場合、その要素が返されます。該当する要素が存在しない場合は null を返します。同じ id を持つ要素が複数ある場合の動作は未定義です。

```csharp
public Element GetElementById(string elementId)
```

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| elementId | String | 要素の一意な id 値です。 |

### 戻り値

一致する要素です。

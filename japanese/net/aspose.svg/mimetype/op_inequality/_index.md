## MimeType Inequality operator

2つの Mime タイプを比較し、一致するかどうかを示すブール値を返します。

```csharp
public static bool operator !=(MimeType a, MimeType b)
```

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| a | MimeType | 比較する最初の Mime。 |
| b | MimeType | 比較する2番目の Mime。 |

### 戻り値

両方の優先度が等しくない場合は true、そうでなければ false。

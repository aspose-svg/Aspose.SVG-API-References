## SVGDocument.GetOverrideStyle method

このメソッドは、指定された要素と指定された疑似要素のオーバーライドスタイル宣言を取得するために使用されます。

```csharp
public ICSSStyleDeclaration GetOverrideStyle(Element elt, string pseudoElt)
```

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| elt | Element | スタイルを変更する要素です。このパラメータは null にできません。 |
| pseudoElt | String | 疑似要素、または存在しない場合は null。 |

### 戻り値

オーバーライドスタイル宣言

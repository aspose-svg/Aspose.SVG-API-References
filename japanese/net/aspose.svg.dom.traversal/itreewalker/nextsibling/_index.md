## ITreeWalker.NextSibling method

TreeWalker を現在のノードの次の兄弟ノードへ移動し、新しいノードを返します。現在のノードに表示可能な次の兄弟ノードがない場合は null を返し、現在のノードを保持します。

```csharp
public Node NextSibling()
```

### 戻り値

新しいノード、または TreeWalker の論理ビューで現在のノードに次の兄弟がない場合は null。

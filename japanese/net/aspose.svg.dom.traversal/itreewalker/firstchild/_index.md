## ITreeWalker.FirstChild method

TreeWalker を現在のノードの最初の表示子ノードに移動し、新しいノードを返します。現在のノードに表示子ノードがない場合は null を返し、現在のノードを保持します。

```csharp
public Node FirstChild()
```

### 戻り値

新しいノード、または TreeWalker の論理ビューで現在のノードに表示可能な子がない場合は null。

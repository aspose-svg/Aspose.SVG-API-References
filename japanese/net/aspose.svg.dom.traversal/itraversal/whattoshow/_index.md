## ITraversal.WhatToShow property

この属性は、イテレータを通じて提示されるノードタイプを決定します。利用可能な定数の集合は NodeFilter インターフェイスで定義されています。whatToShow で受け入れられないノードはスキップされますが、その子ノードは引き続き考慮される場合があります。なお、このスキップはフィルタ（存在する場合）よりも優先されます。

```csharp
public long WhatToShow { get; }
```

表示するもの。

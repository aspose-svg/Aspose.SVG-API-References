## ICSSStyleSheet.OwnerRule property

@import ルールからこのスタイルシートが来た場合、ownerRule 属性には CSSImportRule が含まれます。その場合、StyleSheet インターフェイスの ownerNode 属性は null になります。スタイルシートが要素または処理命令から来た場合、ownerRule 属性は null となり、ownerNode 属性には Node が含まれます。

```csharp
public ICSSRule OwnerRule { get; }
```

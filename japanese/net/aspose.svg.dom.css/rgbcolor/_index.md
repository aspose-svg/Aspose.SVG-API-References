## RGBColor class

RGBColor インターフェイスは任意の RGB カラー値を表すために使用されます。このインターフェイスは基礎となるスタイルプロパティの値を反映します。そのため、CSSPrimitiveValue オブジェクトへの変更はスタイルプロパティを変更します。

```csharp
public class RGBColor : DOMObject
```

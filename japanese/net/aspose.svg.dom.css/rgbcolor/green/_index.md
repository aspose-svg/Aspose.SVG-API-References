### Property Value

この Color の緑成分の値。

## 備考

各ピクセルの色は 32 ビットの数値で表されます：アルファ、赤、緑、青 (ARGB) がそれぞれ 8 ビットです。アルファ成分は色の透明度を指定し、0 は完全に透明、255 は完全に不透明を表します。同様に、アルファ値が 255 の場合は不透明な色です。アルファ値が 1 から 254 の間の場合は半透明の色となります。アルファが 255 に近づくほど色はより不透明になります。

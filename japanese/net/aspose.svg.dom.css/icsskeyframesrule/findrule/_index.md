## ICSSKeyframesRule.FindRule method

findRule メソッドは、渡されたキーと一致するルールを返します。そのようなルールが存在しない場合、null が返されます。

```csharp
public ICSSKeyframeRule FindRule(string key)
```

| パラメータ | 型 | 説明 |

| キー | String | 検索するルールを記述するキー。キーは 0 から 1 の間の数値に解決できなければならず、そうでない場合はルールは無視されます。 |

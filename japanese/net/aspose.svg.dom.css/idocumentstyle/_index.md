## IDocumentStyle interface

DocumentStyle インターフェイスは、ドキュメントに埋め込まれたスタイルシートを取得できるメカニズムを提供します。Document インターフェイスのインスタンスに対してバインディング固有のキャストメソッドを使用することで、DocumentStyle インターフェイスのインスタンスを取得できることが期待されます。

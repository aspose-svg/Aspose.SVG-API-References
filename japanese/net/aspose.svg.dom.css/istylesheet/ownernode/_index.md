## IStyleSheet.OwnerNode property

このスタイルシートをドキュメントに関連付けるノードです。HTML の場合、対応する LINK または STYLE 要素になることがあります。XML の場合、リンク処理命令になることがあります。他のスタイルシートにインクルードされているスタイルシートの場合、この属性の値は null です。

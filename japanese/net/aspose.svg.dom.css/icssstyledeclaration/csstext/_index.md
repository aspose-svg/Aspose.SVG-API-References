## ICSSStyleDeclaration.CSSText property

宣言ブロックの解析可能なテキスト表現（周囲の波括弧は除く）です。この属性を設定すると、新しい値の解析が行われ、宣言ブロック内のすべてのプロパティがリセットされ、プロパティの削除や追加も行われます。

```csharp
public string CSSText { get; set; }
```

### Property Value

CSS テキストです。

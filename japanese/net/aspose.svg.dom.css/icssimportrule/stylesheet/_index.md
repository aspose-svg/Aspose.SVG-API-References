## ICSSImportRule.StyleSheet property

このルールが参照するスタイルシートです（ロード済みの場合）。スタイルシートがまだロードされていない、またはロードされない場合（例：ユーザーエージェントがサポートしないメディアタイプ用の場合）、この属性の値は null になります。

```csharp
public ICSSStyleSheet StyleSheet { get; }
```

## Rect class

Rect インターフェイスは任意の rect 値を表すために使用されます。このインターフェイスは基礎となるスタイルプロパティの値を反映します。そのため、CSSPrimitiveValue オブジェクトへの変更はスタイルプロパティを変更します。

```csharp
public class Rect : DOMObject
```

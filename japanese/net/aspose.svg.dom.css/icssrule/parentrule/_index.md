## ICSSRule.ParentRule property

このルールが別のルール内に含まれている場合（例: @media ブロック内のスタイルルール）、このプロパティはその包含ルールを返します。ルールが他のルールにネストされていない場合は null を返します。

```csharp
public ICSSRule ParentRule { get; }
```

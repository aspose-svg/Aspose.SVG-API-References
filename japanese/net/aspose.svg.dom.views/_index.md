**Aspose.Svg.Dom.Views** namespace describes AbstractView and DocumentView interfaces according Document Object Model Views specification.

## インターフェイス

| インターフェイス | 説明 |
| --- | --- |
| [IAbstractView](./iabstractview/) | すべてのビューが継承すべき基本インターフェイスです。 |
| [IDocumentView](./idocumentview/) | DocumentView インターフェイスは、DOM Views をサポートする DOM 実装の Document オブジェクトによって実装されます。ドキュメントのデフォルトビューを取得する属性を提供します。 |

## Cursor enumeration

SVG 要素のカーソルタイプを定義し、要素上にホバーしたときのカーソル外観をカスタマイズできるようにします。

```csharp
public enum Cursor
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Auto | `0` | ブラウザーは現在のコンテキストに基づいて表示するカーソルを決定します。 |
| Default | `1` | デフォルトのカーソル、通常は矢印です。 |
| None | `2` | カーソルは表示されません。 |
| ContextMenu | `3` | コンテキストメニューが利用可能であることを示すカーソル。 |
| Help | `4` | ヘルプ情報が利用可能であることを示すカーソル。 |
| Pointer | `5` | クリック可能な要素を示すカーソル、通常は手のポインタです。 |
| Progress | `6` | 進行中の操作またはタスクを示すカーソル。 |
| Wait | `7` | システムがビジー状態でユーザーが待機すべきことを示すカーソル。 |
| Cell | `8` | セルまたはテーブル要素を示すカーソル。 |
| Crosshair | `9` | 精密選択を示すカーソル、通常は十字線です。 |
| Text | `10` | テキスト選択を示すカーソル。 |
| VerticalText | `11` | 垂直テキスト選択を示すカーソル。 |

## 備考

この列挙は、SVG 要素に適用できるさまざまなカーソルスタイルを提供します。これらのスタイルは、利用可能な操作の種類やカーソル下の要素の状態を示すのに役立ちます。

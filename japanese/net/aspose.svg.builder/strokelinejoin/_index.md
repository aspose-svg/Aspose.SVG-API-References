## StrokeLineJoin enumeration

ストローク時にパスや基本形状の角で使用される形状を指定します。

```csharp
public enum StrokeLineJoin
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Miter | `0` | 鋭い角がパスセグメントを結合するために使用されます。 |
| MiterClip | `1` | 「miter」に似ていますが、結合が制限を超える場合は切り取られます。 |
| Round | `2` | 丸みを帯びた角がパスセグメントを結合するために使用されます。 |
| Bevel | `3` | 斜めにカットされた角がパスセグメントを結合するために使用されます。 |
| Arcs | `4` | コーナーは弧で結合されます。 |

## FontWeight enumeration

SVG テキスト要素のフォントの異なるウェイトを指定します。

```csharp
public enum FontWeight
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Normal | `0` | 標準のフォント太さ（デフォルトの太さ）を表します。 |
| Bold | `1` | 強調のために通常使用される太字のフォント太さを表します。 |
| Bolder | `2` | 親要素の太さよりも太いフォント太さを表します。 |
| Lighter | `3` | 親要素の太さよりも細いフォント太さを表します。 |
| W100 | `4` | 利用可能な中で最も細い 100 のフォント太さを表します。 |
| W200 | `5` | 200 のフォント太さを表します。 |
| W300 | `6` | 300 のフォント太さを表します。 |
| W400 | `7` | 400 のフォント太さ（'normal' と同等）を表します。 |
| W500 | `8` | 500 のフォント太さを表します。 |
| W600 | `9` | 600 のフォント太さを表します。 |
| W700 | `10` | 700 のフォント太さ（'bold' と同等）を表します。 |
| W800 | `11` | 800 のフォント太さを表します。 |
| W900 | `12` | 利用可能な中で最も太い 900 のフォント太さを表します。 |

## Overflow enumeration

SVG 要素のオーバーフロー動作を指定します。

```csharp
public enum Overflow
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Visible | `0` | 要素の境界を超えるコンテンツは表示されます。 |
| Hidden | `1` | 要素の境界を超えるコンテンツはクリップされ、表示されません。 |
| Scroll | `2` | 要素の境界を超えるコンテンツにスクロールバーを提供します。 |

## 備考

この列挙は SVG 要素の境界を超えるコンテンツの表示方法を制御します。余分なコンテンツが表示されるか、クリップされるか、スクロールバーが提供されるかを決定します。

## BaseLineShift enumeration

SVG における要素のベースラインに対する垂直位置を指定します。

```csharp
public enum BaseLineShift
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Sub | `0` | 要素のベースラインを親テキストの下付き文字ベースラインに合わせます。 |
| Super | `1` | 要素のベースラインを親テキストの上付きベースラインに合わせます。 |
| Top | `2` | 要素の上端を行ボックスの上端に合わせます。 |
| Center | `3` | 要素を行ボックスの中央に配置します。 |
| Bottom | `4` | 要素の下端を行ボックスの下端に合わせます。 |

## 備考

SVG の 'baseline-shift' 属性は、要素のベースラインに対する垂直位置を調整するために使用され、特にテキスト描画で有用です。この列挙体は、ベースラインをシフトしてさまざまなテキスト効果を実現するための複数のオプションを提供します。

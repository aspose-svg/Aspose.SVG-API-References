## RepeatStyle enumeration

SVG の背景画像またはパターンの繰り返しスタイルを指定します。

```csharp
public enum RepeatStyle
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| RepeatX | `0` | 画像またはパターンは水平方向にのみ繰り返されます。 |
| RepeatY | `1` | 画像またはパターンは垂直方向にのみ繰り返されます。 |
| Repeat | `2` | 画像またはパターンは水平および垂直方向の両方に繰り返されます。 |
| Space | `3` | 画像またはパターンは切り取られることなく可能な限り繰り返され、残りのスペースは画像間に均等に配分されます。 |
| Round | `4` | 画像またはパターンはサイズが合わせられ、切り取られることなく繰り返され、アスペクト比が維持されます。 |
| NoRepeat | `5` | 画像またはパターンは繰り返されず、画像は1つだけ描画されます。 |

## LengthAdjust enumeration

SVG におけるテキスト長さの調整方法を指定します。

```csharp
public enum LengthAdjust
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Spacing | `0` | 目的の長さを実現するために文字間の間隔を調整します。 |
| SpacingAndGlyphs | `1` | 目的の長さを実現するために、間隔とグリフのサイズの両方を調整します。 |

## 備考

SVG のテキスト要素にある 'lengthAdjust' 属性は、テキストを指定された長さに合わせる際のスケーリング方法を制御します。

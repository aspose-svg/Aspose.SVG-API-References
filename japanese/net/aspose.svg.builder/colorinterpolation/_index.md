## ColorInterpolation enumeration

SVG 要素およびフィルタのカラー補間モードを指定します。

```csharp
public enum ColorInterpolation
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Auto | `0` | カラー補間モードを自動的に決定します。 |
| SRGB | `1` | カラー補間に標準の RGB カラースペース (sRGB) を使用します。 |
| LinearRGB | `2` | カラー補間にリニア RGB カラースペースを使用します。 |

## 備考

SVG におけるカラー補間は、グラフィック要素やフィルタ効果における色の計算およびブレンド方法に影響します。モードが異なると、色の遷移、グラデーション、全体的な色表現の見た目に大きく影響します。この設定は、SVG グラフィックスで期待通りのビジュアル結果を得るために重要です。

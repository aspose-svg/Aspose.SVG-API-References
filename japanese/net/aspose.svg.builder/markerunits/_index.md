## MarkerUnits enumeration

SVG のマーカーサイズの座標系を指定します。

```csharp
public enum MarkerUnits
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| StrokeWidth | `0` | マーカーのサイズはパスのストローク幅に対して相対的です。 |
| UserSpaceOnUse | `1` | マーカーのサイズはユーザー座標系に基づいており、ストローク幅に依存しません。 |

## 備考

この列挙は、SVG におけるマーカーサイズの計算に使用される座標系を定義します。マーカーサイズがストローク幅に対して相対的か、ユーザー座標系に基づくかを決定します。

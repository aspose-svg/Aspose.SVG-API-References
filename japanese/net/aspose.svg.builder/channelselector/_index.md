## ChannelSelector enumeration

SVG フィルタ操作で使用するチャンネルセレクタを指定します。

```csharp
public enum ChannelSelector
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| R | `0` | 画像の赤チャネルを選択します。 |
| G | `1` | 画像の緑チャネルを選択します。 |
| B | `2` | 画像の青チャネルを選択します。 |
| A | `3` | 画像のアルファ（透明度）チャネルを選択します。 |

## 備考

チャネルセレクタは、さまざまな SVG フィルタプリミティブで特定のカラー チャネル（赤、緑、青）または画像のアルファチャネルを対象に使用されます。これにより、フィルタ処理中にこれらのチャネルを正確に操作できます。

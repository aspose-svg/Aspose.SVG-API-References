## ColorMatrixOperation enumeration

カラーマトリックスフィルタで適用される操作のタイプを指定します。

```csharp
public enum ColorMatrixOperation
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Matrix | `0` | カラー データに行列変換を適用します。 |
| Saturate | `1` | 画像の彩度レベルを調整します。 |
| HueRotate | `2` | 画像に色相回転を適用します。 |
| LuminanceToAlpha | `3` | 画像の色を輝度に基づいてグレースケールに変換します。 |

## 備考

SVG のカラー行列フィルターは、画像のカラー データに対してさまざまな操作を可能にします。各操作タイプは特定の方法で色を操作し、幅広い視覚効果を提供します。

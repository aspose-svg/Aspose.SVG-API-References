## Rotate enumeration

SVG のモーションアニメーション中に要素の回転動作を指定します。

```csharp
public enum Rotate
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Auto | `0` | パスの方向に要素を自動的に回転させます。 |
| AutoReverse | `1` | パスの方向に要素を自動的に回転させ、逆方向にも回転できるようにします。 |

## 備考

SVG の 'animateMotion' 要素にある 'rotate' 属性は、モーション パスに沿った要素の回転を制御します。この列挙体は、要素がパスに沿って回転する方法に関するオプションを提供します。

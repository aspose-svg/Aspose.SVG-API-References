## XLinkShow enumeration

SVG リンクがトリガーされたときの動作を指定します。

```csharp
public enum XLinkShow
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| New | `0` | リンクを新しいウィンドウまたはタブで開きます。 |
| Replace | `1` | 現在の SVG ドキュメントをリンク先のドキュメントに置き換えます。 |
| Embed | `2` | リンク先のドキュメントを現在の SVG ドキュメントに埋め込みます。 |
| Other | `3` | 事前定義された動作以外の動作を指定します。 |
| None | `4` | 特定の動作が要求されていないことを示します。 |

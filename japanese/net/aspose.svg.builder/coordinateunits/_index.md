## CoordinateUnits enumeration

マスク、ペイントサーバー、フィルタなど、さまざまな SVG 要素の座標系単位を指定します。

```csharp
public enum CoordinateUnits
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| UserSpaceOnUse | `0` | SVG 要素にユーザー座標系を使用します。 |
| ObjectBoundingBox | `1` | SVG 要素にオブジェクトのバウンディングボックスを使用します。 |

## 備考

座標単位は、さまざまな SVG コンテキストで値がどのように解釈されるかを決定します。ユーザー空間座標を使用するか、オブジェクトのバウンディングボックスに対して相対的に設定することができます。

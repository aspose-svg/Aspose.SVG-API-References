## TransformationType enumeration

```csharp
public enum TransformationType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Translate | `0` | 要素を一定の距離だけ平行移動（移動）します。 |
| Scale | `1` | 要素のサイズを拡大または縮小します。 |
| Rotate | `2` | 要素を指定された点の周りで回転させます。 |
| SkewX | `3` | 要素をX軸方向にせん断します。 |
| SkewY | `4` | 要素をY軸方向にせん断します。 |

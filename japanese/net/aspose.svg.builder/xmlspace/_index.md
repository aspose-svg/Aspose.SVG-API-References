## XmlSpace enumeration

XML ドキュメントで要素内の空白がどのように処理されるかを指定します。

```csharp
public enum XmlSpace
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Default | `0` | XML プロセッサのデフォルト動作に従って空白を処理すべきことを示します。通常、改行や余分なスペースを削除して空白を正規化します。 |
| Preserve | `1` | XML ドキュメントに現れるまま空白を保持すべきことを示します。空白が重要なテキストの書式を維持するのに役立ちます。 |

## 備考

XML の 'xml:space' 属性は、要素内の空白を保持するか正規化するかを制御するために使用されます。この列挙型は、XML および SVG ドキュメントでこの動作を設定するオプションを提供します。

## DisplayType enumeration

SVG ドキュメント内の要素の表示動作を指定します。

```csharp
public enum DisplayType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Inline | `0` | 要素は 1 つ以上のインラインボックスを生成します。 |
| Block | `1` | 要素はブロックボックスを生成します。 |
| ListItem | `2` | 要素はコンテンツ用にブロックボックスを生成し、別個のリスト項目インラインボックスを生成します。 |
| InlineBlock | `3` | 要素はコンテンツ用にブロックボックスを生成し、コンテナ用にインラインボックスを生成します。 |
| Table | `4` | 要素はテーブル要素のように振る舞います。 |
| InlineTable | `5` | 要素はインラインテーブルのように振る舞います。 |
| TableRowGroup | `6` | 要素はテーブル行グループのように振る舞います。 |
| TableHeaderGroup | `7` | 要素はテーブルヘッダーグループのように振る舞います。 |
| TableFooterGroup | `8` | 要素はテーブルフッターグループのように振る舞います。 |
| TableRow | `9` | 要素はテーブル行のように振る舞います。 |
| TableColumnGroup | `10` | 要素はテーブル列グループのように振る舞います。 |
| TableColumn | `11` | 要素はテーブル列のように振る舞います。 |
| TableCell | `12` | 要素はテーブルセルのように振る舞います。 |
| TableCaption | `13` | 要素はテーブルキャプションのように振る舞います。 |
| None | `14` | 要素はボックスを生成せず、描画もされません。レイアウトにも影響しません。 |
| Flex | `15` | 要素はフレックスコンテナのように振る舞います。 |
| InlineFlex | `16` | 要素はインラインフレックスコンテナのように振る舞います。 |
| Grid | `17` | 要素はグリッドコンテナのように振る舞います。 |
| InlineGrid | `18` | 要素はインライングリッドコンテナのように振る舞います。 |

## 備考

'display' プロパティは SVG と CSS で要素が文書レイアウト内でどのように表示されるかを決定します。この列挙は display タイプを設定するさまざまなオプションを提供し、要素のレンダリングやレイアウトとの相互作用に影響を与えます。

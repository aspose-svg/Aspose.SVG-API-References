## WhiteSpace enumeration

SVG 要素内部の空白の処理方法を指定します。

```csharp
public enum WhiteSpace
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Normal | `0` | 空白は折りたたまれ、改行文字は新しい行を作成します。 |
| Pre | `1` | 空白は保持され、テキストは改行文字が含まれる場所でのみ折り返されます。 |
| NoWrap | `2` | 空白は折りたたまれ、テキストは折り返されません。 |
| PreWrap | `3` | 空白は保持されます；必要に応じてテキストが折り返され、改行文字でも折り返されます。 |
| BreakSpaces | `4` | 空白は保持されます；行ボックスを埋めるために改行が追加されます。 |
| PreLine | `5` | 空白は保持されます；必要に応じてテキストが折り返されますが、改行文字は使用されません。 |

## FontStretch enumeration

```csharp
public enum FontStretch
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Normal | `0` | 標準（デフォルト）のフォント伸縮を表します。 |
| UltraCondensed | `1` | 最も凝縮されたフォント伸縮を表します。 |
| ExtraCondensed | `2` | 「condensed」よりも凝縮され、「ultra-condensed」ほどではないフォント伸縮を表します。 |
| Condensed | `3` | 凝縮されたフォント伸縮を表します。 |
| SemiCondensed | `4` | やや凝縮されたフォント伸縮を表します。 |
| SemiExpanded | `5` | やや拡張されたフォント伸縮を表します。 |
| Expanded | `6` | 拡張されたフォント伸縮を表します。 |
| ExtraExpanded | `7` | 「expanded」よりも拡張され、「ultra-expanded」ほどではないフォント伸縮を表します。 |
| UltraExpanded | `8` | 最も拡張されたフォント伸縮を表します。 |

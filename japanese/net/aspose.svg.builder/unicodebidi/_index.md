## UnicodeBidi enumeration

SVG における双方向テキストの処理を指定します。

```csharp
public enum UnicodeBidi
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Normal | `0` | 標準的な双方向テキスト処理。 |
| Embed | `1` | 異なる、または明示的な方向性を持つテキストセクションを埋め込みます。 |
| Isolate | `2` | 双方向テキスト処理のために、テキストセクションを周囲から分離します。 |
| BidiOverride | `3` | テキストセクション内の文字の固有の方向性を上書きします。 |
| IsolateOverride | `4` | テキストセクションを分離し、その方向性を上書きします。 |
| Plaintext | `5` | テキストセクションを特別な双方向処理なしのプレーンテキストとして扱います。 |

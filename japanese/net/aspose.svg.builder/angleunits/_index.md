## AngleUnits enumeration

SVG でマーカーの向きを定義する際に使用される角度の単位を指定します。

```csharp
public enum AngleUnits
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Degrees | `0` | 角度を度で指定します。1 周は 360 度です。 |
| Gradians | `1` | 角度をグラジアンで指定します。1 周は 400 グラジアンです。 |
| Radians | `2` | 角度をラジアンで指定します。1 周は約 6.283 ラジアン（2π ラジアン）です。 |
| None | `3` | 特定の角度単位がないことを示します。デフォルトまたはコンテキストベースの設定に使用されます。 |

## 備考

SVG マーカーの 'orient' 属性はさまざまな角度単位で指定できます。この列挙型はこれらの単位を設定するオプションを提供します。

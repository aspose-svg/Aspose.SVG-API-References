## MorphologyOperator enumeration

SVG フィルターに適用される形態学的操作のタイプを指定します。

```csharp
public enum MorphologyOperator
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Erode | `0` | グラフィックを侵食し、形状を小さくし、エッジを滑らかにします。 |
| Dilate | `1` | グラフィックを膨張させ、形状を大きくし、エッジをよりはっきりさせます。 |

## 備考

この列挙型は SVG フィルタの文脈で形態学的操作のタイプを定義するために使用されます。形態学的操作は画像内の要素の形状や構造を処理するために使用され、主にグラフィックの侵食や膨張に利用されます。

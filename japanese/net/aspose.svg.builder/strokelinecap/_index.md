## StrokeLineCap enumeration

ストローク時に開いたサブパスの終端で使用される形状を指定します。

```csharp
public enum StrokeLineCap
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Butt | `0` | ストロークは線の方向に対して垂直な平坦なエッジで終わります。 |
| Round | `1` | ストロークは半円で終わり、半径はストローク幅と同じで、線の端を中心に配置されます。 |
| Square | `2` | ストロークは四角形のエッジで終わり、線の端からストローク幅の半分だけ延長されます。 |

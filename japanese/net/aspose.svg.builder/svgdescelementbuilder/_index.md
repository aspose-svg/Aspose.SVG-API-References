## SVGDescElementBuilder class

SVG コンテナ要素の説明を提供するために使用される SVG の 'desc' 要素を構築するビルダー クラスです。'desc' 要素内のコンテンツ構築を可能にし、SVG の 'desc' 要素固有のさまざまな属性を設定するメソッドを提供します。

```csharp
public class SVGDescElementBuilder : SVGElementBuilder<SVGDescElement>, ICoreAttributeSetter, 
    IDescriptiveElementBuilder, IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, 
    ITextContentSetter
```

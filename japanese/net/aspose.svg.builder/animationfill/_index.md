## AnimationFill enumeration

アニメーションの実行前後の動作を指定します。

```csharp
public enum AnimationFill
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Freeze | `0` | アニメーションは、アニメーションが終了した時点のプロパティ値を適用します。 |
| Remove | `1` | アニメーションは、実行が完了した後に値を適用しません。 |

## 備考

SVG アニメーションの 'fill' 属性は、アニメーションが実行中でない期間に適用される値を制御します。この列挙型は、これらの動作を制御するオプションを提供します。

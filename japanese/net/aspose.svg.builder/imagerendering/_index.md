## ImageRendering enumeration

SVG で画像をどのようにレンダリングするかを指定します。

```csharp
public enum ImageRendering
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Auto | `0` | ブラウザーは画像を描画する際、速度と品質の間でトレードオフを行います。 |
| OptimizeSpeed | `1` | ブラウザーは画像品質よりも描画速度を重視します。これにより、画像がピクセル化したりブロック状に見えるようにスケーリングされることがあります。 |
| OptimizeQuality | `2` | ブラウザーは描画速度よりも画像品質を重視します。これにより、画像のスケーリングがより滑らかで高品質になりますが、描画が遅くなる可能性があります。 |

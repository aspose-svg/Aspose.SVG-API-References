## Dash enumeration

SVG 要素で形状の輪郭（ストローク）を描画する際に使用される破線と間隔のパターンを定義します。

```csharp
public enum Dash
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| None | `0` | 破線のない実線ストロークを示します。'stroke-dasharray' が指定されていない場合のデフォルト動作です。 |

## 備考

SVG の 'stroke-dasharray' 属性は、破線と間隔のパターンを指定して破線を作成するために使用されます。この列挙型は、このパターンを設定するためのオプションを提供します。

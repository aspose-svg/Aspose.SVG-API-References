## SVGStyleElementBuilder.Media method

SVG の 'style' 要素の 'media' 属性を設定します。この属性は、スタイルが対象とするメディアを指定し、メディアタイプに応じて条件付きにすることができます。

```csharp
public SVGStyleElementBuilder Media(string mediaDescriptors)
```

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| mediaDescriptors | String | メディア記述子文字列（例: "screen", "print"）。 |

### 戻り値

チェーン用の SVGStyleElementBuilder インスタンスです。

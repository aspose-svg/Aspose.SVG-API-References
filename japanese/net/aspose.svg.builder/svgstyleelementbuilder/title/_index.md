## SVGStyleElementBuilder.Title method

SVG の 'style' 要素の 'title' 属性を設定します。この属性はスタイル要素に助言的なタイトルを提供し、アクセシビリティやツールチップテキストに役立ちます。

```csharp
public SVGStyleElementBuilder Title(string advisoryTitle)
```

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| advisoryTitle | String | 助言的タイトルテキストです。 |

### 戻り値

チェーン用の SVGStyleElementBuilder インスタンスです。

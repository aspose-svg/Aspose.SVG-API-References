## CompositeOperator enumeration

SVG の合成操作で適用されるコンポジット操作のタイプを指定します。

```csharp
public enum CompositeOperator
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Over | `0` | ソース グラフィックをデスティネーション グラフィックの上に配置します。 |
| In | `1` | ソース グラフィックがデスティネーション グラフィックと重なる部分を表示します。 |
| Out | `2` | ソース グラフィックがデスティネーションと重ならない部分を表示します。 |
| Atop | `3` | ソース グラフィックをデスティネーション グラフィックの上に表示します。 |
| Xor | `4` | ソース グラフィックがデスティネーションと重ならない部分、およびその逆の部分を表示します。 |
| Arithmetic | `5` | カスタムの算術合成操作を可能にします。 |

## 備考

SVG の合成操作は、2 つのグラフィック要素を単一の画像に結合する方法を決定します。各オペレーターは、これらの要素をブレンドまたは結合する独自の方法を定義します。

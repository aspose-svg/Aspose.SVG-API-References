## SVGBuilderExtensions.FormatSvgLengths method

double 値の配列を SVG 長さの文字列表現にフォーマットします。

```csharp
public static string FormatSvgLengths(double[] values, LengthType type)
```

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| values | Double[] | 長さを表す double 値の配列です。 |
| type | LengthType | 使用する長さ単位のタイプ（例: ピクセル）。 |

### 戻り値

SVG 長さのフォーマット済み文字列です。

## 備考

このユーティリティメソッドは、SVG 属性の長さ値をフォーマットするために使用され、各値に適切な単位（例: 'px'）を付加します。

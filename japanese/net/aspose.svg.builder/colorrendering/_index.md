## ColorRendering enumeration

SVG 要素のカラー描画モードを指定します。

```csharp
public enum ColorRendering
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Auto | `0` | ブラウザーやビューアがカラーレンダリングモードを選択できるようにし、速度と品質のバランスを取ります。 |
| OptimizeSpeed | `1` | カラー精度や視覚品質よりもレンダリング速度を優先します。 |
| OptimizeQuality | `2` | レンダリング速度よりもカラーの正確さと視覚品質を優先します。 |

## 備考

このプロパティは、特にカラーグラデーション、パターン、画像レンダリングを扱う際に、色がどのように描画されるかを決定します。異なるモードはカラー描画プロセスのパフォーマンスと品質に影響を与える可能性があります。

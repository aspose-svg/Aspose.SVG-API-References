## IAttributeSetter.Attribute method

SVG 要素の属性を設定または更新します。

```csharp
public void Attribute(string name, string value)
```

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| 名前 | String | 設定する属性の名前。これは有効な SVG 属性名である必要があります。 |
| value | String | 属性に割り当てる値。その値は特定の SVG 属性に適した文字列表現である必要があります。 |

## 備考

このメソッドは、構築プロセス中に SVG 要素の属性を動的に追加または変更するために使用されます。さまざまな条件や入力に基づいて属性を設定できるようにすることで、SVG 要素の定義とカスタマイズに柔軟性を提供します。

## MaskBuilder class

CSS のマスクプロパティを作成するビルダー クラスです。このクラスはマスクソース、位置、サイズ、繰り返しスタイルなどのさまざまなプロパティを使用して複雑なマスクスタイルを構築できます。生成された文字列は CSS で要素のマスク動作を定義するために使用できます。

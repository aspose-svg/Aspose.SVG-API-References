## PathBuilder.Ar method

パスデータに相対的な 'Elliptical Arc Curve' コマンドを追加します。

```csharp
public PathBuilder Ar(double r1, double r2, double angle, bool largeArcFlag, bool sweepFlag, 
    double x, double y)
```

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| r1 | Double | 現在位置を基準とした楕円の x 半径。 |
| r2 | Double | 現在位置を基準とした楕円の y 半径。 |
| angle | Double | 現在位置を基準とした楕円の回転角度（度）。 |
| largeArcFlag | Boolean | 弧が 180 度以上であるかどうかを示すフラグです。 |
| sweepFlag | Boolean | 弧が正の角度方向に描かれるかどうかを示すフラグです。 |
| x | Double | 現在位置を基準とした弧の終点の x 座標。 |
| y | Double | 現在位置を基準とした弧の終点の y 座標。 |

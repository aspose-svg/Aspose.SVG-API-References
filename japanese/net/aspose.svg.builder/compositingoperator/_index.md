## CompositingOperator enumeration

SVG のマスク操作で適用されるコンポジット操作のタイプを指定します。

```csharp
public enum CompositingOperator
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Add | `0` | ソース グラフィックのカラー値をデスティネーション グラフィックに加算します。 |
| Subtract | `1` | ソース グラフィックのカラー値をデスティネーション グラフィックから減算します。 |
| Intersect | `2` | ソースとデスティネーションの両方のグラフィックが重なる領域のみを表示します。 |
| Exclude | `3` | ソースとデスティネーションのグラフィックの重なり領域を除外します。 |

## 備考

SVG マスクにおける合成演算子は、異なるグラフィック要素をどのように組み合わせてマスク効果を作り出すかを決定します。各演算子は、これらの要素をブレンドまたは結合する独自の方法を定義し、さまざまなマスク効果を実現します。

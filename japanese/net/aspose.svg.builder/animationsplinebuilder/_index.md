## AnimationSplineBuilder class

キュービックベジエ曲線を使用してアニメーションのタイミング関数を構築するためのビルダー クラスです。このクラスは、2 つの制御点で指定される 1 つ以上のキュービックベジエ曲線の定義を可能にします。生成された文字列は CSS アニメーションやトランジションで使用でき、アニメーションの速度を制御します。

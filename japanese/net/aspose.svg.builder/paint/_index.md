## Paint enumeration

SVG 要素の fill と stroke 属性の塗りオプションを指定します。

```csharp
public enum Paint
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| None | `0` | 塗りを適用しないことを示します。 |
| ContextFill | `1` | 現在のコンテキストの fill カラーを塗りに使用します。 |
| ContextStroke | `2` | 現在のコンテキストの stroke カラーを塗りに使用します。 |

## 備考

この列挙体は、SVG 要素の fill および stroke プロパティに適用できる塗りのタイプを定義します。標準カラー、コンテキストベースの塗りやストローク、または塗りなしを指定できます。

## LengthType enumeration

SVG の長さの測定単位を指定します。

```csharp
public enum LengthType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Number | `1` | 単位なしの数値を表します。これは、他の値やデフォルト単位の文脈で解釈されることが多いです。 |
| Percentage | `2` | 別の値または境界寸法に対して相対的なパーセンテージ値を表します。 |
| Ems | `3` | 現在のフォントサイズに対して相対的なスケーラブルな単位である「ems」での長さを表します。 |
| Exs | `4` | 現在のフォントのxハイトに関連する「exs」での長さを表します。 |
| Px | `5` | 画像のデジタル表現に基づく測定単位であるピクセルでの長さを表します。 |
| Cm | `6` | センチメートルでの長さを表します。 |
| Mm | `7` | ミリメートルでの長さを表します。 |
| In | `8` | インチでの長さを表します。 |
| Pt | `9` | タイポグラフィで伝統的に使用されるポイントでの長さを表します。1ポイントは約1/72インチです。 |
| Pc | `10` | タイポグラフィの測定単位であるパイカでの長さを表します。1パイカは12ポイントに相当します。 |

## 備考

この列挙は、SVG要素で長さを指定する際に使用できるさまざまな単位を定義します。これらの単位には、ピクセルやセンチメートルなどの絶対測定単位と、パーセンテージやemsなどの相対測定単位が含まれます。

## FontStyle enumeration

SVG テキスト要素のフォントの異なるスタイルを指定します。

```csharp
public enum FontStyle
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Normal | `0` | 強調や斜体なしの標準フォントスタイルを表します。 |
| Italic | `1` | イタリック体の外観を持つフォントスタイルを表し、通常は強調に使用されます。 |
| Oblique | `2` | イタリックに似ていますが、傾きが弱い斜体の外観を持つフォントスタイルを表します。 |

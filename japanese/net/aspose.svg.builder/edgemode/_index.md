## EdgeMode enumeration

SVG の feConvolveMatrix フィルタプリミティブのエッジモードを指定します。

```csharp
public enum EdgeMode
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Duplicate | `0` | 入力画像は、必要に応じて各境界に沿って、指定されたエッジの色値を複製することで拡張されます。 |
| Wrap | `1` | 入力画像は概念的にラップ（またはタイル）され、畳み込みはこれらのラップされた値を使用します。これにより画像はトーラス状のトポロジーを持ちます。 |
| None | `2` | エッジモードは定義されておらず、フィルタの効果は実装によって決定されます。 |

**Aspose.Svg.Builder** 名前空間には、Aspose.SVG ライブラリを使用して SVG（Scalable Vector Graphics）ドキュメントを構築および操作するためのクラスとインターフェイスが含まれています。この名前空間は、SVG 要素とその属性の作成と変更を簡素化する豊富なビルダー クラスを提供します。これらのビルダーは流暢な API を提供し、コードをより読みやすく、保守しやすくします。

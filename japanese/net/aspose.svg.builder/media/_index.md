## Media enumeration

SVG アニメーションのメディア関連タイミング条件を指定します。

```csharp
public enum Media
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Media | `0` | アニメーションのタイミングがメディアのタイミングに依存していることを示します。 |

## 備考

この列挙型は SVG アニメーションにおけるメディア関連のタイミング条件を定義するために使用されます。特に、音声や動画などの外部メディアに依存または同期するアニメーションに関連します。

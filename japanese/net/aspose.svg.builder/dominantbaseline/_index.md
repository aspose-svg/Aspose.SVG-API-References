## DominantBaseline enumeration

テキストの配置に使用される支配的ベースラインを指定します。

```csharp
public enum DominantBaseline
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Auto | `0` | フォントや言語に基づいて支配的なベースラインを自動的に決定します。 |
| TextBottom | `1` | テキストを em 正方形の下部に揃えます。 |
| Alphabetic | `2` | テキストをアルファベット文字が使用するベースラインに揃えます。 |
| Ideographic | `3` | テキストを表意文字が使用するベースラインに揃えます。 |
| Middle | `4` | テキストを em 正方形の中央に揃えます。 |
| Central | `5` | テキストを em 正方形の中心ベースラインに揃えます。 |
| Mathematical | `6` | テキストを数学文字が使用するベースラインに揃えます。 |
| Hanging | `7` | テキストをハンギングベースラインに揃えます。これは通常、チベット文字や他のアジア文字に使用されます。 |
| TextTop | `8` | テキストを em 正方形の上部に揃えます。 |

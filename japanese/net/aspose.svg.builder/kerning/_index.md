## Kerning enumeration

SVG のテキストに対するカーニング動作を指定します。

```csharp
public enum Kerning
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Auto | `0` | ブラウザーがカーニングを適用すべきかどうかを判断できるようにします。 |
| Normal | `1` | フォントファイルで定義された標準カーニングを適用します。 |
| None | `2` | カーニングを無効にし、フォント内のカーニング情報を無視します。 |

## 備考

SVG の 'font-kerning' プロパティは、フォントに格納されたカーニング情報の使用を制御します。カーニングは文字ペア間のスペースを調整し、テキストの視覚的外観を向上させます。この列挙型は、SVG テキスト要素におけるカーニング動作を制御するオプションを提供します。

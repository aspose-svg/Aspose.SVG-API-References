## PointerEvents enumeration

SVG のグラフィカル要素がポインターイベントをどのように処理するかを指定します。

```csharp
public enum PointerEvents
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| BoundingBox | `0` | ポインターイベントは要素のバウンディングボックスを対象とします。 |
| VisiblePainted | `1` | ポインターイベントは要素の可視（描画された）部分のみを対象とします。 |
| VisibleFill | `2` | ポインターイベントは要素の可視（塗りつぶされた）部分のみを対象とします。 |
| VisibleStroke | `3` | ポインターイベントは要素の可視（ストロークされた）部分のみを対象とします。 |
| Visible | `4` | ポインターイベントは要素のすべての可視部分を対象とします。 |
| Painted | `5` | ポインターイベントは要素のすべての描画部分（塗りとストロークを含む）を対象とします。 |
| Fill | `6` | ポインターイベントは要素の塗りつぶされた部分のみを対象とします。 |
| Stroke | `7` | ポインターイベントは要素のストロークされた部分のみを対象とします。 |
| All | `8` | ポインターイベントは要素の可視性に関係なく、すべての部分を対象とします。 |
| None | `9` | 要素はポインターイベントの対象になりません。 |

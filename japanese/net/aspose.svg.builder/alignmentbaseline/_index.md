## AlignmentBaseline enumeration

SVG におけるテキストやその他のインラインコンテンツの配置ベースラインを指定します。

```csharp
public enum AlignmentBaseline
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Baseline | `0` | ボックスのベースラインを親ボックスのベースラインに合わせます。 |
| TextBottom | `1` | ボックスの下端を親のコンテンツ領域の下端に合わせます。 |
| Middle | `2` | ボックスの中央を親のコンテンツ領域の中央に合わせます。 |
| Central | `3` | ボックスの中心ベースラインを親ボックスの中心ベースラインに合わせます。 |
| TextTop | `4` | ボックスの上端を親のコンテンツ領域の上端に合わせます。 |
| Ideographic | `5` | ボックスの表意文字ベースラインを親の表意文字ベースラインに合わせます。 |
| Alphabetic | `6` | ボックスのアルファベットベースラインを親のアルファベットベースラインに合わせます。 |
| Mathematical | `7` | ボックスの数学ベースラインを親の数学ベースラインに合わせます。 |

## 備考

‘alignment-baseline’ プロパティは CSS Line Layout Module 3 の仕様で定義されています。SVG 2 ではこのプロパティの定義に変更が導入されています。

**Aspose.Svg.Dom.XPath** 名前空間には、XML ドキュメント内の要素や属性をナビゲートするメソッドが含まれています。

## インターフェイス

| インターフェイス | 説明 |
| --- | --- |
| [IXPathEvaluator](./ixpathevaluator/) | XPath 式の評価は [`IXPathEvaluator`](../aspose.svg.dom.xpath/ixpathevaluator/) によって提供されます。 |
| [IXPathExpression](./ixpathexpression/) | `XPathExpression` インターフェイスは、解析され解決された XPath 式を表します。 |
| [IXPathNamespace](./ixpathnamespace/) | XPathNamespace インターフェイスは、DOM に存在しない XPath 名前空間ノードタイプを表すために XPathResult インターフェイスから返されます。 |
| [IXPathNSResolver](./ixpathnsresolver/) | `XPathNSResolver` インターフェイスは、式中の `prefix` 文字列を適切に `namespaceURI` 文字列にバインドできるようにします。[`IXPathEvaluator`](../aspose.svg.dom.xpath/ixpathevaluator/) はノードから [`IXPathNSResolver`](../aspose.svg.dom.xpath/ixpathnsresolver/) の実装を構築できるか、または任意のアプリケーションがこのインターフェイスを実装することができます。 |
| [IXPathResult](./ixpathresult/) | `XPathResult` インターフェイスは、特定のノードのコンテキスト内で XPath 1.0 式を評価した結果を表します。XPath 式の評価はさまざまな結果タイプになる可能性があるため、このオブジェクトは結果のタイプと値を検出および操作できるようにします。 |
## 列挙型

| 列挙型 | 説明 |
| --- | --- |
| [XPathResultType](./xpathresulttype/) | これは結果のタイプを示す符号なし短整数です。特定の `type` が指定された場合、必要に応じて XPath の型変換を使用し、対応する型として結果が返されます。 |

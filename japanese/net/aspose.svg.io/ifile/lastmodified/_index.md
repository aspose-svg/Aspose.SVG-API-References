## IFile.LastModified property

ファイルの最終更新日時です。取得時に、ユーザーエージェントがこの情報を提供できる場合、Unix エポックからのミリ秒数としてファイルが最後に更新された時刻を表す long long を返す必要があります。

```csharp
public long LastModified { get; }
```

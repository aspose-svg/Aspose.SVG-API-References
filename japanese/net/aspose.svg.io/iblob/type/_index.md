## IBlob.Type property

Blob のメディアタイプを表す小文字の ASCII エンコード文字列です。取得時には、ユーザーエージェントは Blob のタイプを小文字の ASCII エンコード文字列として返す必要があり、バイトシーケンスに変換したときに解析可能な MIME タイプとなるか、タイプが判別できない場合は空文字列（0 バイト）を返します。

```csharp
public string Type { get; }
```

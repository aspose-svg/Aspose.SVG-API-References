## IBlob.Size property

バイトシーケンスのサイズ（バイト数）を返します。取得時には、準拠したユーザーエージェントは FileReader または FileReaderSync オブジェクトで読み取れる総バイト数を返す必要があり、Blob に読み取るバイトがない場合は 0 を返します。

```csharp
public ulong Size { get; }
```

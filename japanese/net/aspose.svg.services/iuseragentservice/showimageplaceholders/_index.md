## IUserAgentService.ShowImagePlaceholders property

画像はフォールバックコンテンツを持つことができます：外部リソースが使用できない場合に使用すべきコンテンツです（例として、サポートされていない形式の場合）。プロパティ `ShowImagePlaceholders` はフォールバック画像を表示するかどうかを指定します（デフォルトは true）。

```csharp
public bool ShowImagePlaceholders { get; set; }
```

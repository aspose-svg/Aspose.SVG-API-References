**Aspose.Svg.Saving** 名前空間は、変換/保存プロセスにおける特定の保存オプションを記述するデータクラスによって構成されています。

## クラス

| クラス | 説明 |
| --- | --- |
| [ImageSaveOptions](./imagesaveoptions/) | 特定のオプションデータクラスです。 |
| [PdfSaveOptions](./pdfsaveoptions/) | 特定のオプションデータクラスです。 |
| [Resource](./resource/) | このクラスはリソースを記述し、それを処理するためのメソッドを提供します。 |
| [ResourceHandlingContext](./resourcehandlingcontext/) | このクラスはリソースを処理する際に使用される情報を含みます。 |
| [ResourceHandlingOptions](./resourcehandlingoptions/) | リソース処理オプションを表します。 |
| [SaveOptions](./saveoptions/) | これは、特定の形式でドキュメントを保存する際にユーザーが追加オプションを指定できるようにするクラスの抽象基底クラスです。 |
| [SVGSaveOptions](./svgsaveoptions/) | SVG 保存オプションを表します。 |
| [SVGZSaveOptions](./svgzsaveoptions/) | SVGZ 保存オプションを表します。 |
| [XpsSaveOptions](./xpssaveoptions/) | 特定のオプションデータクラスです。 |
## 列挙型

| 列挙型 | 説明 |
| --- | --- |
| [ResourceHandling](./resourcehandling/) | この列挙体はリソース処理オプションを表します。 |
| [ResourceStatus](./resourcestatus/) | リソースの状態を示します。 |
| [SVGSaveFormat](./svgsaveformat/) | ドキュメントが保存される形式を指定します。 |
| [UrlRestriction](./urlrestriction/) | この列挙体は処理されたリソースの URL に適用される制限を表します。 |

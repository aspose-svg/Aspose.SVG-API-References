## 名前空間

| 名前空間 | 説明 |
| --- | --- |
| [Aspose.Svg](./aspose.svg/) | **Aspose.Svg.Dom.Svg** 名前空間のすべてのクラスは、w3c SVG2 推奨事項に基づいています。この名前空間を使用すると、要件に応じて SVG ファイルを読み込み、ナビゲート、またはレンダリングできます。 |
| [Aspose.Svg.Builder](./aspose.svg.builder/) | **Aspose.Svg.Builder** 名前空間には、Aspose.SVG ライブラリを使用して SVG（Scalable Vector Graphics）ドキュメントを構築および操作するためのクラスとインターフェイスが含まれています。この名前空間は、SVG 要素とその属性の作成と変更を簡素化する豊富なビルダー クラスを提供します。これらのビルダーは流暢な API を提供し、コードをより読みやすく、保守しやすくします。 |
| [Aspose.Svg.Collections](./aspose.svg.collections/) | **Aspose.Svg.Collections** 名前空間は、ノードや要素を表現、保存、操作するクラスで構成されています。 |
| [Aspose.Svg.Converters](./aspose.svg.converters/) | **Aspose.Svg.Converters** 名前空間の目的は、変換メソッドへの簡単なアクセスを提供することです。PDF、XPS、画像フォーマットなどの一般的なフォーマットへの幅広い変換を提供します。より具体的な変換（レンダリング、保存）ユースケースは、対象別名前空間にあるよく知られた文書化された低レベル API 関数で提示されます。 |
| [Aspose.Svg.DataTypes](./aspose.svg.datatypes/) | この名前空間は、すべての SVG 固有のデータ型へのアクセスを提供します。 |
| [Aspose.Svg.Diagnostics](./aspose.svg.diagnostics/) | **Aspose.Svg.Diagnostics** 名前空間には、メトリクスの操作やログ・トレースの収集のためのインターフェイスが含まれています。 |
| [Aspose.Svg.Dom](./aspose.svg.dom/) | **Aspose.Svg.Dom (Document Object Model)** 名前空間は、任意の HTML、XML、または SVG ドキュメントを表現し、操作する API を提供します。DOM はブラウザで読み込まれるドキュメントモデルで、ドキュメントをノードツリーとして表現し、各ノードはドキュメントの一部（例：要素、テキスト文字列、コメント）を表します。 |
| [Aspose.Svg.Dom.Attributes](./aspose.svg.dom.attributes/) | **Aspose.Svg.Dom.Attributes** 名前空間には、任意のオブジェクト（ノード、要素など）の機能や動作を指定または限定する統一された属性クラスが含まれています。 |
| [Aspose.Svg.Dom.Css](./aspose.svg.dom.css/) | **Aspose.Svg.Dom.Css** 名前空間は、すべての CSS 関連操作のためのものです。CSS 公式文書で指定された CSS プロパティ名と値のペアに集中しています。 |
| [Aspose.Svg.Dom.Events](./aspose.svg.dom.events/) | **Aspose.Svg.Dom.Events** 名前空間は、DOM の更新に関連するあらゆるイベントのオブジェクトを提供します。イベントに関連付けられた特定のコンテキスト情報の観測へのサブスクリプションやカスタムイベントの構築が含まれます。 |
| [Aspose.Svg.Dom.Mutations](./aspose.svg.dom.mutations/) | **Aspose.Svg.Dom.Mutations** は、DOM の変異を観測し、特定のコールバック情報を取得する機会を提供します。 |
| [Aspose.Svg.Dom.Traversal](./aspose.svg.dom.traversal/) | **Aspose.Svg.Dom.Traversal** 名前空間には、要素間をナビゲートし、ドキュメント順でノードとその子を走査するイテレータやツリーワーカーを作成するメソッドが含まれています。 |
| [Aspose.Svg.Dom.Traversal.Filters](./aspose.svg.dom.traversal.filters/) | この名前空間はノードフィルタリング機能を表します。フィルタはノードを\"除外\"する方法を知っているオブジェクトです。ノードイテレータまたはツリーワーカーにノードフィルタが与えられると、次のノードを返す前にフィルタが適用されます。フィルタがノードを受け入れると、走査ロジックはそれを返します。そうでなければ、走査は次のノードを探し、拒否されたノードが存在しなかったかのように振る舞います。 |
| [Aspose.Svg.Dom.Views](./aspose.svg.dom.views/) | **Aspose.Svg.Dom.Views** 名前空間は、Document Object Model Views 仕様に従って AbstractView と DocumentView インターフェイスを記述します。 |
| [Aspose.Svg.Dom.XPath](./aspose.svg.dom.xpath/) | **Aspose.Svg.Dom.XPath** 名前空間には、XML ドキュメント内の要素や属性をナビゲートするメソッドが含まれています。 |
| [Aspose.Svg.Drawing](./aspose.svg.drawing/) | **Aspose.Svg.Drawing** 名前空間には、測定と単位を指定するオブジェクトやインターフェイス、ブラシ、カラー、フォントなどの描画属性オブジェクトが含まれています。 |
| [Aspose.Svg.Events](./aspose.svg.events/) | この名前空間は、時間イベントやズームなどのイベントベースのインタラクティブ機能のためのクラスで構成されています。 |
| [Aspose.Svg.Filters](./aspose.svg.filters/) | **Aspose.Svg.Dom.Svg.Filters** 名前空間には、SVG 仕様のフィルタ効果に関連するクラスとインターフェイスが含まれています。 |
| [Aspose.Svg.ImageVectorization](./aspose.svg.imagevectorization/) | **Aspose.Svg.ImageVectorization** 名前空間には、ラスタ画像をベクトル化し SVG ドキュメントに変換するクラスが含まれています。このプロセスは、ビットマップをパス要素からなる幾何学的形状に変換し、SVG として保存することを伴います。名前空間には、パスセグメントの構築、トレースポイントの単純化と平滑化、ベクトル化オプションの設定のためのクラスが含まれています。 |
| [Aspose.Svg.IO](./aspose.svg.io/) | 標準的な IO（入出力）ツールに加えて、**Aspose.Svg.IO** 名前空間にはヘルパークラスとインターフェイスが含まれています。 |
| [Aspose.Svg.Net](./aspose.svg.net/) | **Aspose.Svg.Net** 名前空間は、簡単なネットワーク処理を支援するクラスとインターフェイスによって構成されています。 |
| [Aspose.Svg.Net.Headers](./aspose.svg.net.headers/) | **Aspose.Svg.Net.Headers** は、ネットワーク時のヘッダー内容を記述するためのデータクラスをいくつか提供します。 |
| [Aspose.Svg.Net.MessageFilters](./aspose.svg.net.messagefilters/) | **Aspose.Svg.Net.MessageFilters** 名前空間は、メッセージフィルタの抽象化を実装するクラスを提供します。 |
| [Aspose.Svg.Net.MessageHandlers](./aspose.svg.net.messagehandlers/) | **Aspose.Svg.Net.MessageHandlers** 名前空間は、さまざまなプロトコルのメッセージハンドラであるクラスによって構成されています。 |
| [Aspose.Svg.Paths](./aspose.svg.paths/) | **Aspose.Svg.Dom.Svg.Paths** 名前空間は、塗りつぶしやストロークが可能な形状の輪郭を表現するクラスを説明します。パスはクリッピングパスとして、アニメーションの記述やテキストの配置にも使用できます。 |
| [Aspose.Svg.Rendering](./aspose.svg.rendering/) | **Aspose.Svg.Rendering** 名前空間は、ドキュメント/ファイルを IDevice 実装にレンダリングする責任を持つ多数のレンダラーオブジェクトと、適切な低レベルオプションクラスで構成されています。 |
| [Aspose.Svg.Rendering.Fonts](./aspose.svg.rendering.fonts/) | **Aspose.Svg.Rendering.Fonts** 名前空間には、フォントマッチングアルゴリズムの一部を制御できるクラスとメソッドが含まれています。 |
| [Aspose.Svg.Rendering.Image](./aspose.svg.rendering.image/) | **Aspose.Svg.Rendering.Image** 名前空間は、ラスタ形式（jpeg、png、bmp、gif、tiff）へのレンダリングを担当する特定のデバイスクラスといくつかのレンダリングオプションクラスを提供します。 |
| [Aspose.Svg.Rendering.Pdf](./aspose.svg.rendering.pdf/) | **Aspose.Svg.Rendering.Pdf** 名前空間は、PDF ドキュメントへのレンダリングを担当する特定のデバイスクラスといくつかのレンダリングオプションクラスを提供します。 |
| [Aspose.Svg.Rendering.Pdf.Encryption](./aspose.svg.rendering.pdf.encryption/) | **Aspose.Svg.Rendering.Pdf.Encryption** 名前空間には、パスワードや暗号化アルゴリズムなど、PDF 暗号化の詳細を記述するデータクラスが含まれています。 |
| [Aspose.Svg.Rendering.Xps](./aspose.svg.rendering.xps/) | **Aspose.Svg.Rendering.Xps** 名前空間は、XPS ドキュメントへのレンダリングを担当する特定のデバイスクラスといくつかのレンダリングオプションクラスを提供します。 |
| [Aspose.Svg.Saving](./aspose.svg.saving/) | **Aspose.Svg.Saving** 名前空間は、変換/保存プロセスにおける特定の保存オプションを記述するデータクラスによって構成されています。 |
| [Aspose.Svg.Saving.ResourceHandlers](./aspose.svg.saving.resourcehandlers/) | **Aspose.Svg.Saving.ResourceHandlers** 名前空間には、リソースの処理を担当するクラスが含まれています。 |
| [Aspose.Svg.Services](./aspose.svg.services/) | **Aspose.Svg.Services** 名前空間には、サービス実装のプロトコルとしてのインターフェイスが含まれています。 |
| [Aspose.Svg.Toolkit.Optimizers](./aspose.svg.toolkit.optimizers/) | **Aspose.Svg.Toolkit.Optimizers** 名前空間には、SVG ドキュメントを最適化するクラスが含まれています。最適化プロセスは、未使用または不可視の要素とその属性の削除、グループの統合、パスセグメントのサイズ削減を行います。 |
| [Aspose.Svg.Window](./aspose.svg.window/) | **Aspose.Svg.Window** 名前空間は、DOM ドキュメントを含むウィンドウを表すウィンドウオブジェクトに関連しています。アクティブなドキュメントのアドレスや閲覧履歴に関するクラスとインターフェイスが含まれます。 |

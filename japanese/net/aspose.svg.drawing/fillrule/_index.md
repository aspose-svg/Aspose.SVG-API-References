## FillRule enumeration

SVG および HTML のレンダリングで使用される塗りつぶしルールを指定します。

```csharp
public enum FillRule
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| EvenOdd | `0` | 偶数-奇数規則を使用して塗り領域を決定します。この動作は System.Drawing.Drawing2D.FillMode.Alternate に対応します。 |
| Nonzero | `1` | 非ゼロ規則を使用して塗り領域を決定します。この動作は System.Drawing.Drawing2D.FillMode.Winding に対応します。 |

**Aspose.Svg.Drawing** 名前空間には、測定と単位を指定するオブジェクトやインターフェイス、ブラシ、カラー、フォントなどの描画属性オブジェクトが含まれています。

## クラス

| クラス | 説明 |
| --- | --- |
| [Angle](./angle/) | 角度データ型 |
| [Color](./color/) | Color クラスを使用すると、赤緑青 (RGB) 値、色相-彩度-輝度 (HSL) 値、色相-彩度-明度 (HSV) 値、色相-白度-黒度 (HWB) 値、光度-A-B (LAB) 値、輝度-クロマ-色相 (LCH) 値、シアン-マゼンタ-イエロー-キー (CMYK) 値、自然色 (NCOL) 値、またはカラー名で色を指定できます。透明度を示すアルファチャンネルも利用可能です。 |
| [Dimension](./dimension/) | 次元の基底クラスを提供します。一般的に「次元」とは単位が付随した数値を指し、[`UnitType`](../aspose.svg.drawing/unittype/) で表されます。 |
| [Frequency](./frequency/) | 「frequency」単位。 |
| [Length](./length/) | 長さ測定単位を表します。 |
| [LengthOrAuto](./lengthorauto/) | 長さまたは「auto」単位を格納するコンテナを表します。 |
| [Margin](./margin/) | ページ余白を表します。 |
| [Numeric](./numeric/) | 数値型の基底クラスを提供します。 |
| [Page](./page/) | ページオブジェクトを表し、出力ページの設定に使用されます。ページサイズの既定値は A4（210×297mm）です。 |
| [Resolution](./resolution/) | 解像度単位を表します。 |
| [Size](./size/) | 高さと幅を指定する値を格納します。 |
| [Time](./time/) | 時間単位を表します。 |
| [Unit](./unit/) | 測定単位の基底クラスを提供します。 |
| [UnitType](./unittype/) | 測定単位を指定します。 |
## インターフェイス

| インターフェイス | 説明 |
| --- | --- |
| [IBrush](./ibrush/) | ブラシタイプを取得するメソッドを宣言します。 |
| [IColorComponents](./icolorcomponents/) | カラーコンポーネントを処理するメソッドとプロパティを宣言します。 |
| [IDrawingFactory](./idrawingfactory/) | 描画関連オブジェクトを作成するファクトリを表します。 |
| [IGradientBrush](./igradientbrush/) | グラデーションブラシの共通プロパティを取得するメソッドを宣言します。 |
| [IInterpolationColor](./iinterpolationcolor/) | 補間色を取得するためのメソッドを宣言します。 |
| [ILinearGradientBrush](./ilineargradientbrush/) | 線形グラデーションを持つブラシのインターフェイスを定義します。 |
| [IMatrix](./imatrix/) | 変換に使用される行列を表します。 |
| [ISolidBrush](./isolidbrush/) | 単一色のブラシインターフェイスを定義します |
| [ITextureBrush](./itexturebrush/) | 画像を使用して形状の内部を塗りつぶすブラシインターフェイスを定義します。 |
| [ITransformableBrush](./itransformablebrush/) | 変換行列とラップモードを取得するメソッドを宣言します。 |
| [ITrueTypeFont](./itruetypefont/) | TrueType フォントを操作するためのメソッドを宣言します。 |
## 列挙型

| 列挙型 | 説明 |
| --- | --- |
| [BrushType](./brushtype/) | ブラシのタイプを指定します。 |
| [ColorModel](./colormodel/) | この列挙は、カラーコンポーネントを操作するためのカラーモデルを選択するために使用されます。 |
| [FillRule](./fillrule/) | SVG および HTML のレンダリングで使用される塗りつぶしルールを指定します。 |
| [SpreadMode](./spreadmode/) | テクスチャまたはグラデーションが塗りつぶし領域より小さい場合のタイル配置方法を指定します。 |
| [StrokeLineCap](./strokelinecap/) | SVG および HTML のレンダリングで使用されるラインキャップを指定します。 |
| [StrokeLineJoin](./strokelinejoin/) | SVG および HTML のレンダリングで使用されるラインジョインスタイルを指定します。 |
| [WebFontStyle](./webfontstyle/) | テキストに適用される書式設定を指定します。 |
| [WebImageFormat](./webimageformat/) | サポートされている画像形式を指定します。 |
| [WebMatrixOrder](./webmatrixorder/) | 行列変換が適用される順序を指定します。 |

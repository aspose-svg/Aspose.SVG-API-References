## Element.LocalName property

このノードの修飾名のローカル部分を返します。ELEMENT_NODE と ATTRIBUTE_NODE 以外のタイプのノードや、Document.createElement() のような DOM Level 1 メソッドで作成されたノードの場合、常に null が返されます。

```csharp
public override string LocalName { get; }
```

### Property Value

ローカルの名前です。

## Node.PreviousSibling property

指定されたノードの直前にあるノードを、親の [`ChildNodes`](../childnodes/) リストから返します。指定されたノードがリストの最初の場合は null を返します。

```csharp
public Node PreviousSibling { get; }
```

### Property Value

[`Node`](../) は現在のノードの前の兄弟ノードを表し、存在しない場合は null です。

## Node.OwnerDocument property

ノードのトップレベルのドキュメントオブジェクトを返します。

```csharp
public virtual Document OwnerDocument { get; }
```

### Property Value

すべての子ノードが作成されるトップレベルオブジェクトである [`Document`](../../document/)。

このプロパティがドキュメント自体であるノードに使用された場合、値は null です。

## Node.NextSibling property

指定されたノードの親の[`ChildNodes`](../childnodes/) の中で直後にあるノードを返します。指定されたノードが親要素の最後の子である場合は null を返します。

```csharp
public Node NextSibling { get; }
```

### Property Value

現在のノードの次の兄弟ノードを表す[`Node`](../)、存在しない場合は null。

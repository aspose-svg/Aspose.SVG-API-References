## Node.LastChild property

ノードの最後の子ノードを返します。親が要素の場合、子は通常要素ノード、テキストノード、またはコメントノードです。子要素がない場合は null を返します。

```csharp
public Node LastChild { get; }
```

### Property Value

ノードの最後の子である [`Node`](../) 、子要素がない場合は null です。

## Node.FirstChild property

ツリー内でノードの最初の子ノードを返します。子が存在しない場合は null を返します。

ノードが Document の場合、このプロパティは直接の子ノードのリストの最初のノードを返します。

```csharp
public Node FirstChild { get; }
```

### Property Value

[`Node`](../)、または存在しない場合は null。

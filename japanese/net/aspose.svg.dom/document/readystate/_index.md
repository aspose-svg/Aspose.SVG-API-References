## Document.ReadyState property

文書の準備状態を返します。Document が読み込み中のときは "loading"、解析が完了しサブリソースの読み込みが続いているときは "interactive"、読み込みが完了したときは "complete"。

```csharp
public string ReadyState { get; }
```

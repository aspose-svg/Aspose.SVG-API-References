## Document.DefaultView property

Document インターフェイスの defaultView IDL 属性は、取得時に、この Document に関連付けられた閲覧コンテキストがある場合はその閲覧コンテキストの WindowProxy オブジェクトを返し、そうでない場合は null を返さなければなりません。

```csharp
public IWindow DefaultView { get; }
```

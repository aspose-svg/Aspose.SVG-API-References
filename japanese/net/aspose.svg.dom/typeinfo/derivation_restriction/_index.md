## TypeInfo.DERIVATION_RESTRICTION field

ドキュメントのスキーマが XML スキーマ [XML Schema Part 1] の場合、この定数は、複合型が関与している場合は制限による派生、単純型が関与している場合は制限を表します。

```csharp
public const ulong DERIVATION_RESTRICTION;
```

## ToggleAttribute(*string*) {#toggleattribute}

force가 제공되지 않으면 qualifiedName을 토글하여 존재하면 제거하고 존재하지 않으면 추가합니다. force가 true이면 qualifiedName을 추가합니다. force가 false이면 qualifiedName을 제거합니다.

```csharp
public bool ToggleAttribute(string qualifiedName)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| qualifiedName | String | QualifiedName 속성. |

### 반환 값

qualifiedName이 현재 존재하면 true를 반환하고, 그렇지 않으면 false를 반환합니다.

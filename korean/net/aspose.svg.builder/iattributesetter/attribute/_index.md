## IAttributeSetter.Attribute method

SVG 요소에 속성을 설정하거나 업데이트합니다.

```csharp
public void Attribute(string name, string value)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| 이름 | String | 설정할 속성의 이름입니다. 유효한 SVG 속성 이름이어야 합니다. |
| 값 | String | 속성에 할당할 값입니다. 해당 SVG 속성에 적합한 문자열 표현이어야 합니다. |

## 비고

이 메서드는 SVG 요소를 구성하는 과정에서 속성을 동적으로 추가하거나 수정하는 데 사용됩니다. 다양한 조건이나 입력에 따라 속성을 설정할 수 있게 하여 SVG 요소를 정의하고 사용자 정의하는 유연성을 제공합니다.

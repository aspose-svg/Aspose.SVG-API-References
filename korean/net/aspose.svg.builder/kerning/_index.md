## Kerning enumeration

SVG 텍스트에 대한 커닝 동작을 지정합니다.

```csharp
public enum Kerning
```

### 값들

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Auto | `0` | 브라우저가 커닝을 적용할지 여부를 결정하도록 허용합니다. |
| Normal | `1` | 폰트 파일에 정의된 표준 커닝을 적용합니다. |
| None | `2` | 커닝을 비활성화하고 폰트의 커닝 정보를 무시합니다. |

## 비고

SVG의 'font-kerning' 속성은 폰트에 저장된 커닝 정보의 사용을 제어합니다. 커닝은 개별 문자 쌍 사이의 간격을 조정하여 텍스트의 시각적 모습을 개선합니다. 이 열거형은 SVG 텍스트 요소에서 커닝 동작을 제어하는 옵션을 제공합니다.

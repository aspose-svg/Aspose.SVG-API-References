## CompositeOperator enumeration

SVG 합성 작업에 적용될 합성 연산 유형을 지정합니다.

```csharp
public enum CompositeOperator
```

### 값들

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Over | `0` | 소스 그래픽을 대상 그래픽 위에 배치합니다. |
| In | `1` | 소스 그래픽이 대상 그래픽과 겹치는 부분을 표시합니다. |
| Out | `2` | 소스 그래픽이 대상 그래픽과 겹치지 않는 부분을 표시합니다. |
| Atop | `3` | 소스 그래픽을 대상 그래픽 위에 표시합니다. |
| Xor | `4` | 소스 그래픽이 대상 그래픽과 겹치지 않는 부분과 그 반대 부분을 표시합니다. |
| Arithmetic | `5` | 사용자 정의 산술 합성 연산을 허용합니다. |

## 비고

SVG에서의 합성 연산은 두 그래픽 요소가 단일 이미지로 결합되는 방식을 결정합니다. 각 연산자는 이러한 요소들을 혼합하거나 결합하는 고유한 방법을 정의합니다.

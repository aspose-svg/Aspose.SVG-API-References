## ChannelSelector enumeration

SVG 필터 작업에 사용할 채널 선택자를 지정합니다.

```csharp
public enum ChannelSelector
```

### 값들

| 이름 | 값 | 설명 |
| --- | --- | --- |
| R | `0` | 이미지의 빨간색 채널을 선택합니다. |
| G | `1` | 이미지의 녹색 채널을 선택합니다. |
| B | `2` | 이미지의 파란색 채널을 선택합니다. |
| A | `3` | 이미지의 알파(투명도) 채널을 선택합니다. |

## 비고

채널 선택기는 다양한 SVG 필터 기본 요소에서 특정 색 채널(빨강, 초록, 파랑) 또는 이미지의 알파 채널을 대상으로 사용됩니다. 이를 통해 필터 처리 중에 이러한 채널을 정밀하게 조작할 수 있습니다.

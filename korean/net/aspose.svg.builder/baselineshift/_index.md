## BaseLineShift enumeration

SVG에서 요소를 기준선에 대해 수직 위치를 지정합니다.

```csharp
public enum BaseLineShift
```

### 값들

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Sub | `0` | 요소의 기준선을 부모 텍스트의 아래첨자 기준선에 맞춥니다. |
| Super | `1` | 요소의 기준선을 부모 텍스트의 위첨자 기준선에 맞춥니다. |
| Top | `2` | 요소의 상단을 라인 박스의 상단에 맞춥니다. |
| Center | `3` | 요소를 라인 박스 중앙에 배치합니다. |
| Bottom | `4` | 요소의 하단을 라인 박스의 하단에 맞춥니다. |

## 비고

'baseline-shift' 속성은 SVG에서 요소를 기준선에 대해 수직 위치를 조정하는 데 사용되며, 특히 텍스트 렌더링에 유용합니다. 이 열거형은 기준선을 이동시켜 다양한 텍스트 효과를 구현할 수 있는 여러 옵션을 제공합니다.

## AlignmentBaseline enumeration

SVG에서 텍스트 및 기타 인라인 콘텐츠의 정렬 기준선을 지정합니다.

```csharp
public enum AlignmentBaseline
```

### 값들

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Baseline | `0` | 박스의 기준선을 부모 박스의 기준선에 맞춥니다. |
| TextBottom | `1` | 박스의 하단을 부모의 콘텐츠 영역 하단에 맞춥니다. |
| Middle | `2` | 박스의 중간을 부모의 콘텐츠 영역 중간에 맞춥니다. |
| Central | `3` | 박스의 중앙 기준선을 부모 박스의 중앙 기준선에 맞춥니다. |
| TextTop | `4` | 박스의 상단을 부모의 콘텐츠 영역 상단에 맞춥니다. |
| Ideographic | `5` | 박스의 표의 문자 기준선을 부모의 표의 문자 기준선에 맞춥니다. |
| Alphabetic | `6` | 박스의 알파벳 기준선을 부모의 알파벳 기준선에 맞춥니다. |
| Mathematical | `7` | 박스의 수학 기준선을 부모의 수학 기준선에 맞춥니다. |

## 비고

'alignment-baseline' 속성은 CSS Line Layout Module 3 사양에 정의되어 있습니다. SVG 2에서는 이 속성 정의에 변경 사항이 도입되었습니다.

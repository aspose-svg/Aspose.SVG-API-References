## Paint enumeration

SVG 요소의 fill 및 stroke 속성에 대한 페인트 옵션을 지정합니다.

```csharp
public enum Paint
```

### 값들

| 이름 | 값 | 설명 |
| --- | --- | --- |
| None | `0` | 페인트를 적용하지 않음을 나타냅니다. |
| ContextFill | `1` | 현재 컨텍스트의 fill 색상을 사용하여 페인팅합니다. |
| ContextStroke | `2` | 현재 컨텍스트의 stroke 색상을 사용하여 페인팅합니다. |

## 비고

이 열거형은 SVG 요소의 fill 및 stroke 속성에 적용될 수 있는 페인트 유형을 정의합니다. 표준 색상, 컨텍스트 기반 fill 및 stroke, 또는 페인트를 전혀 사용하지 않는 옵션을 제공합니다.

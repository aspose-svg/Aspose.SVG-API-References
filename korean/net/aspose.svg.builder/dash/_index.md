## Dash enumeration

```csharp
public enum Dash
```

### 값들

| 이름 | 값 | 설명 |
| --- | --- | --- |
| None | `0` | 대시가 없는 단색 스트로크를 나타냅니다. 이는 'stroke-dasharray'가 지정되지 않았을 때 기본 동작입니다. |

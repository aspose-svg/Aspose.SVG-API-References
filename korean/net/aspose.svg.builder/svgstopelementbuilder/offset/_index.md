## SVGStopElementBuilder.Offset method

'offset' 속성을 SVG 'stop' 요소에 설정하여, 그라디언트 내에서 색상 스톱의 위치를 지정합니다.

```csharp
public SVGStopElementBuilder Offset(double value, StopUnitType unitType = StopUnitType.Number)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| 값 | Double | 색상 스톱의 offset 값(숫자는 0~1, 백분율은 0%~100%). |
| unitType | StopUnitType | offset 값의 단위 유형(숫자 또는 백분율). |

### 반환 값

메서드 체이닝을 위한 SVGStopElementBuilder의 현재 인스턴스.

## LengthType enumeration

SVG에서 길이의 측정 단위를 지정합니다.

```csharp
public enum LengthType
```

### 값들

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Number | `1` | 단위가 없는 숫자 값을 나타냅니다. 이는 종종 다른 값이나 기본 단위와의 맥락에서 해석됩니다. |
| Percentage | `2` | 다른 값이나 경계 차원에 상대적인 백분율 값을 나타냅니다. |
| Ems | `3` | 'ems' 단위의 길이를 나타내며, 현재 글꼴 크기에 상대적인 확장 가능한 단위입니다. |
| Exs | `4` | 'exs' 단위의 길이를 나타내며, 현재 글꼴의 x-높이에 관련됩니다. |
| Px | `5` | 픽셀 단위의 길이를 나타내며, 이미지의 디지털 표현을 기반으로 하는 측정 단위입니다. |
| Cm | `6` | 센티미터 단위의 길이를 나타냅니다. |
| Mm | `7` | 밀리미터 단위의 길이를 나타냅니다. |
| In | `8` | 인치 단위의 길이를 나타냅니다. |
| Pt | `9` | 포인트 단위의 길이를 나타내며, 전통적인 타이포그래피 단위입니다. 1포인트는 약 1/72인치에 해당합니다. |
| Pc | `10` | 파이카(picas) 단위의 길이를 나타내며, 타이포그래피 측정 단위입니다. 1파이카는 12포인트와 동일합니다. |

## 비고

이 열거형은 SVG 요소에서 길이를 지정하는 데 사용할 수 있는 다양한 단위를 정의합니다. 이 단위에는 픽셀 및 센티미터와 같은 절대 측정값과 백분율 및 ems와 같은 상대 측정값이 포함됩니다.

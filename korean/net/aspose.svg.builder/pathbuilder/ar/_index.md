## PathBuilder.Ar method

```csharp
public PathBuilder Ar(double r1, double r2, double angle, bool largeArcFlag, bool sweepFlag, 
    double x, double y)
```

| 매개변수 | 형식 | 설명 |
| --- | --- | --- |
| r1 | Double | 현재 위치를 기준으로 하는 타원의 x-반경입니다. |
| r2 | Double | 현재 위치를 기준으로 하는 타원의 y-반경입니다. |
| angle | Double | 현재 위치를 기준으로 하는 타원의 회전 각도(도)입니다. |
| largeArcFlag | Boolean | 호가 180도 이상이어야 하는지를 나타내는 플래그. |
| sweepFlag | Boolean | 호가 양의 각도 방향으로 그려져야 하는지를 나타내는 플래그. |
| x | Double | 현재 위치를 기준으로 하는 호의 끝점 x좌표입니다. |
| y | Double | 현재 위치를 기준으로 하는 호의 끝점 y좌표입니다. |

## ColorMatrixOperation enumeration

public enum ColorMatrixOperation

### 값들

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Matrix | `0` | 색상 데이터에 매트릭스 변환을 적용합니다. |
| Saturate | `1` | 이미지의 채도 수준을 조정합니다. |

## 비고

SVG의 색상 매트릭스 필터는 이미지의 색상 데이터에 대해 다양한 작업을 수행할 수 있게 합니다. 각 작업 유형은 색상을 특정 방식으로 조작하여 다양한 시각 효과를 제공합니다.

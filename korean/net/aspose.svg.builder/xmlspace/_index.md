## XmlSpace enumeration

XML 문서에서 요소 내부의 공백이 처리되는 방식을 지정합니다.

```csharp
public enum XmlSpace
```

### 값들

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Default | `0` | XML 프로세서의 기본 동작에 따라 공백을 처리해야 함을 나타내며, 일반적으로 줄 바꿈 및 여분의 공백을 제거하여 공백을 정규화합니다. |
| Preserve | `1` | XML 문서에 나타난 그대로 공백을 보존해야 함을 나타냅니다. 이는 공백이 중요한 텍스트의 서식을 유지하는 데 유용합니다. |

## 비고

XML의 'xml:space' 속성은 요소 내부의 공백을 보존할지 정규화할지를 제어하는 데 사용됩니다. 이 열거형은 XML 및 SVG 문서에서 이 동작을 설정할 옵션을 제공합니다.

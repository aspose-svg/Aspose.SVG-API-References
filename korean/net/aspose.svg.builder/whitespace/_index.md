## WhiteSpace enumeration

SVG 요소 내부의 공백이 처리되는 방식을 지정합니다.

```csharp
public enum WhiteSpace
```

### 값들

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Normal | `0` | 공백이 축소됩니다; 줄바꿈 문자는 새 줄을 생성합니다. |
| Pre | `1` | 공백이 보존됩니다; 텍스트는 줄바꿈 문자가 있는 경우에만 줄이 바뀝니다. |
| NoWrap | `2` | 공백이 축소됩니다; 텍스트가 줄 바꿈되지 않습니다. |
| PreWrap | `3` | 공백이 보존됩니다; 필요에 따라 텍스트가 줄 바꿈되고 개행 문자에서도 적용됩니다. |
| BreakSpaces | `4` | 공백이 보존됩니다; 줄 상자를 채우기 위해 줄 바꿈이 추가됩니다. |
| PreLine | `5` | 공백이 보존됩니다; 필요에 따라 텍스트가 줄 바꿈되지만 개행 문자는 없습니다. |

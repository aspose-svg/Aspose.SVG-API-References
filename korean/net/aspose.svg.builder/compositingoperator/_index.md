## CompositingOperator enumeration

SVG 마스킹 작업에 적용될 합성 연산 유형을 지정합니다.

```csharp
public enum CompositingOperator
```

### 값들

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Add | `0` | 소스 그래픽의 색상 값을 대상 그래픽에 추가합니다. |
| Subtract | `1` | 소스 그래픽의 색상 값을 대상 그래픽에서 빼냅니다. |
| Intersect | `2` | 소스와 대상 그래픽이 겹치는 영역만 표시합니다. |
| Exclude | `3` | 소스와 대상 그래픽이 겹치는 영역을 제외합니다. |

## 비고

SVG 마스크의 합성 연산자는 서로 다른 그래픽 요소가 어떻게 결합되어 마스크 효과를 만드는지를 결정합니다. 각 연산자는 이러한 요소들을 혼합하거나 결합하는 고유한 방법을 정의하여 다양한 마스크 효과를 구현합니다.

## ColorRendering enumeration

```csharp
public enum ColorRendering
```

### 값들

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Auto | `0` | 브라우저 또는 뷰어가 색상 렌더링 모드를 선택하도록 허용하며, 속도와 품질 사이의 균형을 맞춥니다. |
| OptimizeSpeed | `1` | 색상 정밀도와 시각적 품질보다 렌더링 속도를 우선시합니다. |

## 비고

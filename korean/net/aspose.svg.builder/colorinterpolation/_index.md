## ColorInterpolation enumeration

SVG 요소 및 필터에 대한 색상 보간 모드를 지정합니다.

```csharp
public enum ColorInterpolation
```

### 값들

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Auto | `0` | 색 보간 모드를 자동으로 결정합니다. |
| SRGB | `1` | 색 보간에 표준 RGB 색 공간(sRGB)을 사용합니다. |
| LinearRGB | `2` | 색 보간에 선형 RGB 색 공간을 사용합니다. |

## 비고

SVG에서 색 보간은 그래픽 요소와 필터 효과 모두에서 색상이 계산되고 혼합되는 방식을 영향을 줍니다. 다양한 모드는 색상 전환, 그라디언트 및 전체 색상 렌더링의 외관에 크게 영향을 미칠 수 있습니다. 이 설정은 SVG 그래픽에서 원하는 시각적 결과를 달성하는 데 필수적입니다.

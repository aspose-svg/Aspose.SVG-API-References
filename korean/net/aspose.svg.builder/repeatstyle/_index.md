## RepeatStyle enumeration

SVG에서 배경 이미지 또는 패턴에 대한 반복 스타일을 지정합니다.

```csharp
public enum RepeatStyle
```

### 값들

| 이름 | 값 | 설명 |
| --- | --- | --- |
| RepeatX | `0` | 이미지 또는 패턴이 가로 방향으로만 반복됩니다. |
| RepeatY | `1` | 이미지 또는 패턴이 수직으로만 반복됩니다. |
| Repeat | `2` | 이미지 또는 패턴이 가로와 세로 모두 반복됩니다. |
| Space | `3` | 이미지 또는 패턴이 잘리지 않도록 가능한 한 많이 반복되며, 남은 공간은 이미지들 사이에 고르게 분배됩니다. |
| Round | `4` | 이미지 또는 패턴이 비율을 유지하면서 맞게 크기가 조정되고, 잘리지 않게 반복됩니다. |
| NoRepeat | `5` | 이미지 또는 패턴이 반복되지 않으며, 이미지 한 개만 그려집니다. |

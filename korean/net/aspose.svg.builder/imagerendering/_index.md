## ImageRendering enumeration

SVG에서 이미지가 렌더링되는 방식을 지정합니다.

```csharp
public enum ImageRendering
```

### 값들

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Auto | `0` | 브라우저는 이미지를 렌더링할 때 속도와 품질 사이에서 균형을 맞춥니다. |
| OptimizeSpeed | `1` | 브라우저는 이미지 품질보다 렌더링 속도를 강조합니다. 이는 종종 이미지를 확대/축소할 때 픽셀화되거나 거칠게 보이게 할 수 있습니다. |
| OptimizeQuality | `2` | 브라우저는 렌더링 속도보다 이미지 품질을 강조합니다. 이는 이미지가 더 부드럽고 고품질로 확대/축소될 수 있지만 렌더링 속도가 느려질 수 있음을 의미합니다. |

## AngleUnits enumeration

SVG에서 마커 방향을 정의하는 데 사용되는 각도의 단위를 지정합니다.

```csharp
public enum AngleUnits
```

### 값들

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Degrees | `0` | 각도를 도(degree) 단위로 지정합니다. 전체 원은 360도입니다. |
| Gradians | `1` | 각도를 그라디언트 단위로 지정합니다. 전체 원은 400 그라디언트입니다. |
| Radians | `2` | 각도를 라디안 단위로 지정합니다. 전체 원은 약 6.283 라디안(2π 라디안)입니다. |
| None | `3` | 특정 각도 단위가 없음을 나타냅니다. 기본값이나 상황에 따라 설정할 때 사용됩니다. |

## 비고

SVG 마커의 'orient' 속성은 다양한 각도 단위로 지정할 수 있습니다. 이 열거형은 이러한 단위를 설정할 옵션을 제공합니다.

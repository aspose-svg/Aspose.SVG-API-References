De code bevat een tekenreeks die de fysieke toets identificeert die wordt ingedrukt. De waarde wordt niet beïnvloed door de huidige toetsenbordindeling of modifier‑status, zodat een bepaalde toets altijd dezelfde waarde retourneert.

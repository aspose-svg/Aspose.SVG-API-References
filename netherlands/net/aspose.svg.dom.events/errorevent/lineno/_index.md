## ErrorEvent.LineNo property

Het attribuut lineno moet de waarde retourneren waarmee het is geïnitialiseerd. Wanneer het object wordt aangemaakt, moet dit attribuut worden geïnitialiseerd op nul. Het vertegenwoordigt het regelnummer waarop de fout in het script optrad.

```csharp
public uint LineNo { get; }
```

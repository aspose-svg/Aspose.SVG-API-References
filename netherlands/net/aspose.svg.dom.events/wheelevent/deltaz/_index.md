## WheelEvent.DeltaZ property

In user agents waar de standaardactie van de wheel‑event is om te scrollen, moet de waarde de meting langs de z-as (in pixels, regels of pagina's) zijn die moet worden gescrold in het geval dat de gebeurtenis niet wordt geannuleerd. Anders is dit een implementatie‑specifieke meting (in pixels, regels of pagina's) van de beweging van een wielapparaat rond de z-as.

public double DeltaZ { get; }

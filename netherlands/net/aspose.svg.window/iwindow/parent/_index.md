## IWindow.Parent property

Het parent IDL-attribuut op het Window-object van een Document in een browsing context b moet het WindowProxy-object van de bovenliggende browsing context teruggeven, als die bestaat (d.w.z. als b een child‑browsing‑context is), of anders het WindowProxy-object van de browsing context b zelf (d.w.z. als het een top‑level browsing context of een losgekoppelde geneste browsing context is).

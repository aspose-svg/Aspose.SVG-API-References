## ResourceHandlingOptions.MaxHandlingDepth property

Haalt op of stelt de maximale diepte van pagina's in die worden verwerkt. Een diepte van 1 betekent dat alleen pagina's die rechtstreeks vanuit het opgeslagen document worden gerefereerd, worden verwerkt. Het instellen van deze eigenschap op -1 leidt tot het verwerken van alle pagina's. Standaardwaarde is 0.

```csharp
public int MaxHandlingDepth { get; set; }
```

## SVGDocument.Referrer property

Retourneert de URI van de pagina die naar deze pagina heeft gelinkt. De waarde is een lege string als de gebruiker rechtstreeks naar de pagina is genavigeerd (niet via een link, maar bijvoorbeeld via een bladwijzer).

```csharp
public string Referrer { get; }
```

### Property Value

De referrer.

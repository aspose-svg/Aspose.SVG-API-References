## Configuration.Security property

Deze eigenschap stelt u in staat een aantal beperkingen in te stellen op de inhoud die in het frame wordt geladen, bijvoorbeeld het blokkeren van formulieren en scripts. Raadpleeg het artikel over [sandboxing](https://docs.aspose.com/html/net/environment-configuration/#sandboxing).

```csharp
public Sandbox Security { get; set; }
```

### Property Value

Een [`Sandbox`](../../sandbox/) vlagset is een verzameling van nul of meer vlaggen, die worden gebruikt om de mogelijkheden van mogelijk onbetrouwbare bronnen te beperken.

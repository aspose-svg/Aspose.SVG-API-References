## SVGSVGElement.CreateSVGTransformFromMatrix method

Maakt een SVGTransform‑object aan buiten enige documentbomen. Het object wordt geïnitialiseerd met de opgegeven matrix‑transformatie (d.w.z. SVG_TRANSFORM_MATRIX). De waarden uit de parameter‑matrix worden gekopieerd; de matrix‑parameter wordt niet overgenomen als SVGTransform::matrix.

```csharp
public SVGTransform CreateSVGTransformFromMatrix(SVGMatrix matrix)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| matrix | SVGMatrix | De transformatiesmatrix. |

### Retourwaarde

Een SVGTransform-object.

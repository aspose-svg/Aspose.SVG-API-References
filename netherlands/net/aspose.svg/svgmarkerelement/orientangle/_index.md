## SVGMarkerElement.OrientAngle property

Komt overeen met het attribuut ‘orient’ op het opgegeven ‘marker’-element. Als markerUnits gelijk is aan SVG_MARKER_ORIENT_ANGLE, dan is de hoekwaarde voor het attribuut ‘orient’; anders wordt deze op nul gezet.

```csharp
public SVGAnimatedAngle OrientAngle { get; }
```

### Property Value

Het attribuut ‘orient’ van het opgegeven ‘marker’-element.

## Attr.LocalName property

Retourneert het lokale deel van de gekwalificeerde naam van deze node. Voor knooppunten van elk type anders dan ELEMENT_NODE en ATTRIBUTE_NODE en knooppunten die zijn gemaakt met een DOM Level 1-methode, zoals Document.createElement(), is dit altijd null.

```csharp
public override string LocalName { get; }
```

### Property Value

De naam van het lokale.

## Document.GetElementsByTagNameNS method

Retourneert een lijst van elementen met de opgegeven tagnaam die tot de opgegeven namespace behoren. Het volledige document wordt doorzocht, inclusief de root‑knoop.

```csharp
public HTMLCollection GetElementsByTagNameNS(string namespaceURI, string localName)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| namespaceURI | String | De namespace‑URI van te zoeken elementen. |
| localName | String | Ofwel de lokale naam van te zoeken elementen of de speciale waarde *, die overeenkomt met alle elementen. |

### Retourwaarde

Een live [`NodeList`](../../../aspose.svg.collections/nodelist/) van gevonden elementen in de volgorde waarin ze in de boom verschijnen.

## Opmerkingen

Zie de officiële [spec](https://dom.spec.whatwg.org/#dom-document-getelementsbytagnamens).

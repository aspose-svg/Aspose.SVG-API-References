## Document.CreateAttributeNS method

Deze methode maakt een nieuw attribuutknooppunt aan en geeft het terug. Het gecreëerde object is een knooppunt dat de [`Attr`](../../attr/)‑klasse implementeert. De DOM dwingt niet af welke soorten attributen op deze manier aan een bepaald element kunnen worden toegevoegd.

```csharp
public Attr CreateAttributeNS(string namespaceURI, string qualifiedName)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| namespaceURI | String | De namespace-URI van het attribuut. |
| qualifiedName | String | is een tekenreeks die de naam van het attribuut bevat. |

### Retourwaarde

De [`Attr`](../../attr/).

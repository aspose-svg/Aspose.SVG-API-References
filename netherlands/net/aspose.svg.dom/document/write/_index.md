## Document.Write method

Schrijf een tekenreeks tekst naar een documentstroom die is geopend met open(). Merk op dat de functie een document kan produceren dat niet noodzakelijkerwijs wordt aangestuurd door een DTD en daarom een ongeldig resultaat kan opleveren in de context van het document.

```csharp
public void Write(params string[] texts)
```

## TypeInfo.DERIVATION_RESTRICTION field

Als het schema van het document een XML-schema is [XML Schema Part 1], vertegenwoordigt deze constante de afleiding door restrictie als complexe types betrokken zijn, of een restrictie als eenvoudige types betrokken zijn.

```csharp
public const ulong DERIVATION_RESTRICTION;
```

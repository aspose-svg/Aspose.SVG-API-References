## Node.NamespaceURI property

Retourneert de namespace-URI van het element, of null als het element zich niet in een namespace bevindt.

```csharp
public virtual string NamespaceURI { get; }
```

### Property Value

Een string die de namespace-URI van de gekwalificeerde naam van het element weergeeft.

## Node.NextSibling property

Retourneert het knooppunt dat direct volgt op het opgegeven knooppunt in de [`ChildNodes`](../childnodes/) van de ouder, of retourneert null als het opgegeven knooppunt het laatste kind is in het bovenliggende element.

```csharp
public Node NextSibling { get; }
```

### Property Value

Een [`Node`](../) die de volgende sibling van het huidige knooppunt vertegenwoordigt, of null als er geen zijn.

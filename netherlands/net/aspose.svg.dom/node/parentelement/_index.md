## Node.ParentElement property

Retourneert de bovenliggende [`Element`](../../element/) van de DOM‑knoop, of null als de knoop geen ouder heeft, of als de ouder geen DOM‑Element is.

```csharp
public Element ParentElement { get; }
```

### Property Value

## Node.InsertBefore method

Voegt het knooppunt in vóór het bestaande kindknooppunt child. Als child null is, wordt het knooppunt aan het einde van de lijst met kinderen ingevoegd. Als child een DocumentFragment-object is, worden al zijn kinderen, in dezelfde volgorde, vóór child ingevoegd. Als het kind al in de boom aanwezig is, wordt het eerst verwijderd.

```csharp
public Node InsertBefore(Node node, Node child)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| node | Node | Het nieuwe kind. |
| child | Node | Het referentie-kind. |

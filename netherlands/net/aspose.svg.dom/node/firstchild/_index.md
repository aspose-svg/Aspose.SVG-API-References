## Node.FirstChild property

Retourneert het eerste kind van de node in de boom, of null als de node geen kinderen heeft.

Als de knoop een Document is, retourneert deze eigenschap de eerste knoop in de lijst van zijn directe kinderen.

```csharp
public Node FirstChild { get; }
```

### Property Value

Een [`Node`](../), of null als er geen zijn.

## Node.PreviousSibling property

Retourneert de knoop die direct voorafgaat aan de opgegeven knoop in de [`ChildNodes`](../childnodes/) lijst van de ouder, of null als de opgegeven knoop de eerste in die lijst is.

```csharp
public Node PreviousSibling { get; }
```

### Property Value

Een [`Node`](../) die de vorige sibling van de huidige knoop vertegenwoordigt, of null als er geen is.

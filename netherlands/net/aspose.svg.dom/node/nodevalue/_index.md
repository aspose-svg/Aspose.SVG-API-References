## Node.NodeValue property

Retourneert of stelt de waarde van het huidige knooppunt in.

```csharp
public virtual string NodeValue { get; set; }
```

### Property Value

Een string die de waarde van de huidige knooppunt bevat, indien aanwezig. Voor het document zelf retourneert `NodeValue` null. Voor tekst-, commentaar- en CDATA-knooppunten retourneert `NodeValue` de inhoud van het knooppunt. Voor attribuutknooppunten wordt de waarde van het attribuut geretourneerd.

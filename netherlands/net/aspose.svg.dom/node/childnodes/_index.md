## Node.ChildNodes property

Retourneert een live [`NodeList`](../../../aspose.svg.collections/nodelist/) van kindknopen van het opgegeven element waarbij de eerste kindknoop index 0 krijgt. Kindknopen omvatten elementen, tekst en opmerkingen.

Opmerking: Het feit dat de [`NodeList`](../../../aspose.svg.collections/nodelist/) live is, betekent dat de inhoud elke keer wordt gewijzigd wanneer nieuwe kinderen worden toegevoegd of verwijderd.

```csharp
public NodeList ChildNodes { get; }
```

### Property Value

Een live [`NodeList`](../../../aspose.svg.collections/nodelist/) die de kinderen van de knoop bevat.

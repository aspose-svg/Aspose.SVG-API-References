## IStyleSheet.OwnerNode property

Het knooppunt dat dit stijlblad aan het document koppelt. Voor HTML kan dit het overeenkomstige LINK‑ of STYLE‑element zijn. Voor XML kan dit de koppel‑verwerkingsinstructie zijn. Voor stijlbladen die door andere stijlbladen worden opgenomen, is de waarde van dit attribuut null.

public Node OwnerNode { get; }

## ICSSRule.ParentRule property

Als deze regel zich binnen een andere regel bevindt (bijv. een stijlregel binnen een @media-blok), is dit de omvattende regel. Als deze regel niet genest is binnen andere regels, wordt null geretourneerd.

```csharp
public ICSSRule ParentRule { get; }
```

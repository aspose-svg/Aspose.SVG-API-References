## CSSValue.CSSText property

De CSSText eigenschap van de [`CSSValue`](../) interface vertegenwoordigt de momenteel berekende CSS-eigenschapswaarde.

Opmerking: Deze eigenschap maakte deel uit van een poging om een getypeerd CSS Object Model te creëren. Deze poging is opgegeven, en de meeste browsers implementeren het niet.

```csharp
public abstract string CSSText { get; set; }
```

### Property Value

Een DOMString die de huidige CSS-eigenschapswaarde vertegenwoordigt.

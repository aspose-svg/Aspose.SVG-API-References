## ICSSKeyframeRule.KeyText property

Dit attribuut vertegenwoordigt de keyframe‑selector als een door komma’s gescheiden lijst van procentwaarden. De sleutelwoorden ‘from’ en ‘to’ komen respectievelijk overeen met ‘0%’ en ‘100%’.

```csharp
public string KeyText { get; }
```

### Property Value

De sleuteltekst.

## ICSSImportRule.StyleSheet property

Het stijlblad waarnaar deze regel verwijst, indien het is geladen. De waarde van dit attribuut is null als het stijlblad nog niet is geladen of als het niet zal worden geladen (bijv. als het stijlblad bedoeld is voor een mediatype dat niet wordt ondersteund door de user agent).

```csharp
public ICSSStyleSheet StyleSheet { get; }
```

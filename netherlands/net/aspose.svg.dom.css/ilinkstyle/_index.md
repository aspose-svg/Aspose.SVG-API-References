## ILinkStyle interface

De LinkStyle interface biedt een mechanisme waarmee een stylesheet kan worden opgehaald van het knooppunt dat verantwoordelijk is voor het koppelen ervan aan een document. Een instantie van de LinkStyle interface kan worden verkregen met binding‑specifieke cast‑methoden op een instantie van een koppelingsknooppunt (HTMLLinkElement, HTMLStyleElement of ProcessingInstruction in DOM Level 2).

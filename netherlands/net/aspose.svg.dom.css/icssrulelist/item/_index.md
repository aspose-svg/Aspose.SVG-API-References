## ICSSRuleList indexer

Wordt gebruikt om een CSS‑regel op te halen via de methode item() (http://www.w3.org/TR/DOM-Level-2-Style/css.html#CSS-CSSRuleList). De volgorde in deze collectie vertegenwoordigt de volgorde van de regels in het CSS‑stijlblad. Als index groter dan of gelijk aan het aantal regels in de lijst is, retourneert dit null.

```csharp
public ICSSRule this[int index] { get; }
```

| index | De regel‑index |

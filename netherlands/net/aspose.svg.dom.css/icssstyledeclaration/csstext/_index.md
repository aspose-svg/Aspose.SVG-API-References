## ICSSStyleDeclaration.CSSText property

De parseerbare tekstuele weergave van het declaratieblok (exclusief de omringende accolades). Het instellen van dit attribuut resulteert in het parseren van de nieuwe waarde en het resetten van alle eigenschappen in het declaratieblok, inclusief het verwijderen of toevoegen van eigenschappen.

```csharp
public string CSSText { get; set; }
```

### Property Value

De CSS-tekst.

## ICSSMediaRule interface

De CSSMediaRule interface vertegenwoordigt een @media-regel in een CSS-stylesheet. Een @media-regel kan worden gebruikt om stijlregels voor specifieke mediatypen af te bakenen.

```csharp
public interface ICSSMediaRule : ICSSRule
```

| [Media](../../aspose.svg.dom.css/icssmediarule/media/) { get; } | Een lijst van mediatypen voor deze regel. |

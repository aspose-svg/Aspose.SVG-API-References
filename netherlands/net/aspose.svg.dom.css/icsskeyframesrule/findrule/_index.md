## ICSSKeyframesRule.FindRule method

De findRule‑methode retourneert de regel met een sleutel die overeenkomt met de opgegeven sleutel. Als zo’n regel niet bestaat, wordt een null‑waarde geretourneerd.

```csharp
public ICSSKeyframeRule FindRule(string key)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| sleutel | String | De sleutel die de te vinden regel beschrijft. De sleutel moet overeenkomen met een getal tussen 0 en 1, anders wordt de regel genegeerd. |

### Retourwaarde

De gevonden regel

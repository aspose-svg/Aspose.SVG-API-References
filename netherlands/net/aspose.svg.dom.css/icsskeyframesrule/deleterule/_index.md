## ICSSKeyframesRule.DeleteRule method

De deleteRule‑methode verwijdert de CSSKeyframeRule met de opgegeven sleutel. Als er geen regel met deze sleutel bestaat, doet de methode niets.

```csharp
public void DeleteRule(string key)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| sleutel | String | De sleutel die de te verwijderen regel beschrijft. De sleutel moet overeenkomen met een getal tussen 0 en 1, anders wordt de regel genegeerd. |

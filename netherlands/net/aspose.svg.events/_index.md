De naamruimte bestaat uit klassen voor op gebeurtenissen gebaseerde interactiviteit, zoals tijdgebeurtenissen en inzoomen.

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [SVGZoomEvent](./svgzoomevent/) | De zoomevenement treedt op wanneer de gebruiker een actie start die ervoor zorgt dat de huidige weergave van het SVG‑documentfragment wordt geschaald. Event‑handlers worden alleen herkend op ‘svg’-elementen. |
| [TimeEvent](./timeevent/) | De TimeEvent‑interface biedt specifieke contextuele informatie die verband houdt met tijdgebeurtenissen. De verschillende typen gebeurtenissen die kunnen optreden zijn: beginEvent, endEvent en repeatEvent. |

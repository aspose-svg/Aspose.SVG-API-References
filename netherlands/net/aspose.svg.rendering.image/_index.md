De **Aspose.Svg.Rendering.Image** namespace biedt een specifieke apparaatklasse evenals enkele renderoptieklassen die verantwoordelijk zijn voor het renderen naar rasterformaten: jpeg, png, bmp, gif, tiff.

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [ImageDevice](./imagedevice/) | Stelt het renderen naar rasterformaten voor: jpeg, png, bmp, gif, tiff. |
| [ImageRenderingOptions](./imagerenderingoptions/) | Stelt renderopties voor [`ImageDevice`](../aspose.svg.rendering.image/imagedevice/) voor. Deze optie wordt gebruikt om het uitvoer‑image‑formaat, compressie, resolutie enz. te specificeren. |
| [TextOptions](./textoptions/) | Stelt tekst‑renderopties voor [`ImageDevice`](../aspose.svg.rendering.image/imagedevice/) voor. |
## Enumeratie

| Enumeratie | Beschrijving |
| --- | --- |
| [Compression](./compression/) | Specificeert de mogelijke compressieschema's voor Tagged Image File Format (TIFF) bitmap‑afbeeldingen. |
| [ImageFormat](./imageformat/) | Specificeert het bestandsformaat van de afbeelding. |

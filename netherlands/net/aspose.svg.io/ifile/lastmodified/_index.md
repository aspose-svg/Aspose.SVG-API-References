## IFile.LastModified property

De laatst gewijzigde datum van het bestand. Bij ophalen, als gebruikersagenten deze informatie beschikbaar kunnen maken, moet dit een long long teruggeven die is ingesteld op het tijdstip waarop het bestand voor het laatst is gewijzigd, uitgedrukt in milliseconden sinds de Unix‑epoch.

public long LastModified { get; }

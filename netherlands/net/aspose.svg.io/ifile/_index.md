## IFile interface

Een File‑object is een Blob‑object met een name‑attribuut, dat een tekenreeks is; het kan binnen de webapplicatie via een constructor worden gemaakt, of is een verwijzing naar een byte‑reeks uit een bestand van het onderliggende (OS)‑bestandssysteem.

```csharp
public interface IFile : IBlob
```

## Eigenschappen

| Naam | Beschrijving |
| --- | --- |
| [LastModified](../../aspose.svg.io/ifile/lastmodified/) { get; } | De laatst gewijzigde datum van het bestand. Bij ophalen, als gebruikersagenten deze informatie beschikbaar kunnen maken, moet dit een long long teruggeven die is ingesteld op het tijdstip waarop het bestand voor het laatst is gewijzigd, uitgedrukt in milliseconden sinds de Unix‑epoch. |
| [Name](../../aspose.svg.io/ifile/name/) { get; } | De naam van het bestand. Bij ophalen moet dit de naam van het bestand als een string teruggeven. |

## IUserAgentService.Language property

De `Language` geeft de primaire taal op voor de inhoud van het element en voor alle attributen van het element die tekst bevatten. De waarde moet een geldige BCP 47‑taaltag zijn, of een lege tekenreeks. Het instellen van het attribuut op een lege tekenreeks geeft aan dat de primaire taal onbekend is.

```csharp
public string Language { get; set; }
```

### Property Value

De user agent-taal.

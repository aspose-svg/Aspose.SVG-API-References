## IRuntimeService.JavaScriptTimeout property

Haalt op of stelt TimeSpan in die de uitvoeringstijd van JavaScript beperkt. Als het script langer wordt uitgevoerd dan de opgegeven TimeSpan, wordt het geannuleerd. Je kunt een oneindige time‑out opgeven door TimeSpan gelijk te stellen aan -1 milliseconden. Standaardwaarde is 1 minuut.

```csharp
public TimeSpan JavaScriptTimeout { get; set; }
```

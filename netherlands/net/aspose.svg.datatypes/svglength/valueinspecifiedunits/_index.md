## SVGLength.ValueInSpecifiedUnits property

De waarde als een zwevend‑kommagetal, in de eenheden die door unitType worden uitgedrukt. Het instellen van dit attribuut zal ervoor zorgen dat value en valueAsString automatisch worden bijgewerkt om deze instelling weer te geven.

```csharp
public float ValueInSpecifiedUnits { get; set; }
```

### Property Value

De waarde in gespecificeerde eenheden.

## SVGAngle.ValueInSpecifiedUnits property

De hoekswaarde als een zwevendekommagetal, in de eenheden die worden uitgedrukt door unitType. Het instellen van dit attribuut zorgt ervoor dat value en valueAsString automatisch worden bijgewerkt om deze instelling weer te geven.

```csharp
public float ValueInSpecifiedUnits { get; set; }
```

### Property Value

De waarde in gespecificeerde eenheden.

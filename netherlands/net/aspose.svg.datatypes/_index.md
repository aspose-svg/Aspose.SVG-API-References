| --- | --- |

| [SVGAnimatedNumber](./svganimatednumber/) | Gebruikt voor attributen van het basistype number die geanimeerd kunnen worden. |
| [SVGAnimatedNumberList](./svganimatednumberlist/) | Gebruikt voor attributen die een lijst met getallen accepteren en die geanimeerd kunnen worden. |

| [SVGLength](./svglength/) | De SVGLength‑interface komt overeen met het basistype length. Een SVGLength‑object kan als alleen‑lezen worden gemarkeerd, wat betekent dat pogingen om het object te wijzigen een uitzondering veroorzaken, zoals hieronder beschreven. |
| [SVGLengthList](./svglengthlist/) | Deze interface definieert een lijst met SVGLength‑objecten. |
| [SVGMatrix](./svgmatrix/) | Veel van de grafische bewerkingen van SVG gebruiken 2x3‑matrices van de vorm: [a c e] [b d f] die, wanneer uitgebreid tot een 3x3‑matrix voor matrixrekenkunde, worden: [a c e] [b d f] [0 0 1] |
| [SVGNumber](./svgnumber/) | Gebruikt voor attributen van het basistype number. |
| [SVGNumberList](./svgnumberlist/) | Deze interface definieert een lijst met SVGNumber‑objecten. |
| [SVGPoint](./svgpoint/) | Veel van de SVG‑DOM‑interfaces verwijzen naar objecten van de klasse SVGPoint. Een SVGPoint is een (x, y) coördinaatpaar. Wanneer gebruikt in matrixbewerkingen, wordt een SVGPoint behandeld als een vector van de vorm: [x] [y] [1] Als een SVGRect‑object als alleen‑lezen wordt gemarkeerd, zal een poging om een van zijn attributen toe te wijzen een uitzondering veroorzaken. |
| [SVGPointList](./svgpointlist/) | Deze interface definieert een lijst met SVGPoint‑objecten. |
| [SVGPreserveAspectRatio](./svgpreserveaspectratio/) | De SVGPreserveAspectRatio‑interface komt overeen met het ‘preserveAspectRatio’-attribuut, dat beschikbaar is voor sommige SVG‑elementen. |
| [SVGRect](./svgrect/) | Stelt rechthoekige geometrie voor. Rechthoeken worden gedefinieerd als bestaande uit een (x,y)-coördinaatpaar dat een minimale X-waarde, een minimale Y-waarde, en een breedte en hoogte identificeert, die meestal beperkt zijn tot niet-negatief. |
| [SVGStringList](./svgstringlist/) | SVGStringList heeft dezelfde attributen en methoden als andere SVGxxxList‑interfaces. Implementatoren kunnen overwegen een enkele basisklasse te gebruiken om de verschillende SVGxxxList‑interfaces te implementeren. |
| [SVGTransform](./svgtransform/) | SVGTransform is de interface voor een van de componenttransformaties binnen een SVGTransformList; een SVGTransform‑object komt dus overeen met één component (bijv. 'scale(…)' of 'matrix(…)') binnen een ‘transform’-attribuutspecificatie. |
| [SVGTransformList](./svgtransformlist/) | Deze interface definieert een lijst van SVGTransform‑objecten. |
| [SVGValueType](./svgvaluetype/) | Het type SVGValueType wordt gebruikt om een basis‑SVG‑waarde‑type te vertegenwoordigen. |

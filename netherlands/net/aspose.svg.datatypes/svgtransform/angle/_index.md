## SVGTransform.Angle property

Een handig attribuut voor SVG_TRANSFORM_ROTATE, SVG_TRANSFORM_SKEWX en SVG_TRANSFORM_SKEWY. Het bevat de opgegeven hoek. Voor SVG_TRANSFORM_MATRIX, SVG_TRANSFORM_TRANSLATE en SVG_TRANSFORM_SCALE zal de hoek nul zijn.

```csharp
public float Angle { get; }
```

### Property Value

De opgegeven hoek.

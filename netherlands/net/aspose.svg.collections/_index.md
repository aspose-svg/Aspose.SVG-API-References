De **Aspose.Svg.Collections** naamruimte bestaat uit klassen om knooppunten en elementen te vertegenwoordigen, op te slaan en te manipuleren.

## Klassen

| Klasse | Beschrijving |
| --- | --- |
| [DOMTokenList](./domtokenlist/) | De DOMTokenList‑klasse vertegenwoordigt een set van door spaties gescheiden tokens. Het is geïndexeerd vanaf 0, net als JavaScript‑arrayobjecten. DOMTokenList is altijd hoofdlettergevoelig. |
| [HTMLCollection](./htmlcollection/) | De [`HTMLCollection`](../aspose.svg.collections/htmlcollection/) vertegenwoordigt een generieke collectie van [`Element`](../aspose.svg.dom/element/). |
| [NamedNodeMap](./namednodemap/) | Vertegenwoordigt collecties van attributen die op naam benaderd kunnen worden. |
| [NodeList](./nodelist/) | De NodeList biedt de abstractie van een geordende collectie van knooppunten, zonder te definiëren of te beperken hoe deze collectie wordt geïmplementeerd. |
| [SVGListBase<T>](./svglistbase-1/) | Deze interface definieert een basislijst van alle SVG‑lijsten. |

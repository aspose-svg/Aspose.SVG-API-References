## PointerEvents enumeration

Specificeert hoe pointer‑events worden afgehandeld door grafische elementen in SVG.

```csharp
public enum PointerEvents
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| BoundingBox | `0` | Pointer‑events zijn gericht op het begrenzingsvak van het element. |
| VisiblePainted | `1` | Pointer‑events zijn alleen gericht op de zichtbare (geschilderde) delen van het element. |
| VisibleFill | `2` | Pointer‑events zijn alleen gericht op de zichtbare (gevulde) delen van het element. |
| VisibleStroke | `3` | Pointer‑events zijn alleen gericht op de zichtbare (omlijnde) delen van het element. |
| Visible | `4` | Pointer‑events zijn gericht op alle zichtbare delen van het element. |
| Painted | `5` | Pointer‑events zijn gericht op alle geschilderde delen van het element, inclusief vulling en omtrek. |
| Fill | `6` | Pointer‑events zijn alleen gericht op de gevulde delen van het element. |
| Stroke | `7` | Pointer‑events zijn alleen gericht op de omlijnde delen van het element. |
| All | `8` | Pointer‑events zijn gericht op alle delen van het element, ongeacht de zichtbaarheid. |
| None | `9` | Het element wordt niet het doelwit van pointer‑events. |

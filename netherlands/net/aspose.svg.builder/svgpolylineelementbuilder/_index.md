## SVGPolylineElementBuilder class

Builder-klasse voor het construeren van een SVG 'polyline'-element. Het 'polyline'-element wordt gebruikt om een reeks rechte lijnen te maken die meerdere punten in SVG-grafieken verbinden. Deze klasse biedt methoden om verschillende attributen in te stellen en het polyline-element te animeren.

```csharp
public class SVGPolylineElementBuilder : SVGElementBuilder<SVGPolylineElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IPointsAttributeSetter, IShapeAttributeSetter, IShapeContentElementBuilder
```

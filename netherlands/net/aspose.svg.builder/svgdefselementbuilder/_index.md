## SVGDefsElementBuilder class

Builderklasse voor het construeren van een SVG 'defs'-element, dat wordt gebruikt om herbruikbare elementen te definiëren. Het maakt het mogelijk om inhoud binnen het 'defs'-element te bouwen en biedt methoden om verschillende attributen in te stellen die specifiek zijn voor het 'defs'-element in SVG.

```csharp
public class SVGDefsElementBuilder : SVGElementBuilder<SVGDefsElement>, ICompositeElementBuilder, 
    ICoreAttributeSetter, IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, 
    IGraphicalEventAttributeSetter, IPresentationAttributeSetter
```

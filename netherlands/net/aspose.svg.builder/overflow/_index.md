## Overflow enumeration

Specificeert het overflow‑gedrag voor SVG‑elementen.

```csharp
public enum Overflow
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Visible | `0` | Inhoud die de grenzen van het element overschrijdt, is zichtbaar. |
| Hidden | `1` | Inhoud die de grenzen van het element overschrijdt, wordt bijgesneden en is niet zichtbaar. |
| Scroll | `2` | Biedt scrollbalken voor de inhoud die de grenzen van het element overschrijdt. |

## Opmerkingen

Deze enumeratie bepaalt hoe inhoud die de grenzen van een SVG-element overschrijdt, wordt weergegeven. Het bepaalt of de overtollige inhoud zichtbaar, bijgesneden of voorzien van scrollbalken is.

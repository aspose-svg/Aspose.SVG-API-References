## SVGForeignObjectElementBuilder class

Builder-klasse voor het construeren van een SVG 'foreignObject'-element, dat het opnemen van externe inhoud in een SVG‑document mogelijk maakt. Dit element kan verschillende soorten inhoud bevatten, zoals HTML en XHTML, waardoor complexere grafische weergaven binnen SVG mogelijk worden.

```csharp
public class SVGForeignObjectElementBuilder : SVGElementBuilder<SVGForeignObjectElement>, 
    ICompositeAttributeSetter, IRectAttributeSetter, ITextContentSetter
```

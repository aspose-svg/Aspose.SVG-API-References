## MaskBuilder class

Een builderklasse voor het creëren van CSS‑maskereigenschappen. Deze klasse maakt het construeren van complexe maskerstijlen mogelijk met verschillende eigenschappen zoals mask‑bron, positie, grootte, herhalingsstijl en meer. De resulterende string kan in CSS worden gebruikt om het maskerende gedrag van een element te definiëren.

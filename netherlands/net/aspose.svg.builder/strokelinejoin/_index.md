## StrokeLineJoin enumeration

Specificeert de vorm die moet worden gebruikt op de hoeken van paden of basisvormen wanneer ze worden gestreken.

```csharp
public enum StrokeLineJoin
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Miter | `0` | Een scherpe hoek wordt gebruikt om padsegmenten te verbinden. |
| MiterClip | `1` | Gelijk aan 'miter', maar als de verbinding buiten een limiet zou uitsteken, wordt deze bijgesneden. |
| Round | `2` | Een afgeronde hoek wordt gebruikt om padsegmenten te verbinden. |
| Bevel | `3` | Een afgeschuinde hoek wordt gebruikt om padsegmenten te verbinden. |
| Arcs | `4` | De hoek wordt verbonden door boogsegmenten. |

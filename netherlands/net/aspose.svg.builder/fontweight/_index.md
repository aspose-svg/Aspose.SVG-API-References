## FontWeight enumeration


### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Normal | `0` | Stelt het normale lettertypegewicht voor, dat het standaardgewicht is. |
| Bold | `1` | Stelt een vet lettertypegewicht voor, meestal gebruikt voor nadruk. |
| Bolder | `2` | Stelt een lettertypegewicht voor dat dikker is dan het gewicht van het bovenliggende element. |
| Lighter | `3` | Stelt een lettertypegewicht voor dat lichter is dan het gewicht van het bovenliggende element. |
| W100 | `4` | Stelt het lettertypegewicht 100 voor, het dunste beschikbare. |
| W200 | `5` | Stelt het lettertypegewicht 200 voor. |
| W300 | `6` | Stelt het lettertypegewicht 300 voor. |
| W400 | `7` | Stelt het lettertypegewicht van 400 voor, gelijk aan 'normal'. |
| W500 | `8` | Stelt het lettertypegewicht van 500 voor. |
| W600 | `9` | Stelt het lettertypegewicht van 600 voor. |
| W700 | `10` | Stelt het lettertypegewicht van 700 voor, gelijk aan 'bold'. |
| W800 | `11` | Stelt het lettertypegewicht van 800 voor. |
| W900 | `12` | Stelt het lettertypegewicht van 900 voor, de dikste beschikbare. |

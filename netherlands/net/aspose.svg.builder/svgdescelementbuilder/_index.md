## SVGDescElementBuilder class

Builderklasse voor het construeren van een SVG 'desc'-element, dat wordt gebruikt om een beschrijving te geven voor SVG‑container‑elementen. Het maakt het mogelijk om inhoud binnen het 'desc'-element te bouwen en biedt methoden om verschillende attributen in te stellen die specifiek zijn voor het 'desc'-element in SVG.

```csharp
public class SVGDescElementBuilder : SVGElementBuilder<SVGDescElement>, ICoreAttributeSetter, 
    IDescriptiveElementBuilder, IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, 
    ITextContentSetter
```

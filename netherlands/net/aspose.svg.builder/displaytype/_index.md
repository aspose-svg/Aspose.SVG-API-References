## DisplayType enumeration

Specificeert het weergavegedrag van elementen in SVG-documenten.

```csharp
public enum DisplayType
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Inline | `0` | Het element genereert één of meer inline‑boxen. |
| Block | `1` | Het element genereert een block‑box. |
| ListItem | `2` | Het element genereert een block‑box voor de inhoud en een aparte list‑item inline‑box. |

## Opmerkingen

De eigenschap 'display' in SVG en CSS bepaalt hoe een element wordt weergegeven in de documentlay-out. Deze enumeratie biedt verschillende opties voor het instellen van het weergavetype, waardoor wordt beïnvloed hoe elementen worden gerenderd en met de lay-out interageren.

## ClipPathBuilder class

Een builderklasse voor het construeren van CSS clip-path-waarden. Deze klasse biedt methoden om clip‑paths te definiëren met behulp van basisvormen, externe referenties of geometrische vakken. Het maakt het creëren van complexe clip‑paths mogelijk op een gestructureerde en leesbare manier.

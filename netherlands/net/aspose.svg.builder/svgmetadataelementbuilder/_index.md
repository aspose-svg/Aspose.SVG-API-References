## SVGMetadataElementBuilder class

Builder-klasse voor het construeren van een SVG 'metadata'-element, dat wordt gebruikt om metadata aan een SVG‑document toe te voegen. Deze klasse maakt het toevoegen van metadata-inhoud mogelijk en biedt methoden om verschillende attributen specifiek voor het 'metadata'-element in SVG in te stellen.

```csharp
public class SVGMetadataElementBuilder : SVGElementBuilder<SVGMetadataElement>, 
    ICoreAttributeSetter, IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, 
    ITextContentSetter
```

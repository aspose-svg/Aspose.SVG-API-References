## SVGPolygonElementBuilder class

Builder-klasse voor het construeren van een SVG 'polygon'-element. Het 'polygon'-element wordt gebruikt om een grafisch object te maken dat minstens drie zijden bevat. Deze klasse biedt methoden om verschillende attributen in te stellen en het polygon-element te animeren.

```csharp
public class SVGPolygonElementBuilder : SVGElementBuilder<SVGPolygonElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IPointsAttributeSetter, IShapeAttributeSetter, IShapeContentElementBuilder
```

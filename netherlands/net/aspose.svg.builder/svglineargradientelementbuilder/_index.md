## SVGLinearGradientElementBuilder class

Builder-klasse voor het construeren van een SVG 'linearGradient'-element, dat wordt gebruikt om een lineaire gradiënt binnen SVG‑graphics te definiëren. Het maakt het mogelijk om inhoud binnen het 'linearGradient'-element op te bouwen en biedt methoden om verschillende attributen specifiek voor het 'linearGradient'-element in SVG in te stellen.

```csharp
public class SVGLinearGradientElementBuilder : SVGElementBuilder<SVGLinearGradientElement>, 
    IBaseAnimationElementBuilder, ICoreAttributeSetter, IDescriptiveElementBuilder, 
    IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, IGradientStopElementBuilder, 
    IPresentationAttributeSetter
```

## ImageRendering enumeration

Specificeert hoe een afbeelding moet worden gerenderd in SVG.

```csharp
public enum ImageRendering
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Auto | `0` | De browser maakt een afweging tussen snelheid en kwaliteit bij het renderen van de afbeelding. |
| OptimizeSpeed | `1` | De browser legt de nadruk op renderingssnelheid boven afbeeldingskwaliteit. Dit betekent vaak dat afbeeldingen worden geschaald op een manier die ze er gepixeld of blokkerig uit kan laten zien. |
| OptimizeQuality | `2` | De browser legt de nadruk op afbeeldingskwaliteit boven renderingssnelheid. Dit kan zorgen voor vloeiendere, hogere kwaliteit schaling van afbeeldingen, maar kan resulteren in langzamer renderen. |

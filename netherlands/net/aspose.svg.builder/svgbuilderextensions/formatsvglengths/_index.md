## SVGBuilderExtensions.FormatSvgLengths method

Formatteert een array van double-waarden naar een tekenreeksrepresentatie van SVG-lengtes.

```csharp
public static string FormatSvgLengths(double[] values, LengthType type)
```

| Parameter | Type | Beschrijving |
| --- | --- | --- |
| waarden | Double[] | De array van double‑waarden die lengtes vertegenwoordigen. |
| type | LengthType | Het type lengteenheid om te gebruiken (bijv. pixels). |

### Retourwaarde

Een geformatteerde tekenreeks van SVG‑lengtes.

## Opmerkingen

Deze hulpmethode wordt gebruikt om lengtes voor SVG‑attributen te formatteren, door de juiste eenheid (zoals 'px') aan elke waarde toe te voegen.

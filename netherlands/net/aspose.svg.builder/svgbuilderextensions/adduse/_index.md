## AddUse<TBuilder>(*this TBuilder, string, OneOf&lt;double, (double, LengthType)&gt;, OneOf&lt;double, (double, LengthType)&gt;, OneOf&lt;double, (double, LengthType)&gt;, OneOf&lt;double, (double, LengthType)&gt;, OneOf&lt;Color, Paint, string&gt;, OneOf&lt;Color, Paint, string&gt;, string, Action&lt;SVGUseElementBuilder&gt;*) {#adduse_1}

Voegt een 'use' element toe aan de SVG builder, waardoor een bestaand element dat elders in de SVG is gedefinieerd, kan worden hergebruikt.

```csharp
public static TBuilder AddUse<TBuilder>(this TBuilder builder, string href = null, 
    OneOf<double, (double, LengthType)> x = null, OneOf<double, (double, LengthType)> y = null, 
    OneOf<double, (double, LengthType)> width = null, 
    OneOf<double, (double, LengthType)> height = null, OneOf<Color, Paint, string> fill = null, 
    OneOf<Color, Paint, string> stroke = null, string id = null, 
    Action<SVGUseElementBuilder> extend = null)
    where TBuilder : ISVGElementBuilder, ICompositeElementBuilder
```

| Parameter | Beschrijving |
| --- | --- |
| TBuilder | Het type van de SVG-elementbuilder, dat vloeiend API-gebruik mogelijk maakt. |
| builder | De SVG-builderinstantie waaraan het 'use'-element zal worden toegevoegd. |
| href | De referentie naar het bestaande element dat opnieuw wordt gebruikt. Optionele parameter. |
| x | De x-coördinaat waar het opnieuw gebruikte element wordt geplaatst. Kan een double of een ValueTuple met LengthType zijn. Optionele parameter. |
| y | De y-coördinaat waar het opnieuw gebruikte element wordt geplaatst. Kan een double of een ValueTuple met LengthType zijn. Optionele parameter. |
| width | De breedte van het opnieuw gebruikte element. Kan een double of een ValueTuple met LengthType zijn. Optionele parameter. |
| height | De hoogte van het opnieuw gebruikte element. Kan een double of een ValueTuple met LengthType zijn. Optionele parameter. |
| fill | De vulkleur, verf of paint server-id voor het element. Optionele parameter. |
| stroke | De lijnkleur, verf of paint server-id voor het element. Optionele parameter. |
| id | De unieke identifier voor het element. Optionele parameter. |
| extend | Een optionele actie om de SVGUseElementBuilder verder te configureren. |

### Retourwaarde

De builder‑instantie, waarmee method chaining mogelijk is.

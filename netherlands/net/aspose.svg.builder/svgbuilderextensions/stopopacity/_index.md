## SVGBuilderExtensions.StopOpacity<TBuilder> method

Stelt het 'stop-opacity' attribuut in voor een SVG-element, waarbij de doorzichtigheid bij een gradient‑stop wordt gedefinieerd.

```csharp
public static TBuilder StopOpacity<TBuilder>(this TBuilder builder, double opacity)
    where TBuilder : IAttributeSetter, IPresentationAttributeSetter
```

| Parameter | Beschrijving |
| --- | --- |
| TBuilder | Het type van de SVG-elementbuilder. |
| builder | De builder‑instantie. |
| opacity | De opacity-waarde (0,0 voor volledig transparant, 1,0 voor volledig ondoorzichtig). |

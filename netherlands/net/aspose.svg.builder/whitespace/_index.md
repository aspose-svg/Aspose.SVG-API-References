## WhiteSpace enumeration

Specificeert hoe witruimte binnen een SVG-element wordt afgehandeld.

```csharp
public enum WhiteSpace
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Normal | `0` | Witruimte wordt samengevoegd; regeleinde‑tekens creëren nieuwe regels. |
| Pre | `1` | Witruimte wordt behouden; tekst wordt alleen afgebroken waar regeleinde‑tekens aanwezig zijn. |
| NoWrap | `2` | Witruimte wordt samengevoegd; tekst wordt niet afgebroken. |
| PreWrap | `3` | Witruimte wordt behouden; tekst wordt afgebroken waar nodig en bij regeleinde‑tekens. |
| BreakSpaces | `4` | Witruimte wordt behouden; regeleinden worden toegevoegd om regelvakken te vullen. |
| PreLine | `5` | Witruimte wordt behouden; tekst wordt afgebroken waar nodig, maar zonder regeleinde‑tekens. |

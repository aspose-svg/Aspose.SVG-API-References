## SVGRadialGradientElementBuilder class

Builder-klasse voor het construeren van een SVG 'radialGradient'-element, dat wordt gebruikt om een radiale gradiënt binnen SVG-grafieken te definiëren. Deze klasse maakt het mogelijk om inhoud binnen het 'radialGradient'-element op te bouwen en biedt methoden om verschillende attributen specifiek voor het 'radialGradient'-element in SVG in te stellen.

```csharp
public class SVGRadialGradientElementBuilder : SVGElementBuilder<SVGRadialGradientElement>, 
    IBaseAnimationElementBuilder, ICoreAttributeSetter, IDescriptiveElementBuilder, 
    IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, IGradientStopElementBuilder, 
    IPresentationAttributeSetter
```

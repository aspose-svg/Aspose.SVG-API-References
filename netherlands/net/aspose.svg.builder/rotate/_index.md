## Rotate enumeration

Specificeert het rotatiegedrag voor elementen tijdens bewegingsanimatie in SVG.

```csharp
public enum Rotate
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Auto | `0` | Roteert het element automatisch in de richting van het pad. |
| AutoReverse | `1` | Roteert het element automatisch in de richting van het pad en staat toe dat het omkeert. |

## Opmerkingen

Het 'rotate'-attribuut in het 'animateMotion'-element van SVG regelt de rotatie van een element langs een bewegingspad. Deze enum biedt opties voor hoe het element moet roteren terwijl het het pad volgt.

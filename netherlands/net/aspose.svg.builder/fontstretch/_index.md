## FontStretch enumeration

Specificeert de verschillende niveaus van lettertype-uitrekking voor SVG-textelementen.

```csharp
public enum FontStretch
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Normal | `0` | Duidt de normale (standaard) lettertype-uitrekking aan. |
| UltraCondensed | `1` | Duidt de meest ingedrukte lettertype-uitrekking aan. |
| ExtraCondensed | `2` | Duidt een meer ingedrukte lettertype-uitrekking aan dan 'condensed', maar minder dan 'ultra-condensed'. |
| Condensed | `3` | Duidt een ingedrukte lettertype-uitrekking aan. |
| SemiCondensed | `4` | Duidt een licht ingedrukte lettertype-uitrekking aan. |
| SemiExpanded | `5` | Duidt een licht uitgerekte lettertype-uitrekking aan. |
| Expanded | `6` | Duidt een uitgerekte lettertype-uitrekking aan. |
| ExtraExpanded | `7` | Duidt een meer uitgerekte lettertype-uitrekking aan dan 'expanded', maar minder dan 'ultra-expanded'. |
| UltraExpanded | `8` | Duidt de meest uitgerekte lettertype-uitrekking aan. |

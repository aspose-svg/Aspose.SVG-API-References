## SVGLineElementBuilder class

Builder-klasse voor het construeren van een SVG 'line'-element, dat wordt gebruikt om rechte lijnen binnen SVG‑graphics te tekenen. Deze klasse maakt het mogelijk om inhoud binnen het 'line'-element op te bouwen en biedt methoden om verschillende attributen specifiek voor het 'line'-element in SVG in te stellen.

```csharp
public class SVGLineElementBuilder : SVGElementBuilder<SVGLineElement>, IAnimationElementBuilder, 
    IDescriptiveElementBuilder, IPaintServerElementBuilder, IShapeAttributeSetter, 
    IShapeContentElementBuilder
```

## SVGRectElementBuilder class

Builder-klasse voor het construeren van een SVG 'rect'-element. Het 'rect'-element wordt gebruikt om rechthoeken binnen SVG-grafieken te maken. Deze klasse biedt methoden om verschillende attributen specifiek voor het 'rect'-element in te stellen, inclusief hoekstraal en afmetingen.

```csharp
public class SVGRectElementBuilder : SVGElementBuilder<SVGRectElement>, IAnimationElementBuilder, 
    IDescriptiveElementBuilder, IPaintServerElementBuilder, IRectAttributeSetter, 
    IShapeAttributeSetter, IShapeContentElementBuilder
```

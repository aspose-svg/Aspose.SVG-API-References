## Cursor enumeration

Definieert cursortypen voor SVG-elementen, waardoor de cursorweergave kan worden aangepast bij het zweven over deze elementen.

```csharp
public enum Cursor
```

### Waarden

| Naam | Waarde | Beschrijving |
| --- | --- | --- |
| Auto | `0` | De browser bepaalt welke cursor moet worden weergegeven op basis van de huidige context. |
| Default | `1` | Standaardcursor, meestal een pijl. |
| None | `2` | Er wordt geen cursor weergegeven. |
| ContextMenu | `3` | Cursor die aangeeft dat een contextmenu beschikbaar is. |
| Help | `4` | Cursor die aangeeft dat helpinformatie beschikbaar is. |
| Pointer | `5` | Cursor die een klikbaar element aangeeft, meestal een handpijl. |
| Progress | `6` | Cursor die een lopende bewerking of taak aangeeft. |
| Wait | `7` | Cursor die aangeeft dat het systeem bezig is en de gebruiker moet wachten. |
| Cell | `8` | Cursor die een cel- of tabelonderdeel aangeeft. |
| Crosshair | `9` | Cursor die precisieselectie aangeeft, meestal een richtkruis. |
| Text | `10` | Cursor die tekstselectie aangeeft. |
| VerticalText | `11` | Cursor die verticale tekstselectie aangeeft. |
| Alias | `12` | Cursor die aangeeft dat een alias of snelkoppeling wordt gemaakt. |
| Copy | `13` | Cursor die een kopieerbewerking aangeeft. |
| Move | `14` | Cursor die een verplaatsbaar item of gebied aangeeft. |
| NoDrop | `15` | Cursor die aangeeft dat neerzetten niet is toegestaan. |
| NotAllowed | `16` | Cursor die aangeeft dat een actie niet is toegestaan. |
| Grab | `17` | Cursor die aangeeft dat een item kan worden gegrepen. |
| Grabbing | `18` | Cursor die aangeeft dat een item momenteel wordt gegrepen. |
| EResize | `19` | Cursor die een vergroting naar het oosten aangeeft. |
| NResize | `20` | Cursor die een vergroting naar het noorden aangeeft. |
| NEResize | `21` | Cursor die een vergroting naar het noordoosten aangeeft. |
| NWResize | `22` | Cursor die een vergroting naar het noordwesten aangeeft. |
| SResize | `23` | Cursor die een vergroting naar het zuiden aangeeft. |
| SEResize | `24` | Cursor die een vergroting naar het zuidoosten aangeeft. |
| SWResize | `25` | Cursor die een vergroting naar het zuidwesten aangeeft. |
| WResize | `26` | Cursor die een vergroting naar het westen aangeeft. |
| EWResize | `27` | Cursor die een vergroting oost-west aangeeft. |
| NSResize | `28` | Cursor die een vergroting noord-zuid aangeeft. |
| NESWResize | `29` | Cursor die een vergroting noord-oost-zuid-west aangeeft. |
| NWSeResize | `30` | Cursor die een noordwest-zuidoost resize aangeeft. |
| ColResize | `31` | Cursor die een kolomresize aangeeft. |
| RowResize | `32` | Cursor die een rijresize aangeeft. |
| AllScroll | `33` | Cursor die scrollen in alle richtingen aangeeft. |
| ZoomIn | `34` | Cursor die zoom-in mogelijkheid aangeeft. |
| ZoomOut | `35` | Cursor die zoom-out mogelijkheid aangeeft. |

## Opmerkingen

Deze enumeratie biedt een reeks cursorstijlen die kunnen worden toegepast op SVG-elementen. Deze stijlen helpen het type beschikbare interactie of de status van het element onder de cursor aan te geven.

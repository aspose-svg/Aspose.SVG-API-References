## SVGEllipseElementBuilder class

Builderklasse voor het construeren van een SVG 'ellipse'-element, dat wordt gebruikt om ellipsen te tekenen binnen SVG‑graphics. Het maakt het mogelijk om inhoud binnen het 'ellipse'-element te bouwen en biedt methoden om verschillende attributen in te stellen die specifiek zijn voor het 'ellipse'-element in SVG.

```csharp
public class SVGEllipseElementBuilder : SVGElementBuilder<SVGEllipseElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IShapeAttributeSetter, IShapeContentElementBuilder
```

## SVGCircleElementBuilder class

Builderklasse voor het construeren van een SVG 'circle'-element, dat wordt gebruikt om cirkels te tekenen binnen SVG‑graphics. Het maakt het mogelijk om inhoud binnen het 'circle'-element te bouwen en biedt methoden om verschillende attributen in te stellen die specifiek zijn voor het 'circle'-element in SVG.

```csharp
public class SVGCircleElementBuilder : SVGElementBuilder<SVGCircleElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IShapeAttributeSetter, IShapeContentElementBuilder
```

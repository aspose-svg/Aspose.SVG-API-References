## IUserAgentService.ShowImagePlaceholders property

Le immagini possono avere contenuti di riserva: contenuti che dovrebbero essere usati quando una risorsa esterna non può essere utilizzata (ad esempio, perché è in un formato non supportato). La proprietà `ShowImagePlaceholders` specifica se visualizzare l'immagine di riserva (il valore predefinito è true)

```csharp
public bool ShowImagePlaceholders { get; set; }
```

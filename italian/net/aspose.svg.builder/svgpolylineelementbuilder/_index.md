## SVGPolylineElementBuilder class

Classe Builder per la costruzione di un elemento SVG 'polyline'. L'elemento 'polyline' è usato per creare una serie di linee rette che collegano più punti nella grafica SVG. Questa classe fornisce metodi per impostare vari attributi e animare l'elemento polyline.

```csharp
public class SVGPolylineElementBuilder : SVGElementBuilder<SVGPolylineElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IPointsAttributeSetter, IShapeAttributeSetter, IShapeContentElementBuilder
```

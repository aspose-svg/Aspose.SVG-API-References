## SVGRectElementBuilder class

Classe Builder per la costruzione di un elemento SVG 'rect'. L'elemento 'rect' è usato per creare rettangoli nella grafica SVG. Questa classe fornisce metodi per impostare vari attributi specifici dell'elemento 'rect', inclusi i raggi degli angoli e le dimensioni.

```csharp
public class SVGRectElementBuilder : SVGElementBuilder<SVGRectElement>, IAnimationElementBuilder, 
    IDescriptiveElementBuilder, IPaintServerElementBuilder, IRectAttributeSetter, 
    IShapeAttributeSetter, IShapeContentElementBuilder
```

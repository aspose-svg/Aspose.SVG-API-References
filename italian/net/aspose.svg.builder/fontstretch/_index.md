## FontStretch enumeration

Specifica i diversi livelli di allungamento del carattere per gli elementi di testo SVG.

```csharp
public enum FontStretch
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Normal | `0` | Rappresenta l'allungamento del font normale (predefinito). |
| UltraCondensed | `1` | Rappresenta l'allungamento del font più condensato. |
| ExtraCondensed | `2` | Rappresenta un allungamento del font più condensato di 'condensed' ma meno di 'ultra-condensed'. |
| Condensed | `3` | Rappresenta un allungamento del font condensato. |
| SemiCondensed | `4` | Rappresenta un leggero allungamento del font condensato. |
| SemiExpanded | `5` | Rappresenta un leggero allungamento del font espanso. |
| Expanded | `6` | Rappresenta un allungamento del font espanso. |
| ExtraExpanded | `7` | Rappresenta una larghezza del carattere più espansa rispetto a 'expanded' ma inferiore a 'ultra-expanded'. |
| UltraExpanded | `8` | Rappresenta la larghezza del carattere più espansa. |

## Media enumeration

Specifica le condizioni temporali legate ai media per le animazioni SVG.

```csharp
public enum Media
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Media | `0` | Indica che la temporizzazione dell'animazione dipende dalla temporizzazione del media. |

## Osservazioni

Questa enumerazione è usata per definire le condizioni di temporizzazione legate ai media nelle animazioni SVG. È particolarmente rilevante per le animazioni che dipendono o sono sincronizzate con media esterni, come audio o video.

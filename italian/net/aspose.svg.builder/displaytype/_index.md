## DisplayType enumeration

Specifica il comportamento di visualizzazione degli elementi nei documenti SVG.

```csharp
public enum DisplayType
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Inline | `0` | L'elemento genera una o più caselle inline. |
| Block | `1` | L'elemento genera una casella block. |
| ListItem | `2` | L'elemento genera una casella block per il contenuto e una casella inline list-item separata. |
| InlineBlock | `3` | L'elemento genera una casella block per il contenuto e una casella inline per il contenitore. |
| Table | `4` | L'elemento si comporta come un elemento tabella. |
| InlineTable | `5` | L'elemento si comporta come una tabella inline. |
| TableRowGroup | `6` | L'elemento si comporta come un gruppo di righe di tabella. |
| TableHeaderGroup | `7` | L'elemento si comporta come un gruppo di intestazione di tabella. |
| TableFooterGroup | `8` | L'elemento si comporta come un gruppo di piè di pagina di tabella. |
| TableRow | `9` | L'elemento si comporta come una riga di tabella. |
| TableColumnGroup | `10` | L'elemento si comporta come un gruppo di colonne di tabella. |
| TableColumn | `11` | L'elemento si comporta come una colonna di tabella. |
| TableCell | `12` | L'elemento si comporta come una cella di tabella. |
| TableCaption | `13` | L'elemento si comporta come una didascalia di tabella. |
| None | `14` | L'elemento non genera alcun box e non viene renderizzato. Non influisce sul layout. |
| Flex | `15` | L'elemento si comporta come un contenitore flex. |
| InlineFlex | `16` | L'elemento si comporta come un contenitore flex inline. |
| Grid | `17` | L'elemento si comporta come un contenitore grid. |
| InlineGrid | `18` | L'elemento si comporta come un contenitore grid inline. |

## Osservazioni

La proprietà 'display' in SVG e CSS determina come un elemento viene visualizzato nel layout del documento. Questa enumerazione fornisce varie opzioni per impostare il tipo di visualizzazione, influenzando il modo in cui gli elementi sono renderizzati e interagiscono con il layout.

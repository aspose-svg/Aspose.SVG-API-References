## SVGPathElementBuilder class

Classe Builder per costruire un elemento SVG 'path', che è usato per definire un percorso in un documento SVG. Questa classe fornisce metodi per impostare vari attributi specifici dell'elemento 'path' e per costruirne il contenuto.

```csharp
public class SVGPathElementBuilder : SVGElementBuilder<SVGPathElement>, IAnimationElementBuilder, 
    IDescriptiveElementBuilder, IPaintServerElementBuilder, IShapeAttributeSetter, 
    IShapeContentElementBuilder
```

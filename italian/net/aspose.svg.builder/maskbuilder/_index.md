## MaskBuilder class

Una classe builder per creare proprietà mask CSS. Questa classe consente la costruzione di stili mask complessi utilizzando varie proprietà come sorgente della maschera, posizione, dimensione, stile di ripetizione e altro. La stringa risultante può essere utilizzata in CSS per definire il comportamento di mascheramento di un elemento.

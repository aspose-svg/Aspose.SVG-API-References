## StrokeLineJoin enumeration

Specifica la forma da utilizzare agli angoli dei percorsi o delle forme di base quando vengono tracciati.

```csharp
public enum StrokeLineJoin
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Miter | `0` | Un angolo acuto è usato per unire i segmenti di percorso. |
| MiterClip | `1` | Simile a 'miter', ma se la giunzione si estende oltre un limite, viene tagliata. |
| Round | `2` | Un angolo arrotondato è usato per unire i segmenti di percorso. |
| Bevel | `3` | Un angolo smussato è usato per unire i segmenti di percorso. |
| Arcs | `4` | L'angolo è unito da archi. |

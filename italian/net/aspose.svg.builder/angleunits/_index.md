## AngleUnits enumeration

Specifica le unità per gli angoli utilizzati nella definizione dell'orientamento dei marcatori in SVG.

```csharp
public enum AngleUnits
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Degrees | `0` | Specifica l'angolo in gradi. Un cerchio completo è di 360 gradi. |
| Gradians | `1` | Specifica l'angolo in gradiani. Un cerchio completo è di 400 gradiani. |
| Radians | `2` | Specifica l'angolo in radianti. Un cerchio completo è circa 6,283 radianti (2π radianti). |
| None | `3` | Indica nessuna unità di angolo specifica. Utilizzato per impostazioni predefinite o basate sul contesto. |

## Osservazioni

L'attributo 'orient' dei marcatori SVG può essere specificato in varie unità di angolo. Questo enum fornisce opzioni per impostare queste unità.

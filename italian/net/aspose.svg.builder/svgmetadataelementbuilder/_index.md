## SVGMetadataElementBuilder class

Classe Builder per costruire un elemento SVG 'metadata', che è usato per aggiungere metadati a un documento SVG. Questa classe consente l'aggiunta di contenuti di metadati e fornisce metodi per impostare vari attributi specifici dell'elemento 'metadata' in SVG.

```csharp
public class SVGMetadataElementBuilder : SVGElementBuilder<SVGMetadataElement>, 
    ICoreAttributeSetter, IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, 
    ITextContentSetter
```

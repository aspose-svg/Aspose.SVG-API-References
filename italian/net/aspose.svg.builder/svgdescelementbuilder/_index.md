## SVGDescElementBuilder class

Classe Builder per la costruzione di un elemento SVG 'desc', utilizzato per fornire una descrizione per gli elementi contenitori SVG. Consente la creazione di contenuti all'interno dell'elemento 'desc' e fornisce metodi per impostare vari attributi specifici dell'elemento 'desc' in SVG.

```csharp
public class SVGDescElementBuilder : SVGElementBuilder<SVGDescElement>, ICoreAttributeSetter, 
    IDescriptiveElementBuilder, IDocumentElementEventAttributeSetter, IGlobalEventAttributeSetter, 
    ITextContentSetter
```

## RepeatStyle enumeration

Specifica lo stile di ripetizione per le immagini di sfondo o i pattern in SVG.

```csharp
public enum RepeatStyle
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| RepeatX | `0` | L'immagine o il pattern viene ripetuto solo orizzontalmente. |
| RepeatY | `1` | L'immagine o il pattern viene ripetuto solo verticalmente. |
| Repeat | `2` | L'immagine o il pattern viene ripetuto sia orizzontalmente che verticalmente. |
| Space | `3` | L'immagine o il pattern viene ripetuto il più possibile senza ritaglio, e lo spazio rimanente è distribuito uniformemente tra le immagini. |
| Round | `4` | L'immagine o il pattern viene scalato in modo che si adatti e sia ripetuto senza ritaglio, mantenendo le proporzioni. |
| NoRepeat | `5` | L'immagine o il pattern non viene ripetuto, e verrà disegnata solo una copia dell'immagine. |

## DominantBaseline enumeration

Specifica la linea di base dominante utilizzata per allineare il testo.

```csharp
public enum DominantBaseline
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Auto | `0` | Determina automaticamente la linea di base dominante in base al carattere e/o alla lingua. |
| TextBottom | `1` | Allinea il testo al fondo del quadrato em. |
| Alphabetic | `2` | Allinea il testo sulla linea di base usata dai caratteri alfabetici. |
| Ideographic | `3` | Allinea il testo sulla linea di base usata dai caratteri ideografici. |
| Middle | `4` | Allinea il testo al centro del quadrato em. |
| Central | `5` | Allinea il testo alla linea di base centrale del quadrato em. |
| Mathematical | `6` | Allinea il testo sulla linea di base usata dai caratteri matematici. |
| Hanging | `7` | Allinea il testo sulla linea di base sospesa, tipicamente usata per il tibetano o altri script asiatici. |
| TextTop | `8` | Allinea il testo alla parte superiore del quadrato em. |

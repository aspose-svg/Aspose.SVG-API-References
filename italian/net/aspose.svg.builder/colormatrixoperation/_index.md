## ColorMatrixOperation enumeration

Specifica il tipo di operazione da applicare in un filtro a matrice di colore.

```csharp
public enum ColorMatrixOperation
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Matrix | `0` | Applica una trasformazione matriciale ai dati di colore. |
| Saturate | `1` | Regola il livello di saturazione dell'immagine. |
| HueRotate | `2` | Applica una rotazione della tonalità sull'immagine. |
| LuminanceToAlpha | `3` | Converte i colori dell'immagine in scala di grigi in base alla loro luminanza. |

## Osservazioni

Il filtro a matrice di colore in SVG consente varie operazioni sui dati di colore di un'immagine. Ogni tipo di operazione manipola i colori in modo specifico, offrendo una gamma di effetti visivi.

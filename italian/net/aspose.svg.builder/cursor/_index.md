## Cursor enumeration

Definisce i tipi di cursore per gli elementi SVG, consentendo la personalizzazione dell'aspetto del cursore al passaggio del mouse su questi elementi.

```csharp
public enum Cursor
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Auto | `0` | Il browser determina il cursore da visualizzare in base al contesto corrente. |
| Default | `1` | Cursore predefinito, tipicamente una freccia. |
| None | `2` | Nessun cursore viene visualizzato. |
| ContextMenu | `3` | Cursore che indica la disponibilità di un menu contestuale. |
| Help | `4` | Cursore che indica la disponibilità di informazioni di aiuto. |
| Pointer | `5` | Cursore che indica un elemento cliccabile, tipicamente un puntatore a mano. |
| Progress | `6` | Cursore che indica un'operazione o un'attività in corso. |
| Wait | `7` | Cursore che indica che il sistema è occupato e l'utente deve attendere. |
| Cell | `8` | Cursore che indica una cella o un elemento di tabella. |
| Crosshair | `9` | Cursore che indica una selezione precisa, tipicamente un mirino a croce. |
| Text | `10` | Cursore che indica la selezione del testo. |
| VerticalText | `11` | Cursore che indica la selezione di testo verticale. |
| Alias | `12` | Cursore che indica la creazione di un alias o di una scorciatoia. |
| Copy | `13` | Cursore che indica l'operazione di copia. |
| Move | `14` | Cursore che indica un elemento o un'area spostabile. |
| NoDrop | `15` | Cursore che indica che il rilascio non è consentito. |
| NotAllowed | `16` | Cursore che indica che un'azione non è consentita. |
| Grab | `17` | Cursore che indica che un elemento può essere afferrato. |
| Grabbing | `18` | Cursore che indica che un elemento è attualmente afferrato. |
| EResize | `19` | Cursore che indica il ridimensionamento verso est. |
| NResize | `20` | Cursore che indica il ridimensionamento verso nord. |
| NEResize | `21` | Cursore che indica il ridimensionamento verso nord-est. |
| NWResize | `22` | Cursore che indica il ridimensionamento verso nord-ovest. |
| SResize | `23` | Cursore che indica il ridimensionamento verso sud. |
| SEResize | `24` | Cursore che indica il ridimensionamento verso sud-est. |
| SWResize | `25` | Cursore che indica il ridimensionamento verso sud-ovest. |
| WResize | `26` | Cursore che indica il ridimensionamento verso ovest. |
| EWResize | `27` | Cursore che indica il ridimensionamento est-ovest. |
| NSResize | `28` | Cursore che indica il ridimensionamento nord-sud. |
| NESWResize | `29` | Cursore che indica il ridimensionamento nord-est-sud-ovest. |
| NWSeResize | `30` | Cursore che indica il ridimensionamento nord-ovest-sud-est. |
| ColResize | `31` | Cursore che indica il ridimensionamento della colonna. |
| RowResize | `32` | Cursore che indica il ridimensionamento della riga. |
| AllScroll | `33` | Cursore che indica lo scorrimento in tutte le direzioni. |
| ZoomIn | `34` | Cursore che indica la capacità di ingrandire. |
| ZoomOut | `35` | Cursore che indica la capacità di ridurre. |

## Osservazioni

Questa enumerazione fornisce una gamma di stili di cursore che possono essere applicati agli elementi SVG. Questi stili aiutano a indicare il tipo di interazione disponibile o lo stato dell'elemento sotto il cursore.

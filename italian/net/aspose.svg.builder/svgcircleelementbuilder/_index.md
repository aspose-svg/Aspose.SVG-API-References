## SVGCircleElementBuilder class

Classe Builder per la costruzione di un elemento SVG 'circle', utilizzato per disegnare cerchi all'interno della grafica SVG. Consente la creazione di contenuti all'interno dell'elemento 'circle' e fornisce metodi per impostare vari attributi specifici dell'elemento 'circle' in SVG.

```csharp
public class SVGCircleElementBuilder : SVGElementBuilder<SVGCircleElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IShapeAttributeSetter, IShapeContentElementBuilder
```

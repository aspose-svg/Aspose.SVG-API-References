## SVGLineElementBuilder class

Classe Builder per costruire un elemento SVG 'line', che è usato per disegnare linee rette nella grafica SVG. Questa classe consente la costruzione del contenuto all'interno dell'elemento 'line' e fornisce metodi per impostare vari attributi specifici dell'elemento 'line' in SVG.

```csharp
public class SVGLineElementBuilder : SVGElementBuilder<SVGLineElement>, IAnimationElementBuilder, 
    IDescriptiveElementBuilder, IPaintServerElementBuilder, IShapeAttributeSetter, 
    IShapeContentElementBuilder
```

## AnimationSplineBuilder class

Una classe builder per la costruzione di funzioni di temporizzazione delle animazioni utilizzando curve Bézier cubiche. Questa classe consente la definizione di una o più curve Bézier cubiche, ciascuna specificata da due punti di controllo. La stringa risultante può essere utilizzata nelle animazioni o transizioni CSS per controllare il ritmo dell'animazione.

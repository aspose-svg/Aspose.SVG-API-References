## SVGBuilderExtensions.OnResize<TBuilder> method

Imposta l'attributo evento 'onresize' per gestire gli eventi di ridimensionamento della finestra o degli elementi.

```csharp
public static TBuilder OnResize<TBuilder>(this TBuilder builder, string value)
    where TBuilder : ISVGElementBuilder, ICommonEventAttributeSetter
```

| Parametro | Descrizione |
| --- | --- |
| TBuilder | Il tipo del costruttore di elementi SVG. |
| costruttore | Il costruttore di elementi SVG. |
| value | La funzione o lo script JavaScript da eseguire quando l'elemento o la finestra viene ridimensionata. |

### Valore di ritorno

L'istanza del costruttore per concatenazione.

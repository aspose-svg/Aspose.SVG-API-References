## SVGBuilderExtensions.Opacity<TBuilder> method

Imposta l'attributo 'opacity' per un elemento SVG, definendo il suo livello di trasparenza.

```csharp
public static TBuilder Opacity<TBuilder>(this TBuilder builder, double opacity)
    where TBuilder : IAttributeSetter, IPresentationAttributeSetter
```

| Parametro | Descrizione |
| --- | --- |
| TBuilder | Il tipo del costruttore di elementi SVG. |
| costruttore | L'istanza del costruttore. |
| opacity | Il valore di opacity (0.0 per completamente trasparente, 1.0 per completamente opaco). |

### Valore di ritorno

L'istanza del costruttore per concatenazione.

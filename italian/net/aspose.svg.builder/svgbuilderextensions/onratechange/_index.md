## SVGBuilderExtensions.OnRateChange<TBuilder> method

Imposta l'attributo evento 'onratechange' per gestire gli eventi quando la velocità di riproduzione del media viene modificata.

```csharp
public static TBuilder OnRateChange<TBuilder>(this TBuilder builder, string value)
    where TBuilder : ISVGElementBuilder, IGlobalEventAttributeSetter
```

| Parametro | Descrizione |
| --- | --- |

| costruttore | Il costruttore di elementi SVG. |
| value | La funzione JavaScript o lo script da eseguire quando la velocità di riproduzione cambia. |

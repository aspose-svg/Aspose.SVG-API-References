## SVGBuilderExtensions.SetAttribute<TBuilder> method

Imposta un attributo sull'elemento SVG. Questo metodo è usato per aggiungere o modificare un attributo dell'elemento SVG in costruzione.

```csharp
public static TBuilder SetAttribute<TBuilder>(this TBuilder builder, string name, string value)
    where TBuilder : IAttributeSetter
```

| Parametro | Descrizione |
| --- | --- |
| TBuilder | Il tipo del costruttore di elementi SVG. |
| costruttore | Il costruttore dell'elemento SVG su cui viene impostato l'attributo. |
| nome | Il nome dell'attributo da impostare. |
| value | Il valore dell'attributo. |

### Valore di ritorno

Il costruttore originale dell'elemento SVG per il chaining dei metodi.

## SVGBuilderExtensions.SpreadMethod<TBuilder> method

Imposta l'attributo 'spreadMethod' per un elemento gradiente.

```csharp
public static TBuilder SpreadMethod<TBuilder>(this TBuilder builder, SpreadMethod method)
    where TBuilder : ISVGElementBuilder, IGradientStopElementBuilder
```

| Parametro | Descrizione |
| --- | --- |
| TBuilder | Il tipo del costruttore di elementi SVG. |
| costruttore | Il builder dell'elemento SVG a cui viene applicato l'attributo. |
| metodo | Il metodo di diffusione per il gradiente (pad, reflect o repeat). |

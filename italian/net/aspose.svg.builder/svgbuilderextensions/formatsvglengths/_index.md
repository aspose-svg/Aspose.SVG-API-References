## SVGBuilderExtensions.FormatSvgLengths method

Formatta un array di valori double in una rappresentazione stringa delle lunghezze SVG.

```csharp
public static string FormatSvgLengths(double[] values, LengthType type)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| valori | Double[] | L'array di valori double che rappresentano le lunghezze. |
| tipo | LengthType | Il tipo di unità di lunghezza da utilizzare (ad es., pixel). |

### Valore di ritorno

Una stringa formattata di lunghezze SVG.

## Osservazioni

Questo metodo di utilità è usato per formattare i valori di lunghezza per gli attributi SVG, aggiungendo l'unità appropriata (come 'px') a ciascun valore.

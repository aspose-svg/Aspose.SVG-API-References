## AlignmentBaseline enumeration

Specifica la linea di base di allineamento per il testo e altri contenuti in linea in SVG.

```csharp
public enum AlignmentBaseline
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Baseline | `0` | Allinea la linea di base della casella con la linea di base della casella padre. |
| TextBottom | `1` | Allinea il fondo della casella con il fondo dell'area di contenuto del padre. |
| Middle | `2` | Allinea il centro della casella con il centro dell'area di contenuto del padre. |
| Central | `3` | Allinea la linea di base centrale della casella con la linea di base centrale della casella padre. |
| TextTop | `4` | Allinea la parte superiore della casella con la parte superiore dell'area di contenuto del padre. |
| Ideographic | `5` | Allinea la linea di base ideografica della casella con la linea di base ideografica del padre. |
| Alphabetic | `6` | Allinea la linea di base alfabetica della casella con la linea di base alfabetica del padre. |
| Mathematical | `7` | Allinea la linea di base matematica della casella con la linea di base matematica del padre. |

## Osservazioni

La proprietà 'alignment-baseline' è definita nella specifica CSS Line Layout Module 3. SVG 2 introduce modifiche alla definizione di questa proprietà.

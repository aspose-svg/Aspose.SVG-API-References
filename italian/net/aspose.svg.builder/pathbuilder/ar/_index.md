## PathBuilder.Ar method

Aggiunge un comando 'Elliptical Arc Curve' relativo ai dati del percorso.

```csharp
public PathBuilder Ar(double r1, double r2, double angle, bool largeArcFlag, bool sweepFlag, 
    double x, double y)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| r1 | Double | Il raggio x dell'ellisse, relativo alla posizione corrente. |
| r2 | Double | Il raggio y dell'ellisse, relativo alla posizione corrente. |
| angle | Double | L'angolo di rotazione dell'ellisse in gradi, relativo alla posizione corrente. |
| largeArcFlag | Boolean | Flag che indica se l'arco deve essere maggiore o uguale a 180 gradi. |
| sweepFlag | Boolean | Flag che indica se l'arco deve essere disegnato in una direzione di angolo positivo. |
| x | Double | La coordinata x del punto finale dell'arco, relativo alla posizione corrente. |
| y | Double | La coordinata y del punto finale dell'arco, relativo alla posizione corrente. |

L'istanza corrente di PathBuilder.

## SVGGElementBuilder class

Classe Builder per costruire un elemento SVG 'g' (gruppo). L'elemento 'g' è usato per raggruppare forme SVG insieme. Il raggruppamento degli elementi consente una manipolazione e uno stile più facili di più elementi come un'unica unità nella grafica SVG.

public class SVGGElementBuilder : SVGElementBuilder<SVGGElement>, ICompositeAttributeSetter,

## Kerning enumeration

Specifica il comportamento del kerning per il testo in SVG.

```csharp
public enum Kerning
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Auto | `0` | Consente al browser di determinare se il kerning deve essere applicato. |
| Normal | `1` | Applica il kerning standard, come definito nel file del font. |
| None | `2` | Disabilita il kerning, ignorando qualsiasi informazione di kerning nel font. |

## Osservazioni

La proprietà 'font-kerning' in SVG controlla l'uso delle informazioni di kerning memorizzate in un font. Il kerning regola lo spazio tra coppie di lettere individuali per migliorare l'aspetto visivo del testo. Questo enum fornisce opzioni per controllare il comportamento del kerning negli elementi di testo SVG.

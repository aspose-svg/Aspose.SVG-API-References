## EdgeMode enumeration

Specifica la modalità di bordo per la primitiva di filtro feConvolveMatrix in SVG.

```csharp
public enum EdgeMode
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Duplicate | `0` | L'immagine di input viene estesa lungo ciascuno dei suoi bordi, se necessario, duplicando i valori di colore al bordo specificato dell'immagine di input. |
| Wrap | `1` | L'immagine di input è concettualmente avvolta (o tassellata) e la convoluzione utilizza questi valori avvolti. Questo crea una topologia toroidale per l'immagine. |
| None | `2` | La modalità del bordo non è definita e l'effetto del filtro è determinato dall'implementazione. |

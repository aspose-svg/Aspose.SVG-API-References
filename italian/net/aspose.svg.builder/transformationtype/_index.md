### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Translate | `0` | Trasla (sposta) un elemento di una certa distanza. |
| Scale | `1` | Scala un elemento aumentando o diminuendo le dimensioni. |
| Rotate | `2` | Ruota un elemento attorno a un punto specificato. |

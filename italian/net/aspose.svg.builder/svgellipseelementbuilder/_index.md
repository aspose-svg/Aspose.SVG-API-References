## SVGEllipseElementBuilder class

Classe Builder per la costruzione di un elemento SVG 'ellipse', utilizzato per disegnare ellissi all'interno della grafica SVG. Consente la creazione di contenuti all'interno dell'elemento 'ellipse' e fornisce metodi per impostare vari attributi specifici dell'elemento 'ellipse' in SVG.

```csharp
public class SVGEllipseElementBuilder : SVGElementBuilder<SVGEllipseElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IShapeAttributeSetter, IShapeContentElementBuilder
```

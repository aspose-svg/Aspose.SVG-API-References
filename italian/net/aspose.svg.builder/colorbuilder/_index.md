## ColorBuilder class

Una classe builder per la costruzione di valori di colore in vari formati. Questa classe fornisce metodi per impostare i valori di colore e generarli in rappresentazioni stringa che possono essere utilizzate nei contesti di stile, come attributi CSS o SVG.

public class ColorBuilder

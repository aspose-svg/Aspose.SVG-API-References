## Restart enumeration

Specifica il comportamento di riavvio per le animazioni SVG.

```csharp
public enum Restart
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Always | `0` | L'animazione può essere riavviata in qualsiasi momento, anche se è attualmente attiva. |
| WhenNotActive | `1` | L'animazione può essere riavviata solo quando non è attualmente attiva. |
| Never | `2` | L'animazione non può essere riavviata una volta iniziata; continuerà fino al completamento. |

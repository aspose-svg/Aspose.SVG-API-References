## SVGAElementBuilder class

Classe builder per la costruzione di un elemento SVG 'a', utilizzato per definire collegamenti ipertestuali. Consente la creazione di contenuti all'interno dell'elemento 'a' e fornisce metodi per impostare vari attributi specifici dell'elemento 'a' in SVG.

```csharp
public class SVGAElementBuilder : SVGElementBuilder<SVGAElement>, ICompositeAttributeSetter, 
    ICompositeElementBuilder
```

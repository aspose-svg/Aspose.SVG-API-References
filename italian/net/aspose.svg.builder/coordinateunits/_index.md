## CoordinateUnits enumeration

Specifica le unità del sistema di coordinate per vari elementi SVG come maschere, server di pittura e filtri.

```csharp
public enum CoordinateUnits
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| UserSpaceOnUse | `0` | Utilizza il sistema di coordinate dell'utente per l'elemento SVG. |
| ObjectBoundingBox | `1` | Utilizza il riquadro di delimitazione (bounding box) dell'oggetto per l'elemento SVG. |

## Osservazioni

Le unità di coordinate determinano come i valori sono interpretati in diversi contesti SVG. Possono essere impostate per utilizzare le coordinate dello spazio utente o per essere relative al riquadro di delimitazione dell'oggetto.

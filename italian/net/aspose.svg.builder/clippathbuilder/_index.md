## ClipPathBuilder class

Una classe builder per la costruzione di valori CSS clip-path. Questa classe fornisce metodi per definire clip path utilizzando forme di base, riferimenti esterni o geometry box. Consente la creazione di percorsi di ritaglio complessi in modo strutturato e leggibile.

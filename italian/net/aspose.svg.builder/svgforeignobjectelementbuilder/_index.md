## SVGForeignObjectElementBuilder class

Classe Builder per costruire un elemento SVG 'foreignObject', che consente l'inclusione di contenuti esterni in un documento SVG. Questo elemento può contenere vari tipi di contenuto, come HTML e XHTML, permettendo rappresentazioni grafiche più complesse all'interno di SVG.

```csharp
public class SVGForeignObjectElementBuilder : SVGElementBuilder<SVGForeignObjectElement>, 
    ICompositeAttributeSetter, IRectAttributeSetter, ITextContentSetter
```

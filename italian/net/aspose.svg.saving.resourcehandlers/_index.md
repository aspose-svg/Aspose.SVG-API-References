Il namespace **Aspose.Svg.Saving.ResourceHandlers** contiene classi responsabili della gestione delle risorse.

## Classi

| Classe | Descrizione |
| --- | --- |
| [FileSystemResourceHandler](./filesystemresourcehandler/) | Questa classe è un'implementazione della classe [`ResourceHandler`](../aspose.svg.saving.resourcehandlers/resourcehandler/) progettata per salvare le risorse sul file system locale. |
| [ResourceHandler](./resourcehandler/) | Questa classe è responsabile della gestione delle risorse. Fornisce metodi che consentono di controllare cosa verrà fatto con il [`Resource`](../aspose.svg.saving/resource/), così come quale riferimento sarà scritto nella risorsa padre [`Resource`](../aspose.svg.saving/resource/). |

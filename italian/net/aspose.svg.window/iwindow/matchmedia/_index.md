## IWindow.MatchMedia method

Restituisce un nuovo oggetto MediaQueryList che può quindi essere usato per determinare se il documento corrisponde alla stringa di media query, così come per monitorare il documento per rilevare quando corrisponde (o smette di corrispondere) a quella media query. Vedi la specifica del modulo CSSOM View: [https://www.w3.org/TR/cssom-view/#extensions-to-the-window-interface](https://www.w3.org/TR/cssom-view/#extensions-to-the-window-interface)

```csharp
public MediaQueryList MatchMedia(string query)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| query | String | La stringa contenente una media query; vedi [https://drafts.csswg.org/mediaqueries/](https://drafts.csswg.org/mediaqueries/) per i dettagli. |

## IWindow.MatchMedia method

Mengembalikan objek MediaQueryList baru yang kemudian dapat digunakan untuk menentukan apakah dokumen cocok dengan string kueri media, serta untuk memantau dokumen guna mendeteksi kapan ia cocok (atau tidak lagi cocok) dengan kueri media tersebut. Lihat spesifikasi CSSOM View Module: [https://www.w3.org/TR/cssom-view/#extensions-to-the-window-interface](https://www.w3.org/TR/cssom-view/#extensions-to-the-window-interface)

```csharp
public MediaQueryList MatchMedia(string query)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| query | String | String yang berisi kueri media; lihat [https://drafts.csswg.org/mediaqueries/](https://drafts.csswg.org/mediaqueries/) untuk detail. |

## ToggleAttribute(*string*) {#toggleattribute}

Jika force tidak diberikan, \"men-toggle\" qualifiedName, menghapusnya jika ada dan menambahkannya jika tidak ada. Jika force true, menambah qualifiedName. Jika force false, menghapus qualifiedName.

```csharp
public bool ToggleAttribute(string qualifiedName)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| qualifiedName | String | QualifiedName atribut. |

### Nilai Kembalian

Mengembalikan true jika qualifiedName sekarang ada; jika tidak false.

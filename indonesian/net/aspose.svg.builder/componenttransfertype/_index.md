## ComponentTransferType enumeration

Menentukan jenis fungsi transfer komponen yang akan diterapkan dalam primitif filter FeComponentTransfer pada SVG.

```csharp
public enum ComponentTransferType
```

### Nilai-nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Identity | `0` | Mewakili tidak ada perubahan pada grafik input. Ini adalah tipe default. |
| Table | `1` | Menggunakan tabel pencarian untuk mendefinisikan fungsi dalam filter. |
| Discrete | `2` | Menggunakan sekumpulan nilai diskrit untuk mendefinisikan fungsi dalam filter. |
| Linear | `3` | Mendefinisikan transformasi linear komponen dalam filter. |
| Gamma | `4` | Mendefinisikan transformasi koreksi gamma dalam filter. |

## Catatan

Primitif filter FeComponentTransfer memungkinkan manipulasi individual komponen warna (RGB dan alfa) dari elemen grafis menggunakan berbagai jenis fungsi transfer. Setiap jenis mendefinisikan metode perhitungan yang berbeda untuk transformasi komponen warna dalam filter.

## PathBuilder.Ar method

Menambahkan perintah 'Elliptical Arc Curve' relatif ke data jalur.

```csharp
public PathBuilder Ar(double r1, double r2, double angle, bool largeArcFlag, bool sweepFlag, 
    double x, double y)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| r1 | Double | Radius x dari elips, relatif terhadap posisi saat ini. |
| r2 | Double | Radius y dari elips, relatif terhadap posisi saat ini. |
| angle | Double | Sudut rotasi elips dalam derajat, relatif terhadap posisi saat ini. |
| largeArcFlag | Boolean | Bendera yang menunjukkan apakah busur harus lebih besar dari atau sama dengan 180 derajat. |
| sweepFlag | Boolean | Bendera yang menunjukkan apakah busur harus digambar dalam arah sudut positif. |
| x | Double | Koordinat x dari titik akhir busur, relatif terhadap posisi saat ini. |
| y | Double | Koordinat y dari titik akhir busur, relatif terhadap posisi saat ini. |

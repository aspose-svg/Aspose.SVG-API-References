## IAttributeSetter.Attribute method

Mengatur atau memperbarui sebuah atribut pada elemen SVG.

```csharp
public void Attribute(string name, string value)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| nama | String | Nama atribut yang akan diatur. Ini harus berupa nama atribut SVG yang valid. |
| nilai | String | Nilai yang akan diberikan ke atribut. Nilai harus berupa representasi string yang cocok untuk atribut SVG tertentu. |

## Catatan

Metode ini digunakan untuk secara dinamis menambah atau memodifikasi atribut elemen SVG selama proses konstruksi. Metode ini memberikan fleksibilitas dalam mendefinisikan dan menyesuaikan elemen SVG dengan memungkinkan atribut diatur berdasarkan berbagai kondisi atau masukan.

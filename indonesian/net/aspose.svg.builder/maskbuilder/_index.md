## MaskBuilder class

Kelas builder untuk membuat properti mask CSS. Kelas ini memungkinkan pembuatan gaya mask yang kompleks menggunakan berbagai properti seperti sumber mask, posisi, ukuran, gaya pengulangan, dan lainnya. String yang dihasilkan dapat digunakan dalam CSS untuk mendefinisikan perilaku masking sebuah elemen.

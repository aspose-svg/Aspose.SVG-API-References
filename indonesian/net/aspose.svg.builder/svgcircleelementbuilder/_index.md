## SVGCircleElementBuilder class

Kelas builder untuk membangun elemen SVG 'circle', yang digunakan untuk menggambar lingkaran dalam grafik SVG. Ini memungkinkan pembuatan konten di dalam elemen 'circle' dan menyediakan metode untuk mengatur berbagai atribut khusus elemen 'circle' dalam SVG.

```csharp
public class SVGCircleElementBuilder : SVGElementBuilder<SVGCircleElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IShapeAttributeSetter, IShapeContentElementBuilder
```

## AngleUnits enumeration

Menentukan satuan untuk sudut yang digunakan dalam mendefinisikan orientasi penanda dalam SVG.

```csharp
public enum AngleUnits
```

### Nilai-nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Degrees | `0` | Menentukan sudut dalam derajat. Satu lingkaran penuh adalah 360 derajat. |
| Gradians | `1` | Menentukan sudut dalam gradian. Satu lingkaran penuh adalah 400 gradian. |
| Radians | `2` | Menentukan sudut dalam radian. Satu lingkaran penuh kira-kira 6,283 radian (2π radian). |
| None | `3` | Menunjukkan tidak ada satuan sudut khusus. Digunakan untuk pengaturan default atau berbasis konteks. |

## Catatan

Atribut 'orient' pada penanda SVG dapat ditentukan dalam berbagai satuan sudut. Enum ini menyediakan opsi untuk mengatur satuan tersebut.

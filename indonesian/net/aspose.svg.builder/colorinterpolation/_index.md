## ColorInterpolation enumeration

Menentukan mode interpolasi warna untuk elemen SVG dan filter.

```csharp
public enum ColorInterpolation
```

### Nilai-nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Auto | `0` | Menentukan mode interpolasi warna secara otomatis. |
| SRGB | `1` | Menggunakan ruang warna RGB standar (sRGB) untuk interpolasi warna. |
| LinearRGB | `2` | Menggunakan ruang warna RGB linear untuk interpolasi warna. |

## Catatan

Interpolasi warna dalam SVG memengaruhi cara warna dihitung dan dicampur pada elemen grafis maupun efek filter. Mode yang berbeda dapat secara signifikan memengaruhi tampilan transisi warna, gradien, dan render warna secara keseluruhan. Pengaturan ini penting untuk mencapai hasil visual yang diinginkan dalam grafik SVG.

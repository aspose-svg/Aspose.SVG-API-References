## Kerning enumeration

Menentukan perilaku kerning untuk teks dalam SVG.

```csharp
public enum Kerning
```

### Nilai-nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Auto | `0` | Mengizinkan peramban menentukan apakah kerning harus diterapkan. |
| Normal | `1` | Menerapkan kerning standar, sebagaimana didefinisikan dalam berkas font. |
| None | `2` | Menonaktifkan kerning, mengabaikan semua informasi kerning dalam font. |

## Catatan

Properti 'font-kerning' dalam SVG mengontrol penggunaan informasi kerning yang disimpan dalam font. Kerning menyesuaikan ruang antara pasangan huruf individu untuk meningkatkan tampilan visual teks. Enum ini menyediakan opsi untuk mengendalikan perilaku kerning pada elemen teks SVG.

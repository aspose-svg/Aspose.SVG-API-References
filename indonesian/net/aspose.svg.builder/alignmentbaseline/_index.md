## AlignmentBaseline enumeration

Menentukan garis dasar perataan untuk teks dan konten sebaris lainnya dalam SVG.

```csharp
public enum AlignmentBaseline
```

### Nilai-nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Baseline | `0` | Menyelaraskan baseline kotak dengan baseline kotak induk. |
| TextBottom | `1` | Menyelaraskan bagian bawah kotak dengan bagian bawah area konten induk. |
| Middle | `2` | Menyelaraskan tengah kotak dengan tengah area konten induk. |
| Central | `3` | Menyelaraskan garis dasar pusat kotak dengan garis dasar pusat kotak induk. |
| TextTop | `4` | Menyelaraskan bagian atas kotak dengan bagian atas area konten induk. |
| Ideographic | `5` | Menyelaraskan garis dasar ideografis kotak dengan garis dasar ideografis induk. |
| Alphabetic | `6` | Menyelaraskan garis dasar alfabetik kotak dengan garis dasar alfabetik induk. |
| Mathematical | `7` | Menyelaraskan garis dasar matematis kotak dengan garis dasar matematis induk. |

## Catatan

Properti 'alignment-baseline' didefinisikan dalam spesifikasi CSS Line Layout Module 3. SVG 2 memperkenalkan perubahan pada definisi properti ini.

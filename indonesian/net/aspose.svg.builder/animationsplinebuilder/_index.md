## AnimationSplineBuilder class

Kelas builder untuk membuat fungsi timing animasi menggunakan kurva Bézier kubik. Kelas ini memungkinkan definisi satu atau lebih kurva Bézier kubik, masing-masing ditentukan oleh dua titik kontrol. String yang dihasilkan dapat digunakan dalam animasi CSS atau transisi untuk mengontrol kecepatan animasi.

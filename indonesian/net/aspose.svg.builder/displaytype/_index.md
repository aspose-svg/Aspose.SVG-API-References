## DisplayType enumeration

Menentukan perilaku tampilan elemen dalam dokumen SVG.

```csharp
public enum DisplayType
```

### Nilai-nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Inline | `0` | Elemen ini menghasilkan satu atau lebih kotak inline. |
| Block | `1` | Elemen ini menghasilkan sebuah kotak blok. |
| ListItem | `2` | Elemen ini menghasilkan kotak blok untuk konten dan kotak inline list-item terpisah. |
| InlineBlock | `3` | Elemen ini menghasilkan kotak blok untuk konten dan kotak inline untuk kontainer. |
| Table | `4` | Elemen ini berperilaku seperti elemen tabel. |
| InlineTable | `5` | Elemen ini berperilaku seperti tabel inline. |
| TableRowGroup | `6` | Elemen ini berperilaku seperti grup baris tabel. |
| TableHeaderGroup | `7` | Elemen ini berperilaku seperti grup header tabel. |
| TableFooterGroup | `8` | Elemen ini berperilaku seperti grup footer tabel. |
| TableRow | `9` | Elemen ini berperilaku seperti baris tabel. |
| TableColumnGroup | `10` | Elemen ini berperilaku seperti grup kolom tabel. |
| TableColumn | `11` | Elemen ini berperilaku seperti kolom tabel. |
| TableCell | `12` | Elemen ini berperilaku seperti sel tabel. |
| TableCaption | `13` | Elemen ini berperilaku seperti keterangan tabel. |
| None | `14` | Elemen ini tidak menghasilkan kotak apa pun dan tidak dirender. Itu tidak memengaruhi tata letak. |
| Flex | `15` | Elemen ini berperilaku seperti kontainer flex. |
| InlineFlex | `16` | Elemen ini berperilaku seperti kontainer flex inline. |
| Grid | `17` | Elemen ini berperilaku seperti kontainer grid. |
| InlineGrid | `18` | Elemen ini berperilaku seperti kontainer grid inline. |

## Catatan

Properti 'display' dalam SVG dan CSS menentukan bagaimana sebuah elemen ditampilkan dalam tata letak dokumen. Enumerasi ini menyediakan berbagai opsi untuk mengatur tipe tampilan, memengaruhi cara elemen dirender dan berinteraksi dengan tata letak.

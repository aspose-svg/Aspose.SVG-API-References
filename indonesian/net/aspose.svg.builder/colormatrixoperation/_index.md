## ColorMatrixOperation enumeration

Menentukan jenis operasi yang akan diterapkan dalam filter matriks warna.

```csharp
public enum ColorMatrixOperation
```

### Nilai-nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Matrix | `0` | Menerapkan transformasi matriks pada data warna. |
| Saturate | `1` | Menyesuaikan tingkat saturasi gambar. |
| HueRotate | `2` | Menerapkan rotasi hue pada gambar. |
| LuminanceToAlpha | `3` | Mengonversi warna gambar menjadi skala abu-abu berdasarkan luminansinya. |

## Catatan

Filter matriks warna dalam SVG memungkinkan berbagai operasi pada data warna sebuah gambar. Setiap jenis operasi memanipulasi warna dengan cara tertentu, menawarkan beragam efek visual.

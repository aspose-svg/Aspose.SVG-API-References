## ColorRendering enumeration

Menentukan mode rendering warna untuk elemen SVG.

```csharp
public enum ColorRendering
```

### Nilai-nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Auto | `0` | Mengizinkan peramban atau penampil untuk memilih mode rendering warna, menyeimbangkan antara kecepatan dan kualitas. |
| OptimizeSpeed | `1` | Memprioritaskan kecepatan rendering dibandingkan presisi warna dan kualitas visual. |
| OptimizeQuality | `2` | Memprioritaskan akurasi warna dan kualitas visual dibandingkan kecepatan rendering. |

## Catatan

Properti ini menentukan bagaimana warna dirender, terutama saat menangani gradien warna, pola, dan rendering gambar. Mode yang berbeda dapat memengaruhi kinerja dan kualitas proses rendering warna.

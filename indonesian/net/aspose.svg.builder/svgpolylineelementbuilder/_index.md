## SVGPolylineElementBuilder class

Kelas builder untuk membuat elemen SVG 'polyline'. Elemen 'polyline' digunakan untuk membuat serangkaian garis lurus yang menghubungkan beberapa titik dalam grafik SVG. Kelas ini menyediakan metode untuk mengatur berbagai atribut dan menganimasikan elemen polyline.

```csharp
public class SVGPolylineElementBuilder : SVGElementBuilder<SVGPolylineElement>, 
    IAnimationElementBuilder, IDescriptiveElementBuilder, IPaintServerElementBuilder, 
    IPointsAttributeSetter, IShapeAttributeSetter, IShapeContentElementBuilder
```

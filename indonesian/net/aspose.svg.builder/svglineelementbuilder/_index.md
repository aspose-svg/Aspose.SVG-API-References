## SVGLineElementBuilder class

Kelas Builder untuk membangun elemen SVG 'line', yang digunakan untuk menggambar garis lurus dalam grafik SVG. Kelas ini memungkinkan pembuatan konten dalam elemen 'line' dan menyediakan metode untuk mengatur berbagai atribut khusus elemen 'line' dalam SVG.

```csharp
public class SVGLineElementBuilder : SVGElementBuilder<SVGLineElement>, IAnimationElementBuilder,
```

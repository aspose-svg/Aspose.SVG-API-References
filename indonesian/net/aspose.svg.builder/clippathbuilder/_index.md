## ClipPathBuilder class

Kelas builder untuk membuat nilai CSS clip-path. Kelas ini menyediakan metode untuk mendefinisikan clip path menggunakan bentuk dasar, referensi eksternal, atau kotak geometri. Ini memungkinkan pembuatan jalur pemotongan yang kompleks secara terstruktur dan mudah dibaca.

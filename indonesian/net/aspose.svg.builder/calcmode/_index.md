## CalcMode enumeration

Menentukan mode perhitungan untuk menginterpolasi nilai dalam animasi SVG.

```csharp
public enum CalcMode
```

### Nilai-nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Discrete | `0` | Animasi melompat dari satu nilai ke nilai berikutnya tanpa interpolasi apa pun. |
| Linear | `1` | Nilai animasi diinterpolasi secara linier sepanjang durasi animasi. |
| Paced | `2` | Animasi dipercepat sehingga kemajuan merata di seluruh animasi. |
| Spline | `3` | Animasi menggunakan spline Bézier kubik untuk menginterpolasi nilai. |

## Catatan

Mode perhitungan menentukan bagaimana animasi SVG bertransisi antar nilai selama animasi. Berbagai mode dapat digunakan untuk menciptakan efek yang berbeda dan mengontrol kecepatan serta kelancaran animasi.

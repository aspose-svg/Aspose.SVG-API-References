## SVGAElementBuilder class

Kelas builder untuk membuat elemen SVG 'a', yang digunakan untuk mendefinisikan hyperlink. Ini memungkinkan pembuatan konten di dalam elemen 'a' dan menyediakan metode untuk mengatur berbagai atribut khusus elemen 'a' dalam SVG.

public class SVGAElementBuilder : SVGElementBuilder<SVGAElement>, ICompositeAttributeSetter,

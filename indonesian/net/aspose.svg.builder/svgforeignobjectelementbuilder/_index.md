## SVGForeignObjectElementBuilder class

Kelas Builder untuk membangun elemen SVG 'foreignObject', yang memungkinkan penyertaan konten eksternal dalam dokumen SVG. Elemen ini dapat berisi berbagai jenis konten, seperti HTML dan XHTML, memungkinkan representasi grafis yang lebih kompleks dalam SVG.

```csharp
public class SVGForeignObjectElementBuilder : SVGElementBuilder<SVGForeignObjectElement>,
```

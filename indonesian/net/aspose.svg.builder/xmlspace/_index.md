## XmlSpace enumeration

Menentukan bagaimana spasi putih di dalam elemen ditangani dalam dokumen XML.

```csharp
public enum XmlSpace
```

### Nilai-nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Default | `0` | Menunjukkan bahwa spasi putih harus ditangani sesuai dengan perilaku default pemroses XML, biasanya dengan menormalkan spasi putih melalui penghapusan jeda baris dan spasi tambahan. |
| Preserve | `1` | Menunjukkan bahwa spasi putih harus dipertahankan sebagaimana muncul dalam dokumen XML. Ini berguna untuk menjaga format teks di mana spasi putih penting. |

## Catatan

Atribut 'xml:space' dalam XML digunakan untuk mengontrol apakah spasi putih di dalam elemen harus dipertahankan atau dinormalisasi. Enumerasi ini menyediakan opsi untuk mengatur perilaku ini dalam dokumen XML dan SVG.
